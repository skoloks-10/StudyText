# 📡 네트워크 기초 복습자료

## 02-2. NIC와 케이블

### 🔌 NIC (Network Interface Card)란?

**NIC는 컴퓨터를 네트워크에 연결하기 위한 하드웨어 장치**입니다.

#### 언제 필요한가?

- 컴퓨터를 LAN에 연결할 때
- 네트워크 통신을 하려고 할 때
- 유선/무선 네트워크 접속이 필요할 때

#### 주요 특징

- **트위스티드 페어 케이블**과 **광섬유 케이블** 모두 연결 가능
- 케이블과 NIC의 규격이 일치해야 함
- 과거에는 별도 장착, 현재는 **메인보드에 내장**됨
- 호스트를 네트워크에 연결하는 관문 역할

#### NIC의 생김새

다양한 형태로 존재:

- 네트워크 인터페이스 카드 (확장 카드 형태)
- 네트워크 어댑터
- LAN 카드
- 네트워크 카드
- 이더넷 카드 (이더넷 네트워크용)

> 💡 **참고**: 확장 카드(Expansion card)는 컴퓨터의 기능을 추가할 목적으로 메인보드에 꽂는 카드 형태의 기판입니다.

---

### 🔗 트위스티드 페어 케이블

#### 언제 사용하는가?

- 일반적인 유선 네트워크 연결
- 호스트와 네트워크를 연결할 때
- 정확한 순서로 배선해야 할 때

#### 생김새와 구조

트위스티드 페어 케이블은 **케이블과 커넥터**로 이루어져 있습니다.

**커넥터 종류:**

- 토퍼스티드: 랜에서 쓰이는 커넥터
- 잭/플러그: 일반 명칭

**케이블 내부:**
8개의 선이 **두 개씩 꼬여있는** 형태 (총 4쌍)

> ⚠️ **중요**: 트위스티드 페어 케이블의 순서는 정해진 규칙대로 연결해야 합니다. 노이즈를 감소시키기 위해 구리선을 꼬아놓은 것입니다.

#### 트위스티드 페어 케이블의 생김새

**커넥터 연결:**

- RJ-45라고 부름
- 먼저 커넥터를 삽입한 뒤 연결
- 실제로는 8개의 선이 각자의 위치에 정확히 연결됨

**케이블 배선 순서:**
브레이드/실드에 따라 선의 순서가 달라질 수 있지만, 기본적으로 정해진 배선 기준을 따라야 합니다.

---

### 🔍 실드에 따른 트위스티드 페어 케이블 분류

#### UTP (Unshielded Twisted Pair)

- **실드 없음** (차폐 없음)
- 가장 일반적으로 사용
- 외부 전기/자기 간섭에 민감

#### 종류별 특징

**XX/YTP 표기법:**

- **U**: 실드 없음
- **S**: 브레이드 실드
- **F**: 포일 실드

**XX**는 케이블 외부부분 감싸는 실드의 종류를 나타내며, 하나 혹은 두 개가 있을 수 있습니다.  
**Y**에는 각각 구리 선 쌍을 감싸는 실드의 종류가 나타납니다.

#### 대표적인 케이블 종류

**S/FTP 케이블:**

- 케이블 외부와 각 구리 선 쌍을 브레이드 실드로 보호
- 꼬인 각 구리 선 쌍을 포일 실드로 감싼 케이블

**F/FTP 케이블:**

- 케이블 외부와 각 구리 선 쌍을 모두 포일 실드로 감싼 케이블

**SF/FTP 케이블:**

- 케이블 외부는 브레이드 실드와 포일 실드로 감쌈
- 각 구리 선 쌍은 포일 실드로 감싼 케이블

**U/UTP 케이블:**

- 아무것도 감싸지 않은 케이블

---

### 🌐 광섬유 케이블

#### 언제 사용하는가?

- 먼 거리의 데이터 전송
- 빠른 전송 속도가 필요할 때
- 전자기 간섭에 영향받지 않아야 할 때

#### 광섬유 케이블의 생김새

빛을 이용해 데이터를 전송합니다.

**단일 모드 광섬유 케이블:**

- 코어의 지름이 8~10μm 정도
- 먼 거리 전송에 적합
- 50~100μm 정도의 범위

**멀티 모드 광섬유 케이블:**

- 코어의 지름이 50~62.5μm 정도
- 비교적 가까운 거리 전송

#### 구조

- **코어**: 빛을 전달하는 중심부
- **클래딩**: 코어를 감싸고 빛의 반사를 돕는 부분

> 💡 μm는 길이의 단위로, 마이크로미터라고 읽습니다.

**광섬유 케이블의 빛 전달:**
코어의 지름이 작다면 빛이 아무곳에나 반사되지 않고 직진합니다. 다시 말해, 코어의 지름이 작다면 빛이 이동할 경로가 하나라고 표현합니다.

**단일 모드 vs 멀티 모드:**

- 단일 모드: 빛이 이동할 경로가 적음 → 먼 거리 전송 가능
- 멀티 모드: 빛이 여러 각도로 반사 → 가까운 거리 전송

---

### 🔌 광섬유 커넥터 종류

트위스티드 페어 케이블이 RJ-45라는 커넥터를 사용하듯, 광섬유 케이블도 다양한 커넥터가 있습니다.

**대표적인 커넥터:**

- **LC 커넥터**
- **SC 커넥터**
- **FC 커넥터**
- **ST 커넥터**

> 광섬유 케이블 본체 내부는 머리 이마리카락과 같은 형태의 광섬유로 구성되어 있습니다.

---

### 🔀 광섬유 색상 구분

광섬유 케이블은 색상으로 구분할 수 있습니다.

#### 핵심 원리

색상과 코어의 지름 정보가 일치해야 정확하게 연결됩니다.

**중요한 점:**

- 코어의 지름이 작다면 빛이 아무데나 반사되지 않음
- 지름이 크면 빛이 여러 방향으로 반사
- 이동 모드로 '모드'라는 용어가 표현됨

---

## 02-3. 허브 (Hub)

### 🔄 허브의 역할

**허브는 여러 대의 호스트를 연결하는 네트워크 장비**입니다.

#### 언제 사용하는가?

- 다수의 컴퓨터를 네트워크에 연결할 때
- 중앙 집중식 네트워크 구성
- 신호를 증폭하고 재전송해야 할 때

#### 동작 방식

- 물리 계층에서 동작
- **단순 반복 장치** 역할
- 데이터 링크 계층, 네트워크 계층은 존재하지 않음
- 특정 호스트에게만 전달하는 것이 불가능

---

### ⚙️ 주소 개념이 없는 물리 계층

물리 계층에서는 호스트를 송수신하는 역할을 수행합니다.

**계층 구조:**

- **응용 계층**
- **표현 계층**
- **세션 계층**
- **전송 계층**
- **네트워크 계층**
- **데이터 링크 계층**
- **물리 계층** ← 허브가 여기서 동작
- **호스트**

#### 허브의 특징

- 허브는 여러 대의 호스트를 연결하는 **리피터(repeater)**
- 리피터는 약해진 신호를 증폭시키는 역할
- 호스트를 연결하는 리피터의 역할만 수행

> 💡 **포트(port)**: 허브에는 다른 장비와 연결하는 연결구가 4개 정도 있으며, 04~1을 참고하세요.

---

### 🏗️ 허브의 특징

#### 브로드캐스트 문제

허브에 연결된 모든 호스트에게 신호를 전달합니다.

**문제점:**

- 충돌(collision)이 자주 발생
- 전체 네트워크의 성능 저하
- 동시에 둘 이상의 호스트가 통신 시도 시 충돌 발생

#### 한계

- 첫째, 전달받은 신호를 다른 모든 포트로 그대로 다시 내보냄
- 허브에 부착된 각각의 장치는 같이 보내면 안됨
- 따라서 효율이 떨어지고, 이를 해결하기 위해 프로토콜인 **CSMA/CD**를 사용

---

### 🔁 물리층, 반이중 통신

#### 반이중(Half duplex)과 전이중(Full duplex)

**반이중 모드:**

- 송수신을 동시에 할 수 없음
- 한 번에 한 방향으로만 통신 가능

**전이중 모드:**

- 양방향 동시 통신 가능
- 1대1 직접 연결에서 가능

> ⚠️ **주의**: 반이중 모드는 동시에 통신하려고 하면 신호 충돌이 일어날 수 있습니다. 이를 방지하기 위해 한 번에 한쪽만 통신해야 합니다.

**리피터:**

- 이더넷을 전기 신호로 받아 감쇠시킨 전기 신호를 증폭하는 역할을 하는 장비입니다.
- 리피터는 이더넷 장치간 신호의 감쇠를 보완하고 먼 거리 전송을 가능하게 합니다.

---

### ⚠️ 충돌 도메인 (Collision Domain)

**허브를 통해 연결된 호스트들이 만드는 영역**을 충돌 도메인이라고 합니다.

#### 충돌 도메인의 문제

- 충돌이 발생하면 모든 호스트가 영향을 받음
- 네트워크가 커질수록 충돌 가능성 증가

**해결 방법:**
충돌 도메인은 좁을수록 좋습니다. 이를 해결하기 위한 장비가 바로 **브리지**와 **스위치**입니다.

---

### 🌐 CSMA/CD (Carrier Sense Multiple Access with Collision Detection)

**허브에서 충돌이 발생하는 근본적인 이유는 허브가 반이중 모드로 통신하기 때문입니다.**

#### CSMA/CD의 동작 방식

예를 들어 A와 B가 동시에 허브에 신호를 송출하면 다른 그림과 같이 충돌이 발생합니다.

**프로토콜 동작:**

1. **Carrier Sense**: 네트워크 상태를 확인 (메시지가 전송 중인지 확인)
2. **Multiple Access**: 다중 접근 (여러 호스트가 네트워크 사용)
3. **Collision Detection**: 충돌 감지 후 재전송

> 💡 CSMA/CD는 허브 호스트가 공유하는 통신 방법입니다. 반이중이며 한 번에 한 호스트만 통신 가능하므로, 동시에 둘이 보내면 안 되기 때문입니다.

---

### 🎯 Carrier Sense

**첫째, CS는 Carrier Sense, 캐리어 감지를 의미합니다.**

CSMA/CD 프로토콜을 사용하는 반이중 네트워크에서는 메시지를 보내기 전에 신호를 전송 중인 호스트가 없는지 먼저 확인합니다.

**전송 중인 호스트 확인 절차:**

- 만약 전송 중이면 대기
- 전송 중이 아니면 신호 전송 시작

---

### 🚦 Multiple Access

**둘째, MA는 Multiple Access, 다중 접근을 의미합니다.**

패킷을 캐리어를 감지하는 것은 도움 두 개 이상의 호스트가 네트워크를 사용하기 위해 동시에 접근하면 이것을 감지하는 상황은 다음 접근이라 합니다. 이때 충돌이 발생합니다.

---

### 💥 Collision Detection

**셋째, CD는 Collision Detection, 충돌 검출을 의미합니다.**

충돌이 발생하면 이를 감지하는데, 이를 **충돌 검출(Collision Detection)**이라고 합니다.

**충돌 감지 시 동작:**

- 충돌을 감지하면 호스트는 다른 이전에게 충돌이 발생했다는 신호를 전달함
- 잘 전달된 신호를 제외시켜 다시 전송하되, 각 구리 선 쌍에 충돌이 발생했다면 임의의 시간만큼 대기 후 재전송

> ⚠️ **핵심**: CSMA/CD는 허브를 이용한 네트워크환경에서 충돌을 방지하고 효율적으로 통신하기 위한 프로토콜입니다.

---

## 🎯 최종 핵심 요약

### NIC (Network Interface Card)

- 컴퓨터를 네트워크에 연결하는 하드웨어
- 현재는 메인보드에 내장됨
- 케이블과 규격이 일치해야 함

### 트위스티드 페어 케이블

- 8개의 선이 2개씩 꼬여있는 구조 (4쌍)
- RJ-45 커넥터 사용
- UTP(차폐 없음)가 가장 일반적
- 실드 유무에 따라 S/FTP, F/FTP, SF/FTP, U/UTP로 구분

### 광섬유 케이블

- 빛을 이용한 데이터 전송
- 단일 모드: 코어 지름 8~10μm, 먼 거리 전송
- 멀티 모드: 코어 지름 50~62.5μm, 가까운 거리 전송
- LC, SC, FC, ST 커넥터 사용

### 허브 (Hub)

- 물리 계층에서 동작하는 단순 반복 장치
- 모든 포트로 신호를 브로드캐스트
- 반이중 통신만 가능
- 충돌 도메인 발생 → CSMA/CD 프로토콜로 해결
- CSMA/CD: Carrier Sense(신호 감지) + Multiple Access(다중 접근) + Collision Detection(충돌 검출)

## 📝 복습 퀴즈

### Q1. NIC에 대한 설명으로 옳지 않은 것은?

1. NIC는 Network Interface Card의 약자이다
2. 과거에는 별도로 장착했지만 현재는 메인보드에 내장되어 있다
3. 트위스티드 페어 케이블과만 연결 가능하다
4. LAN 카드, 네트워크 어댑터 등으로도 불린다
5. 호스트를 네트워크에 연결하는 관문 역할을 한다

**정답: 3번**  
NIC는 트위스티드 페어 케이블뿐만 아니라 광섬유 케이블과도 연결이 가능합니다. 다양한 네트워크 매체와 호환되도록 설계되어 있습니다.

---

### Q2. 트위스티드 페어 케이블의 RJ-45 커넥터에는 몇 개의 선이 연결되는가?

1. 4개
2. 6개
3. 8개
4. 10개
5. 12개

**정답: 3번**  
트위스티드 페어 케이블은 8개의 선이 2개씩 꼬여있는 구조로 총 4쌍을 이루며, RJ-45 커넥터에는 이 8개의 선이 모두 정해진 순서대로 연결됩니다.

---

### Q3. 다음 중 광섬유 케이블에 대한 설명으로 옳은 것은?

1. 전기 신호를 이용해 데이터를 전송한다
2. 단일 모드는 멀티 모드보다 코어의 지름이 크다
3. 단일 모드는 먼 거리 전송에 적합하다
4. 전자기 간섭에 취약하다
5. RJ-45 커넥터를 사용한다

**정답: 3번**

### Q4. 허브(Hub)에 대한 설명으로 옳지 않은 것은?

1. 물리 계층에서 동작한다
2. 특정 호스트에게만 선택적으로 신호를 전달할 수 있다
3. 리피터 역할을 수행한다
4. 모든 포트로 신호를 브로드캐스트한다

### Q5. CSMA/CD 프로토콜의 각 부분이 의미하는 것을 바르게 연결한 것은?

1. CS - 충돌 감지, MA - 다중 접근, CD - 캐리어 감지
2. CS - 캐리어 감지, MA - 다중 접근, CD - 충돌 검출
3. CS - 캐리어 전송, MA - 메시지 접근, CD - 충돌 방지
4. CS - 신호 제어, MA - 매체 접근, CD - 캐리어 검출

### Q6. 충돌 도메인(Collision Domain)에 대한 설명으로 옳은 것은?

1. 충돌 도메인은 넓을수록 좋다
2. 허브를 통해 연결된 호스트들이 만드는 영역이다
3. 스위치는 충돌 도메인을 확장시킨다
4. 전이중 통신 환경에서 발생한다
5. 충돌 도메인에서는 충돌이 절대 발생하지 않는다

**정답: 2번**  
충돌 도메인은 허브를 통해 연결된 호스트들이 만드는 영역으로, 한 호스트에서 충돌이 발생하면 도메인 내 모든 호스트가 영향을 받습니다. 충돌 도메인은 좁을수록 좋으며, 스위치나 브리지를 사용하면 충돌 도메인을 분리할 수 있습니다.
