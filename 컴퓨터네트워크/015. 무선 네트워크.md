## 1. 전파와 주파수 🌊

### 전파란?
- **전파(Radio Wave)**: 약 3kHz ~ 3THz 사이의 진동수를 가진 전자기파
- 눈에 보이지 않는 전자기파의 일종
- TV, 라디오, 무전기, 노트북, 스마트폰 등 무수한 기기가 전파를 이용해 통신

### 전파의 특징
- 인위적으로만 생성되는 것이 아니라 **자연적으로도 발생**
    - 번개, 태양 활동 등에서도 발생
    - 자연 전파가 통신에 사용하는 주파수 대역과 겹치면 **잡음(노이즈)** 발생
    - 예: 번개 칠 때 라디오에서 "지직" 소리 → 자연 전파 간섭

### 주파수 대역 분배
- 많은 기기가 동시에 전파로 통신하기 때문에 **서로 다른 신호를 구분**할 방법 필요
- 통신에 사용되는 전파에는 **주파수 대역**이 미리 정해져 있음
- 나라마다 주파수 대역 용도가 다름 (방송용, 위성 통신용, 항공/해양 통신용 등)

## 2. 와이파이와 802.11 📶

### 무선 LAN 표준
- 유선 LAN이 **IEEE 802.3**으로 표준화된 것처럼
- 무선 LAN은 **IEEE 802.11**로 표준화
    - 버전을 알파벳으로 표현: 802.11b, 802.11g, 802.11n, 802.11ac 등

### IEEE 802.11 주요 규격

| 표준 규격 | 주파수 대역 | 최대 전송 속도 |
|---|---|---|
| IEEE 802.11a | 5GHz | 54Mbps |
| IEEE 802.11g | 2.4GHz | 54Mbps |
| IEEE 802.11n | 2.4/5GHz | 450Mbps |
| IEEE 802.11ac | 5GHz | 6.9Gbps |
| IEEE 802.11ax | 2.4/5/6GHz | 9.6Gbps |
| IEEE 802.11be | 2.4/5/6GHz | 46.1Gbps |

### 와이파이(Wi-Fi)란?
- **와이파이(Wi-Fi)**: IEEE 802.11 표준을 따르는 무선 LAN 기술의 **트레이드마크(브랜드) 이름**
- **와이파이 얼라이언스(Wi-Fi Alliance)** 라는 비영리단체가 관리
- 세대별 분류:

| 세대 이름 | 표준 규격 |
|---|---|
| Wi-Fi 7 | IEEE 802.11be |
| Wi-Fi 6 | IEEE 802.11ax |
| Wi-Fi 5 | IEEE 802.11ac |
| Wi-Fi 4 | IEEE 802.11n |

- Wi-Fi 인증 마크가 붙은 제품 → 해당 IEEE 802.11 규격을 지켰다는 의미

## 3. 2.4GHz vs 5GHz 비교 ⚖️

### 핵심 차이: 회절성

| 비교 항목 | 2.4GHz | 5GHz |
|---|---|---|
| 전송 속도 | 상대적으로 느림 | 상대적으로 빠름 |
| 장애물 영향 | 덜 받음 (회절성↑) | 더 받음 (회절성↓) |
| 도달 거리 | 멀리 도달 | 가까운 거리에 강함 |
| 혼잡도 | 기기 많아 혼잡할 수 있음 | 상대적으로 덜 혼잡 |

> 💡 **회절성**: 파동이 장애물을 넘어 전달되는 성질. 주파수가 낮을수록 회절성이 높다.

**결론**
- 장애물이 많은 환경 → **2.4GHz** 추천 (더 멀리, 잘 침투)
- 속도가 중요하고 장애물이 적은 환경 → **5GHz** 추천

## 4. 채널 (Channel) 📻

### 채널이란?
- 동일한 주파수 대역(2.4GHz, 5GHz)을 사용하더라도 **별개의 무선 네트워크**들이 공존 가능
- 이를 위해 주파수 대역을 더 세분화한 것 → **채널(Channel)**
- 각 채널에는 번호가 할당됨

### 채널 간섭 주의
- 같은 공간에서 서로 다른 네트워크를 구성할 때 **간섭이 없는 채널 선택** 권장
- 2.4GHz에서는 **1, 6, 11번 채널**은 서로 주파수가 중첩되지 않아 권장됨
- 채널은 보통 자동 설정되지만 수동으로도 변경 가능

---

## 5. AP와 서비스 셋 🔌

### AP(Access Point)란?
- **AP(무선 액세스 포인트)**: 무선 통신 기기들을 연결하여 무선 네트워크를 구성하는 장치
- 가정의 무선 공유기가 AP 역할
- AP에는 유선 연결 매체를 연결할 수 있는 지점도 있어 → 유선 ↔ 무선 연결 담당

### 인프라스트럭처 모드
- 무선 LAN 기기들은 **AP를 경유**해 인터넷 접속 또는 메시지 교환
- AP를 경유하는 통신 방식 → **인프라스트럭처 모드(Infrastructure Mode)**
- 오늘날 대부분의 무선 LAN이 이 방식으로 동작

> 📝 AP 없이 기기끼리 직접 통신하는 방식 → **애드 혹 모드(Ad Hoc Mode)**

### 서비스 셋(Service Set)
- AP를 중심으로 연결된 여러 장치가 무선 네트워크를 형성 → 이 집합을 **서비스 셋**이라 부름
- 서비스 셋에 속한 장치들은 **같은 무선 네트워크**에 속함

| 종류 | 설명 |
|---|---|
| BSS (Basic Service Set) | 하나의 AP로 구성된 무선 LAN |
| ESS (Extended Service Set) | 여러 AP로 구성된 무선 LAN |

---

## 6. SSID와 비컨 프레임 📣

### SSID(Service Set Identifier)
- **SSID**: 서비스 셋을 식별하기 위한 이름 = **무선 네트워크의 고유한 이름**
- 우리가 와이파이에 연결할 때 보이는 **와이파이 이름**이 바로 SSID
- 현재 사용 중인 무선 네트워크 속성에서 확인 가능

### 비컨 프레임(Beacon Frame)
- AP가 자신의 존재를 외부에 알리기 위해 **주기적으로 브로드캐스트하는 메시지**
- 비컨 프레임에 포함된 정보:
    - SSID (무선 네트워크 이름)
    - AP의 MAC 주소
- 기기가 와이파이 목록을 표시할 수 있는 이유 → **AP로부터 비컨 프레임을 수신**했기 때문

## 🧪 복습 퀴즈

**Q1.** IEEE 802.11 표준에서 가장 빠른 최대 전송 속도를 지원하는 규격은?

1. IEEE 802.11a
2. IEEE 802.11n
3. IEEE 802.11ac
4. IEEE 802.11ax
5. IEEE 802.11be

정답: 5번 - IEEE 802.11be(Wi-Fi 7)는 최대 46.1Gbps로 현재 가장 빠른 규격입니다.

---

**Q2.** 와이파이(Wi-Fi)에 대한 설명으로 올바른 것은?

1. IEEE 802.3을 따르는 무선 LAN 기술이다
2. Wi-Fi는 와이파이 얼라이언스가 관리하는 트레이드마크 이름이다
3. Wi-Fi 5는 IEEE 802.11ax 규격을 따른다
4. Wi-Fi는 5GHz 대역만 사용한다
5. Wi-Fi는 유선 LAN보다 항상 빠르다

정답: 2번 - Wi-Fi는 IEEE 802.11 표준을 따르는 기술의 브랜드명으로, Wi-Fi Alliance가 관리합니다.

---

**Q3.** 2.4GHz 와이파이와 5GHz 와이파이를 비교할 때, 2.4GHz가 5GHz보다 유리한 상황은?

1. 짧은 거리에서 빠른 속도가 필요할 때
2. 장애물이 많고 멀리 신호를 보내야 할 때
3. 주변에 기기가 적어 채널 혼잡이 없을 때
4. 최신 규격(Wi-Fi 6 이상)을 사용할 때
5. 영상 스트리밍처럼 고대역폭이 필요할 때

정답: 2번 - 2.4GHz는 회절성이 높아 장애물을 잘 통과하고 더 멀리 도달합니다. 반면 5GHz는 속도가 빠르지만 회절성이 낮아 장애물에 약합니다.

---

**Q4.** AP(Access Point)에 대한 설명으로 틀린 것은?

1. 무선 통신 기기들을 연결하여 무선 네트워크를 구성한다
2. 가정의 무선 공유기가 AP 역할을 한다
3. AP를 경유하는 통신 방식을 인프라스트럭처 모드라 한다
4. AP 없이는 어떤 경우에도 무선 통신이 불가능하다
5. AP에는 유선 연결 매체를 연결할 수 있는 지점이 있다

정답: 4번 - AP 없이 기기끼리 직접 통신하는 애드 혹 모드(Ad Hoc Mode)도 존재합니다.

---

**Q5.** SSID와 비컨 프레임에 대한 설명으로 올바른 것은?

1. SSID는 AP의 IP 주소를 의미한다
2. 비컨 프레임은 사용자가 수동으로 전송해야 한다
3. SSID는 무선 네트워크를 구분하는 고유한 이름이며, 우리가 보는 와이파이 이름이다
4. 비컨 프레임은 유니캐스트 방식으로 특정 기기에만 전송된다
5. SSID가 같으면 반드시 동일한 AP를 사용하는 것이다

정답: 3번 - SSID(Service Set Identifier)는 무선 네트워크의 고유한 이름으로, 일상에서 보는 와이파이 이름이 바로 SSID입니다. 비컨 프레임은 AP가 자신의 존재를 알리기 위해 주기적으로 브로드캐스트(불특정 다수에게 전송)하는 메시지입니다.
