## 1. 조건문

### 1.1 if문

### 기본 개념

조건식이 참(true)일 때 코드 블록을 실행하는 제어문입니다. 한 줄 코드는 중괄호 생략 가능하지만, 여러 줄은 반드시 블록문({})을 사용해야 합니다.

| 구분             | 설명                          | 사용 상황                        | 예시 코드                                                           |
| ---------------- | ----------------------------- | -------------------------------- | ------------------------------------------------------------------- |
| **단순 if문**    | 조건이 참일 때만 실행         | 단일 조건 검사가 필요할 때       | `if (open) console.log('영업중');`                                  |
| **if-else문**    | 참/거짓에 따라 다른 코드 실행 | 두 가지 경로 중 하나를 선택할 때 | `if (x % 2) { console.log('홀수'); } else { console.log('짝수'); }` |
| **if-else if문** | 여러 조건을 순차적으로 검사   | 3개 이상의 조건 분기가 필요할 때 | `if (x % 2) { ... } else if (x % 4) { ... } else { ... }`           |
| **중첩 if문**    | if문 안에 또 다른 if문 사용   | 복잡한 조건 검사가 필요할 때     | `if (x % 4) { if (x % 2) { ... } }`                                 |

### 💡 권장 패턴: Early Return

함수 내에서 조건을 만족하면 즉시 return하여 중첩을 줄이고 가독성을 높입니다.

```jsx
function evalNum() {
  const x = 21;

  if (x % 2) {
    console.log("홀수입니다.");
    return; // 함수 즉시 종료
  }

  if (x % 4) {
    console.log("짝수입니다.");
    return;
  }

  console.log("4의 배수입니다.");
}
```

**장점** : 중첩된 else if 체인보다 코드 흐름이 명확하고, 각 조건이 독립적으로 보입니다.

### 1.2 switch문

### 기본 개념

하나의 표현식을 여러 case 값과 비교하여 일치하는 case의 코드를 실행합니다. 다수의 옵션 중 하나를 선택하는 상황에 적합합니다.

| 구분             | 설명                          | 사용 상황                      | 예시 코드                                        |
| ---------------- | ----------------------------- | ------------------------------ | ------------------------------------------------ |
| **기본 switch**  | case별로 다른 코드 실행       | 명확한 값 비교가 필요할 때     | `switch(value) { case 1: ...; break; }`          |
| **break문**      | 해당 case 실행 후 switch 탈출 | 각 case를 독립적으로 실행할 때 | `case 2: console.log('가위'); break;`            |
| **fall-through** | break 없이 다음 case도 실행   | 여러 case를 연속 실행할 때     | `case 1: case 2: case 3: ...;`                   |
| **default**      | 모든 case와 불일치 시 실행    | 예외 처리나 기본값 설정 시     | `default: console.log('무효');`                  |
| **다중 case**    | 여러 값에 동일한 처리 적용    | 그룹화된 조건 처리 시          | `case 1: case 2: case 3: season='1분기'; break;` |

### 💡 객체를 활용한 대체 패턴

간단한 값 매핑은 객체로 더 간결하게 표현 가능합니다.

```jsx
const direction = "north";
const directionKor =
  {
    north: "북",
    south: "남",
    east: "동",
    west: "서",
  }[direction] ?? "무효";
```

**주의사항** : break를 생략하면 다음 case도 실행되므로 의도하지 않은 fall-through에 주의해야 합니다.

## 2. 반복문

### 2.1 for문

### 기본 개념

초기화, 조건식, 증감식을 한 곳에 정의하여 정해진 횟수만큼 반복 실행하는 구문입니다.

| 구분           | 설명                       | 사용 상황                        | 예시 코드                                                               |
| -------------- | -------------------------- | -------------------------------- | ----------------------------------------------------------------------- |
| **기본 for문** | 카운터 변수로 반복 제어    | 정확한 반복 횟수를 알 때         | `for (let i = 0; i < 5; i++) { ... }`                                   |
| **중첩 for문** | 반복문 안에 또 다른 반복문 | 2차원 구조 처리(구구단 등)       | `for (let i = 1; i <= 9; i++) { for (let j = 1; j <= 9; j++) { ... } }` |
| **다중 변수**  | 여러 변수를 동시에 제어    | 두 값을 동시에 변경하며 반복     | `for (let x = 0, y = 10; x <= y; x++, y--) { ... }`                     |
| **무한 루프**  | 종료 조건이 없는 반복      | 명시적으로 무한 반복이 필요할 때 | `for (;;) { ... }`                                                      |

### 구조 분석

```jsx
for (초기화; 조건식; 증감식) {
  // 실행 코드
}

// 예시
for (let i = 0; i < 5; i++) {
  console.log(i); // 0, 1, 2, 3, 4
}
```

1. **초기화** : 반복 시작 전 한 번만 실행 (`let i = 0`)
2. **조건식** : 매 반복마다 검사, false면 종료 (`i < 5`)
3. **증감식** : 각 반복 후 실행 (`i++`)

### 2.2 for...in / for...of문

### 기본 개념

객체의 키나 배열/이터러블의 값을 순회하는 특화된 반복문입니다.

| 구분         | 설명                             | 사용 상황                  | 예시 코드                                                |
| ------------ | -------------------------------- | -------------------------- | -------------------------------------------------------- |
| **for...in** | 객체의 키(key)를 순회            | 객체의 속성을 열거할 때    | `for (const key in obj) { console.log(key, obj[key]); }` |
| **for...of** | 배열/이터러블의 값(value)을 순회 | 배열 요소를 직접 접근할 때 | `for (const item of array) { console.log(item); }`       |

### for...of의 장점

```jsx
const numbers = [1, 2, 3, 4, 5];

// ⚠️ 기존 방식: 인덱스 변수 조작 위험
for (let i = 0; i < numbers.length; i++) {
  console.log(numbers[i]);
  // i를 실수로 변경하면 문제 발생 가능
}

// ⭐ for...of: 안전하고 간결
for (const num of numbers) {
  console.log(num);
  // 인덱스 변수가 없어 더 안전
}
```

**중요** : for...of에서 변수는 복사본이므로 원본 배열을 변경하려면 인덱스 접근이 필요합니다.

---

### 2.3 while문

### 기본 개념

조건식이 참인 동안 계속 반복 실행하는 구문입니다. 반복 횟수를 모를 때 유용합니다.

| 구분           | 설명                  | 사용 상황             | 예시 코드                              |
| -------------- | --------------------- | --------------------- | -------------------------------------- |
| **while문**    | 조건이 참인 동안 반복 | 반복 횟수가 미정일 때 | `while (x < 10) { console.log(x++); }` |
| **무한 while** | 의도적인 무한 반복    | break로 제어하는 반복 | `while (true) { if (조건) break; }`    |

### 주의사항

```jsx
let x = 0;
// ⚠️ 무한루프 발생! continue 후 x가 증가하지 않음
while (x < 14) {
  if (x % 2 === 0) continue;
  console.log(x++);
}

// ✅ 수정: 증감을 조건 검사에 포함
while (x < 14) {
  if (x++ % 2 === 0) continue;
  console.log(x - 1);
}
```

---

### 2.4 do...while문

### 기본 개념

코드를 먼저 실행한 후 조건을 검사하므로 최소 1회는 반드시 실행됩니다.

| 구분           | 설명               | 사용 상황                          | 예시 코드                                  |
| -------------- | ------------------ | ---------------------------------- | ------------------------------------------ |
| **do...while** | 최소 1회 실행 보장 | 입력 검증 등 최소 1회 실행 필요 시 | `do { console.log(x++); } while (x < 10);` |

```jsx
let x = 12;
do {
  console.log(x++); // 12 출력 (조건 false여도 1회 실행)
} while (x < 10);
```

## 3. 흐름 제어

### 3.1 continue와 break

| 구분         | 설명                               | 사용 상황               | 예시 코드                    |
| ------------ | ---------------------------------- | ----------------------- | ---------------------------- |
| **continue** | 현재 반복을 건너뛰고 다음 반복으로 | 특정 조건의 항목만 처리 | `if (i % 3 === 0) continue;` |
| **break**    | 반복문을 완전히 종료               | 조건 만족 시 반복 중단  | `if (i === 5) break;`        |

```jsx
// continue 예시: 3의 배수 건너뛰기
for (let i = 1; i <= 10; i++) {
  if (i % 3 === 0) continue;
  console.log(i); // 1, 2, 4, 5, 7, 8, 10
}

// break 예시: 5에서 종료
for (let i = 1; i <= 10; i++) {
  if (i === 5) break;
  console.log(i); // 1, 2, 3, 4
}
```

---

### 3.2 label문

### 기본 개념

중첩된 반복문에서 특정 반복문을 지정하여 continue/break 할 수 있습니다. (실무에서는 드물게 사용)

| 구분      | 설명                 | 사용 상황                         | 예시 코드                                                |
| --------- | -------------------- | --------------------------------- | -------------------------------------------------------- |
| **label** | 반복문에 이름을 부여 | 중첩 반복문에서 외부 반복 제어 시 | `outer: for (...) { inner: for (...) { break outer; } }` |

```jsx
outer: for (let i = 1; i < 10; i++) {
  inner: for (let j = 1; j < 10; j++) {
    if (j % 2 === 0) continue inner; // 내부 반복 건너뛰기
    if (i * j >= 30) continue outer; // 외부 반복 건너뛰기
    console.log(i, j, i * j);
  }
}
```

## 4. 핵심 요약

### 📌 조건문

| 구문             | 핵심                   | 언제 사용                 |
| ---------------- | ---------------------- | ------------------------- |
| **if/else**      | 조건에 따른 분기 처리  | 2~3개의 조건 분기         |
| **switch**       | 다수의 값 비교         | 5개 이상의 명확한 값 비교 |
| **early return** | 중첩 감소, 가독성 향상 | 함수 내 조건 분기         |

### 📌 반복문

| 구문           | 핵심                  | 언제 사용          |
| -------------- | --------------------- | ------------------ |
| **for**        | 정확한 반복 횟수 제어 | 카운터 기반 반복   |
| **for...in**   | 객체 키 순회          | 객체 속성 열거     |
| **for...of**   | 배열 값 순회 (안전)   | 배열/이터러블 순회 |
| **while**      | 조건 기반 반복        | 반복 횟수 미정     |
| **do...while** | 최소 1회 실행 보장    | 입력 검증 등       |

### 📌 흐름 제어

| 구문         | 핵심               | 효과               |
| ------------ | ------------------ | ------------------ |
| **continue** | 현재 반복 건너뛰기 | 다음 반복으로 이동 |
| **break**    | 반복문 종료        | 반복문 완전 탈출   |
| **label**    | 중첩 반복문 제어   | 특정 반복문 지정   |

### 🎯 핵심 원칙

1. **가독성 우선** : early return으로 중첩 최소화
2. **안전성** : for...of로 인덱스 조작 위험 회피
3. **적절한 선택** : 상황에 맞는 제어문 사용
4. **무한루프 주의** : break 또는 적절한 종료 조건 필수

## 5. 복습 퀴즈

### Q1. 다음 코드의 출력 결과는?

```jsx
for (let i = 1; i <= 5; i++) {
  if (i === 3) continue;
  if (i === 5) break;
  console.log(i);
}
```

**선택지:**

1. 1 2 3 4
2. 1 2 4
3. 1 2 3 4 5
4. 1 2

**정답: 2번 (1 2 4)**

**해설** :

- i=1, 2일 때: 조건에 걸리지 않아 출력됨
- i=3일 때: `continue`로 출력 건너뜀
- i=4일 때: 조건에 걸리지 않아 출력됨
- i=5일 때: `break`로 반복문 종료 (출력 전에 종료)

---

### Q2. switch문에서 break를 생략하면 어떻게 되는가?

**선택지:**

1. 에러가 발생한다
2. 해당 case만 실행된다
3. 다음 case도 계속 실행된다 (fall-through)
4. switch문이 종료된다

**정답: 3번 (다음 case도 계속 실행된다)**

**해설** :
break를 생략하면 일치하는 case부터 아래의 모든 case가 순차적으로 실행됩니다. 이를 fall-through라고 하며, 의도적으로 여러 case를 연속 실행할 때 사용하지만, 실수로 break를 누락하면 버그가 발생할 수 있습니다.

```jsx
switch (2) {
  case 1:
    console.log("A");
  case 2:
    console.log("B"); // 여기서 시작
  case 3:
    console.log("C"); // break 없어서 실행
  default:
    console.log("D"); // break 없어서 실행
}
// 출력: B C D
```

### Q3. for...of와 일반 for문의 차이점으로 올바른 것은?

**선택지:**

1. for...of가 더 빠르다
2. for...of는 인덱스 변수를 사용하지 않아 더 안전하다
3. for...of는 객체를 순회할 수 있다
4. 둘은 완전히 동일하다

**정답: 2번 (인덱스 변수를 사용하지 않아 더 안전하다)**

**해설** :
for...of는 배열의 값을 직접 순회하므로 인덱스 변수(`i`)를 조작할 위험이 없습니다. 반면 일반 for문은 인덱스를 직접 다루므로 실수로 `i`를 변경하면 예상치 못한 동작이 발생할 수 있습니다. 단, for...of는 객체가 아닌 이터러블(배열, 문자열 등)을 순회하며, 객체는 for...in을 사용합니다.

### Q4. 다음 중 무한루프를 안전하게 사용하는 올바른 패턴은?

**선택지:**

1. `for (;;) { console.log('무한'); }`
2. `while (true) { if (조건) break; 작업수행(); }`
3. `while (x < 10) { console.log(x); }`
4. `do { console.log('무한'); } while (true);`

**정답: 2번**

**해설** :
무한루프(`while(true)` 또는 `for(;;)`)를 사용할 때는 반드시 **break 조건**을 포함해야 합니다. 2번은 특정 조건에서 break로 탈출하므로 안전합니다. 1번과 4번은 탈출 조건이 없어 브라우저가 멈출 수 있으며, 3번은 x가 증가하지 않으면 무한루프가 됩니다.

### Q5. early return 패턴의 주요 장점은?

**선택지:**

1. 실행 속도가 빨라진다
2. 메모리를 절약한다
3. 중첩을 줄여 가독성을 높인다
4. 더 많은 조건을 처리할 수 있다

**정답: 3번 (중첩을 줄여 가독성을 높인다)**

**해설** :
early return은 조건을 만족하면 즉시 함수를 종료하므로, 깊은 중첩(else if 체인)을 피할 수 있습니다. 이로 인해 코드의 흐름이 명확해지고 가독성이 크게 향상됩니다. 성능이나 메모리 측면의 이점은 미미하며, 핵심은 **코드 구조 개선**입니다.

### Q6. while문에서 continue 사용 시 주의할 점은?

**선택지:**

1. continue를 사용할 수 없다
2. 증감식이 continue 이전에 있어야 한다
3. break와 함께 사용할 수 없다
4. 조건식이 false가 된다

**정답: 2번 (증감식이 continue 이전에 있어야 한다)**

**해설** :
while문에서 continue를 만나면 즉시 조건 검사로 돌아갑니다. 만약 증감식이 continue 이후에 있으면 실행되지 않아 **무한루프**가 발생합니다.

```jsx
// ⚠️ 무한루프 발생
let x = 0;
while (x < 10) {
  if (x % 2 === 0) continue; // x가 증가 안함!
  console.log(x++);
}

// ✅ 올바른 방법
while (x < 10) {
  if (x++ % 2 === 0) continue; // 증감을 먼저 수행
  console.log(x - 1);
}
```

### 문제 2: 합계가 100 이상이 되는 순간 멈추기 (break 활용)

**문제** : 1부터 시작해서 숫자를 누적 합산하다가 합계가 100 이상이 되면 멈추고, 그때의 숫자와 합계를 출력하세요.

**기본 코드** :

```jsx
let sum = 0;
let num = 0;

// 여기에 코드를 작성하세요

console.log(`숫자: ${num}, 합계: ${sum}`);
```

**정답** :

```jsx
let sum = 0;
let num = 0;

while (true) {
  num++;
  sum += num;
  if (sum >= 100) break;
}

console.log(`숫자: ${num}, 합계: ${sum}`);
// 출력: 숫자: 14, 합계: 105
```

**풀이 및 해설** :

- 무한 루프 `while(true)`를 사용하여 계속 누적
- 매 반복마다 `num`을 증가시키고 `sum`에 누적
- `sum >= 100`이 되면 `break`로 반복 종료
- 1+2+3+...+13=91, 1+2+...+14=105이므로 14에서 멈춤

### 문제 3: 객체를 switch로 변환하기

**문제** : 아래 객체를 활용한 코드를 switch문으로 다시 작성하세요.

**기본 코드** :

```jsx
const grade = "B";

const gradeMessage =
  {
    A: "최우수",
    B: "우수",
    C: "보통",
    D: "미흡",
    F: "재수강",
  }[grade] ?? "잘못된 학점";

console.log(gradeMessage);
```

**switch문으로 변환** :

```jsx
const grade = "B";
let gradeMessage;

// 여기에 switch문을 작성하세요

console.log(gradeMessage);
```

**정답** :

```jsx
const grade = "B";
let gradeMessage;

switch (grade) {
  case "A":
    gradeMessage = "최우수";
    break;
  case "B":
    gradeMessage = "우수";
    break;
  case "C":
    gradeMessage = "보통";
    break;
  case "D":
    gradeMessage = "미흡";
    break;
  case "F":
    gradeMessage = "재수강";
    break;
  default:
    gradeMessage = "잘못된 학점";
}

console.log(gradeMessage); // 출력: 우수
```

**풀이 및 해설** :

- 각 case는 객체의 키에 해당하고, 할당되는 값은 객체의 값에 해당합니다
- `break`를 생략하면 fall-through가 발생하므로 반드시 포함해야 합니다
- `default`는 객체의 `?? '잘못된 학점'` 부분과 동일한 역할을 합니다

### 문제 4: for...of로 배열 합계 구하기

**문제** : 아래 배열의 모든 숫자를 합산하세요. for...of를 사용해야 합니다.

**기본 코드** :

```jsx
const numbers = [10, 25, 30, 15, 40];
let total = 0;

// 여기에 코드를 작성하세요

console.log(total); // 출력: 120
```

**정답** :

```jsx
const numbers = [10, 25, 30, 15, 40];
let total = 0;

for (const num of numbers) {
  total += num;
}

console.log(total); // 출력: 120
```

**풀이 및 해설** :

- for...of는 배열의 각 값을 직접 순회합니다
- `num`에는 10, 25, 30, 15, 40이 차례로 할당됩니다
- 각 값을 `total`에 누적하여 최종 합계 120을 얻습니다
- 인덱스가 필요 없을 때는 for...of가 일반 for문보다 안전하고 간결합니다

### 문제 5: 중첩 for문으로 패턴 출력하기

**문제** : 아래와 같은 패턴을 출력하세요.

```
*
**
***
****
*****

```

**기본 코드** :

```jsx
// 여기에 코드를 작성하세요
```

**정답** :

```jsx
for (let i = 1; i <= 5; i++) {
  let line = "";
  for (let j = 1; j <= i; j++) {
    line += "*";
  }
  console.log(line);
}
```

**풀이 및 해설** :

- 외부 반복문(`i`)은 줄 번호를 나타냅니다 (1~5줄)
- 내부 반복문(`j`)은 각 줄에서 별의 개수를 나타냅니다
- 1번째 줄: j가 1번 반복 →
- 2번째 줄: j가 2번 반복 → `*`
- 5번째 줄: j가 5번 반복 → `****`
- `line` 변수에 별을 누적한 후 한 번에 출력합니다

### 문제 6: early return 패턴으로 리팩토링

**문제** : 아래 중첩된 if-else 코드를 early return 패턴으로 리팩토링하세요.

**기본 코드 (리팩토링 전)** :

```jsx
function checkAge(age) {
  if (age >= 0) {
    if (age < 20) {
      return "미성년자";
    } else {
      if (age < 65) {
        return "성인";
      } else {
        return "노인";
      }
    }
  } else {
    return "잘못된 나이";
  }
}

console.log(checkAge(15)); // 미성년자
console.log(checkAge(30)); // 성인
console.log(checkAge(70)); // 노인
console.log(checkAge(-5)); // 잘못된 나이
```

**리팩토링할 코드:**

```jsx
function checkAge(age) {
  // 여기에 early return 패턴으로 작성하세요
}

console.log(checkAge(15));
console.log(checkAge(30));
console.log(checkAge(70));
console.log(checkAge(-5));
```

**정답** :

```jsx
function checkAge(age) {
  if (age < 0) {
    return "잘못된 나이";
  }

  if (age < 20) {
    return "미성년자";
  }

  if (age < 65) {
    return "성인";
  }

  return "노인";
}

console.log(checkAge(15)); // 미성년자
console.log(checkAge(30)); // 성인
console.log(checkAge(70)); // 노인
console.log(checkAge(-5)); // 잘못된 나이
```

**풀이 및 해설** :

- early return은 조건을 만족하면 즉시 반환하여 중첩을 제거합니다
- 가장 예외적인 경우(`age < 0`)를 먼저 처리합니다
- 각 조건이 독립적으로 보이므로 코드 흐름이 명확합니다
- else 블록이 사라져 들여쓰기가 줄어들고 가독성이 향상됩니다
- 마지막 return은 모든 조건을 통과한 경우(65세 이상)를 처리합니다
