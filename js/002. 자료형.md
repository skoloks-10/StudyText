# JavaScript 자료형 완벽 정리

---

## 1. 자료형의 기본 개념

### 1.1 자료형이란?

자료형(Data Type)은 프로그래밍에서 다루는 데이터의 종류를 의미합니다. JavaScript는 값의 성격에 따라 여러 가지 자료형으로 데이터를 분류하며, 각 자료형은 고유한 특성과 사용 목적을 가지고 있습니다.

### 1.2 typeof 연산자

`typeof` 연산자는 특정 값의 자료형을 문자열로 반환하는 연산자입니다.

| 속성          | 설명                                                                                                                                                                            |
| ------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **사용법**    | `typeof 값`또는 `typeof(값)`                                                                                                                                                    |
| **반환값**    | 자료형을 나타내는 문자열 (예: 'number', 'string', 'boolean')                                                                                                                    |
| **사용 상황** | 변수나 값의 자료형을 확인해야 할 때                                                                                                                                             |
| **예시 코드** | `javascript<br>console.log(typeof 123); // 'number'<br>console.log(typeof 'hello'); // 'string'<br>console.log(typeof typeof 123); // 'string' - typeof의 반환값은 항상 문자열` |

**중요 포인트** : `typeof` 연산자의 반환값 자체도 문자열(string) 자료형입니다.

---

## 2. 원시 자료형 (Primitive Data Types)

원시 자료형은 단일 값만을 담는 가장 기본적인 자료형입니다. JavaScript에는 6가지 원시 자료형이 있습니다.

### 2.1 불리언 (Boolean)

불리언은 참(true) 또는 거짓(false) 두 가지 값만을 가질 수 있는 자료형입니다.

| 속성              | 설명                                                                                                                                                               |
| ----------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **가능한 값**     | `true`,`false`                                                                                                                                                     |
| **사용 상황**     | 조건문, 논리 판단, 상태 표현 (예: 로그인 여부, 활성화 상태)                                                                                                        |
| **typeof 반환값** | `'boolean'`                                                                                                                                                        |
| **예시 코드**     | `javascript<br>let isEmployed = true;<br>let isMarried = false;<br><br>// 비교 연산의 결과로 자주 사용됨<br>const a = 1 > 2; // false<br>const b = 1 < 2; // true` |

**특징** : 직접 할당되기보다는 비교 연산이나 함수의 반환값으로 프로그램 곳곳에서 활용됩니다.

### 2.2 숫자 (Number)

숫자 자료형은 정수와 실수를 모두 표현할 수 있는 자료형입니다.

| 속성                 | 설명                                                                                                                                                                    |
| -------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **포함 범위**        | 정수, 실수, 음수 모두 포함                                                                                                                                              |
| **안전한 정수 범위** | -(2^53 - 1) ~ (2^53 - 1)                                                                                                                                                |
| **typeof 반환값**    | `'number'`                                                                                                                                                              |
| **사용 상황**        | 수치 계산, 카운팅, 수학 연산 등                                                                                                                                         |
| **예시 코드**        | `javascript<br>let integer = 100;<br>let real = 12.34;<br>let negative = -99;<br><br>console.log(integer, real, negative);<br>console.log(typeof integer); // 'number'` |

**중요 포인트** : JavaScript는 정수와 실수를 구분하지 않습니다. 모든 숫자는 내부적으로 실수로 처리됩니다. 더 큰 정수가 필요한 경우 `BigInt` 자료형을 사용합니다.

### 2.3 문자열 (String)

문자열은 텍스트 데이터를 표현하는 자료형입니다.

### 2.3.1 기본 표기 방법

| 표기법         | 기호    | 특징                           |
| -------------- | ------- | ------------------------------ |
| **작은따옴표** | `' ~ '` | 가장 일반적인 표기법           |
| **큰따옴표**   | `" ~ "` | 작은따옴표와 동일한 기능       |
| **백틱**       | `~`     | 템플릿 리터럴 기능 제공 (ES6+) |

**기본 예시:**

```jsx
let word1 = "안녕하세요!";
let word2 = "반갑습니다~";
console.log(word1, word2);
```

### 2.3.2 따옴표 안에 따옴표 사용하기

문자열 내부에 따옴표를 사용하는 방법은 두 가지입니다.

**방법 1: 다른 종류의 따옴표 사용**

```jsx
let word1 = '작은따옴표 안에 "큰따옴표" 사용';
let word2 = "큰따옴표 안에 '작은따옴표' 사용";
```

**방법 2: 이스케이프 표현(Escape Sequence) 사용**

```jsx
let word1 = '작은따옴표 안에 \\'작은따옴표\\' 사용';
let word2 = "큰따옴표 안에 \\"큰따옴표\\" 사용";

```

### 2.3.3 이스케이프 표현

| 이스케이프 표현 | 의미       | 사용 상황                                  |
| --------------- | ---------- | ------------------------------------------ |
| `\\'`           | 작은따옴표 | 작은따옴표 문자열 내부에서 작은따옴표 표현 |
| `\\"`           | 큰따옴표   | 큰따옴표 문자열 내부에서 큰따옴표 표현     |
| `\\n`           | 줄바꿈     | 텍스트를 다음 줄로 이동                    |
| `\\t`           | 탭         | 탭 간격 삽입                               |
| `\\\\`          | 백슬래시   | 백슬래시 문자 자체를 표현                  |

**예시 코드:**

```jsx
let word = "안녕하세요~\\t\\t반갑습니다!\\n저는 \\\\홍길동\\\\입니다.";
console.log(word);
// 출력:
// 안녕하세요~		반갑습니다!
// 저는 \\홍길동\\입니다.
```

### 2.3.4 여러 줄 문자열

**일반 따옴표 사용 시:**

```jsx
// 백슬래시를 사용하여 다음 줄로 이어짐 (실제로는 한 줄)
let longName = '김수한무 거북이와 두루미 \\
삼천갑자 동방삭 치치카포 사리사리센타';

```

**주의** : 위 방법은 코드 가독성을 위한 것이며, 실제 출력 시 줄바꿈이 되지 않습니다.

### 2.3.5 백틱 (Template Literal)

백틱은 ES6에서 도입된 강력한 문자열 표기법입니다.

| 특징                 | 설명                                                 |
| -------------------- | ---------------------------------------------------- |
| **탭과 줄바꿈 유지** | 코드에 입력한 그대로 출력됨                          |
| **변수 삽입**        | `${}`문법으로 변수나 표현식 삽입 가능                |
| **사용 상황**        | 여러 줄 문자열, 동적 문자열 생성, 복잡한 텍스트 조합 |

**기본 예시:**

```jsx
let word = `안녕하세요~		반갑습니다!
저는 \\\\홍길동\\\\입니다.`;
// 실제로 줄바꿈과 탭이 유지됨
```

**템플릿 리터럴 - 변수 삽입:**

```jsx
const NAME = "홍길동";
let age = 20;
let married = false;

console.log(
  `제 이름은 ${NAME}, 나이는 ${age}세구요, \\
${married ? "기혼" : "미혼"}입니다.`
);
// 출력: 제 이름은 홍길동, 나이는 20세구요, 미혼입니다.
```

**중요 포인트** : `${}` 안에는 변수뿐만 아니라 표현식, 함수 호출 등 어떤 JavaScript 코드든 넣을 수 있습니다.

### 2.4 undefined

`undefined`는 값이 할당되지 않은 상태를 나타내는 특별한 자료형입니다.

| 속성              | 설명                                                                                                                                                                                    |
| ----------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **의미**          | "값이 아직 부여되지 않았다"                                                                                                                                                             |
| **typeof 반환값** | `'undefined'`                                                                                                                                                                           |
| **발생 상황**     | 변수 선언 후 값 할당 전, 함수에서 return 없을 때, 존재하지 않는 객체 속성 접근                                                                                                          |
| **예시 코드**     | `javascript<br>let x;<br>console.log(x); // undefined<br>console.log(typeof x); // 'undefined'<br><br>// 아무것도 반환하지 않는 구문<br>let y = console.log('hello'); // y는 undefined` |

**중요 포인트** : `undefined`도 하나의 값입니다. 많은 프로그래밍 언어와 달리 JavaScript에서는 "값이 없음"도 값으로 취급합니다.

### 2.5 null

`null`은 의도적으로 "비어있음"을 나타내는 값입니다.

| 속성              | 설명                                                                                                                                                                         |
| ----------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **의미**          | "의도적으로 비어있는 값"                                                                                                                                                     |
| **typeof 반환값** | `'object'`⚠️ (초기 설계 오류)                                                                                                                                                |
| **사용 상황**     | 객체가 들어갈 자리에 아직 객체가 없을 때, 함수가 객체를 반환해야 하지만 실패했을 때                                                                                          |
| **예시 코드**     | `javascript<br>let x = null;<br>console.log(x); // null<br>console.log(typeof x); // 'object' (주의!)<br><br>// null 체크는 다음과 같이<br>console.log(x === null); // true` |

**undefined vs null 비교:**

```jsx
let x; // undefined - 값이 할당되지 않음
let y = null; // null - 의도적으로 비운 값

console.log(x === undefined); // true
console.log(y === null); // true
```

**사용 시나리오:**

- `undefined`: "아직 정해지지 않았어요"
- `null`: "비어있다는 걸 알려드립니다"

## 3. JavaScript의 동적 타입 시스템

### 3.1 동적 타입이란?

JavaScript는 동적 타입(Dynamic Typing) 언어입니다. 이는 변수의 자료형이 실행 시점에 결정되며, 같은 변수에 다른 자료형의 값을 자유롭게 할당할 수 있다는 의미입니다.

| 구분          | 정적 타입 (예: Java, C++)   | 동적 타입 (JavaScript) |
| ------------- | --------------------------- | ---------------------- |
| **타입 결정** | 컴파일 시점                 | 런타임(실행) 시점      |
| **변수 선언** | 타입 명시 필요              | 타입 명시 불필요       |
| **타입 변경** | 불가능                      | 가능                   |
| **장점**      | 타입 안정성, 오류 조기 발견 | 유연성, 빠른 개발      |
| **단점**      | 코드 작성 복잡              | 런타임 오류 위험       |

**예시 코드:**

```jsx
let job = "학생"; // 문자열 할당
let age = 17; // 숫자 할당

console.log(job, age);
console.log(typeof age); // 'number'

// 동일한 변수에 다른 자료형 값 할당 가능
age = "열일곱";
console.log(age); // '열일곱'
console.log(typeof age); // 'string'
```

### 3.2 동적 타입의 문제점

### 3.2.1 런타임 오류

특정 자료형에만 사용할 수 있는 메서드를 다른 자료형에 사용하면 오류가 발생합니다.

```jsx
function getUpperCase(str) {
  return str.toUpperCase(); // 문자열 메서드
}

console.log(getUpperCase("hello")); // 'HELLO' - 정상 작동
console.log(getUpperCase(1)); // TypeError! - 숫자는 toUpperCase 메서드 없음
```

**문제점** : 코드 실행 전에는 오류를 발견할 수 없습니다.

### 3.2.2 논리 오류

의도와 다른 연산이 수행될 수 있습니다.

```jsx
console.log(1 + 1); // 2 (숫자 덧셈)
console.log("1" + 1); // '11' (문자열 연결)
```

**해결 방법:**

- TypeScript 사용 (정적 타입 체크)
- 엄격한 타입 검사 코드 작성
- 방어적 프로그래밍 (타입 체크 추가)

## 📝 항목별 핵심 요약

### 자료형 기본

- **자료형** : 데이터의 종류를 분류하는 체계
- **typeof 연산자** : 값의 자료형을 문자열로 반환

### 원시 자료형 5가지

1. **Boolean** : `true` 또는 `false`, 조건 판단에 사용
2. **Number** : 정수와 실수 모두 포함, 구분 없이 처리
3. **String** : 텍스트 데이터, 3가지 표기법 (따옴표, 백틱)
4. **undefined** : 값이 할당되지 않은 상태
5. **null** : 의도적으로 비어있는 값

### 문자열 핵심

- **이스케이프 표현** : `\\'`, `\\"`, `\\n`, `\\t`, `\\\\`
- **백틱** : 템플릿 리터럴, `${}` 로 변수 삽입 가능
- **줄바꿈** : 백틱 사용 시 실제 줄바꿈 유지

### 동적 타입

- **특징** : 변수에 다른 자료형 값을 자유롭게 재할당 가능
- **장점** : 유연성, 빠른 개발
- **단점** : 런타임 오류 위험, 논리 오류 가능성

### typeof 주의사항

- `typeof null` → `'object'` (초기 설계 오류)
- `typeof undefined` → `'undefined'`
- `typeof`의 반환값은 항상 문자열

## 🎯 복습 퀴즈

### 퀴즈 1

다음 코드의 출력 결과는 무엇인가요?

```jsx
console.log(typeof typeof 42);
```

**① `'number'`**

② `'string'`

③ `'undefined'`

④ `42`

**정답: ② `'string'`**

**해설** :

- 첫 번째 `typeof 42`는 `'number'`를 반환합니다
- 두 번째 `typeof 'number'`는 `'string'`을 반환합니다
- **핵심** : `typeof` 연산자의 반환값은 항상 문자열입니다

---

### 퀴즈 2

다음 중 `null`에 대한 설명으로 올바르지 않은 것은?

① `null`은 의도적으로 비어있는 값을 나타낸다

② `typeof null`의 결과는 `'null'`이다

③ `null`도 하나의 값이다

④ 객체가 들어갈 자리에 아직 객체가 없을 때 사용한다

**정답: ② `typeof null`의 결과는 `'null'`이다**

**해설** :

- `typeof null`은 `'object'`를 반환합니다 (JavaScript의 초기 설계 오류)
- `null` 체크는 `=== null`을 사용해야 합니다
- **핵심** : `null`은 원시 타입이지만 `typeof`는 `'object'`를 반환하므로 주의가 필요합니다

### 퀴즈 3

다음 코드의 출력 결과는?

```jsx
console.log("5" + 3);
console.log(5 + 3);
```

① `53`, `8`

② `8`, `53`

③ `'53'`, `8`

④ `'8'`, `'53'`

**정답: ③ `'53'`, `8`**

**해설** :

- 첫 번째: 문자열 `'5'`와 숫자 `3`의 연산은 문자열 연결이 되어 `'53'` 반환
- 두 번째: 숫자 `5`와 숫자 `3`의 연산은 덧셈이 되어 `8` 반환
- **핵심** : JavaScript의 동적 타입 특성으로 인해 같은 `+` 연산자도 피연산자 타입에 따라 다르게 동작합니다

---

### 퀴즈 4

백틱(Template Literal)에 대한 설명으로 옳은 것은?

① 백틱 내부에서는 줄바꿈을 사용할 수 없다

② `${}` 안에는 변수만 넣을 수 있다

③ `${}` 안에 표현식과 함수 호출도 가능하다

④ 이스케이프 표현을 사용할 수 없다

**정답: ③ `${}` 안에 표현식과 함수 호출도 가능하다**

**해설** :

```jsx
const name = "홍길동";
const age = 20;
console.log(
  `이름: ${name}, 내년 나이: ${age + 1}, 상태: ${age >= 20 ? "성인" : "미성년"}`
);
```

- 백틱은 줄바꿈과 탭을 그대로 유지합니다
- `${}` 안에는 변수, 표현식, 삼항 연산자, 함수 호출 등 모든 JavaScript 코드를 넣을 수 있습니다
- **핵심** : 템플릿 리터럴은 동적 문자열 생성에 매우 강력한 도구입니다

---

### 퀴즈 5

다음 중 `undefined`를 반환하는 경우가 아닌 것은?

① 선언만 하고 값을 할당하지 않은 변수

② `return` 문이 없는 함수의 반환값

③ 존재하지 않는 객체 속성에 접근할 때

④ 의도적으로 빈 값을 할당하고 싶을 때

**정답: ④ 의도적으로 빈 값을 할당하고 싶을 때**

**해설** :

- 의도적으로 빈 값을 표현할 때는 `null`을 사용합니다
- `undefined`는 JavaScript가 자동으로 할당하는 "값이 없음"의 상태입니다

```jsx
let x; // undefined (자동 할당)
let y = null; // null (의도적 할당)
```

- **핵심** : `undefined`는 "아직 정해지지 않음", `null`은 "의도적으로 비움"을 나타냅니다

```jsx
  // 여기에 코드를 작성하세요
```

```jsx
function safeGetUpperCase(value) {
  // typeof로 문자열인지 확인
  if (typeof value === "string") {
    return value.toUpperCase();
  } else {
    console.log(`⚠️ 입력값이 문자열이 아닙니다. (타입: ${typeof value})`);
    return value;
  }
}

// 테스트 실행
console.log(safeGetUpperCase("hello"));
// 출력: HELLO

console.log(safeGetUpperCase(123));
// 출력: ⚠️ 입력값이 문자열이 아닙니다. (타입: number)
//       123

console.log(safeGetUpperCase(true));
// 출력: ⚠️ 입력값이 문자열이 아닙니다. (타입: boolean)
//       true

console.log(safeGetUpperCase(null));
// 출력: ⚠️ 입력값이 문자열이 아닙니다. (타입: object)
//       null

// 개선 버전 - null도 정확히 체크
function safeGetUpperCaseImproved(value) {
  if (value === null) {
    console.log("⚠️ 입력값이 null입니다.");
    return value;
  }

  if (typeof value === "string") {
    return value.toUpperCase();
  } else {
    console.log(`⚠️ 입력값이 문자열이 아닙니다. (타입: ${typeof value})`);
    return value;
  }
}
```

**핵심 개념** :

- 런타임 오류를 예방하는 패턴

### 문제 5: 동적 타입 변환 추적기

**문제** :
변수에 여러 자료형의 값을 순차적으로 할당하면서, 각 단계마다 값과 타입을 추적하는 프로그램을 작성하세요.

**요구사항** :

- 변수 하나를 선언
- 5가지 이상의 서로 다른 자료형 값을 순차적으로 할당
- 각 할당마다 현재 값과 타입을 출력
- 템플릿 리터럴 사용

  **골자** :

```jsx
// 여기에 코드를 작성하세요
let myVariable;

// 1단계: undefined 상태
// 2단계: 숫자 할당
// 3단계: 문자열 할당
// 4단계: 불리언 할당
// 5단계: null 할당
```

---

**정답 및 해설** :

```jsx
function trackTypeChanges() {
  let myVariable;
  let step = 1;

  // 1단계: undefined 상태
  console.log(`[${step++}단계] 값: ${myVariable}, 타입: ${typeof myVariable}`);

  // 2단계: 숫자 할당
  myVariable = 42;
  console.log(`[${step++}단계] 값: ${myVariable}, 타입: ${typeof myVariable}`);

  // 3단계: 문자열 할당
  myVariable = "안녕하세요";
  console.log(`[${step++}단계] 값: ${myVariable}, 타입: ${typeof myVariable}`);

  // 4단계: 불리언 할당
  myVariable = true;
  console.log(`[${step++}단계] 값: ${myVariable}, 타입: ${typeof myVariable}`);

  // 5단계: null 할당
  myVariable = null;
  console.log(
    `[${step++}단계] 값: ${myVariable}, 타입: ${typeof myVariable} (⚠️ 실제로는 null)`
  );

  // 6단계: 배열 할당 (보너스)
  myVariable = [1, 2, 3];
  console.log(`[${step++}단계] 값: ${myVariable}, 타입: ${typeof myVariable}`);
}

trackTypeChanges();

// 출력:
// [1단계] 값: undefined, 타입: undefined
// [2단계] 값: 42, 타입: number
// [3단계] 값: 안녕하세요, 타입: string
// [4단계] 값: true, 타입: boolean
// [5단계] 값: null, 타입: object (⚠️ 실제로는 null)
// [6단계] 값: 1,2,3, 타입: object
```

**핵심 개념** :

- JavaScript의 동적 타입 특성 체험
- 같은 변수에 다른 타입 값 재할당 가능
- 템플릿 리터럴로 가독성 높은 출력
- `null`의 `typeof` 오류 인지
