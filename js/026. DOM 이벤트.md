## 1️⃣ addEventListener - 이벤트 리스너의 핵심

### 📌 기본 개념

**언제 쓰나요?**
- 버튼 클릭, 마우스 이동, 키보드 입력 등 사용자 행동에 반응해야 할 때
- HTML 요소에 인라인으로 `onclick="..."` 쓰는 것보다 훨씬 권장되는 방식
- 하나의 요소에 여러 개의 이벤트 핸들러를 등록할 수 있음

**기본 문법**:
```javascript
요소.addEventListener('이벤트명', 콜백함수);
```

**실전 예시**:
```javascript
const button = document.querySelector('#myButton');

// 클릭 시 실행할 함수 등록
button.addEventListener('click', () => {
  console.log('버튼이 클릭되었습니다!');
});
```

## 2️⃣ 주요 이벤트 타입별 활용법

### 🖱️ click - 클릭 이벤트

```javascript
document.querySelector('#button1')
```

```javascript
// 삭제 확인 후 실행
deleteButton.addEventListener('click', () => {

    deleteItem();
  }
});
```

### 🎯 이벤트 객체 (Event Object)

**언제 필요한가요?**
- 어떤 요소가 클릭되었는지 알아야 할 때
- 키보드 어떤 키가 눌렸는지 확인할 때
- 마우스 좌표가 필요할 때

```javascript
button.addEventListener('click', (e) => {
  console.log(e);  // 이벤트 정보가 담긴 객체
  console.log(e.target);  // 이벤트가 발생한 실제 요소
  console.log(e.type);  // 'click'
});
```

**자주 사용하는 이벤트 객체 속성**:
| 속성 | 의미 | 사용 예시 |
|------|------|-----------|
| `e.target` | 이벤트가 발생한 요소 | 클릭된 버튼 찾기 |
| `e.key` | 눌린 키 | 'Enter', 'Escape' 등 |
| `e.preventDefault()` | 기본 동작 막기 | 폼 제출 방지 |
| `e.stopPropagation()` | 이벤트 전파 중단 | 부모 요소로 전파 막기 |

### ⚠️ this vs e.target - 헷갈리는 포인트!

**일반 함수에서의 this**:
```javascript
button.addEventListener('click', function(e) {
  console.log(this);  // button 요소 자체
  console.log(e.target);  // button 요소 자체
  
  this.textContent = '클릭됨';  // ✅ 작동함
});
```

**화살표 함수에서의 this**:
```javascript
button.addEventListener('click', (e) => {
  console.log(this);  // Window 객체 (상위 스코프)
  console.log(e.target);  // button 요소
  
  // this.textContent = '클릭됨';  // ❌ 작동 안 함!
  e.target.textContent = '클릭됨';  // ✅ 이렇게 사용
});
```

**핵심 정리**:
- 일반 함수: `this`가 이벤트가 발생한 요소를 가리킴
- 화살표 함수: `this`가 상위 스코프를 가리킴 → `e.target` 사용 필수!

**실무에서는?**
```javascript
// ✅ 추천: 화살표 함수 + e.target (명확함)
button.addEventListener('click', (e) => {
  e.target.classList.add('active');
});

// ✅ 가능: 일반 함수 + this (간결함)
button.addEventListener('click', function() {
  this.classList.add('active');
});
```

### 🐭 mouseenter / mouseleave - 마우스 진입/이탈

**언제 쓰나요?**
- 호버(hover) 효과 구현
- 툴팁 표시/숨김
- 드롭다운 메뉴 제어

```javascript
const hoverBox = document.querySelector('#hoverBox');

hoverBox.addEventListener('mouseenter', () => {
  console.log('마우스가 들어왔어요!');
  hoverBox.style.backgroundColor = 'lightblue';
});

hoverBox.addEventListener('mouseleave', () => {
  console.log('마우스가 나갔어요!');
  hoverBox.style.backgroundColor = 'white';
});
```

**실무 패턴 - 타이머와 함께 사용**:
```javascript
const tooltip = document.querySelector('#tooltip');
let timeoutId;

button.addEventListener('mouseenter', () => {
  // 이전 타이머가 있다면 취소
  if (timeoutId) clearTimeout(timeoutId);
  
  // 5초 후 경고 표시
  timeoutId = setTimeout(() => {
    tooltip.textContent = '⚠️ 너무 오래 머물렀습니다';
  }, 5000);
});

button.addEventListener('mouseleave', () => {
  // 마우스가 나가면 타이머 취소
  if (timeoutId) clearTimeout(timeoutId);
  tooltip.textContent = '';
});
```

### ⏱️ setTimeout / setInterval 활용

**setTimeout - 일정 시간 후 한 번 실행**:
```javascript
// 3초 후 실행
const timeoutId = setTimeout(() => {
  console.log('3초가 지났습니다');
}, 3000);

// 취소하고 싶다면
clearTimeout(timeoutId);
```

**setInterval - 일정 간격마다 반복 실행**:
```javascript
let count = 5;

// 1초마다 실행
const intervalId = setInterval(() => {
  console.log(count);
  count--;
  
  if (count === 0) {
    clearInterval(intervalId);  // 0이 되면 중단
  }
}, 1000);
```

**실무 예제 - 카운트다운 구현**:
```javascript
const countdownDisplay = document.querySelector('#countdown');
let countdown = 10;
let intervalId;

startButton.addEventListener('click', () => {
  // 기존 인터벌이 있다면 정리
  if (intervalId) clearInterval(intervalId);
  
  countdown = 10;
  countdownDisplay.textContent = countdown;
  
  intervalId = setInterval(() => {
    countdown--;
    countdownDisplay.textContent = countdown;
    
    if (countdown === 0) {
      clearInterval(intervalId);
      alert('시간 종료!');
    }
  }, 1000);
});
```

**💡 주의사항**:
- `setTimeout`과 `setInterval`은 반드시 `clear` 해주기
- 안 그러면 메모리 누수 발생 가능
- 컴포넌트 언마운트 시 정리 필수

### 📝 focus / blur - 입력 필드 포커스

**언제 쓰나요?**
- 입력창 클릭 시 안내 문구 표시
- 입력 검증 (유효성 체크)
- 자동 완성 기능

```javascript
const input = document.querySelector('#emailInput');

// 포커스될 때 (클릭하거나 탭으로 선택)
input.addEventListener('focus', () => {
  input.placeholder = '이메일을 입력하세요';
  input.style.borderColor = 'blue';
});

// 포커스 해제될 때 (다른 곳 클릭)
input.addEventListener('blur', () => {
  input.placeholder = '';
  input.style.borderColor = 'gray';
  
  // 검증 로직 추가 가능
  if (!input.value.includes('@')) {
    alert('올바른 이메일 형식이 아닙니다');
  }
});
```

**실무 패턴**:
```javascript
// 입력 시작 시 에러 메시지 숨기기
input.addEventListener('focus', () => {
  errorMessage.style.display = 'none';
});

// 입력 완료 시 유효성 검사
input.addEventListener('blur', () => {
  if (input.value.length < 8) {
    errorMessage.textContent = '최소 8자 이상 입력하세요';
    errorMessage.style.display = 'block';
  }
});
```

### ⌨️ keyup - 키보드 입력 처리

**언제 쓰나요?**
- Enter 키로 검색/제출
- ESC 키로 모달 닫기
- 실시간 검색 기능

```javascript
const searchInput = document.querySelector('#search');

searchInput.addEventListener('keyup', (e) => {
  console.log('입력된 키:', e.key);
  console.log('현재 값:', e.target.value);
});
```

**keydown vs keypress vs keyup - 헷갈리는 포인트!**
| 이벤트 | 발생 시점 | 사용 시나리오 |
|--------|-----------|---------------|
| `keydown` | 키를 누르는 순간 | 게임 조작, 방향키 감지 |
| `keypress` | 문자 입력 시 | ⚠️ 더 이상 권장되지 않음 |
| `keyup` | 키에서 손을 뗄 때 | 입력 완료 후 처리 (추천) |

**실무 패턴 - Enter로 항목 추가**:
```javascript
const input = document.querySelector('#todoInput');
const list = document.querySelector('#todoList');

input.addEventListener('keyup', (e) => {
  // Enter가 아니면 무시
  if (e.key !== 'Enter') return;
  
  // 빈 값이면 무시
  if (!e.target.value.trim()) return;
  
  // 새 항목 생성
  const newItem = document.createElement('li');
  newItem.textContent = e.target.value;
  list.appendChild(newItem);
  
  // 입력창 비우기
  e.target.value = '';
});
```

**자주 사용하는 키 값들**:
```javascript
e.key === 'Enter'     // 엔터
e.key === 'Escape'    // ESC
e.key === 'ArrowUp'   // 위쪽 화살표
e.key === 'ArrowDown' // 아래쪽 화살표
e.key === ' '         // 스페이스바
```

### 🔄 change - 값 변경 감지

**언제 쓰나요?**
- `<select>` 드롭다운 선택 변경
- 체크박스 체크/해제
- 숫자 입력 (`<input type="number">`)
- 필터링, 정렬 기능 구현

```javascript
// 드롭다운 선택 변경
const schoolSelect = document.querySelector('#school');

schoolSelect.addEventListener('change', (e) => {
  console.log('선택된 값:', e.target.value);
  filterBySchool(e.target.value);
});
```

**input vs change - 언제 뭘 써야 할까?**
| 이벤트 | 발생 시점 | 사용 예시 |
|--------|-----------|-----------|
| `input` | 입력값이 바뀔 때마다 (실시간) | 실시간 검색, 글자수 카운트 |
| `change` | 입력 완료 후 포커스 이탈 시 | 폼 제출, 필터링 |


**체크박스 활용**:
```javascript
const checkbox = document.querySelector('#sortCheckbox');

checkbox.addEventListener('change', (e) => {
  if (e.target.checked) {
```

## 3️⃣ 여러 이벤트 핸들러 등록하기

### 🎨 같은 요소, 같은 이벤트에 여러 핸들러 가능!

**언제 유용한가요?**
- 하나의 동작이 여러 기능을 수행해야 할 때
- 코드를 기능별로 분리하고 싶을 때

```javascript
const button = document.querySelector('#multiButton');

// 첫 번째 핸들러 - 로그 기록
button.addEventListener('click', () => {
  console.log('버튼이 클릭되었습니다');
});

// 두 번째 핸들러 - 애니메이션
button.addEventListener('click', () => {
  button.classList.add('animate');
});

// 세 번째 핸들러 - 데이터 전송
button.addEventListener('click', () => {
  sendAnalytics('button_clicked');
});
```

**실무 패턴**:
```javascript
// 기능별로 분리하여 관리
function logClick() {
  console.log('클릭됨');
}

function updateUI() {
  button.textContent = '완료!';
}

function sendData() {
  fetch('/api/click', { method: 'POST' });
}

// 모두 등록
button.addEventListener('click', logClick);
button.addEventListener('click', updateUI);
button.addEventListener('click', sendData);
```

## 4️⃣ 실전 종합 예제

### 📊 동적 테이블 필터링 시스템

```javascript
// HTML 구조
/*
<select id="school">
  <option value="">전체 학교</option>
  <option value="근성">근성대</option>
  <option value="복근">복근대</option>
</select>

<input type="number" id="grade" min="1" max="4">
<input type="checkbox" id="sort">
<table id="raceTable">...</table>
*/

const schoolSelect = document.querySelector('#school');
const gradeInput = document.querySelector('#grade');
const sortCheckbox = document.querySelector('#sort');
const tableBody = document.querySelector('#raceTbody');

// 모든 필터에 change 이벤트 등록
schoolSelect.addEventListener('change', fillRaceTable);
gradeInput.addEventListener('change', fillRaceTable);
sortCheckbox.addEventListener('change', fillRaceTable);

function fillRaceTable() {
  // 현재 필터 값들 가져오기
  const selectedSchool = schoolSelect.value;
  const minGrade = parseInt(gradeInput.value);
  const shouldSort = sortCheckbox.checked;
  
  // 데이터 필터링
  let filteredData = raceData.filter(student => {
    // 학교 필터
    if (selectedSchool && student.school !== selectedSchool) {
      return false;
    }
    
    // 학년 필터
    if (student.grade < minGrade) {
      return false;
    }
    
    return true;
  });
  
  // 정렬 (체크박스가 선택되었을 때만)
  if (shouldSort) {
    filteredData.sort((a, b) => a.record - b.record);
  }
  
  // 테이블 업데이트
  tableBody.innerHTML = '';
  filteredData.forEach((student, index) => {
    const row = document.createElement('tr');
    row.innerHTML = `
      <td>${index + 1}</td>
      <td>${student.school}</td>
      <td>${student.grade}</td>
      <td>${student.name}</td>
      <td>${student.record}초</td>
    `;
    tableBody.appendChild(row);
  });
}
```

## 📌 핵심 요약

### 🎯 이벤트 타입 빠른 참조

| 이벤트 | 발생 시점 | 주요 용도 | 이벤트 객체 주요 속성 |
|--------|-----------|-----------|------------------------|
| `click` | 요소 클릭 | 버튼, 링크 동작 | `e.target` |
| `mouseenter` | 마우스 진입 | 호버 효과, 툴팁 | - |
| `mouseleave` | 마우스 이탈 | 호버 효과 해제 | - |
| `focus` | 입력 필드 선택 | 안내 문구, 스타일 변경 | `e.target` |
| `blur` | 포커스 해제 | 유효성 검사 | `e.target.value` |
| `keyup` | 키보드 입력 완료 | Enter 처리, 검색 | `e.key`, `e.target.value` |
| `change` | 값 변경 완료 | 드롭다운, 체크박스 | `e.target.value`, `e.target.checked` |
| `input` | 실시간 입력 | 실시간 검색, 글자수 | `e.target.value` |

### 💡 자주 헷갈리는 포인트

**1. this vs e.target**
- 일반 함수: `this` 사용 가능
- 화살표 함수: `e.target` 사용 필수

**2. keyup vs keydown**
- keydown: 키를 누르는 순간 (게임 조작)
- keyup: 키에서 손을 뗄 때 (입력 처리, 추천)

**3. input vs change**
- input: 타이핑할 때마다 (실시간)
- change: 입력 완료 후 포커스 이탈 시

**4. mouseenter vs mouseover**
- mouseenter: 자식 요소 영향 받지 않음 (추천)
- mouseover: 자식 요소 진입 시에도 발생

**5. setTimeout/setInterval 정리**
- 항상 `clearTimeout`, `clearInterval` 호출
- 컴포넌트 제거 시 정리 필수 (메모리 누수 방지)

### 🛠️ 실무 체크리스트

**이벤트 리스너 등록 시**
- ✅ 화살표 함수 사용 (명확성)
- ✅ 이벤트 객체 활용 (`e.target`, `e.key` 등)
- ✅ 조건문으로 불필요한 실행 방지 (`if (e.key !== 'Enter') return;`)

**타이머 사용 시**
- ✅ 변수에 ID 저장 (`const timeoutId = setTimeout(...)`)
- ✅ 새 타이머 전에 기존 타이머 정리 (`clearTimeout(timeoutId)`)
- ✅ 컴포넌트 종료 시 정리

**입력 처리 시**
- ✅ 빈 값 검증 (`if (!value.trim()) return;`)
- ✅ 입력 후 필드 초기화 (`input.value = ''`)
- ✅ 적절한 이벤트 선택 (실시간 vs 완료 시)

## 🧪 복습 퀴즈

### Q1. 다음 중 화살표 함수를 이벤트 핸들러로 사용할 때 올바른 코드는?

```javascript
button.addEventListener('click', (e) => {
  // 버튼 텍스트를 '클릭됨'으로 변경하려고 합니다
});
```

1. `this.textContent = '클릭됨';`
2. `e.target.textContent = '클릭됨';`
3. `button.textContent = '클릭됨';`
4. 2번과 3번 모두 가능
5. 1번과 2번 모두 가능

**정답: 4번**

화살표 함수에서 `this`는 상위 스코프를 가리키므로 1번은 작동하지 않습니다. 2번의 `e.target`은 클릭된 요소(여기서는 button)를 정확히 가리키므로 작동합니다. 3번도 외부에서 선언된 `button` 변수를 직접 참조하므로 작동합니다. 따라서 2번과 3번 모두 올바른 방법입니다.

### Q2. 사용자가 입력창에 타이핑할 때마다 실시간으로 검색 결과를 보여주려고 합니다. 어떤 이벤트를 사용해야 하나요?

1. `change`
2. `keyup`
3. `input`
4. `blur`
5. `focus`

**정답: 3번**

`input` 이벤트는 입력값이 변경될 때마다 즉시 발생하여 실시간 검색에 가장 적합합니다. `change`는 입력 완료 후 포커스를 이탈해야 발생하고, `keyup`은 키보드로만 입력할 때만 감지되며 붙여넣기 등은 감지하지 못합니다. `blur`와 `focus`는 입력값 변경과는 관계없는 포커스 관련 이벤트입니다.

### Q3. 다음 코드에서 메모리 누수가 발생할 수 있는 부분은?

```javascript
button.addEventListener('mouseenter', () => {
  setTimeout(() => {
    showWarning();
  }, 5000);
});

button.addEventListener('mouseleave', () => {
  // 아무 것도 하지 않음
});
```

1. `addEventListener` 사용
2. `setTimeout`을 정리하지 않음
3. 화살표 함수 사용
4. `showWarning` 함수 호출
5. 문제 없음

**정답: 2번**

마우스가 들어올 때마다 `setTimeout`이 새로 생성되지만, `clearTimeout`으로 정리하지 않으면 이전 타이머들이 계속 실행됩니다. 사용자가 마우스를 빠르게 여러 번 움직이면 여러 타이머가 동시에 실행될 수 있습니다. 올바른 코드는 `setTimeout`의 반환값을 변수에 저장하고, `mouseleave`나 다음 `mouseenter`에서 `clearTimeout`으로 정리해야 합니다.

### Q4. Enter 키를 눌렀을 때만 할 일 목록에 항목을 추가하려고 합니다. 빈칸에 들어갈 코드는?

```javascript
input.addEventListener('keyup', (e) => {
  if (______) return;
  
  addTodoItem(e.target.value);
  e.target.value = '';
});
```

1. `e.key === 'Enter'`
2. `e.key !== 'Enter'`
3. `e.target.value === ''`
4. `e.keyCode === 13`
5. `e.type === 'keyup'`

**정답: 2번**

Enter 키가 **아닐 때** 함수를 종료(return)해야 하므로 `!==` 연산자를 사용합니다. 이는 "가드 클로즈(guard clause)" 패턴으로, 불필요한 실행을 조기에 차단하는 실무에서 자주 사용하는 패턴입니다. 1번은 Enter일 때 종료되므로 반대로 작동하고, 4번은 구식 방법이며 현대 JavaScript에서는 `e.key` 사용을 권장합니다.

### Q5. 체크박스의 체크 상태를 확인하려면 어떤 속성을 사용해야 하나요?

```javascript
const checkbox = document.querySelector('#myCheckbox');

checkbox.addEventListener('change', (e) => {
  if (______) {
    console.log('체크됨');
  }
});
```

1. `e.target.value`
2. `e.target.selected`
3. `e.target.checked`
4. `e.target.status`
5. `e.checked`

**정답: 3번**

체크박스와 라디오 버튼의 체크 상태는 `checked` 속성으로 확인합니다. 이 값은 `true` 또는 `false`를 반환합니다. `value`는 체크박스의 값(보통 'on')을 반환하며 체크 여부와는 무관합니다. `selected`는 `<select>` 요소의 옵션에 사용되는 속성입니다. 5번의 `e.checked`는 존재하지 않는 속성입니다.
