## 1. 콘솔(Console) 기초

### 1.1 콘솔이란?

**콘솔**은 자바스크립트 자체의 기능이 아니라 **실행 환경에서 제공하는 기능**입니다.

- **브라우저** : Web API의 일부로 제공
- **Node.js** : 디버깅을 위한 모듈로 제공 (브라우저와 유사하게 동작)
- **특징** : 소프트웨어 외적으로 영향을 끼치지 않는 개발자 전용 도구

### 1.2 console.log() 문법

| 구분                   | 문법                         | 설명                                                  | 예시 코드                                |
| ---------------------- | ---------------------------- | ----------------------------------------------------- | ---------------------------------------- |
| **기본 사용**          | `console.log(값)`            | 단일 값을 콘솔에 출력                                 | `console.log('Hello World!')`            |
| **다중 출력**          | `console.log(값1, 값2, ...)` | 여러 값을 쉼표로 구분하여 출력                        | `console.log('Hi!', 100, true)`          |
| **다양한 데이터 타입** | `console.log(데이터)`        | 문자열, 숫자, 불린, 객체, 배열 등 모든 타입 출력 가능 | `console.log({name: '홍길동', age: 20})` |

**예시 코드:**

```jsx
console.log("Hello World!"); // 문자열 출력
console.log(1); // 숫자 출력
console.log(true); // 불린 출력
console.log({ name: "홍길동", age: 20, married: false }); // 객체 출력
console.log("Hi!", 100, true, [1, 2, 3]); // 여러 값 동시 출력
```

### 1.3 실행 환경별 사용법

| 환경                  | 사용 방법                       | 설명                             | 단축키/명령어                     |
| --------------------- | ------------------------------- | -------------------------------- | --------------------------------- |
| **브라우저 콘솔**     | F12 개발자 도구 → Console 탭    | 가장 직관적이고 빠른 테스트 환경 | 콘솔 비우기:`Ctrl + L`            |
| **Node.js REPL**      | 터미널에서 `node`입력           | Read-Eval-Print-Loop 대화형 모드 | 종료:`Ctrl + C`2회                |
| **Node.js 파일 실행** | `.js`파일 작성 후 `node 파일명` | 실제 개발 환경과 유사            | Code Runner:`Ctrl + Alt + N`(Win) |

### 1.4 콘솔의 다양한 메서드

| 메서드                                    | 용도               | 사용 상황                                  | 예시                                  |
| ----------------------------------------- | ------------------ | ------------------------------------------ | ------------------------------------- |
| **console.log()**                         | 일반적인 로그 출력 | 기본적인 디버깅, 값 확인                   | `console.log('로그 - 기본적인 출력')` |
| **[console.info](http://console.info)()** | 정보성 로그        | 기능적으로는 log와 동일하나 용도 구분 가능 | `console.info('로그 - 정보')`         |
| **console.warn()**                        | 경고 메시지        | 문제가 될 수 있는 부분 표시 (노란색)       | `console.warn('경고 - 주의 필요')`    |
| **console.error()**                       | 에러 메시지        | 오류 발생 상황 표시 (빨간색)               | `console.error('오류 - 에러 발생')`   |

### 1.5 주석(Comment)

**주석**은 컴퓨터는 무시하고 사람만 읽는 메시지입니다.

| 종류             | 문법         | 사용 상황                   | 예시                          |
| ---------------- | ------------ | --------------------------- | ----------------------------- |
| **한 줄 주석**   | `// 내용`    | 짧은 설명, 코드 옆 메모     | `// 사용자 정보를 가져옴`     |
| **여러 줄 주석** | `/* 내용 */` | 긴 설명, 코드 블록 비활성화 | `/* 이 함수는 ... */`         |
| **주석 토글**    | 단축키 사용  | 빠르게 주석 처리/해제       | Win:`Ctrl + /`, Mac:`Cmd + /` |

```jsx
console.log("Hello");
// 이 줄은 실행되지 않습니다
// console.log('나를 밟고 가라');
console.log("World");

/*
여러 줄에 걸친
긴 설명을 작성할 때 사용
console.log('이것도 실행 안 됨');
*/
```

**💡 주석 작성 원칙:**

- 주석은 가능한 한 **적게** 사용하는 것이 좋음
- 주석 없이도 이해되는 명확한 코드 작성이 목표
- 주석이 많이 필요한 코드 = 개선이 필요한 코드

## 2. 변수(Variable)와 상수(Constant)

### 2.1 변수와 상수의 개념

**변수**와 **상수**는 데이터를 담는 "주머니"입니다.

| 구분     | 키워드  | 값 변경 가능 여부 | 사용 상황                | 명명 규칙                |
| -------- | ------- | ----------------- | ------------------------ | ------------------------ |
| **변수** | `let`   | ✅ 가능           | 값이 변할 수 있는 데이터 | 소문자 camelCase         |
| **상수** | `const` | ❌ 불가능         | 값이 변하지 않는 데이터  | 대문자 SNAKE_CASE (권장) |

**⚠️ var는 사용하지 마세요!**

- 과거에 사용되던 키워드로 많은 문제점 존재
- 현대 JavaScript에서는 `let`과 `const`만 사용

### 2.2 변수(let) 사용법

### (1) 선언과 초기화

| 방식              | 코드         | 설명                                    | 초기값      |
| ----------------- | ------------ | --------------------------------------- | ----------- |
| **선언만**        | `let x;`     | 변수를 만들기만 하고 값은 나중에 할당   | `undefined` |
| **선언 + 초기화** | `let x = 1;` | 변수를 만들면서 동시에 값 할당 (일반적) | 지정한 값   |

```jsx
// 방식 1: 선언만
let x;
console.log(x); // undefined
x = 1;
console.log(x); // 1

// 방식 2: 선언과 동시에 초기화 (권장)
let y = 2;
console.log(y); // 2
```

**💡 undefined란?**

- "아직 값이 정해지지 않았다"는 의미를 가진 특수한 값
- 변수를 선언만 하고 값을 할당하지 않으면 자동으로 할당됨

### (2) 변수의 값 복사

```jsx
let x = 1;
let y = x; // x의 값(1)을 y에 복사

console.log(x, y); // 1 1

x = "Hello!";
console.log(x, y); // 'Hello!' 1
```

**⭐ 중요 개념:**

- `let y = x;`는 x가 가리키는 **값을 복사**하는 것
- 메모리상 같은 값은 중복 저장되지 않음 (메모리 절약)
- x를 변경해도 y는 영향을 받지 않음

### (3) 변수의 재할당

```jsx
let x = 1; // 숫자 할당
console.log(x); // 1

x = "Hello!"; // 문자열로 재할당
console.log(x); // 'Hello!'

x = [1, 2, 3]; // 배열로 재할당
console.log(x); // [1, 2, 3]
```

**⭐ JavaScript의 특징:**

- C언어 등과 달리 메모리상 **가리키는 위치 자체가 변경**됨
- 다른 자료형의 데이터로 자유롭게 재할당 가능 (동적 타입)

### (4) 변수 재선언 불가

```jsx
let x = 1;
console.log("첫 선언", x);

let x = 2; // ❌ 오류 발생!
```

**규칙:**

- 이미 선언된 변수는 다시 선언할 수 없음
- `var`는 재선언이 가능했으나, 이것이 문제가 되어 `let`이 도입됨

### (5) 선언 전 사용 불가

```jsx
console.log(xyz); // ❌ 오류 발생!
let xyz = 1;
```

### 2.3 상수(const) 사용법

### (1) 선언과 초기화

```jsx
const PI = 3.14;
console.log("원주율:", PI); // 원주율: 3.14
```

**규칙:**

- 상수는 **반드시 선언과 동시에 초기화**해야 함
- 선언만 하는 것은 불가능

```jsx
const PI;      // ❌ 오류 발생!
PI = 3.14;

```

### (2) 값 변경 불가

```jsx
const PI = 3.14;
PI = 3.14159; // ❌ 오류 발생!
```

**⭐ 중요 원칙:**

- 값이 변하지 않을 데이터는 **반드시 상수로 선언**
- 의도치 않은 값 변경 방지
- 코드의 의도를 명확히 전달

### (3) 상수 명명 규칙

| 상황                     | 명명 방식           | 예시                       |
| ------------------------ | ------------------- | -------------------------- |
| **공통 값, 설정값**      | 대문자 + 언더스코어 | `const MAX_SIZE = 100;`    |
| **일반적인 불변 데이터** | camelCase           | `const userName = 'John';` |

### 2.4 여러 변수/상수 동시 선언

```jsx
// 개별 선언
let a = 1;
let b = 2;
let c = 3;

// 동시 선언 (권장)
let a = 1,
  b = 2,
  c = 3;
const X = 4,
  Y = 5,
  Z = 6;

console.log(a, b, c); // 1 2 3
console.log(X, Y, Z); // 4 5 6
```

## 3. 식별자(Identifier) 명명 규칙

### 3.1 식별자란?

**식별자**는 변수, 상수, 함수 등의 이름을 의미합니다.

### 3.2 명명 규칙

| 규칙                 | 가능 여부 | 예시               | 설명               |
| -------------------- | --------- | ------------------ | ------------------ | --- | --- |
| **영문자**           | ✅        | `userName`,`age`   | 대소문자 구분      |
| **한글 및 유니코드** | ✅        | `이름`,`나이`      | 현대에는 종종 사용 |
| **숫자**             | ✅        | `user1`,`data2`    | 첫 글자는 불가     |
| **특수문자$ \_**     | ✅        | `_name`,`$price`   | 이 두 가지만 가능  |     |     |
| **숫자로 시작**      | ❌        | `1user`            | 불가능             |
| **공백(스페이스)**   | ❌        | `user name`        | 불가능             |
| **예약어**           | ❌        | `let`,`const`,`if` | 불가능             |

**예시:**

```jsx
// ✅ 올바른 식별자
let userName = '홍길동';
let _privateValue = 100;
let $price = 5000;
let user1 = 'Kim';

// ❌ 잘못된 식별자
let 1user = 'Kim';      // 숫자로 시작 불가
let user-name = 'Kim';  // 하이픈 사용 불가
let user name = 'Kim';  // 공백 사용 불가

```

### 3.3 예약어(Reserved Words)

**예약어**는 JavaScript 문법에서 이미 사용 중인 단어로, 식별자로 사용할 수 없습니다.

```jsx
const let = 1;        // ❌ 오류!
let typeof = 2;       // ❌ 오류!
const function = 3;   // ❌ 오류!

```

**주요 예약어:** `let`, `const`, `var`, `function`, `if`, `else`, `for`, `while`, `return`, `class`, `typeof` 등

### 3.4 한글 식별자

```jsx
const 이름 = "홍길동";
let 나이 = 20;

console.log(이름, 나이); // 홍길동 20
```

**특징:**

- 예전에는 권장되지 않았으나, 현대에는 일부 기업에서 사용
- 도메인 특화 용어를 명확히 표현할 때 유용
- 국제 협업이 많은 프로젝트에서는 여전히 영문 권장

## 4. 메모리와 데이터 저장 구조

### 4.1 컴퓨터의 작업 구조

| 구성 요소                  | 비유         | 역할                       | 특징         |
| -------------------------- | ------------ | -------------------------- | ------------ |
| **CPU**                    | 일하는 사람  | 작업을 실행하는 주체       | 컴퓨터의 뇌  |
| **보조기억장치**(SSD, HDD) | 서랍         | 프로그램과 파일 저장       | 공간↑, 속도↓ |
| **메모리**(RAM)            | 책상 위 공간 | 실행 중인 데이터 임시 저장 | 공간↓, 속도↑ |

### 4.2 변수/상수와 메모리

```jsx
let userName = "홍길동";
const PI = 3.14;
```

**메모리 동작:**

1. **변수/상수 선언** : 메모리(RAM)에 공간 할당
2. **값 할당** : 해당 공간에 데이터 저장
3. **값 사용** : CPU가 메모리에서 데이터를 읽어옴
4. **값 변경** (변수만): 메모리의 다른 위치를 가리킴

**⭐ 메모리 효율성:**

- 같은 값은 메모리에 중복 저장되지 않음
- 여러 변수가 같은 값을 가질 때 동일한 메모리 위치를 참조
- 효율적인 메모리 사용을 위해 적절한 변수/상수 선택이 중요

### 4.3 JavaScript의 메모리 관리 특징

```jsx
let x = 1; // 숫자 저장
x = "Hello!"; // 문자열로 변경 → 메모리 위치 자체가 변경됨
```

**다른 언어(C, Java 등)와의 차이:**

- C언어: 변수 선언 시 자료형 고정, 같은 메모리 위치에서 값만 변경
- JavaScript: 자료형이 자유롭게 변경 가능, 메모리 위치도 변경됨

## 📝 항목별 핵심 요약

### 1. 콘솔 핵심 요약

- **콘솔은 자바스크립트가 아닌 실행 환경의 기능** (브라우저 Web API, Node.js 모듈)
- `console.log()`, `console.warn()`, `console.error()` 등으로 디버깅
- 주석(`//`, `/* */`)은 최소한으로 사용, 코드 자체가 명확해야 함

### 2. 변수와 상수 핵심 요약

- **변수(`let`)** : 값이 변할 수 있는 데이터 저장
- **상수(`const`)** : 값이 변하지 않는 데이터 저장 (선언과 동시에 초기화 필수)
- **var는 사용 금지** , let과 const만 사용
- 같은 이름으로 재선언 불가, 선언 전 사용 불가

### 3. 식별자 핵심 요약

- 영문, 한글, 숫자, `$`, `_` 사용 가능
- 숫자로 시작 불가, 공백 불가
- 예약어(`let`, `const`, `if` 등) 사용 불가
- 명확하고 의미 있는 이름 사용 권장

### 4. 메모리 핵심 요약

- 변수/상수는 **메모리(RAM)에 저장**되어 빠르게 접근
- 같은 값은 중복 저장되지 않아 메모리 효율적
- JavaScript는 재할당 시 메모리 위치 자체가 변경됨
- 메모리 효율을 위해 적절한 변수/상수 선택 중요


<details>
<summary><b>정답 및 해설 보기</b></summary>

**정답: B**

**해설:**

- 콘솔은 자바스크립트 자체의 기능이 아니라 **실행 환경(런타임)에서 제공하는 기능**입니다.
- 브라우저에서는 Web API의 일부로, Node.js에서는 디버깅 모듈로 제공됩니다.
- 콘솔 출력은 개발자 도구에서만 확인 가능하며, 일반 사용자에게는 보이지 않습니다.
- `console.log()` 외에도 `console.warn()`, `console.error()`, `console.info()` 등 다양한 메서드가 있습니다.

</details>

```
C) JavaScript에서 재할당 시 메모리의 가리키는 위치 자체가 변경된다
```

컴퓨터 구조: CPU(작업 수행) ↔ RAM(임시 저장, 빠름) ↔ SSD/HDD(영구 저장, 느림)

### Q8. 다음 중 `let`과 `const`의 차이점으로 **올바른 것**은?

```
A) let은 재할당 불가능하고, const는 재할당 가능하다
B) let은 선언만 가능하고, const는 선언만 불가능하다
C) let으로 선언한 변수는 재선언이 가능하다
D) const는 반드시 대문자로 작성해야 한다

```

<details>
<summary><b>정답 및 해설 보기</b></summary>

**정답: B**

**해설:**

- **A** : 반대입니다. `let`은 재할당 가능, `const`는 재할당 불가능
- **B** : 올바른 설명 ✅
- `let`은 선언만 하고 나중에 값 할당 가능: `let x; x = 1;`
- `const`는 선언과 동시에 초기화 필수: `const x = 1;`
- **C** : `let`으로 선언한 변수는 재선언이 **불가능**합니다
- **D** : `const`는 일반적으로 대문자로 작성하지만, 이것은 관례일 뿐 필수는 아닙니다

핵심: `let`은 유연하고, `const`는 엄격합니다.

</details>
