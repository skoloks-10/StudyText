## 1. 전역 객체 (Global Object)

### 1.1 개념

**전역 객체**는 코드로 선언하지 않아도 전역 범위에 항상 존재하는 객체입니다. 언제 어디서든 접근 가능한 공기와 같은 존재입니다.

**출처** : ECMAScript 사양에서 정의
**MDN 문서** : [Global Object](https://developer.mozilla.org/ko/docs/Glossary/Global_object)

### 1.2 환경별 전역 객체

| 환경        | 전역 객체 식별자         |
| ----------- | ------------------------ |
| 브라우저    | `window`,`self`,`frames` |
| Node.js     | `global`                 |
| 통합 식별자 | `globalThis`(ES2020)     |

**사용 예시** :

```jsx
// 브라우저 환경
console.log(this);
console.log(this === window); // true
console.log(window === self); // true
console.log(self === frames); // true

// Node.js 환경
console.log(global);

// 모든 환경에서 동작 (권장)
console.log(globalThis);
```

**주의사항** : Node.js에서 문서 실행 시 `this`는 전역 객체를 가리키지 않습니다. 이는 모듈 시스템과 관련이 있습니다.

### 1.3 전역 객체에 포함되는 것

1. **표준 빌트인 객체** : ECMAScript 사양에 정의된 객체들
2. **호스트 객체** : 환경에서 제공하는 기타 객체들 (브라우저의 Web API, Node.js API 등)
3. **브라우저 한정** : `var`로 선언된 전역 변수와 전역 함수

**예시** :

```jsx
var myGlobalVar = 1;
const myGlobalConst = 1;
function myGlobalFunc() {}

console.log(globalThis.myGlobalVar); // 1
console.log(globalThis.myGlobalConst); // undefined (const는 전역 객체의 프로퍼티가 되지 않음)
console.log(globalThis.myGlobalFunc); // function myGlobalFunc() {}
```

**언제 사용하는가** :

- 전역적으로 접근 가능한 변수나 함수가 필요할 때
- 환경에 관계없이 통일된 방식으로 전역 객체에 접근할 때 `globalThis` 사용

## 2. 표준 빌트인 객체 (Standard Built-in Objects)

### 2.1 개념

**표준 빌트인 객체**는 ECMAScript 사양에 정의된 객체들로, 어떤 JavaScript 환경에서든 사용 가능합니다. 전역 프로퍼티로 제공되어 `globalThis` 등을 붙이지 않고 바로 사용할 수 있습니다.

**출처** : ECMAScript 사양
**MDN 문서** : [Standard built-in objects](https://developer.mozilla.org/ko/docs/Web/JavaScript/Reference/Global_Objects)

### 2.2 주요 표준 빌트인 객체

- `Object`, `Array`, `Function`
- `String`, `Number`, `Boolean`
- `Date`, `Math`, `RegExp`
- `Promise`, `Set`, `Map`
- 기타 등등

  **예시** :

```jsx
// Node.js에서 globalThis 출력 시 표준 빌트인 객체는 표시되지 않음
console.log(globalThis);

// 하지만 접근은 가능
console.log(globalThis.Infinity); // Infinity
console.log(globalThis.isNaN); // function isNaN()
console.log(globalThis.Object); // function Object()
```

**언제 사용하는가** : 데이터 타입 생성, 조작, 변환 등 거의 모든 JavaScript 프로그래밍에서 사용됩니다.

## 3. 래퍼 객체 (Wrapper Object)

### 3.1 개념

**래퍼 객체**는 원시 타입 값을 객체처럼 다룰 수 있게 해주는 표준 빌트인 객체입니다. JavaScript는 원시값에서 프로퍼티나 메서드를 호출할 때, 자동으로 해당 원시값을 래퍼 객체로 감싸서(wrap) 인스턴스를 만들고 기능을 실행합니다.

### 3.2 동작 원리

```jsx
const str = "abcde";
console.log(str.length); // 5
console.log(str.toUpperCase()); // 'ABCDE'
console.log(str[0]); // 'a'
```

위 코드에서 `str`은 원시 문자열인데 어떻게 `.length`나 `.toUpperCase()` 같은 프로퍼티와 메서드를 사용할 수 있을까요?

**답** : JavaScript가 자동으로 `String` 래퍼 객체로 변환하여 처리하고, 처리 후에는 다시 원시값으로 돌아갑니다.

### 3.3 명시적 래퍼 객체 생성

```jsx
const str = new String("abcde");
const num = new Number(123.4567);
const bool = new Boolean(true);

console.log(typeof str, str); // object String {'abcde'}
console.log(typeof num, num); // object Number {123.4567}
console.log(typeof bool, bool); // object Boolean {true}
```

### 3.4 메모리 효율성

**중요** : 래퍼 객체는 기능 사용 후 즉시 원시 객체로 돌아갑니다. 이는 메모리를 절약하기 위함입니다.

```jsx
const str = "abcde";
console.log(str.length); // 래퍼 객체로 변환 → length 접근 → 원시값으로 복귀
console.log(typeof str, str); // string 'abcde' (여전히 원시값)
```

### 3.5 valueOf() 메서드

래퍼 객체의 인스턴스에서 원시값을 반환합니다.

```jsx
const str = new String("abcde");
const num = new Number(123.4567);
const bool = new Boolean(true);

console.log(str.valueOf()); // 'abcde'
console.log(num.valueOf()); // 123.4567
console.log(bool.valueOf()); // true
```

**언제 사용하는가** :

- 일반적으로는 명시적 래퍼 객체 생성을 하지 않습니다.
- 원시값에서 메서드를 호출할 때 자동 래핑이 발생합니다.
- `valueOf()`는 래퍼 객체를 원시값으로 변환할 때 사용합니다.

## 4. 빌트인 전역 프로퍼티

### 4.1 개념

**빌트인 전역 프로퍼티**는 스스로 다른 프로퍼티나 메서드를 갖지 않고 값만 반환하는 전역 객체의 프로퍼티입니다.

**출처** : ECMAScript 사양
**MDN 문서** : [Global properties](https://developer.mozilla.org/ko/docs/Web/JavaScript/Reference/Global_Objects#%EC%A0%84%EC%97%AD_%ED%94%84%EB%A1%9C%ED%8D%BC%ED%8B%B0)

### 4.2 주요 전역 프로퍼티

```jsx
console.log(globalThis.Infinity); // Infinity
console.log(globalThis.NaN); // NaN
console.log(globalThis.undefined); // undefined
```

**특징** :

- `Infinity`, `NaN`, `undefined` 등의 원시값들은 이 프로퍼티들을 가리킵니다.
- `null`은 포함되지 않습니다 (가리키는 값이 없음을 의미하므로).

### 4.3 globalThis의 재귀적 참조

```jsx
console.log(globalThis.globalThis); // globalThis 자신

console.log(
  globalThis == globalThis.globalThis, // true
  globalThis == globalThis.globalThis.globalThis, // true
  globalThis == globalThis.globalThis.globalThis.globalThis // true
);
```

**언제 사용하는가** : 무한대, 숫자가 아닌 값, 정의되지 않은 값을 나타낼 때 사용합니다.

## 5. 빌트인 전역 함수

### 5.1 개념

**빌트인 전역 함수**는 전역 객체의 메서드로, 어디서나 호출 가능한 함수들입니다.

**출처** : ECMAScript 사양
**MDN 문서** : [Global functions](https://developer.mozilla.org/ko/docs/Web/JavaScript/Reference/Global_Objects#%ED%95%A8%EC%88%98_%ED%94%84%EB%A1%9C%ED%8D%BC%ED%8B%B0)

### 5.2 eval()

**문법** : `eval(string)` **설명** : 문자열로 된 코드를 받아 실행합니다.

```jsx
const x = eval("1 + 2 + 3"); // 6

// 객체나 함수의 리터럴은 괄호로 감싸야 함
const obj = eval("({a: 1, b: 2})"); // {a: 1, b: 2}

// 표현식이 아닐 경우 해당 코드 실행
const code = `
  let x = 1;
  console.log(x++, x);
`;
eval(code); // 1 2
```

**⚠️ 경고** :

- 보안에 매우 취약합니다.
- 엔진이 코드를 최적화하지 못해 처리 속도가 느립니다.
- 특별한 경우가 아니면 절대 사용하지 마세요.

### 5.3 isFinite()

**문법** : `isFinite(value)` **설명** : 유한수 여부를 반환합니다.

```jsx
console.log(
  isFinite(1), // true
  isFinite(0), // true
  isFinite("1"), // true (문자열 '1'이 숫자 1로 변환됨)
  isFinite(null) // true (null이 0으로 변환됨)
);

console.log(
  isFinite(1 / 0), // false
  isFinite(Infinity), // false
  isFinite(-Infinity), // false
  isFinite(NaN), // false
  isFinite("abc") // false
);
```

**언제 사용하는가** : 계산 결과가 유효한 숫자인지 검증할 때 사용합니다.

### 5.4 isNaN()

**문법** : `isNaN(value)` **설명** : NaN 여부를 반환합니다.

```jsx
console.log(
  isNaN(NaN), // true
  isNaN("abcde"), // true
  isNaN({}), // true
  isNaN(undefined) // true
);
```

**특징** : Number 타입이 아닌 경우 Number로 변환하여 평가합니다.
**참고** : `Number.isNaN()`은 타입 변환을 하지 않습니다.

### 5.5 parseFloat()

**문법** : `parseFloat(string)` **설명** : 인자로 받은 값을 실수로 변환합니다.

```jsx
console.log(
  parseFloat(123.4567), // 123.4567
  parseFloat("123.4567"), // 123.4567
  parseFloat(" 123.4567 ") // 123.4567 (앞뒤 공백 무시)
);

console.log(
  parseFloat("123.0"), // 123
  parseFloat("123"), // 123
  parseFloat(" 123ABC "), // 123 (숫자로 시작하면 읽을 수 있는 부분까지만)
  parseFloat([123, 456, 789]) // 123 (배열의 첫 요소가 숫자면 반환)
);

console.log(
  parseFloat("ABC123"), // NaN
  parseFloat({ x: 1 }), // NaN
  parseFloat([]), // NaN
  parseFloat(["a", 1, true]) // NaN
);
```

**언제 사용하는가** : 문자열을 실수로 파싱할 때 사용합니다.

### 5.6 parseInt()

**문법** : `parseInt(string, radix)` **설명** : 인자로 받은 값을 정수로 변환합니다.

```jsx
console.log(
  parseInt(123), // 123
  parseInt("123"), // 123
  parseInt(" 123.4567 "), // 123 (소수점 이하는 버림, 반올림 안 함)
  parseInt("345.6789") // 345
);

console.log(
  parseInt("abc"), // NaN
  parseInt("{}"), // NaN
  parseInt("[]") // NaN
);
```

**진법 변환** :

```jsx
console.log(
  parseInt("11"), // 11 (10진수)
  parseInt("11", 2), // 3 (2진수 11 → 10진수 3)
  parseInt("11", 8), // 9 (8진수 11 → 10진수 9)
  parseInt("11", 16), // 17 (16진수 11 → 10진수 17)
  parseInt("11", 32), // 33 (32진수 11 → 10진수 33)

  parseInt("11", 37), // NaN (유효하지 않은 진법)
  parseInt("11", "A") // NaN
);
```

**언제 사용하는가** : 문자열을 정수로 파싱하거나, 다른 진법의 숫자를 10진법으로 변환할 때 사용합니다.

### 5.7 encodeURI(), encodeURIComponent()

**설명** : URI는 아스키 문자 셋으로만 구성되어야 하므로, 아스키가 아닌 문자(한글 등)와 일부 특수문자를 포함한 URI를 유효하게 인코딩합니다.

```jsx
// encodeURI: 완성된 URI를 인코딩
const searchURI = "<https://www.google.com/search?q=얄코>";
const encodedURI = encodeURI(searchURI);
console.log(encodedURI);
// <https://www.google.com/search?q=%EC%96%84%EC%BD%94>

// encodeURIComponent: URI의 구성 요소를 인코딩
const keyword = "얄코";
const encodedKeyword = encodeURIComponent(keyword);
console.log(encodedKeyword); // %EC%96%84%EC%BD%94

const searchURI2 = `https://www.google.com/search?q=${encodedKeyword}`;
console.log(searchURI2);
```

**차이점** :

```jsx
const raw = "?q=얄코";
console.log(encodeURI(raw)); // ?q=%EC%96%84%EC%BD%94
console.log(encodeURIComponent(raw)); // %3Fq%3D%EC%96%84%EC%BD%94
```

- `encodeURI`: URI의 특수문자(`=`, `?`, `&` 등)는 인코딩하지 않음
- `encodeURIComponent`: 모든 특수문자를 인코딩함

  **언제 사용하는가** :

- `encodeURI`: 완성된 URI 전체를 인코딩할 때
- `encodeURIComponent`: URI의 일부분(쿼리 파라미터 값 등)을 인코딩할 때

### 5.8 decodeURI(), decodeURIComponent()

**설명** : 인코딩된 URI를 디코딩합니다.

```jsx
const encodedURI = "<https://www.google.com/search?q=%EC%96%84%EC%BD%94>";
const decodedURI = decodeURI(encodedURI);
console.log(decodedURI); // <https://www.google.com/search?q=얄코>

const encodedComp = "%EC%96%84%EC%BD%94";
const decodedComp = decodeURIComponent(encodedComp);
console.log(decodedComp); // 얄코
```

**언제 사용하는가** : URL에서 인코딩된 파라미터를 원래 문자열로 복원할 때 사용합니다.

## 6. String 객체

### 6.1 개념

**String 객체**는 문자열을 다루기 위한 표준 빌트인 객체입니다. 문자열 원시값을 감싸는 래퍼 객체이며, 다양한 문자열 조작 메서드를 제공합니다.

**출처** : ECMAScript 사양
**MDN 문서** : [String](https://developer.mozilla.org/ko/docs/Web/JavaScript/Reference/Global_Objects/String)

### 6.2 생성자 함수

```jsx
// 기본 생성
const strObj1 = new String();
const strObj2 = new String("Hello World!");

console.log(strObj1); // String {''}
console.log(strObj2); // String {'Hello World!'}

// 원시값 반환
console.log(strObj1.valueOf(), strObj1.toString()); // '' ''
console.log(strObj2.valueOf(), strObj2.toString()); // 'Hello World!' 'Hello World!'
```

**다른 타입 변환** :

```jsx
const fromNum = new String(123);
const fromBool = new String(true);
const fromArr = new String([1, "A", false]);
const fromObj = new String({ a: 1 });

console.log(typeof fromNum, fromNum); // object String {'123'}
console.log(typeof fromBool, fromBool); // object String {'true'}
console.log(typeof fromArr, fromArr); // object String {'1,A,false'}
console.log(typeof fromObj, fromObj); // object String {'[object Object]'}
```

### 6.3 new 없이 사용 - 타입 변환 함수

```jsx
const str1 = String("Hello World!");
const str2 = String(123);
const str3 = String(true);
const str4 = String({ x: 1, y: 2 }); // [object Object]
const str5 = String([1, 2, 3]); // 1,2,3

console.log(typeof str1, str1); // string 'Hello World!'
console.log(typeof str2, str2); // string '123'
console.log(typeof str3, str3); // string 'true'
console.log(typeof str4, str4); // string '[object Object]'
console.log(typeof str5, str5); // string '1,2,3'
```

**언제 사용하는가** : 다른 타입의 값을 문자열로 변환할 때 `new` 없이 사용합니다.

### 6.4 유사 배열 객체 특성

```jsx
let myStr = "안녕하세요!";

console.log(
  myStr.length, // 6
  myStr[0], // '안'
  myStr[myStr.length - 1] // '!'
);

// 문자 수정 시도 (불가능)
myStr[myStr.length - 1] = "?";
console.log(myStr); // '안녕하세요!' (변경되지 않음)

// for...of 순회 가능
for (const letter of myStr) {
  console.log(letter); // '안', '녕', '하', '세', '요', '!'
}
```

**중요** : String은 원시값이므로 `[]` 접근이나 메서드로 특정 글자만 수정하는 것은 불가능합니다. 수정하려면 변수 값 전체를 다른 문자열로 대체해야 합니다.

### 6.5 주요 인스턴스 메서드

### 6.5.1 toUpperCase(), toLowerCase()

**설명** : 라틴어 문자를 모두 대문자/소문자로 변경하여 반환합니다.

```jsx
const word = "Hello, World.";
console.log(
  word.toUpperCase(), // 'HELLO, WORLD.'
  word.toLowerCase() // 'hello, world.'
);

console.log(word); // 'Hello, World.' (원본은 변경되지 않음)
```

**활용 예시** :

```jsx
function areSameWords(word1, word2) {
  return word1.toLowerCase() === word2.toLowerCase();
}

console.log(
  areSameWords("Hello", "hello"), // true
  areSameWords("가나다", "가나다"), // true
  areSameWords("ABC", "DEF") // false
);
```

**언제 사용하는가** : 대소문자 구분 없이 문자열을 비교할 때 사용합니다.

### 6.5.2 charAt(), at()

**설명** : 인자로 주어진 인덱스의 문자를 반환합니다.

```jsx
// charAt
console.log(
  "Hello World!".charAt(0), // 'H'
  "안녕하세요~".charAt(2) // '하'
);

// at (ES2022 신기능)
console.log(
  "안녕하세요~".at(1), // '녕'
  "안녕하세요~".at(-1) // '~' (음수로 뒤에서부터 접근 가능)
);
```

**언제 사용하는가** :

- `charAt`: 특정 위치의 문자를 가져올 때
- `at`: 음수 인덱스로 뒤에서부터 접근할 때 (배열에서도 사용 가능)

### 6.5.3 indexOf(), lastIndexOf()

**설명** : 인자로 주어진 문자열이 앞 또는 뒤에서 처음 나타나는 인덱스를 반환합니다. 없으면 -1을 반환합니다.

```jsx
const word = "반갑습니다!";
console.log(
  word.indexOf("습"), // 2
  word.lastIndexOf("습") // 2
);

const word2 = "아니, 하나마나한 걸 왜 하나?";
console.log(
  word2.indexOf("하나"), // 4
  word2.lastIndexOf("하나") // 15
);

console.log(
  "가나다라마".indexOf("하"), // -1
  "가나다라마".lastIndexOf("하") // -1
);
```

**언제 사용하는가** : 문자열 내에서 특정 부분 문자열의 위치를 찾을 때 사용합니다.

### 6.5.4 includes(), startsWith(), endsWith()

**설명** : 인자로 주어진 문자열 포함 여부를 불리언으로 반환합니다.

```jsx
const sentence = "옛날에 호랑이 한 마리가 살았어요.";

for (const word of ["옛날에", "호랑이", "살았어요.", "나무꾼"]) {
  console.log("includes", word, sentence.includes(word));
  console.log("startsWith", word, sentence.startsWith(word));
  console.log("endsWith", word, sentence.endsWith(word));
  console.log("- - - - -");
}

// 결과:
// includes 옛날에 true
// startsWith 옛날에 true
// endsWith 옛날에 false
// ...
```

**언제 사용하는가** :

- `includes`: 문자열이 특정 부분 문자열을 포함하는지 확인
- `startsWith`: 특정 문자열로 시작하는지 확인
- `endsWith`: 특정 문자열로 끝나는지 확인

### 6.5.5 search()

**설명** : 정규표현식과 일치하는 첫 부분의 인덱스를 반환합니다. 없으면 -1을 반환합니다.

```jsx
console.log(
  "하루가 7번 지나면 1주일이 되는 거야.".search(/[0-9]/), // 4
  "하루가 일곱 번 지나면 일주일이 되는 거야.".search(/[0-9]/) // -1
);
```

**언제 사용하는가** : 정규표현식 패턴과 일치하는 부분의 위치를 찾을 때 사용합니다.

### 6.5.6 substring()

**설명** : 인자로 전달받은 인덱스를 기준으로 자른 문자열을 반환합니다.

```jsx
const word = "ABCDEFGHIJKL";
const part = word.substring(4, 8);
console.log(word, part); // 'ABCDEFGHIJKL' 'EFGH'

// 인자를 하나만 넣으면 해당 인덱스부터 끝까지
console.log(word.substring(4)); // 'EFGHIJKL'

// 음수나 범위 외 숫자는 범위 내 최소/최대 숫자로 처리
console.log(
  word.substring(-1), // 'ABCDEFGHIJKL' (0으로 처리)
  word.substring(4, 100), // 'EFGHIJKL' (끝까지)
  word.substring(100) // '' (빈 문자열)
);
```

**활용 예시** :

```jsx
const sentence = "옛날에 호랑이 한 마리가 살았어요.";

const firstWord = sentence.substring(0, sentence.indexOf(" "));
const lastWord = sentence.substring(
  sentence.lastIndexOf(" ") + 1,
  sentence.length
);

console.log(firstWord, lastWord); // '옛날에' '살았어요.'
```

**언제 사용하는가** : 문자열의 특정 범위를 추출할 때 사용합니다.

### 6.5.7 slice()

**설명** : `substring`과 같으나 음수로 뒤에서부터 자를 수 있습니다.

```jsx
const word = "ABCDEFGHIJKL";
console.log(
  word.substring(4, 8), // 'EFGH'
  word.slice(4, 8) // 'EFGH'
);

console.log(
  word.substring(-4), // 'ABCDEFGHIJKL' (음수는 0으로 처리)
  word.slice(-4) // 'IJKL' (뒤에서 4개)
);
```

**활용 예시** :

```jsx
const sentence = "옛날에 호랑이 한 마리가 살았어요.";

const firstWord = sentence.slice(0, sentence.indexOf(" "));
const lastWord = sentence.slice(
  sentence.lastIndexOf(" ") + 1 - sentence.length
);

console.log(firstWord, lastWord); // '옛날에' '살았어요.'
```

**언제 사용하는가** : 음수 인덱스로 뒤에서부터 문자열을 자를 때 사용합니다.

### 6.5.8 split()

**설명** : 인수로 주어진 문자열이나 정규표현식으로 분리하여 배열을 반환합니다.

```jsx
console.log(
  "010-1234-5678".split("-"), // ['010', '1234', '5678']
  "ABC1DEF2GHI3JKL".split(/[0-9]/) // ['ABC', 'DEF', 'GHI', 'JKL']
);

// 빈 문자열이나 인자 생략 시
const word = "안녕하세요";
console.log(
  word.split(""), // ['안', '녕', '하', '세', '요']
  word.split() // ['안녕하세요']
);

// 두 번째 인자로 배열의 최대 길이 지정
const word2 = "하나 하면 할머니가 지팡이 짚고서 잘잘잘";
console.log(
  word2.split(" ", 2), // ['하나', '하면']
  word2.split(" ", 4) // ['하나', '하면', '할머니가', '지팡이']
);
```

**활용 예시** :

```jsx
const sentence = "옛날에 호랑이 한 마리가 살았어요.";
const splitted = sentence.split(" ");

const firstWord = splitted[0];
const lastWord = splitted[splitted.length - 1];

console.log(firstWord, lastWord); // '옛날에' '살았어요.'
```

**언제 사용하는가** : 구분자를 기준으로 문자열을 배열로 변환할 때 사용합니다.

### 6.5.9 trim(), trimStart(), trimEnd()

**설명** : 앞뒤의 공백을 제거하여 반환합니다.

```jsx
const word = "  Hello World!  ";
console.log(`--${word}--`); // '--  Hello World!  --'
console.log(`--${word.trim()}--`); // '--Hello World!--'
console.log(`--${word.trimStart()}--`); // '--Hello World!  --'
console.log(`--${word.trimEnd()}--`); // '--  Hello World!--'
```

**주의** : 중간의 공백은 제거하지 않습니다.

**언제 사용하는가** : 사용자 입력값에서 불필요한 앞뒤 공백을 제거할 때 사용합니다.

### 6.5.10 repeat()

**설명** : 인자로 주어진 정수만큼 문자열을 반복하여 반환합니다.

```jsx
const word = "호이";

console.log(word.repeat(3)); // '호이호이호이'
console.log(word.repeat(0)); // ''
console.log(word.repeat()); // ''

console.log(word.repeat(-1)); // RangeError
```

**언제 사용하는가** : 같은 문자열을 여러 번 반복할 때 사용합니다 (예: 구분선 생성).

### 6.5.11 replace(), replaceAll()

**설명** : 첫 번째 인자로 받은 문자열 또는 정규식을 두 번째 인자로 치환한 결과를 반환합니다.

```jsx
console.log(
  "이스탄불은 터키의 수도이다.".replace("터키", "튀르키예")
  // '이스탄불은 튀르키예의 수도이다.'
);

const word = "밥 좀 먹자, 밥. 응? 야, 밥 좀 먹자고 밥, 밥!";

console.log(word.replace("밥", "라면"));
// '라면 좀 먹자, 밥. 응? 야, 밥 좀 먹자고 밥, 밥!' (첫 번째만 치환)

console.log(word.replace(/밥/g, "라면"));
// '라면 좀 먹자, 라면. 응? 야, 라면 좀 먹자고 라면, 라면!' (모두 치환)

console.log(word.replaceAll("밥", "라면"));
// '라면 좀 먹자, 라면. 응? 야, 라면 좀 먹자고 라면, 라면!'

console.log(word.replaceAll(/밥/g, "라면"));
// '라면 좀 먹자, 라면. 응? 야, 라면 좀 먹자고 라면, 라면!'
```

**차이점** :

- `replace`: 첫 인자가 문자열이면 첫 번째 일치만 치환
- `replaceAll`: 문자열도 자동으로 전체 치환 (정규식 사용 시 `/g` 플래그 필수)

  **언제 사용하는가** : 문자열 내의 특정 부분을 다른 문자열로 교체할 때 사용합니다.

### 6.6 메서드 체이닝 (Method Chaining)

**설명** : 값을 반환하는 인스턴스 메서드를 연속으로 사용하는 기법입니다.

```jsx
const word = " 모두 HELLO! ";
const rpFrom = "hello";
const rpTo = "bye";

console.log(
  word
    .trimStart() // '모두 HELLO! '
    .toLowerCase() // '모두 hello! '
    .replaceAll(rpFrom, rpTo) // '모두 bye! '
    .toUpperCase() // '모두 BYE! '
    .repeat(3) // '모두 BYE! 모두 BYE! 모두 BYE! '
    .trimEnd() // '모두 BYE! 모두 BYE! 모두 BYE!'
);

console.log(word); // ' 모두 HELLO! ' (원본은 그대로)
```

**중요** :

- 각 메서드는 원본을 변경하지 않고 새로운 문자열을 반환합니다.
- 반환된 문자열에 다시 메서드를 호출할 수 있습니다.

  **언제 사용하는가** : 여러 문자열 변환을 순차적으로 적용할 때 코드를 간결하게 작성할 수 있습니다.

## 최종 핵심 요약

### 전역 객체와 표준 빌트인 객체

- **전역 객체** : 어디서든 접근 가능한 최상위 객체 (`globalThis`로 통합)
- **표준 빌트인 객체** : ECMAScript 사양에 정의된 기본 제공 객체들
- **래퍼 객체** : 원시값을 임시로 객체로 감싸 메서드 사용을 가능하게 함

### 빌트인 전역 함수 주요 특징

- `eval()`: 사용 금지 (보안 취약)
- `isFinite()`, `isNaN()`: 값의 유효성 검증
- `parseInt()`, `parseFloat()`: 문자열을 숫자로 파싱
- `encodeURI()` vs `encodeURIComponent()`: 전체 URI vs 구성 요소 인코딩

### String 객체 핵심 개념

- **불변성** : 문자열은 원시값이므로 변경 불가, 항상 새 문자열 반환
- **유사 배열** : `length` 프로퍼티와 인덱스 접근 가능
- **메서드 체이닝** : 여러 메서드를 연속 호출 가능

### String 메서드 분류

- **검색** : `indexOf()`, `lastIndexOf()`, `includes()`, `search()`
- **변환** : `toUpperCase()`, `toLowerCase()`, `trim()`
- **추출** : `substring()`, `slice()`, `charAt()`, `at()`
- **분리/결합** : `split()`, `repeat()`
- **치환** : `replace()`, `replaceAll()`

## 복습용 퀴즈

### 퀴즈 1

전역 객체에 대한 설명으로 올바르지 않은 것은?

1. 브라우저에서 `window`, `self`, `frames`는 모두 같은 전역 객체를 가리킨다
2. `globalThis`는 모든 JavaScript 환경에서 전역 객체를 가리키는 통일된 식별자이다
3. `const`로 선언한 전역 변수는 전역 객체의 프로퍼티가 된다
4. 표준 빌트인 객체들은 전역 객체에 포함된다

정답: 3

해설: `var`로 선언한 전역 변수만 전역 객체의 프로퍼티가 됩니다. `const`와 `let`으로 선언한 변수는 전역 스코프에 존재하지만 전역 객체의 프로퍼티가 되지 않습니다. 이는 전역 객체의 오염을 방지하기 위한 ES6의 설계입니다.

### 퀴즈 2

래퍼 객체에 대한 설명으로 올바른 것은?

1. 래퍼 객체는 메모리에 영구적으로 저장되어 성능이 떨어진다
2. 원시값에서 메서드를 호출하면 자동으로 래퍼 객체로 변환되었다가 다시 원시값으로 돌아간다
3. `new String('hello')`와 `String('hello')`는 완전히 동일한 결과를 반환한다
4. `null`과 `undefined`도 래퍼 객체를 가지고 있다

정답: 2

해설: JavaScript는 원시값에서 메서드를 호출할 때 자동으로 해당 원시값을 래퍼 객체로 변환하고, 메서드 실행 후에는 다시 원시값으로 돌아갑니다. 이는 메모리를 절약하기 위한 최적화 기법입니다. `new String()`은 객체를 반환하고, `String()`은 원시 문자열을 반환합니다. `null`과 `undefined`는 래퍼 객체가 없습니다.

### 퀴즈 3

다음 코드의 출력 결과는?

```jsx
console.log(parseInt("11", 2));
console.log(parseInt("11", 16));
```

1. 11, 11
2. 2, 16
3. 3, 17
4. 11, 17

정답: 3

해설: `parseInt()`의 두 번째 인자는 진법을 의미합니다. '11'을 2진법으로 해석하면 (1×2¹ + 1×2⁰ = 3)이고, 16진법으로 해석하면 (1×16¹ + 1×16⁰ = 17)입니다. 이 함수는 주어진 진법의 숫자를 10진법으로 변환합니다.

### 퀴즈 4

`encodeURI()`와 `encodeURIComponent()`의 차이점은?

1. `encodeURI()`는 한글만 인코딩하고, `encodeURIComponent()`는 모든 문자를 인코딩한다
2. `encodeURI()`는 URI의 특수문자(`?`, `=`, `&` 등)를 인코딩하지 않지만, `encodeURIComponent()`는 인코딩한다
3. 두 함수는 완전히 동일하게 동작한다
4. `encodeURI()`가 더 강력한 인코딩을 수행한다

정답: 2

해설: `encodeURI()`는 완성된 URI를 인코딩하므로 URI에서 의미를 가지는 특수문자(`?`, `=`, `&`, `:`, `/` 등)는 인코딩하지 않습니다. 반면 `encodeURIComponent()`는 URI의 구성 요소(예: 쿼리 파라미터 값)를 인코딩하므로 모든 특수문자를 인코딩합니다.

### 퀴즈 5

```jsx
const word = "밥 좀 먹자, 밥!";

console.log(word.replaceAll("밥", "라면"));
```

4. 두 줄 모두 "밥 좀 먹자, 밥!"

정답: 2

해설: `replace()`는 첫 번째 인자가 문자열일 때 일치하는 첫 번째 부분만 치환합니다. `replaceAll()`은 일치하는 모든 부분을 치환합니다. 원본 문자열은 변경되지 않고 새로운 문자열이 반환됩니다.

### 퀴즈 6

다음 코드의 출력 결과는?

```jsx
const word = "ABCDEFGH";
console.log(word.substring(2, 5));
console.log(word.slice(-3));
```

1. "CDE", "FGH"
2. "BCD", "EFG"
3. "CDE", "EFG"
4. "DEF", "FGH"

### 퀴즈 7

문자열의 불변성에 대한 설명으로 올바른 것은?

1. 문자열은 배열처럼 인덱스로 특정 글자를 수정할 수 있다
2. 문자열 메서드들은 원본 문자열을 직접 변경한다
3. 문자열은 원시값이므로 수정 불가능하며, 메서드는 항상 새로운 문자열을 반환한다

```jsx
function getQueryParams(url) {
  const queryStart = url.indexOf("?");
  if (queryStart === -1) return {};

  const queryString = url.substring(queryStart + 1);
  const pairs = queryString.split("&");
  const params = {};

  for (const pair of pairs) {
    const [key, value] = pair.split("=");
    params[key] = decodeURIComponent(value);

  return params;
}
```

```jsx
function maskString(str, showFirst, showLast) {
  if (str.length <= showFirst + showLast) {
```

```jsx
console.log(capitalizeWords("JAVASCRIPT is AWESOME")); // 'Javascript Is Awesome'
```

**정답** :

```jsx
function capitalizeWords(str) {
  const words = str.toLowerCase().split(" ");
  const capitalized = [];

  for (const word of words) {
    if (word.length > 0) {
      const first = word.charAt(0).toUpperCase();
      const rest = word.slice(1);
      capitalized.push(first + rest);
    }
  }

  return capitalized.join(" ");
}

// 테스트
console.log(capitalizeWords("hello world")); // 'Hello World'
console.log(capitalizeWords("JAVASCRIPT is AWESOME")); // 'Javascript Is Awesome'
```

**해설** :

- `split(' ')`로 공백 기준으로 단어를 분리합니다.

- 나머지 부분은 `slice(1)`로 추출합니다.
- `join(' ')`로 단어들을 다시 결합합니다.

### 문제 6: 문자열 압축

연속된 동일 문자를 "문자+개수" 형식으로 압축하는 함수를 작성하세요.

**기본 코드** :

```jsx

  // 여기에 코드를 작성하세요
}

// 테스트
console.log(compressString("aaabbcccc")); // 'a3b2c4'
console.log(compressString("abc")); // 'a1b1c1'
console.log(compressString("aabbbaaa")); // 'a2b3a3'
```

**정답** :

```jsx
function compressString(str) {
  if (str.length === 0) return "";

  let compressed = "";
  let currentChar = str.charAt(0);
  let count = 1;

  for (let i = 1; i < str.length; i++) {
    if (str.charAt(i) === currentChar) {
      count++;
    } else {
      compressed += currentChar + count;
      currentChar = str.charAt(i);
      count = 1;
    }
  }

  // 마지막 문자 처리
  compressed += currentChar + count;

  return compressed;
}

// 테스트
console.log(compressString("aaabbcccc")); // 'a3b2c4'
console.log(compressString("abc")); // 'a1b1c1'
console.log(compressString("aabbbaaa")); // 'a2b3a3'
```

**해설** :

- 첫 번째 문자를 기준으로 시작합니다.
- 문자열을 순회하면서 현재 문자와 같으면 카운트를 증가시킵니다.
- 다른 문자가 나오면 "문자+개수"를 결과 문자열에 추가하고 새로운 문자로 전환합니다.
- 마지막 문자 그룹은 반복문 종료 후 별도로 처리합니다.
