## 🔄 Iterable 객체

### 💡 핵심 개념

**Iterable(이터러블)**은 `for...of` 반복문을 사용할 수 있는 객체를 말합니다.

### 📌 언제 사용하나?

- 컬렉션(목록, 집합 등)을 순회하고 싶을 때
- 커스텀 객체에 반복 기능을 추가하고 싶을 때
- 배열처럼 동작하지만 배열이 아닌 객체를 만들 때

### ⚙️ 동작 원리

```javascript
// 1. Symbol.iterator 메서드 구현
let range = {
  from: 1,
  to: 5,
  
  [Symbol.iterator]() {
    return {
      current: this.from,
      last: this.to,
      
      next() {
        if (this.current <= this.last) {
          return { done: false, value: this.current++ };
        } else {
          return { done: true };
        }
      }
    };
  }
};

// 2. for...of로 순회 가능
for (let num of range) {
  console.log(num); // 1, 2, 3, 4, 5
}
```

### 🎯 실행 흐름

1. `for...of` 시작 → `Symbol.iterator` 호출
2. 이터레이터 객체 반환 (반드시 `next()` 메서드 필요)
3. 반복마다 `next()` 호출
4. `{done: Boolean, value: any}` 형태로 반환
5. `done: true`일 때 반복 종료

### 🔥 자주 헷갈리는 포인트

#### ❌ Iterable vs 유사 배열

```javascript
// Iterable이지만 유사 배열은 아님
let range = {
  from: 1,
  to: 5,
  [Symbol.iterator]() { /* ... */ }
  // ❌ 인덱스와 length가 없음
};

// 유사 배열이지만 Iterable은 아님
let arrayLike = {
  0: "Hello",
  1: "World",
  length: 2
  // ❌ Symbol.iterator가 없음
};

// for...of 사용 불가!
for (let item of arrayLike) {} // TypeError!
```

**해결책**: `Array.from()` 사용

```javascript
let arr = Array.from(arrayLike);
arr.pop(); // 이제 배열 메서드 사용 가능!
```

### 💪 Array.from() 활용법

```javascript
// 1. 기본 변환
let arr = Array.from(arrayLike);

// 2. 매핑 함수 적용
let squares = Array.from(range, num => num * num);
// [1, 4, 9, 16, 25]

// 3. 서로게이트 쌍 안전하게 처리
let str = '𝒳😂';
let chars = Array.from(str); // ['𝒳', '😂']
// str.split('')은 서로게이트 쌍을 깨뜨림 ⚠️
```

### 🌟 실무 패턴

#### 무한 이터레이터
```javascript
let infiniteRange = {
  from: 1,
  [Symbol.iterator]() {
    return {
      current: this.from,
      next() {
        return { done: false, value: this.current++ };
      }
    };
  }
};

// break로 제어 필수!
for (let num of infiniteRange) {
  if (num > 100) break;
  console.log(num);
}
```

## ⚡ Generator 함수

### 💡 핵심 개념

**Generator**는 여러 값을 필요에 따라 하나씩 반환(`yield`)할 수 있는 특수 함수입니다.

### 📌 언제 사용하나?

- 데이터 스트림을 다룰 때
- 이터러블 객체를 쉽게 만들고 싶을 때
- 지연 평가(lazy evaluation)가 필요할 때
- 실행을 일시 정지했다가 재개해야 할 때

### ⚙️ 기본 문법

```javascript
// function* (별표 필수!)
function* generateSequence() {
  yield 1;
  yield 2;
  return 3;
}

// 제너레이터 객체 생성
let generator = generateSequence();

// next()로 값 하나씩 받기
console.log(generator.next()); // {value: 1, done: false}
console.log(generator.next()); // {value: 2, done: false}
console.log(generator.next()); // {value: 3, done: true}
```

### 🔥 자주 헷갈리는 포인트

#### ❌ return vs yield in for...of

```javascript
function* gen1() {
  yield 1;
  yield 2;
  return 3; // ⚠️ for...of는 이 값을 무시함!
}

for (let value of gen1()) {
  console.log(value); // 1, 2만 출력 (3은 출력 안 됨!)
}

// ✅ 모든 값을 출력하려면
function* gen2() {
  yield 1;
  yield 2;
  yield 3; // yield로 반환!
}
```

### 💪 Iterable 객체를 Generator로 간단히!

```javascript
// Before: 복잡한 이터레이터 구현
let range = {
  from: 1,
  to: 5,
  [Symbol.iterator]() {
    return {
      current: this.from,
      last: this.to,
      next() { /* ... */ }
    };
  }
};

// After: Generator로 간결하게!
let range = {
  from: 1,
  to: 5,
  
  *[Symbol.iterator]() {
    for(let value = this.from; value <= this.to; value++) {
      yield value;
    }
  }
};
```

### 🎨 Generator Composition (합성)

여러 제너레이터를 조합할 때 `yield*` 사용:

```javascript
function* generateSequence(start, end) {
  for (let i = start; i <= end; i++) yield i;
}

function* generatePasswordCodes() {
  yield* generateSequence(48, 57);   // 0..9
  yield* generateSequence(65, 90);   // A..Z
  yield* generateSequence(97, 122);  // a..z
}

let str = '';
for(let code of generatePasswordCodes()) {
  str += String.fromCharCode(code);
}
console.log(str); // "0123456789ABC...XYZabc...xyz"
```

### 🔄 양방향 통신: next(arg)

Generator는 값을 받을 수도 있습니다!

```javascript
function* gen() {
  let result = yield "2 + 2 = ?"; // 질문을 던짐
  console.log(result); // 외부에서 받은 답을 출력
}

let generator = gen();

let question = generator.next().value; // "2 + 2 = ?"
console.log(question);

generator.next(4); // 답 4를 전달 → console.log(4) 실행
```

**실행 흐름**:
1. 첫 `next()`: 첫 번째 `yield`까지 실행, 값 반환
2. 두 번째 `next(arg)`: `arg`가 이전 `yield`의 결과가 됨

### ⚠️ 에러 처리

```javascript
function* gen() {
  try {
    let result = yield "2 + 2 = ?";
    console.log("이 줄은 실행 안 됨");
  } catch(e) {
    console.log(e); // 에러 잡기
  }
}

let generator = gen();
let question = generator.next().value;

// 에러를 제너레이터 안으로 던지기
generator.throw(new Error("답을 찾지 못했습니다"));
```

### 🌟 실무 패턴

#### 무한 데이터 생성기
```javascript
function* idGenerator() {
  let id = 1;
  while (true) {
    yield id++;
  }
}

const ids = idGenerator();
console.log(ids.next().value); // 1
console.log(ids.next().value); // 2
```

#### 페이지네이션 처리
```javascript
function* fetchPages(apiUrl) {
  let page = 1;
  while (true) {
    const data = yield fetch(`${apiUrl}?page=${page}`);
    if (!data.hasMore) break;
    page++;
  }
}
```

## 📝 핵심 요약

### Iterable
- `Symbol.iterator` 메서드가 있는 객체
- `for...of`, 전개 연산자(`...`) 사용 가능
- 배열, 문자열, Map, Set 등이 기본 내장
- 유사 배열 ≠ Iterable (개념 구분 필수!)
- `Array.from()`으로 진짜 배열로 변환 가능

### Generator
- `function*` 문법으로 정의
- `yield`로 값을 하나씩 반환
- `next()`로 실행 제어
- 자동으로 Iterable 객체가 됨
- `yield*`로 다른 제너레이터 합성 가능
- `next(arg)`로 양방향 통신 가능
- 지연 실행(lazy evaluation)으로 메모리 효율적

### 언제 뭘 쓸까?
- **간단한 순회**: 배열 사용
- **커스텀 순회 로직**: Iterable 구현
- **복잡한 순회/지연 실행**: Generator 사용
- **유사 배열 → 배열**: `Array.from()` 사용

## ✅ 정답 및 해설

### A1. ② `Symbol.iterator` 메서드

Iterable 객체가 되려면 반드시 `Symbol.iterator` 메서드가 있어야 합니다. 이 메서드는 `next()` 메서드를 가진 이터레이터 객체를 반환해야 하죠. `length`나 숫자 인덱스는 유사 배열의 특징이며, 배열 메서드들은 Iterable과 무관합니다.

### A2. ② 1, 2

`for...of` 반복문은 `done: true`일 때 마지막 `value`를 무시합니다. `return 3`은 `{value: 3, done: true}`를 반환하므로 출력되지 않습니다. 모든 값을 출력하려면 `yield 3`으로 바꿔야 합니다.

### A3. ① `{ 0: 'a', 1: 'b', length: 2 }`

이 객체는 숫자 인덱스와 `length` 프로퍼티가 있어 유사 배열이지만, `Symbol.iterator`가 없어서 Iterable이 아닙니다. 따라서 `for...of`를 사용할 수 없습니다. 나머지는 모두 Iterable입니다.

### A4. ② 10

실행 흐름:
- 첫 번째 `g.next()`: `yield "질문"`까지 실행, `"질문"` 반환
- 두 번째 `g.next(5)`: 숫자 `5`가 `yield`의 결과가 되어 `result`에 할당
- `return result * 2`에서 `5 * 2 = 10` 반환
- `answer.value`는 `10`

### A5. ⑤ 원본 객체를 직접 수정함

`Array.from()`은 새로운 배열을 만들어 반환하며, 원본 객체를 수정하지 않습니다. 이는 장점이 아니라 잘못된 설명입니다. 나머지는 모두 `Array.from()`의 실제 장점들입니다.
