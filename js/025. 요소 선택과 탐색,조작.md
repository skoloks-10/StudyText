# JavaScript DOM 조작 완벽 가이드

## 📌 Overview

DOM(Document Object Model) API를 사용해 HTML 요소를 선택하고 조작하는 방법을 정리한 문서입니다.

---

## 1️⃣ DOM 요소 선택하기

### 🎯 언제 어떤 선택자를 쓸까?

| 상황 | 추천 메서드 | 이유 |
|------|------------|------|
| 특정 요소 1개만 필요 | `querySelector()` | CSS 선택자 그대로 사용 가능, 가장 직관적 |
| 같은 조건의 여러 요소 | `querySelectorAll()` | 유연한 선택자, NodeList 반환 |
| 오래된 코드 유지보수 | `getElementById()` 등 | 레거시 코드에서 자주 보임 |

### 📖 선택 메서드 상세

#### `querySelector()` / `querySelectorAll()` ⭐ 실무 추천

```javascript
// 첫 번째 section 요소 1개
document.querySelector('section');

// 모든 section 요소들
document.querySelectorAll('section');

// CSS 선택자 그대로 사용 가능
document.querySelector('.plant > ul > .soldout');
document.querySelector('#sweets ul > :nth-child(2)');
```

**언제 쓰나요?**
- 복잡한 조건으로 요소를 찾을 때
- CSS 선택자에 익숙하다면 가장 편한 방법
- Document와 Element 둘 다에서 사용 가능

**💡 헷갈리는 포인트**
- `querySelector()`: 단수형, 1개만 반환
- `querySelectorAll()`: 복수형, NodeList(유사배열) 반환

#### `getElementsByTagName()` / `getElementsByClassName()`

```javascript
// 태그명으로 검색
const sections = document.getElementsByTagName('section');
const listItems = document.getElementsByTagName('li');

// 클래스명으로 검색
const plants = document.getElementsByClassName('plant');
const soldOuts = document.getElementsByClassName('soldout');
```

**언제 쓰나요?**
- 단순한 조건으로 여러 요소를 찾을 때
- 특정 태그나 클래스 전체를 가져올 때

**⚠️ 주의사항**
- HTMLCollection 반환 (live collection이라 실시간 반영됨)
- Document와 Element 둘 다에서 사용 가능 → 특정 영역 안에서만 검색 가능

```javascript
// 첫 번째 section 안의 li만 검색
sections[0].getElementsByTagName('li');
```

#### `getElementById()`

```javascript
document.getElementById('sweets');
```

**언제 쓰나요?**
- ID로 딱 1개 요소를 찾을 때
- 오래된 코드에서 자주 보임

**💡 특징**
- Document에만 있는 메서드 (Element에는 없음)
- ID는 문서 내 유일하므로 1개만 반환

## 2️⃣ DOM 탐색하기 (부모/자식/형제)

### 🔍 자식 요소 찾기

```javascript
const section = document.querySelector('section');

// Element의 메서드 - 요소 노드만
section.children;                // HTMLCollection
section.firstElementChild;       // 첫 번째 자식 요소
section.lastElementChild;        // 마지막 자식 요소

// Node의 메서드 - 텍스트 노드 포함
section.childNodes;              // NodeList (공백, 줄바꿈도 텍스트 노드!)
section.firstChild;              // 첫 번째 자식 노드
section.lastChild;               // 마지막 자식 노드
```

**언제 쓰나요?**
- `children` / `firstElementChild`: 실무에서 대부분 이것만 씀
- `childNodes`: 텍스트 노드까지 접근해야 할 때 (드물음)

**⚠️ 헷갈리는 포인트**
- `childNodes`는 공백, 줄바꿈도 텍스트 노드로 인식!
- 보통은 **Element 계열 메서드**만 쓰면 됨

### 🔍 형제 요소 찾기

```javascript
const secondLi = document.querySelector('li:nth-child(2)');

// Element 메서드 (실무 추천)
secondLi.previousElementSibling;  // 이전 형제 요소
secondLi.nextElementSibling;      // 다음 형제 요소

// Node 메서드
secondLi.previousSibling;         // 이전 형제 노드 (텍스트 포함)
secondLi.nextSibling;             // 다음 형제 노드 (텍스트 포함)
```

**실무 패턴**
```javascript
// 클릭된 요소의 다음 형제를 숨기기
button.addEventListener('click', () => {
  button.nextElementSibling.style.display = 'none';
});
```

### 🔍 부모 요소 찾기

```javascript
const li = document.querySelector('li');

li.parentNode;      // 부모 노드
li.parentElement;   // 부모 요소 (부모가 Element일 때만 반환)

// 대부분의 경우 같음
li.parentNode === li.parentElement;  // true
```

**실무 패턴**
```javascript
// 삭제 버튼 클릭 시 부모 요소 제거
deleteBtn.addEventListener('click', (e) => {
  e.target.parentElement.remove();
});
```

## 3️⃣ DOM 요소 조작하기

### ✏️ 텍스트 내용 수정

#### `textContent` ⭐ 실무 추천

```javascript
const carrot = document.querySelector('li');

carrot.textContent;              // 읽기: "당근"
carrot.textContent = '제주당근';  // 쓰기
```

**언제 쓰나요?**
- 요소의 텍스트를 읽거나 변경할 때
- `innerText`보다 성능이 좋아서 권장됨

**💡 차이점**
- `textContent`: 모든 텍스트 (숨겨진 것도 포함)
- `innerText`: 화면에 보이는 텍스트만

#### `nodeValue`

```javascript
carrot.firstChild.nodeValue;              // 텍스트 노드의 값
carrot.firstChild.nodeValue = '친환경당근';
```

**언제 쓰나요?**
- 텍스트 노드에 직접 접근할 때 (실무에서 드물게 씀)

---

### 🎨 클래스 조작

#### `className` - 문자열로 다루기

```javascript
const onion = document.querySelector('.hidden');

onion.className;                    // "hidden"
onion.className = '';               // 모든 클래스 제거
onion.className = 'soldout organic'; // 덮어쓰기
```

**언제 쓰나요?**
- 모든 클래스를 한 번에 교체할 때

**⚠️ 주의**: 기존 클래스가 전부 사라짐!

#### `classList` ⭐ 실무 추천

```javascript
const onion = document.querySelector('.hidden');

onion.classList;                    // DOMTokenList (유사배열)
[...onion.classList];               // 배열로 변환 가능

// 개별 클래스 조작
onion.classList.add('organic');     // 추가
onion.classList.remove('organic');  // 제거
onion.classList.toggle('hidden');   // 토글 (없으면 추가, 있으면 제거)
onion.classList.replace('hidden', 'organic'); // 교체
```

**실무 패턴**
```javascript
// 메뉴 토글
menuBtn.addEventListener('click', () => {
  menu.classList.toggle('active');
});

// 조건부 클래스 추가
if (isLoggedIn) {
  header.classList.add('logged-in');
}
```

**💡 헷갈리는 포인트**
- `toggle()`: 반복 실행하면 on/off 반복됨
- 여러 클래스 동시 추가: `classList.add('class1', 'class2')`

---

### 🎨 스타일 조작

#### `style` - 인라인 스타일 직접 수정

```javascript
const onion = document.querySelector('.hidden');

// 읽기
onion.style.fontSize;               // ""

// 쓰기 - camelCase 사용
onion.style.fontSize = '2em';
onion.style.color = '#ff0000';

// 대괄호 접근자로는 CSS 속성명 그대로
onion.style['font-size'] = '1em';
```

**언제 쓰나요?**
- 동적으로 스타일을 변경할 때
- 애니메이션이나 상호작용 구현

**⚠️ 주의사항**
- `style`은 인라인 스타일만 읽음 (CSS 파일의 스타일은 못 읽음!)
- CSS 속성명: `font-size` → JS: `fontSize` (kebab-case → camelCase)

**실무 패턴**
```javascript
// 진행률 바 업데이트
progressBar.style.width = `${percentage}%`;

// 동적 위치 설정
popup.style.top = `${y}px`;
popup.style.left = `${x}px`;
```

#### `getComputedStyle()` - 계산된 스타일 읽기 ⭐

```javascript
const onion = document.querySelector('.hidden');
const computedStyle = window.getComputedStyle(onion);

computedStyle.fontSize;    // "16px"
computedStyle.opacity;     // "0.3"
computedStyle.color;       // "rgb(51, 51, 51)"
```

**언제 쓰나요?**
- CSS 파일에 정의된 스타일을 읽을 때
- 클래스나 상속에 의한 최종 스타일 값을 알아야 할 때

**💡 차이점 정리**
```javascript
// style: 인라인 스타일만 (직접 설정한 것만)
element.style.fontSize;           // "" (CSS 파일 스타일은 못 읽음)

// getComputedStyle: 최종 계산된 모든 스타일
window.getComputedStyle(element).fontSize;  // "16px" (실제 적용값)
```

### 📝 속성(Attribute) 조작

```javascript
const link = document.querySelector('a');

// 읽기
link.getAttribute('href');          // "https://www.naver.com"
link.getAttribute('target');        // "_blank"

// 쓰기
link.setAttribute('href', 'https://www.google.com');
link.setAttribute('target', '_self');
```

**실무 패턴**
```javascript
// 이미지 소스 변경
img.setAttribute('src', 'new-image.jpg');

// data 속성 활용
button.setAttribute('data-id', '123');
const id = button.getAttribute('data-id');

// 폼 입력값 제어
input.setAttribute('value', 'Hello World!');
```

## 📝 핵심 요약

### 요소 선택 - 이것만 기억하자

- **실무 필수**: `querySelector()`, `querySelectorAll()`
- **레거시 대응**: `getElementById()`, `getElementsByClassName()`
- **Document vs Element**: 대부분 메서드는 둘 다 사용 가능 (ID 제외)

### 요소 탐색 - Element 계열만 쓰자

- **자식**: `children`, `firstElementChild`, `lastElementChild`
- **형제**: `previousElementSibling`, `nextElementSibling`
- **부모**: `parentElement`
- ❌ Node 계열 메서드는 텍스트 노드 때문에 헷갈림 → 웬만하면 쓰지 말 것

### 요소 조작 - 상황별 추천

- **텍스트 변경**: `textContent`
- **클래스 조작**: `classList` (add, remove, toggle)
- **스타일 읽기**: `getComputedStyle()`
- **스타일 쓰기**: `style` (camelCase로!)
- **속성 조작**: `getAttribute()`, `setAttribute()`

### ⚠️ 자주 하는 실수

1. `querySelectorAll()`로 가져온 결과에 바로 메서드 적용
   ```javascript
   // ❌ 안됨
   document.querySelectorAll('li').textContent = 'test';
   
   // ✅ forEach로 순회해야 함
   document.querySelectorAll('li').forEach(li => {
     li.textContent = 'test';
   });
   ```

2. `style`로 CSS 파일 스타일 읽으려고 시도
   ```javascript
   // ❌ 안됨 (CSS 파일 스타일은 못 읽음)
   element.style.color;
   
   // ✅ getComputedStyle 사용
   window.getComputedStyle(element).color;
   ```

3. CSS 속성명 그대로 사용
   ```javascript
   // ❌ 안됨
   element.style.font-size = '16px';
   
   // ✅ camelCase로
   element.style.fontSize = '16px';
   ```

## 🧪 복습 퀴즈

### Q1. 다음 중 CSS 파일에 정의된 스타일을 읽을 수 있는 방법은?

A) `element.style.color`  
B) `element.className`  
C) `window.getComputedStyle(element).color`  
D) `element.getAttribute('style')`

<details>
<summary>정답 확인</summary>

**정답: C**

해설: `element.style`은 인라인 스타일(직접 설정한 것)만 읽을 수 있습니다. CSS 파일이나 상속된 스타일을 포함한 최종 계산 값을 읽으려면 `window.getComputedStyle()`을 사용해야 합니다.
</details>

### Q2. `classList.toggle('active')`를 반복 실행하면?

A) 클래스가 계속 추가된다  
B) 에러가 발생한다  
C) 클래스가 추가/제거를 반복한다  
D) 첫 실행 후 아무 일도 일어나지 않는다

<details>
<summary>정답 확인</summary>

**정답: C**

해설: `toggle()` 메서드는 해당 클래스가 없으면 추가하고, 있으면 제거합니다. 따라서 반복 실행하면 on/off가 반복됩니다. 메뉴 열기/닫기 같은 기능에 자주 사용됩니다.
</details>

### Q3. 다음 중 Document에만 있고 Element에는 없는 메서드는?

A) `querySelector()`  
B) `getElementById()`  
C) `getElementsByClassName()`  
D) `querySelectorAll()`

<details>
<summary>정답 확인</summary>

**정답: B**

해설: `getElementById()`는 ID가 문서 내에서 유일하다는 특성 때문에 Document에만 존재하는 메서드입니다. 나머지는 Document와 Element 모두에서 사용할 수 있어, 특정 요소 하위에서만 검색하는 것도 가능합니다.
</details>

### Q4. `element.style.fontSize = '2em'`으로 설정한 후, `element.style['font-size']`로 읽으면 어떤 값이 반환되나?

A) `undefined`  
B) `"2em"`  
C) `null`  
D) 에러 발생

<details>
<summary>정답 확인</summary>

**정답: B**

해설: `style` 객체는 camelCase(`fontSize`)와 kebab-case(`'font-size'`) 모두로 접근할 수 있습니다. 마침표 접근자를 쓸 때는 camelCase를, 대괄호 접근자를 쓸 때는 원래 CSS 속성명을 사용할 수 있습니다.
</details>

### Q5. `querySelectorAll()`이 반환하는 NodeList와 `getElementsByClassName()`이 반환하는 HTMLCollection의 차이는?

A) NodeList는 배열이고, HTMLCollection은 유사배열이다  
B) NodeList는 정적이고, HTMLCollection은 실시간으로 업데이트된다  
C) NodeList는 요소만 담고, HTMLCollection은 텍스트 노드도 담는다  
D) 둘은 완전히 동일하다

<details>
<summary>정답 확인</summary>

**정답: B**

해설: HTMLCollection은 live collection으로 DOM이 변경되면 자동으로 업데이트됩니다. 반면 `querySelectorAll()`이 반환하는 NodeList는 정적(static)이어서 생성 시점의 스냅샷을 유지합니다. 둘 다 유사배열 객체입니다.
</details>
