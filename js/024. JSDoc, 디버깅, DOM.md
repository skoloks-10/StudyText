## 1. JSDoc - 코드 문서화 도구 📝

### 📌 JSDoc이란?

JavaScript 코드에 주석을 달기 위한 **마크업 언어**로, IDE에서 타입 힌트와 자동 완성을 제공합니다.

**언제 사용하나요?**
- 함수나 변수의 타입을 명시하고 싶을 때
- 팀 프로젝트에서 코드 가독성을 높이고 싶을 때
- API 문서를 자동 생성하고 싶을 때

### 🔧 주요 태그와 사용법

#### 기본 주석 작성

```javascript
/** 코드의 제목으로 사용될 문자열 */
const TITLE = 'JSDoc 사용하기';
```

💡 `/**` 입력 후 엔터를 치면 자동으로 JSDoc 템플릿이 생성됩니다.

---

#### `@type` - 자료형 명시

```javascript
/**
 * 원주율
 * @type {number}
 * @const
 */
const PI = 3.14;
```

**언제 쓰나요?**
- 변수의 타입이 명확하지 않을 때
- 타입 체크를 통해 실수를 방지하고 싶을 때

---

#### `@param`, `@returns` - 함수 파라미터와 반환값

```javascript
/**
 * 두 수를 더합니다
 * @param {number} x - 첫 번째 숫자
 * @param {number} y - 두 번째 숫자
 * @returns {number} 두 수의 합
 */
const add = (x, y) => x + y;
```

**자주 헷갈리는 포인트**
- `@param`은 매개변수마다 각각 작성
- 화살표 함수에도 동일하게 사용 가능

---

#### `@typedef`, `@property` - 커스텀 객체 타입

```javascript
/**
 * @typedef {Object} PersonObj 사람 객체
 * @property {string} name 이름
 * @property {number} age 나이
 * @property {boolean} married 기혼여부
 */

/**
 * @param {string} name 이름
 * @param {number} age 나이
 * @param {boolean} married 기혼여부
 * @returns {PersonObj}
 */
function getPersonObj(name, age, married) {
  return {name, age, married};
}

const person1 = getPersonObj('홍길동', 20, false);
```

**언제 쓰나요?**
- 복잡한 객체 구조를 반복해서 사용할 때
- 팀원들과 객체 형식을 공유할 때

---

#### `@constructor`, `@class` - 생성자와 클래스

```javascript
/**
 * 사람 객체 생성 함수
 * @constructor
 * @param {string} name
 * @param {number} age
 */
function Person(name, age) {
  this.name = name;
  this.age = age;
}

/**
 * 새 클래스
 * @class
 */
class Bird {
  /**
   * @constructs
   * @param {string} name
   */
  constructor(name) {
    this.name = name;
  }
}
```

---

#### 기타 유용한 태그들

```javascript
/**
 * @todo 실행 속도 개선 필요
 */
function slowFunction() {
  console.log('느릿느릿');
}

/**
 * @see {@link https://www.yalco.kr} 얄코사이트 참조
 */
function yalcoFunc() {
  // ...
}

/**
 * @readonly
 * @const {string}
 */
const READONLY = '건들지 마라';

/**
 * @deprecated 버전 3부터 안 씀
 */
function oldFunction() {
  console.warn('왜 실행했어요?');
}
```

**실무 패턴**
- `@todo`: 코드 리뷰 시 개선 사항 표시
- `@deprecated`: 레거시 코드 마이그레이션 시 유용
- `@readonly`: 상수 값 보호

### 📄 문서 자동 생성하기

```bash
# 1. JSDoc 설치 (전역)
npm install -g jsdoc

# Mac의 경우
sudo npm install -g jsdoc

# 2. 문서 생성
jsdoc ./

# 특정 파일만
jsdoc ./myfile.js
```

⚠️ **주의사항**: 프로젝트에 `_`로 시작하는 폴더가 있으면 안 됩니다 (JSDoc 버그)

생성된 `out` 폴더의 `index.html`을 브라우저로 열면 API 문서를 볼 수 있습니다.

## 2. 디버깅 🐛

### 📌 VS Code 디버깅

**언제 사용하나요?**
- 변수 값의 변화를 단계별로 확인하고 싶을 때
- 예상과 다른 결과가 나올 때
- 복잡한 로직의 흐름을 추적하고 싶을 때

---

### 🔴 Breakpoint (중단점)

코드 실행을 멈추고 싶은 라인 왼쪽을 클릭하면 빨간 점이 생깁니다.

**디버깅 실행 방법**
1. `Run and Debug` 탭 열기
2. `Node.js` 모드 선택
3. 디버깅 시작

---

### 🎮 디버깅 컨트롤

| 버튼 | 기능 | 언제 쓰나요 |
|------|------|--------------|
| **Continue** | 다음 브레이크포인트로 이동 | 특정 구간만 빠르게 확인하고 싶을 때 |
| **Step Over** | 다음 라인으로 이동 | 함수 내부는 건너뛰고 싶을 때 |
| **Step Into** | 함수 안으로 진입 | 함수 내부 동작을 확인하고 싶을 때 |
| **Step Out** | 함수에서 빠져나옴 | 함수 나머지 부분을 건너뛰고 싶을 때 |

---

### 📊 디버깅 패널 활용

#### VARIABLES 섹션
- 현재 스코프의 모든 변수 값 확인
- 💡 **꿀팁**: 변수 값을 직접 수정해서 테스트 가능!

#### CALL STACK 섹션
- 함수 호출 순서 확인
- 각 함수의 `this` 값 추적

#### WATCH 섹션
- 특정 변수나 표현식을 계속 감시
- 예: `x % 2`, `!!(x % 2)` 같은 표현식도 가능

#### BREAKPOINTS 섹션
- 모든 브레이크포인트 관리
- 일시적으로 비활성화하거나 전체 삭제 가능

---

### 🎯 조건부 브레이크포인트

**Expression (표현식)**
```javascript
// dice < 3일 때만 멈춤
if (Math.random() > 0.5) dice *= -1;
```

**Hit Count (실행 횟수)**
```javascript
// 3번 이상 실행될 때만 멈춤
for (let i = 0; i < 5; i++) {
  x = addOrSubtDice(x);
}
```

**자주 헷갈리는 포인트**
- Expression: 조건이 `true`일 때 멈춤
- Hit Count: 정확히 N번째나 N번 이상 실행 시 멈춤

---

### 🌐 브라우저 디버깅

4. 브레이크포인트 추가 후 새로고침

💡 VS Code와 거의 동일한 기능 제공

**실무 패턴**
- 프론트엔드: 브라우저 디버깅 (DOM 조작 확인 가능)
- 백엔드/로직: VS Code 디버깅 (더 빠름)

## 3. DOM (Document Object Model) 🌳

### 📌 DOM이란?

HTML 문서를 JavaScript가 접근할 수 있는 **객체 트리 구조**로 표현한 것입니다.

```javascript
// 브라우저 전역 객체의 프로퍼티
console.log(
  document === window.document,        // true
  document === globalThis.document     // true
);
```

---

### 🌲 DOM 구조 이해하기

#### HTML 예제
```html
<!DOCTYPE html>
<html lang="ko">
<head>
  <title>DOM 예제</title>
</head>
<body>
  <h1 id="title">장 봐올 것</h1>
  <ul>
    <li>당근</li>
    <li>오이</li>
    <li>양파</li>
  </ul>
  <button>알~겠나요?</button>
</body>
</html>
```

---

### 🔍 DOM 요소 선택과 탐색

```javascript
// HTML 요소 선택
const html = document.querySelector('html');

console.log(html);             // DOM 형태로 출력
console.log(html.children);    // HTMLCollection (이터러블)
```

---

### 📝 DOM 트리 재귀적으로 출력하기

```javascript
function getNameAndChildren(node, indent) {
  console.log(
    '  '.repeat(indent),  // 들여쓰기
    node.nodeName         // 노드 이름 (예: DIV, P, SPAN)
  );
  
  for (child of node.children) {
    getNameAndChildren(child, indent + 1);
  }
}

getNameAndChildren(html, 0);
```

**출력 예시**
```
HTML
  HEAD
    TITLE
  BODY
    H1
    UL
      LI
      LI
      LI
    BUTTON
```

---

### 🧬 DOM 상속 구조 확인하기

```javascript
function listAncestors(obj) {
  let curObj = obj;
  let constNames = [];
  
  while (Object.getPrototypeOf(curObj)) {
    curObj = Object.getPrototypeOf(curObj);
    constNames.push(curObj.constructor.name);
  }
  
  return constNames.join(', ');
}

function printAncestors(node) {
  console.log(listAncestors(node));
  
  for (child of node.children) {
    printAncestors(child);
  }
}

printAncestors(document);
```

**주요 포인트**
- 모든 DOM 요소는 `EventTarget`을 최상위로 상속받음
- `Document`는 다른 DOM 요소들과 계열이 다름
- 각 HTML 태그는 고유한 프로토타입 체인을 가짐

**자주 헷갈리는 포인트**
- `children`: HTMLCollection (HTML 요소만)
- `childNodes`: NodeList (텍스트 노드 포함)

## 📝 복습 퀴즈

### Q1. JSDoc에서 함수의 반환 타입을 명시하는 태그는?

1. `@return`
2. `@returns`
3. `@type`
4. `@output`

**정답: 2번**

`@returns` 태그를 사용합니다. `@return`은 일부 다른 문서화 도구에서 사용되지만, JSDoc의 공식 태그는 `@returns`입니다. `@type`은 변수나 상수의 타입을 지정할 때 사용합니다.

---

### Q2. VS Code 디버깅에서 함수 내부로 진입하고 싶을 때 사용하는 버튼은?

1. Continue
2. Step Over
3. Step Into
4. Step Out

**정답: 3번**

Step Into는 함수 내부로 진입하여 한 줄씩 실행을 추적합니다. Step Over는 함수를 실행하되 내부는 건너뛰고, Step Out은 현재 함수를 빠져나갑니다. Continue는 다음 브레이크포인트까지 실행합니다.

---

### Q3. 다음 중 DOM에 대한 설명으로 올바르지 않은 것은?

1. Document는 window 객체의 프로퍼티다
2. 모든 DOM 요소는 EventTarget을 상속받는다
3. children 프로퍼티는 텍스트 노드를 포함한다
4. querySelector로 특정 요소를 선택할 수 있다

**정답: 3번**

`children` 프로퍼티는 HTML 요소만 포함하는 HTMLCollection을 반환합니다. 텍스트 노드를 포함한 모든 노드를 확인하려면 `childNodes` 프로퍼티를 사용해야 합니다. 나머지 선택지는 모두 올바른 설명입니다.

### Q4. JSDoc에서 커스텀 객체 타입을 정의할 때 사용하는 태그 조합은?

1. `@object`, `@field`
2. `@typedef`, `@property`
3. `@type`, `@param`
4. `@interface`, `@member`

**정답: 2번**

`@typedef`로 새로운 타입을 정의하고, `@property`로 객체의 각 속성을 명시합니다. 이렇게 정의한 타입은 `@param`이나 `@returns`에서 재사용할 수 있습니다.

### Q5. 디버깅 중 특정 표현식의 값을 계속 관찰하고 싶을 때 사용하는 패널은?

1. VARIABLES
2. CALL STACK
3. WATCH
4. BREAKPOINTS

**정답: 3번**

WATCH 패널에 변수명이나 표현식(예: `x % 2`)을 추가하면 디버깅 중 해당 값의 변화를 계속 추적할 수 있습니다. VARIABLES는 현재 스코프의 모든 변수를 보여주고, CALL STACK은 함수 호출 순서를, BREAKPOINTS는 설정된 중단점 목록을 관리합니다.
