## 1. Number 객체 🔢

### 1.1 생성자 함수

**개념** : Number 객체는 숫자 값을 다루기 위한 래퍼(wrapper) 객체입니다.

**문법** :

```jsx
new Number([value]);
Number(value); // 생성자가 아닌 함수로 사용
```

**사용 상황** :

- 숫자를 객체로 래핑해야 할 때
- 다양한 형태의 값을 숫자로 변환할 때

  **예시 코드** :

```jsx
// 생성자로 사용 - 객체 반환
const numObj1 = new Number(); // 인자 없으면 0
const numObj2 = new Number(123);
const numObj3 = new Number(-123.45);

console.log(numObj1.valueOf()); // 0
console.log(numObj2.valueOf()); // 123

// 문자열을 숫자로 변환
console.log(new Number("-123.4567")); // Number {-123.4567}
console.log(new Number("Infinity")); // Number {Infinity}

// NaN 반환 케이스
console.log(new Number("123ABC")); // Number {NaN}
console.log(new Number([1, 2, 3])); // Number {NaN}

// ⭐ new 없이 사용 - 원시 타입 반환
const num1 = Number("123");
const num2 = Number(true);
const num3 = Number(null);

console.log(typeof num1, num1); // number 123
console.log(typeof num2, num2); // number 1
console.log(typeof num3, num3); // number 0
```

**핵심** : `new`를 사용하면 Number 객체를 반환하고, `new` 없이 사용하면 주어진 값을 숫자 타입으로 변환하여 반환합니다.

---

### 1.2 정적 프로퍼티

**개념** : Number 생성자 함수 자체에 정의된 상수 값들입니다.

### 1.2.1 Number.EPSILON

**설명** : Number 타입에서 표현 가능한 1보다 큰 가장 작은 수와 1의 차이값입니다.

**사용 상황** : 부동소수점 계산 오차를 해결할 때 사용합니다.

```jsx
console.log(Number.EPSILON); // 2.220446049250313e-16

// 부동소수점 오차 문제
console.log(0.1 + 0.2); // 0.30000000000000004

// EPSILON을 이용한 해결
console.log(0.1 + 0.2 - 0.3 < Number.EPSILON); // true
```

### 1.2.2 Number.MAX_VALUE / Number.MIN_VALUE

**설명** : JavaScript에서 표현 가능한 가장 큰 양수와 가장 작은 양수입니다.

```jsx
console.log(Number.MAX_VALUE); // 1.7976931348623157e+308
console.log(Number.MIN_VALUE); // 5e-324
```

### 1.2.3 Number.MAX_SAFE_INTEGER / Number.MIN_SAFE_INTEGER

**설명** : 안전하게 표현 가능한 정수의 최대값과 최소값입니다.

**사용 상황** : 정수 연산의 정확성을 보장해야 할 때 이 범위 내에서 작업합니다.

```jsx
console.log(Number.MAX_SAFE_INTEGER); // 9007199254740991
console.log(Number.MIN_SAFE_INTEGER); // -9007199254740991
```

### 1.2.4 Number.POSITIVE_INFINITY / Number.NEGATIVE_INFINITY

```jsx
console.log(Number.POSITIVE_INFINITY); // Infinity
console.log(Number.NEGATIVE_INFINITY); // -Infinity
```

### 1.2.5 Number.NaN

```jsx
console.log(Number.NaN); // NaN
```

---

### 1.3 정적 메서드

### 1.3.1 Number.isFinite() / Number.isNaN()

**개념** : 전역 함수와 달리 암묵적 타입 변환을 하지 않습니다.

**사용 상황** : 엄격한 타입 체크가 필요할 때 사용합니다.

```jsx
// 전역 함수 vs Number 메서드
console.log(isFinite(null)); // true (null을 0으로 변환)
console.log(Number.isFinite(null)); // false (변환 안 함)

console.log(isNaN("abc")); // true (NaN으로 변환)
console.log(Number.isNaN("abc")); // false (숫자 타입이 아님)
```

### 1.3.2 Number.parseInt() / Number.parseFloat()

**설명** : 전역의 parseInt, parseFloat를 가리킵니다.

```jsx
console.log(Number.parseInt("123.4567")); // 123
console.log(Number.parseFloat("123.4567")); // 123.4567
```

### 1.3.3 Number.isInteger() / Number.isSafeInteger()

**사용 상황** : 정수 여부와 안전한 정수 범위 내 여부를 확인할 때 사용합니다.

```jsx
console.log(Number.isInteger(123)); // true
console.log(Number.isInteger(123.45)); // false
console.log(Number.isInteger("123")); // false (암묵적 변환 안 함)

console.log(Number.isSafeInteger(123)); // true
console.log(Number.isSafeInteger(Number.MAX_SAFE_INTEGER)); // true
console.log(Number.isSafeInteger(Number.MAX_SAFE_INTEGER + 1)); // false
```

---

### 1.4 인스턴스 메서드

**주의** : 숫자 리터럴에서 직접 호출할 때는 괄호로 감싸야 합니다 (소수점과 구분하기 위해).

### 1.4.1 toExponential()

**개념** : 숫자를 지수 표기법 문자열로 변환합니다.

**사용 상황** : 매우 크거나 작은 숫자를 간결하게 표현할 때 사용합니다.

```jsx
const numInExp = (123.456789).toExponential();
console.log(typeof numInExp, numInExp); // string 1.23456789e+2

// 자릿수 제한
console.log((123.456789).toExponential(2)); // 1.23e+2
console.log((123.456789).toExponential(4)); // 1.2346e+2
```

### 1.4.2 toFixed()

**개념** : 소수점 이하 자릿수를 반올림하여 문자열로 반환합니다.

**사용 상황** : 금액 표시, 소수점 자릿수를 고정해야 할 때 사용합니다.

```jsx
console.log((111.234567).toFixed()); // "111" (기본값 0)
console.log((111.234567).toFixed(2)); // "111.23"
console.log((111.234567).toFixed(3)); // "111.235" (반올림)
```

### 1.4.3 toPrecision()

**개념** : 전체 유효 자릿수를 지정하여 문자열로 반환합니다.

**사용 상황** : 과학적 표기나 일정한 정밀도가 필요할 때 사용합니다.

```jsx
console.log((1234.56789).toPrecision()); // "1234.56789"

// 정수부보다 적으면 지수 표기
console.log((1234.56789).toPrecision(2)); // "1.2e+3"
console.log((1234.56789).toPrecision(4)); // "1235"

// 반올림
console.log((1234.56789).toPrecision(6)); // "1234.57"
```

### 1.4.4 toString()

**개념** : 숫자를 문자열로 변환합니다. 진수 변환도 가능합니다.

**사용 상황** : 2진수, 8진수, 16진수 등으로 변환할 때 유용합니다.

```jsx
console.log((11).toString()); // "11"
console.log((11).toString(2)); // "1011" (2진수)
console.log((11).toString(8)); // "13" (8진수)
console.log((11).toString(16)); // "b" (16진수)
```

## 2. Math 객체 📐

### 2.1 개요

**개념** : 수학 연산을 위한 빌트인 객체로, 정적 프로퍼티와 메서드만 제공합니다.

**특징** :

- 생성자 함수가 아님 (new 사용 불가)
- Number 타입만 지원 (BigInt 사용 불가)

---

### 2.2 정적 프로퍼티

### 2.2.1 Math.PI

**설명** : 원주율 π 값입니다.

```jsx
console.log(Math.PI); // 3.141592653589793
```

### 2.2.2 Math.E

**설명** : 자연로그의 밑 e 값입니다.

```jsx
console.log(Math.E); // 2.718281828459045
```

---

### 2.3 정적 메서드

### 2.3.1 Math.abs()

**개념** : 절댓값을 반환합니다.

**사용 상황** : 두 값의 차이를 비교하거나 거리를 계산할 때 사용합니다.

```jsx
console.log(Math.abs(123)); // 123
console.log(Math.abs(-123)); // 123

// 0 반환 케이스
console.log(Math.abs(0), Math.abs(""), Math.abs(null), Math.abs([])); // 모두 0

// NaN 반환 케이스
console.log(Math.abs("abc"), Math.abs(undefined), Math.abs({ a: 1 })); // 모두 NaN

// 실용 예제: 부동소수점 오차 비교
const isEqual = (a, b) => Math.abs(a - b) < Number.EPSILON;
console.log(isEqual(0.1 + 0.2, 0.3)); // true
```

### 2.3.2 Math.ceil() / Math.round() / Math.floor() / Math.trunc()

**개념** : 올림, 반올림, 내림, 정수부만 추출합니다.

**사용 상황** :

- ceil: 페이지네이션 계산
- round: 일반적인 반올림
- floor: 배열 인덱스 계산
- trunc: 소수점 제거

```jsx
for (const num of [1.4, 1.6, -1.4, -1.6]) {
  console.log(
    num + " : ",
    Math.ceil(num), // 2, 2, -1, -1 (올림)
    Math.round(num), // 1, 2, -1, -2 (반올림)
    Math.floor(num), // 1, 1, -2, -2 (내림)
    Math.trunc(num) // 1, 1, -1, -1 (정수부)
  );
}
```

**핵심** : 음수에서 floor와 trunc의 동작이 다릅니다.

### 2.3.3 Math.pow()

**개념** : 거듭제곱 값을 반환합니다.

**사용 상황** : 지수 연산이 필요할 때 사용하며, `**` 연산자로 대체 가능합니다.

```jsx
console.log(Math.pow(4, 2)); // 16 (4 ** 2와 동일)
console.log(Math.pow(4, -1)); // 0.25 (4 ** -1과 동일)

console.log(Math.pow(4)); // NaN (인자 2개 필요)
```

### 2.3.4 Math.sqrt()

**개념** : 제곱근을 반환합니다.

```jsx
console.log(Math.sqrt(25)); // 5 (25 ** 0.5와 동일)
console.log(Math.sqrt(2)); // 1.4142135623730951

// NaN 반환
console.log(Math.sqrt(-25)); // NaN (음수의 제곱근)
```

### 2.3.5 Math.max() / Math.min()

**개념** : 인자들 중 최댓값과 최솟값을 반환합니다.

**사용 상황** : 배열에서 최댓값/최솟값 찾기, 값의 범위 제한 등

```jsx
console.log(Math.max(8, 5, 9, 6, 3, 1, 4, 2, 7)); // 9
console.log(Math.min(8, 5, 9, 6, 3, 1, 4, 2, 7)); // 1

// 배열과 함께 사용
const arr = [8, 5, 9, 6, 3, 1, 4, 2, 7];
console.log(Math.max(...arr)); // 9
```

### 2.3.6 Math.random()

**개념** : 0 이상 1 미만의 난수를 반환합니다.

**사용 상황** : 랜덤 값 생성이 필요할 때 사용합니다.

**⚠️ 주의** : 보안이 중요한 경우 `Crypto.getRandomValues()` 메서드를 사용해야 합니다.

```jsx
// 0 ~ 1 사이 난수
for (let i = 0; i < 3; i++) {
  console.log(Math.random()); // 예: 0.234567, 0.891234, 0.456789
}

// 0 ~ 9 사이 정수 난수
for (let i = 0; i < 10; i++) {
  console.log(Math.floor(Math.random() * 10));
}

// min ~ max 사이 정수 난수 함수
function getRandomInt(min, max) {
  return Math.floor(Math.random() * (max - min + 1)) + min;
}
```

### 2.3.7 삼각함수 메서드

**개념** : sin, cos, tan과 그 역함수들을 제공합니다.

**사용 상황** : 그래픽, 애니메이션, 물리 시뮬레이션 등에서 사용합니다.

```jsx
// 삼각함수 (라디안 단위)
console.log(Math.sin(Math.PI / 2)); // 1
console.log(Math.cos(Math.PI * 2)); // 1
console.log(Math.tan((Math.PI / 180) * 45)); // 1

// 역삼각함수
console.log(Math.asin(1)); // Math.PI / 2
console.log(Math.acos(0)); // Math.PI / 2
console.log(Math.atan(Infinity)); // Math.PI / 2
```

## 3. Date 객체 📅

### 3.1 생성자 함수

**개념** : 날짜와 시간을 다루는 빌트인 객체입니다.

### 3.1.1 현재 날짜와 시간

```jsx
const now = new Date();
console.log(typeof now); // object
console.log(now); // 현재 날짜/시간 객체

// new 없이 사용하면 문자열 반환
const nowStr = Date();
console.log(typeof nowStr); // string
console.log(nowStr); // 현재 날짜/시간 문자열
```

### 3.1.2 밀리초 기준 생성

**개념** : 1970년 1월 1일 00:00:00 UTC부터의 밀리초를 인자로 받습니다.

```jsx
console.log(new Date(0)); // 1970-01-01T00:00:00.000Z

// 30년 후
console.log(new Date(1000 * 60 * 60 * 24 * 365 * 30));
```

### 3.1.3 단위별 숫자 입력

**문법** : `new Date(year, month[, date[, hours[, minutes[, seconds[, milliseconds]]]]])`

**주의** :

- 연, 월은 필수 (월은 0부터 시작)
- 나머지는 선택적 (기본값 0)

```jsx
console.log(new Date(2022, 8)); // 2022년 9월 1일 00:00:00

console.log(new Date(2022, 8, 20, 14, 35)); // 2022년 9월 20일 14:35:00

console.log(new Date(2022, 8, 20, 14, 35, 47, 789)); // 밀리초까지
```

### 3.1.4 dateString 입력

**⚠️ 주의** : 브라우저마다 동작이 다를 수 있어 권장하지 않습니다.

```jsx
console.log(new Date("August 20, 2022 14:35:47"));
console.log(new Date("2022-08-20T14:35:47"));
```

---

### 3.2 정적 메서드

### 3.2.1 Date.now()

**개념** : 현재 시간의 밀리초 값을 반환합니다.

**사용 상황** : 타임스탬프 생성, 성능 측정 등에 사용합니다.

```jsx
console.log(Date.now()); // 예: 1673952000000
```

### 3.2.2 Date.parse() / Date.UTC()

**개념** : 특정 시간의 밀리초 값을 반환합니다.

```jsx
// parse: 문자열을 파싱
console.log(Date.parse("August 20, 2022 00:00:00 UTC"));

// 시스템 시간대가 한국이면 시차 9시간 적용
console.log(Date.parse("August 20, 2022 09:00:00"));

// UTC: 단위별 숫자 입력 (월은 0부터)
console.log(Date.UTC(2022, 7, 20, 0, 0, 0));
```

---

### 3.3 인스턴스 메서드

### 3.3.1 문자열 변환 메서드

**개념** : Date 객체를 다양한 형식의 문자열로 변환합니다.

```jsx
const now = new Date();

console.log(now.toString()); // 전체 정보
console.log(now.toDateString()); // 날짜만
console.log(now.toTimeString()); // 시간만
```

### 3.3.2 toLocaleString()

**개념** : 지정된 언어 코드로 날짜/시간을 표현합니다.

**사용 상황** : 다국어 지원 애플리케이션에서 사용합니다.

```jsx
const now = new Date();

console.log(now.toLocaleString()); // 시스템 언어
console.log(now.toLocaleString("ko-KR")); // 한국어
console.log(now.toLocaleString("en-US")); // 영어
console.log(now.toLocaleString("de-DE")); // 독일어
```

### 3.3.3 Getter 메서드

**개념** : Date 객체에서 개별 단위 값을 가져옵니다.

```jsx
const now = new Date();

console.log("연:", now.getFullYear()); // 2022
console.log("월:", now.getMonth()); // 0 ~ 11
console.log("일:", now.getDate()); // 1 ~ 31
console.log("요일:", now.getDay()); // 0(일) ~ 6(토)
console.log("시:", now.getHours()); // 0 ~ 23
console.log("분:", now.getMinutes()); // 0 ~ 59
console.log("초:", now.getSeconds()); // 0 ~ 59
console.log("밀리초:", now.getMilliseconds()); // 0 ~ 999
```

**실용 예제** :

```jsx
const now = new Date();
const year = now.getFullYear();
const month = now.getMonth() + 1; // 0부터 시작하므로 +1
const date = now.getDate();
const day = "일월화수목금토"[now.getDay()];

console.log(`오늘은 ${year}년 ${month}월 ${date}일, ${day}요일입니다.`);
```

### 3.3.4 Setter 메서드

**개념** : Date 객체의 개별 단위 값을 설정합니다.

**주의** : 요일(getDay)에는 setter가 없습니다.

```jsx
const now = new Date();
console.log(now.toString());

now.setFullYear(2022);
now.setMonth(7); // 8월
now.setDate(20);
now.setHours(14);
now.setMinutes(35);
now.setSeconds(47);
now.setMilliseconds(789);

console.log(now.toString());
```

### 3.3.5 getTime() / setTime()

**개념** : 밀리초 타임스탬프를 get/set 합니다.

**사용 상황** : 날짜 복사, 날짜 비교, 날짜 계산 등에 사용합니다.

```jsx
const date1 = new Date(2020, 7, 20);
const date1value = date1.getTime();

console.log(date1.toString());
console.log(date1value); // 밀리초 값

const date2 = new Date();
date2.setTime(date1value); // date1과 같은 날짜로 설정
console.log(date2.toString());
```

### 3.3.6 getTimezoneOffset()

**개념** : 시스템 시간대와 UTC의 시간 차이를 분 단위로 반환합니다.

**사용 상황** : 시간대 변환이 필요할 때 사용합니다.

```jsx
console.log(new Date().getTimezoneOffset() / 60); // 한국: -9
```

### 3.3.7 toISOString()

**개념** : ISO 8601 형식의 문자열을 반환합니다 (UTC 기준).

**사용 상황** : API 통신, 데이터베이스 저장 등 표준 형식이 필요할 때 사용합니다.

```jsx
const now = new Date();
console.log(now.toISOString()); // 2022-09-20T05:35:47.789Z (UTC)
console.log(now.toString()); // 로컬 시간

// 로컬 시간으로 ISO 문자열 생성
const timezoneOffset = now.getTimezoneOffset() * 60000;
const isoStr = new Date(now.getTime() - timezoneOffset).toISOString();
console.log(isoStr);
```

## 📝 핵심 요약

### Number 객체

- `new Number()`는 객체 반환, `Number()`는 타입 변환
- `Number.EPSILON`: 부동소수점 오차 해결
- `Number.isFinite()`, `Number.isNaN()`: 암묵적 변환 없음
- `toFixed()`: 소수점 고정, `toPrecision()`: 유효 자릿수 지정
- `toString(radix)`: 진수 변환 가능

### Math 객체

- 정적 메서드만 제공 (생성자 아님)
- `Math.abs()`: 절댓값, 부동소수점 비교에 유용
- `Math.ceil/round/floor/trunc()`: 올림/반올림/내림/정수부
- `Math.random()`: 0 이상 1 미만 난수 (보안용은 Crypto 사용)
- `Math.max/min()`: 최댓값/최솟값

### Date 객체

- 월은 0부터 시작 (0=1월, 11=12월)
- `Date.now()`: 현재 타임스탬프
- `getMonth()`: 0~11, `getDay()`: 0(일)~6(토)
- `toISOString()`: UTC 기준 ISO 8601 형식
- `getTimezoneOffset()`: 시간대 차이 (분 단위)

### 문제 5: D-Day 계산기

특정 날짜까지 남은 일수를 계산하는 함수를 작성하세요.

**기본 코드** :

```jsx
function calculateDday(targetDate) {
  // 여기에 코드를 작성하세요
}

// 테스트
const newYear = new Date(2025, 0, 1);
console.log(calculateDday(newYear)); // 남은 일수 출력
```

**정답** :

```jsx
function calculateDday(targetDate) {
  const today = new Date();

  // 시간 부분을 제거하고 날짜만 비교
  today.setHours(0, 0, 0, 0);
  targetDate.setHours(0, 0, 0, 0);

  const diffTime = targetDate.getTime() - today.getTime();
  const diffDays = Math.ceil(diffTime / (1000 * 60 * 60 * 24));

  if (diffDays > 0) {
    return `D-${diffDays}`;
  } else if (diffDays === 0) {
    return "D-Day";
  } else {
    return `D+${Math.abs(diffDays)}`;
  }
}

// 테스트
const newYear = new Date(2025, 0, 1);
console.log(calculateDday(newYear));

const past = new Date(2020, 0, 1);
console.log(calculateDday(past)); // D+xxx
```

**해설** :

- `setHours(0, 0, 0, 0)`로 시간을 자정으로 설정하여 날짜만 비교
- `getTime()`으로 밀리초 값을 얻어 차이 계산
- `1000 * 60 * 60 * 24`는 1일의 밀리초 값
- `Math.ceil()`로 올림하여 당일을 포함
- 양수/0/음수에 따라 D-/D-Day/D+ 형식으로 반환
