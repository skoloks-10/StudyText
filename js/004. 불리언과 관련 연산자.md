## 1. 불리언(Boolean) 타입의 이해

### 1.1 불리언의 개념

**개념** : 참(`true`) 또는 거짓(`false`) 두 가지 값만 가지는 논리적 데이터 타입

**특징** :

- JavaScript의 원시 타입(Primitive Type) 중 하나
- 조건문과 논리 연산의 기초
- 비교 연산자의 결과값으로 반환됨

| 항목           | 설명                             | 예시 코드                  |
| -------------- | -------------------------------- | -------------------------- |
| 기본값         | `true`,`false`두 가지만 존재     | `let isTrue = true;`       |
| 타입 확인      | `typeof`연산자로 확인            | `typeof true // 'boolean'` |
| 비교 연산 결과 | 비교 연산자는 boolean 반환       | `1 === 2 // false`         |
| 사용 상황      | 조건문, 반복문의 조건, 상태 표현 | `if (isLoggedIn) { ... }`  |

```jsx
console.log(true, typeof true); // true 'boolean'
console.log(false, typeof false); // false 'boolean'

let a = 1 === 2; // false (1과 2는 같지 않음)
let b = "abc" !== "def"; // true (두 문자열은 다름)
let c = a !== b; // true (false !== true)

console.log(a, typeof a); // false 'boolean'
console.log(b, typeof b); // true 'boolean'
console.log(c, typeof c); // true 'boolean'
```

### 1.2 비교 연산자와 불리언

**개념** : 두 값을 비교하여 boolean 값을 반환하는 연산자

| 연산자    | 의미                        | 예시        | 결과    |
| --------- | --------------------------- | ----------- | ------- |
| `===`     | 일치 (값과 타입 모두 같음)  | `1 === 1`   | `true`  |
| `!==`     | 불일치 (값이나 타입이 다름) | `1 !== '1'` | `true`  |
| `==`      | 동등 (타입 변환 후 비교)    | `1 == '1'`  | `true`  |
| `!=`      | 부등 (타입 변환 후 비교)    | `1 != '1'`  | `false` |
| `>`,`<`   | 크다, 작다                  | `5 > 3`     | `true`  |
| `>=`,`<=` | 크거나 같다, 작거나 같다    | `5 >= 5`    | `true`  |

**주의사항** :

```jsx
// ⚠️ 연산자 체이닝 주의
let d = (typeof a === typeof b) === true;
// 실행 순서: (typeof a === typeof b) === true
// ('boolean' === 'boolean') === true
// true === true
// 결과: true

console.log(d, typeof d); // true 'boolean'
```

## 2. 논리 연산자

### 2.1 부정 연산자 (NOT)

**개념** : 불리언 값을 반대로 뒤집는 연산자

| 항목      | 설명                                | 예시 코드               |
| --------- | ----------------------------------- | ----------------------- |
| 문법      | `!`기호 사용                        | `!true // false`        |
| 기능      | true를 false로, false를 true로 변환 | `!false // true`        |
| 중첩 사용 | 여러 번 사용 가능                   | `!!true // true`        |
| 사용 상황 | 조건 반전, boolean 변환             | `if (!isError) { ... }` |

```jsx
console.log(
  true,
  !true, // true, false
  false,
  !false // false, true
);

// 중첩된 부정 연산자
console.log(
  true,
  !true,
  !!true,
  !!!true
  // true, false, true, false
);

console.log(
  false,
  !false,
  !!false,
  !!!false
  // false, true, false, true
);
```

**실용 예시** :

```jsx
console.log(
  true === !false, // true (참은 거짓의 부정)
  !(1 == "1"), // false (1과 '1'은 같음, 그것의 부정)
  !(1 === "1"), // true (1과 '1'은 다름, 그것의 부정은 참)
  !(typeof false === "boolean") // false (false는 boolean, 그것의 부정)
);
```

### 2.2 AND 연산자 (&&)

**개념** : 양쪽 조건이 모두 `true`일 때만 `true`를 반환하는 논리 연산자

**진리표** :

| A     | B     | A && B |
| ----- | ----- | ------ |
| true  | true  | true   |
| true  | false | false  |
| false | true  | false  |
| false | false | false  |

| 항목      | 설명                                       | 예시 코드                            |
| --------- | ------------------------------------------ | ------------------------------------ |
| 문법      | `&&`기호 사용                              | `true && false // false`             |
| 조건      | 양쪽 모두 true여야 true 반환               | `(x > 0) && (x < 10)`                |
| 사용 상황 | 여러 조건을 동시에 만족해야 할 때          | 범위 체크, 복합 조건                 |
| 특징      | 앞이 false면 뒤 코드 실행 안 함 (단축평가) | `false && console.log('실행 안 됨')` |

```jsx
console.log(
  true && true, // true
  true && false, // false
  false && true, // false
  false && false // false
);

// 실용 예시
let x = 14;
console.log(
  (x > 10 && x <= 20) || x % 3 === 0
  // (14 > 10 && 14 <= 20) || 14 % 3 === 0
  // (true && true) || false
  // true || false
  // true
);
```

### 2.3 OR 연산자 (||)

**개념** : 양쪽 중 하나라도 `true`이면 `true`를 반환하는 논리 연산자

**진리표** :

| A     | B     | A     |     | B   |
| ----- | ----- | ----- | --- | --- |
| true  | true  | true  |
| true  | false | true  |
| false | true  | true  |
| false | false | false |

| 항목      | 설명                                      | 예시 코드                |
| --------- | ----------------------------------------- | ------------------------ |
| 문법      | `                                         |                          |
| 조건      | 하나라도 true면 true 반환                 | `(x < 0)                 |
| 사용 상황 | 여러 조건 중 하나만 만족하면 될 때        | 기본값 설정, 대체값 제공 |
| 특징      | 앞이 true면 뒤 코드 실행 안 함 (단축평가) | `true                    |

```jsx
console.log(
  true || true, // true
  true || false, // true
  false || true, // true
  false || false // false
);
```

### 2.4 드 모르간의 법칙

**개념** : 논리 연산자를 변환하는 수학적 법칙

| 법칙          | 설명              | 예시 |
| ------------- | ----------------- | ---- |
| NOT (A AND B) | !(A && B) === (!A |      |
| NOT (A OR B)  | !(A               |      |

```jsx
let a = true;
let b = true;

console.log(
  !(a && b) === (!a || !b), // true (항상)
  !(a || b) === (!a && !b) // true (항상)
);
```

**활용** :

- 복잡한 조건문을 단순화할 때 사용
- 코드 가독성 향상
- 조건 반전이 필요할 때 유용

### 2.5 단축 평가 (Short Circuit)

**개념** : 논리 연산자가 결과를 미리 알 수 있을 때 나머지 코드를 실행하지 않는 특성

**동작 원리** :

- `&&`: 앞이 **false**면 뒤를 평가하지 않음 (어차피 결과는 false)
- `||`: 앞이 **true**면 뒤를 평가하지 않음 (어차피 결과는 true)

| 연산자 | 단축 조건  | 설명               | 예시                        |
| ------ | ---------- | ------------------ | --------------------------- |
| `&&`   | 앞이 false | 뒤를 실행하지 않음 | `false && console.log('X')` |
| `      |            | `                  | 앞이 true                   |

```jsx
let error = true;

// 앞이 true일 때만 뒤 코드 실행
error && console.warn("오류 발생!"); // 실행됨

// 앞이 false일 때만 뒤 코드 실행
error || console.log("이상 없음."); // 실행 안 됨
```

**값 반환 특성** :

```jsx
let x = true;

// ⭐️ &&, || 연산자는 boolean이 아닌 값 자체를 반환
let y = x && "abc"; // x가 true이므로 'abc' 반환
let z = x || 123; // x가 true이므로 x 반환 (true)

console.log(y, z); // 'abc' true
```

**실용 패턴** :

| 패턴        | 용도                       | 예시 코드                          |
| ----------- | -------------------------- | ---------------------------------- |
| 조건부 실행 | 조건이 참일 때만 실행      | `isLoggedIn && showDashboard()`    |
| 기본값 설정 | 값이 없을 때 대체값 사용   | `let name = input                  |
| 에러 처리   | 에러 시에만 로그 출력      | `error && console.error(error)`    |
| 성능 최적화 | 부하 적은 코드를 앞에 배치 | `cheapCheck() && expensiveCheck()` |

```jsx
// 실용 예시
let x = false;
let y = x && "abc"; // x가 false이므로 false 반환
let z = x || 123; // x가 false이므로 123 반환

console.log(y, z); // false 123
```

## 3. 삼항 연산자

### 3.1 삼항 연산자의 개념

**개념** : 조건에 따라 두 값 중 하나를 선택하는 연산자

**문법** : `조건 ? 참일때값 : 거짓일때값`

| 항목      | 설명                                           | 예시 코드                         |
| --------- | ---------------------------------------------- | --------------------------------- |
| 문법      | `? :`기호 사용                                 | `x > 0 ? 'positive' : 'negative'` |
| 조건      | 조건이 true면 첫 번째, false면 두 번째 값 반환 | `age >= 18 ? '성인' : '미성년'`   |
| 사용 상황 | 간단한 조건부 값 할당, if-else 대체            | 변수 초기화, 출력 메시지 선택     |
| 특징      | 표현식으로 사용 가능 (값을 반환)               | `let result = condition ? a : b`  |

```jsx
let x = true;

let y = x ? "참입니다." : "거짓입니다.";
console.log(y); // '참입니다.'
```

### 3.2 실용 예시

**문자열 결합** :

```jsx
let num = 103247;

console.log("num은 3의 배수" + (num % 3 === 0 ? "입니다." : "가 아닙니다."));
// 'num은 3의 배수가 아닙니다.'
```

**조건부 함수 실행** :

```jsx
let error = true;

error ? console.error("오류 발생!") : console.log("이상 없음");
// '오류 발생!' 출력
```

**중첩 삼항 연산자** (비권장 - 가독성 저하):

```jsx
let score = 85;
let grade = score >= 90 ? "A" : score >= 80 ? "B" : score >= 70 ? "C" : "F";
console.log(grade); // 'B'
```

## 4. Truthy와 Falsy

### 4.1 개념

**Truthy** : 불리언 컨텍스트에서 `true`로 평가되는 값

**Falsy** : 불리언 컨텍스트에서 `false`로 평가되는 값

**중요** : 이들은 `true`/`false`와 **같다는 의미가 아니라** , 불리언으로 **평가된다**는 의미

### 4.2 Falsy 값 (정확히 8개)

**JavaScript의 모든 Falsy 값** :

| 값          | 설명         | 예시                 |
| ----------- | ------------ | -------------------- |
| `false`     | 불리언 false | `if (false) { }`     |
| `0`         | 숫자 0       | `if (0) { }`         |
| `-0`        | 음수 0       | `if (-0) { }`        |
| `0n`        | BigInt 0     | `if (0n) { }`        |
| `''`        | 빈 문자열    | `if ('') { }`        |
| `null`      | null 값      | `if (null) { }`      |
| `undefined` | undefined 값 | `if (undefined) { }` |
| `NaN`       | Not a Number | `if (NaN) { }`       |

```jsx
console.log(
  0 ? true : false, // false
  -0 ? true : false, // false
  "" ? true : false, // false
  null ? true : false, // false
  undefined ? true : false, // false
  NaN ? true : false // false
);
```

**타입 변환 시 주의** :

```jsx
// 💡 일부 값들은 false로 타입 변환됨
console.log(
  0 == false, // true (타입 변환됨)
  0 === false, // false (타입 다름)
  "" == false, // true (타입 변환됨)
  "" === false // false (타입 다름)
);

// ⚠️ 하지만 이들은 타입 변환되지 않음
console.log(
  null == false, // false
  undefined == false, // false
  NaN == false // false
);
```

### 4.3 Truthy 값

**개념** : **Falsy 8개를 제외한 모든 값**이 Truthy

| 범주   | 예시                      | 결과   |
| ------ | ------------------------- | ------ |
| 숫자   | `1.23`,`-999`,`Infinity`  | Truthy |
| 문자열 | `'0'`,`' '`,`'false'`     | Truthy |
| 객체   | `{}`,`[]`,`function() {}` | Truthy |
| 기타   | `new Date()`,`/regex/`    | Truthy |

```jsx
console.log(
  1.23 ? true : false, // true
  -999 ? true : false, // true
  "0" ? true : false, // true (문자열 '0'은 Truthy!)
  " " ? true : false, // true (공백도 Truthy!)
  Infinity ? true : false, // true
  -Infinity ? true : false, // true
  {} ? true : false, // true (빈 객체도 Truthy!)
  [] ? true : false // true (빈 배열도 Truthy!)
);
```

**주의사항** :

```jsx
// ⚠️ Truthy라고 해서 true와 같은 것은 아님
console.log(
  1.23 == true, // false (1만 true로 변환됨)
  " " == true, // false
  {} == true // false
);
```

### 4.4 실용 예시

**증감 연산자와 조합** :

```jsx
let x = 0; // Falsy
let y = 1; // Truthy

x && x++; // x가 0(falsy)이므로 x++ 실행 안 됨
y && y++; // y가 1(truthy)이므로 y++ 실행됨

console.log(x, y); // 0, 2
```

**홀짝 판별** :

```jsx
let x = 2;
let y = 3;

console.log(
  x % 2 ? "홀" : "짝", // '짝' (0은 falsy)
  y % 2 ? "홀" : "짝" // '홀' (1은 truthy)
);
```

**기본값 설정** :

```jsx
let x = ""; // Falsy
let y = "회사원"; // Truthy
let z = x || y;

console.log(z); // '회사원' (x가 falsy이므로 y 반환)

x = x || "단기알바";
y = y || "단기알바";

console.log(x, y); // '단기알바', '회사원'
```

## 5. Boolean 타입 변환

### 5.1 명시적 변환 방법

**개념** : 다른 타입의 값을 명시적으로 boolean으로 변환

| 방법        | 설명             | 예시 코드            |
| ----------- | ---------------- | -------------------- |
| `Boolean()` | 생성자 함수 사용 | `Boolean(1) // true` |
| `!!`        | 이중 부정 연산자 | `!!1 // true`        |
| 삼항 연산자 | 조건식 활용      | `x ? true : false`   |

### 5.2 이중 부정 연산자 (!!)

**개념** : 부정 연산자를 두 번 사용하여 boolean 값으로 변환

**동작 원리** :

1. 첫 번째 `!`: 값을 boolean으로 변환하고 반전
2. 두 번째 `!`: 다시 반전하여 원래 boolean 값 획득

```jsx
// 한 번 부정 - boolean으로 변환 후 반전
console.log(
  !1,
  !-999,
  !"hello", // false, false, false
  !0,
  !"",
  !null // true, true, true
);

// ⭐️ 두 번 부정 - 해당 boolean 값 그대로
console.log(
  !!1,
  !!-999,
  !!"hello", // true, true, true
  !!0,
  !!"",
  !!null // false, false, false
);
```

### 5.3 실용 예시

**조건 판별** :

```jsx
let x = 123;

console.log(
  "x는 홀수인가?",
  !!(x % 2) // true (1은 truthy, !!1은 true)
);
```

**입력값 검증** :

```jsx
let userInput = "";

if (!!userInput) {
  console.log("입력값이 있습니다.");
} else {
  console.log("입력값이 없습니다."); // 이게 실행됨
}
```

**데이터 존재 여부 확인** :

```jsx
let data = null;
let hasData = !!data; // false

console.log(hasData); // false
```

## 📌 핵심 요약본

### 불리언 타입

- **값** : `true`, `false` 두 가지만 존재
- **타입** : `'boolean'`
- **생성** : 비교 연산자 결과, 직접 할당

### 논리 연산자

- **부정 `!`** : 불리언 값 반전, `!true === false`
- **AND `&&`** : 양쪽 모두 true여야 true
- **OR `||`** : 하나라도 true면 true
- **단축 평가** : 결과가 확정되면 나머지 평가 안 함

### 삼항 연산자

- **문법** : `조건 ? 참값 : 거짓값`
- **용도** : 간단한 조건부 값 선택
- **특징** : 표현식으로 사용 가능

### Truthy vs Falsy

- **Falsy 8개** : `false`, `0`, `0`, `0n`, `''`, `null`, `undefined`, `NaN`
- **Truthy** : Falsy를 제외한 모든 값
- **주의** : Truthy ≠ `true`, Falsy ≠ `false` (평가만 같음)

### Boolean 변환

- **`!!`** : 이중 부정으로 boolean 변환
- **`Boolean()`** : 생성자 함수 사용
- **활용** : 조건 검사, 입력 검증

## 🧪 복습용 퀴즈

### 퀴즈 1. 불리언 타입의 이해

**문제** : 다음 코드의 출력 결과는?

```jsx
let a = 5 > 3;
let b = "hello" === "world";
console.log(a, b, typeof a);
```

1. `true false 'boolean'`
2. `false true 'boolean'`
3. `true false 'string'`
4. `1 0 'number'`

**정답** : 1. `true false 'boolean'`

**해설** : `5 > 3`은 참이므로 `a`는 `true`, `'hello' === 'world'`는 거짓이므로 `b`는 `false`입니다. 비교 연산자의 결과는 항상 boolean 타입이므로 `typeof a`는 `'boolean'`을 반환합니다.

### 퀴즈 2. AND 연산자

**문제** : 다음 코드의 출력 결과는?

```jsx
let x = 15;
console.log(x > 10 && x < 20 && x % 5 === 0);
```

1. `true`
2. `false`
3. `15`
4. `0`

**정답** : 1. `true`

**해설** :

- `x > 10` → `true` (15는 10보다 큼)
- `x < 20` → `true` (15는 20보다 작음)
- `true && true` → `true`
- `x % 5 === 0` → `true` (15를 5로 나눈 나머지는 0)
- `true && true` → `true`

모든 조건이 참이므로 최종 결과는 `true`입니다.

---

### 퀴즈 3. 단축 평가

**문제** : 다음 코드에서 실제로 실행되는 `console.log`는?

```jsx
let error = false;
error && console.log("A");
error || console.log("B");
```

1. A만 실행
2. B만 실행
3. A와 B 모두 실행
4. 아무것도 실행 안 됨

**정답** : 2. B만 실행

**해설** :

- `error && console.log('A')`: `error`가 `false`(falsy)이므로 뒤의 코드를 평가하지 않습니다. 실행 안 됨.
- `error || console.log('B')`: `error`가 `false`이므로 뒤의 코드를 평가합니다. 'B'가 출력됩니다.

### 퀴즈 4. 삼항 연산자

**문제** : 다음 코드의 출력 결과는?

```jsx
let score = 75;
let result = score >= 80 ? "Pass" : score >= 60 ? "Retry" : "Fail";
console.log(result);
```

1. `'Pass'`
2. `'Retry'`
3. `'Fail'`
4. `undefined`

**정답** : 2. `'Retry'`

**해설** :

- `score >= 80` → `false` (75는 80보다 작음)
- 거짓이므로 `:` 뒤로 이동
- `score >= 60` → `true` (75는 60보다 큼)
- 참이므로 `'Retry'` 반환

### 퀴즈 5. Falsy 값

**문제** : 다음 중 **Truthy** 값은?

1. `0`
2. `''`
3. `'0'`
4. `null`

**정답** : 3. `'0'`

**해설** :

- `0`: 숫자 0은 falsy
- `''`: 빈 문자열은 falsy
- `'0'`: 문자열 '0'은 truthy (내용이 있는 문자열)
- `null`: null은 falsy

문자열은 빈 문자열(`''`)만 falsy이고, 나머지는 모두 truthy입니다.

---

### 퀴즈 6. OR 연산자와 기본값

**문제** : 다음 코드의 `result` 값은?

```jsx
let username = "";
let result = username || "Guest";
console.log(result);
```

1. `''`
2. `'Guest'`
3. `undefined`
4. `true`

**정답** : 2. `'Guest'`

**해설** : `username`은 빈 문자열(`''`)로 falsy 값입니다. OR 연산자(`||`)는 왼쪽이 falsy일 때 오른쪽 값을 반환하므로, `'Guest'`가 `result`에 할당됩니다. 이는 기본값 설정의 일반적인 패턴입니다.

---

### 퀴즈 7. 이중 부정 연산자

**문제** : 다음 코드의 출력 결과는?

```jsx
console.log(!!0, !!"hello", !!null, !![]);
```

1. `false true false true`
2. `true false true false`
3. `false false false false`
4. `true true true true`

**정답** : 1. `false true false true`

**해설** :

- `!!0`: 0은 falsy → `false`
- `!!'hello'`: 'hello'는 truthy → `true`
- `!!null`: null은 falsy → `false`
- `!![]`: 빈 배열도 truthy → `true`

이중 부정(`!!`)은 값을 boolean으로 변환합니다.

---

### 퀴즈 8. 드 모르간의 법칙

**문제** : 다음 중 항상 `true`를 반환하는 표현식은?

```jsx
let a = true,
  b = false;
```

1. `!(a && b) === (!a || !b)`
2. `!(a && b) === (a || b)`
3. `(a && b) === (!a || !b)`
4. `!(a || b) === (a && b)`

**정답** : 1. `!(a && b) === (!a || !b)`

**해설** : 이것이 드 모르간의 법칙입니다. NOT (A AND B) = (NOT A) OR (NOT B). 이 법칙은 `a`와 `b`의 값에 관계없이 항상 참입니다.

```jsx
let age = 25;
```

```jsx
let age = 25;
```

```jsx
age = 30;
isPremium = true;
// 결과: '할인 적용'

// 테스트 4: 일반 성인
age = 25;
isPremium = false;
// 결과: '정상 가격'
```

**풀이** :

- `age < 18`: 미성년자 체크
- `age >= 65`: 노인 체크

### 문제 2: 단축 평가 활용

### 문제 3: Truthy/Falsy 활용

**과제** : 입력값의 유효성을 검사하고 기본값을 설정하는 함수를 작성하세요.

**조건** :

- `input`이 falsy면 `'기본값'` 사용
- `input`이 truthy면 그대로 사용
- 결과를 반환

  **기본 코드** :

```jsx
function processInput(input) {
  // 여기에 코드 작성
  let result = /* 기본값 설정 로직 */;

  return result;
}

// 테스트
console.log(processInput('Hello'));    // 'Hello'
console.log(processInput(''));         // '기본값'
console.log(processInput(0));          // '기본값'
console.log(processInput(null));       // '기본값'
console.log(processInput('   '));      // '   ' (공백은 truthy)

```

**정답** :

```jsx
function processInput(input) {
  // 방법 1: OR 연산자 사용
  let result = input || "기본값";

  return result;
}

// 테스트
console.log(processInput("Hello")); // 'Hello'
console.log(processInput("")); // '기본값'
console.log(processInput(0)); // '기본값'
console.log(processInput(null)); // '기본값'
console.log(processInput("   ")); // '   '
```

**추가 버전 - 공백 문자열도 처리** :

```jsx
function processInputStrict(input) {
  // 문자열의 경우 trim 후 체크
  let trimmed = typeof input === "string" ? input.trim() : input;
  let result = trimmed || "기본값";

  return result;
}

console.log(processInputStrict("   ")); // '기본값'
console.log(processInputStrict("Hello")); // 'Hello'
```

**풀이** :

- OR 연산자(`||`)는 왼쪽이 falsy면 오른쪽 값 반환
- 이를 이용한 기본값 설정은 JavaScript의 일반적인 패턴
- 단, 숫자 0이나 빈 문자열도 유효한 값인 경우 주의 필요

### 문제 5: 종합 문제

**과제** : 사용자 권한 검사 시스템을 구현하세요.

**조건** :

- `isLoggedIn`: 로그인 여부
- `role`: 사용자 역할 ('admin', 'user', 'guest')
- `hasPermission`: 특정 권한 보유 여부

  **요구사항** :

1. 로그인하지 않았으면 "로그인 필요" 반환
2. 관리자면 "전체 접근 가능" 반환
3. 일반 사용자이고 권한이 있으면 "제한적 접근 가능" 반환
4. 그 외는 "접근 불가" 반환

**기본 코드** :

```jsx
function checkAccess(isLoggedIn, role, hasPermission) {
  // 여기에 코드 작성

  return /* 결과 */;
}

// 테스트
console.log(checkAccess(false, "user", true)); // "로그인 필요"
console.log(checkAccess(true, "admin", false)); // "전체 접근 가능"
console.log(checkAccess(true, "user", true)); // "제한적 접근 가능"
console.log(checkAccess(true, "user", false)); // "접근 불가"
console.log(checkAccess(true, "guest", false)); // "접근 불가"
```

**정답** :

```jsx
function checkAccess(isLoggedIn, role, hasPermission) {
  // 방법 1: 논리 연산자와 삼항 연산자 조합
  return !isLoggedIn
    ? "로그인 필요"
    : role === "admin"
      ? "전체 접근 가능"
      : role === "user" && hasPermission
        ? "제한적 접근 가능"
        : "접근 불가";
}

// 방법 2: 단축 평가 활용
function checkAccessAlt(isLoggedIn, role, hasPermission) {
  if (!isLoggedIn) return "로그인 필요";
  if (role === "admin") return "전체 접근 가능";
  if (role === "user" && hasPermission) return "제한적 접근 가능";
  return "접근 불가";
}

// 테스트
console.log(checkAccess(false, "user", true)); // "로그인 필요"
console.log(checkAccess(true, "admin", false)); // "전체 접근 가능"
console.log(checkAccess(true, "user", true)); // "제한적 접근 가능"
console.log(checkAccess(true, "user", false)); // "접근 불가"
console.log(checkAccess(true, "guest", false)); // "접근 불가"
```

**풀이** :

- 우선순위에 따라 조건을 순차적으로 검사
- `!isLoggedIn`: 부정 연산자로 로그인 상태 반전 체크
- `role === 'admin'`: 관리자 확인
- `role === 'user' && hasPermission`: AND 연산자로 두 조건 동시 확인
- 모든 조건에 해당하지 않으면 기본값 반환
