## 1. 함수의 기본 개념

### 1.1 함수란 무엇인가?

함수는 반복될 수 있는 작업을 정의해두고, 필요할 때마다 호출하여 사용할 수 있는 코드 블록입니다.

**기본 문법:**

```jsx
function 함수명(입력값) {
  // 수행할 일
  return 반환값; // 있을 시
}

함수명(입력값); // 함수 호출
```

### 1.2 함수를 사용하는 이유

### 1.2.1 코드 재사용성

함수를 사용하지 않으면 동일한 작업을 반복적으로 작성해야 합니다.

**함수 사용 전:**

```jsx
let a = 3,
  b = 4;
console.log(`${a} + ${b} = ${a + b}`);
console.log(`${a} - ${b} = ${a - b}`);
console.log(`${a} * ${b} = ${a * b}`);
console.log(`${a} / ${b} = ${a / b}`);

let c = 10,
  d = 2;
console.log(`${c} + ${d} = ${c + d}`);
console.log(`${c} - ${d} = ${c - d}`);
console.log(`${c} * ${d} = ${c * d}`);
console.log(`${c} / ${d} = ${c / d}`);
```

**함수 사용 후:**

```jsx
function allArithemics(x, y) {
  console.log(`${x} + ${y} = ${x + y}`);
  console.log(`${x} - ${y} = ${x - y}`);
  console.log(`${x} * ${y} = ${x * y}`);
  console.log(`${x} / ${y} = ${x / y}`);
}

allArithemics(3, 4);
allArithemics(10, 2);
allArithemics(7, 5);
```

### 1.2.2 값의 반환

함수는 `return` 키워드를 사용하여 계산된 결과를 반환할 수 있습니다.

```jsx
function add(x, y) {
  return x + y;
}

let z = add(2, 3);
console.log(z); // 5

console.log(add(4, 5)); // 9
console.log(add(add(6, 7), add(8, 9))); // 30
```

**사용 상황:** 계산 결과를 변수에 저장하거나 다른 함수의 인자로 사용할 때

### 1.3 인자(Parameter)와 인수(Argument)

```jsx
function add(x, y) {
  // x, y는 인자(parameter) 또는 매개변수
  return x + y;
}

let result = add(2, 3); // 2, 3은 인수(argument)
```

**개념 설명:**

- **인자(Parameter)** : 함수 정의 시 선언하는 변수
- **인수(Argument)** : 함수 호출 시 전달하는 실제 값
- 실무에서는 두 용어를 엄격하게 구분하지 않고 혼용하여 사용합니다.

### 1.4 반환값이 없는 함수

함수가 반드시 값을 반환할 필요는 없습니다.

```jsx
let currentTemp = 24.5;

function logCurrentTemp() {
  console.log(`현재 온도는 섭씨 ${currentTemp}도입니다.`);
}

console.log("반환값:", logCurrentTemp()); // 반환값: undefined
```

**주요 포인트:**

- `return` 문이 없으면 함수는 `undefined`를 반환합니다.
- `console.log()` 실행 후 `undefined`가 나타나는 이유도 이 때문입니다.

### 1.5 return 문의 위치

`return` 문 이후의 코드는 실행되지 않습니다.

```jsx
function add(x, y) {
  console.log(`${x}와 ${y}를 더합니다.`); // 실행됨
  return x + y;
  console.log(`결과는 ${x + y}입니다.`); // 실행되지 않음
}

console.log(add(2, 7));
```

**사용 상황:** 조건에 따라 함수를 조기 종료할 때 유용합니다.

### 1.6 호이스팅(Hoisting)

함수 선언문은 코드 실행 전에 먼저 생성되므로, 선언 전에 호출할 수 있습니다.

```jsx
console.log(add(2, 7)); // 9 - 정상 작동

function add(x, y) {
  return x + y;
}
```

**개념 설명:**

- JavaScript 엔진이 코드를 실행하기 전에 함수 선언문을 메모리에 먼저 등록합니다.
- 변수나 상수는 호이스팅되지 않습니다. (`var`는 예외)

## 2. 함수 정의 방법

### 2.1 함수 선언문 (Function Declaration)

가장 기본적인 함수 정의 방법입니다.

```jsx
function add(x, y) {
  return x + y;
}

console.log(add(2, 7)); // 9
```

**특징:**

- 호이스팅이 적용됩니다.
- 함수 이름이 필수입니다.

**사용 상황:** 일반적인 함수 정의, 호이스팅이 필요한 경우

### 2.2 함수 표현식 (Function Expression)

함수를 값으로 취급하여 변수나 상수에 할당하는 방법입니다.

```jsx
const subt = function (x, y) {
  return x - y;
};

console.log(subt(7, 2)); // 5
```

**함수 재정의도 가능:**

```jsx
function add(x, y) {
  return x + y;
}

console.log(add(2, 7)); // 9

// 함수 재정의
add = function (x, y) {
  console.log(`${x}와 ${y}를 더합니다.`);
  console.log(`결과는 ${x + y}입니다.`);
  return x + y;
};

console.log(add(2, 7));
```

**특징:**

- 호이스팅되지 않습니다.
- 익명 함수로 작성 가능합니다.

**사용 상황:** 함수를 값으로 다루어야 할 때, 조건부로 함수를 정의할 때

### 2.3 화살표 함수 (Arrow Function)

ES6에서 도입된 간결한 함수 표현 방식입니다.

**한 줄 반환:**

```jsx
const mult = (x, y) => x * y;

console.log(mult(2, 7)); // 14
```

**여러 줄 작업:**

```jsx
const mult = (x, y) => {
  console.log(`${x}와 ${y}를 곱합니다.`);
  console.log(`결과는 ${x * y}입니다.`);
  return x * y;
};

console.log(mult(2, 7));
```

**인자가 하나일 때:**

```jsx
const pow = (x) => x ** 2;
console.log(pow(3)); // 9
```

**특징:**

- 호이스팅되지 않습니다.
- `function` 키워드 함수와 `this` 바인딩이 다릅니다.
- 인자가 하나일 때 괄호 생략 가능합니다.
- 한 줄 표현식일 때 `return` 생략 가능합니다.

**사용 상황:** 간결한 콜백 함수, 배열 메서드, 함수형 프로그래밍

### 2.4 호이스팅 차이점

```jsx
// ❌ 에러 발생
console.log(div(8, 4));

const div = function (x, y) {
  return x / y;
};
```

```jsx
// ❌ 에러 발생
console.log(div(8, 4));

const div = (x, y) => x / y;
```

**핵심 개념:**

- 함수 선언문: 코드 실행 전 생성 (호이스팅 O)
- 함수 표현식/화살표 함수: 코드 실행 시 생성 (호이스팅 X)

## 3. 일급 객체로서의 함수

### 3.1 일급 객체(First-Class Object)란?

**정의:** 함수를 변수와 같이 다룰 수 있는 프로그래밍 언어의 특성

JavaScript의 함수는 일급 객체이며, 기본적으로 객체입니다.

```jsx
function addNumbers(a, b) {
  return a + b;
}

console.log(typeof addNumbers); // "function"
```

**일급 객체의 조건:**

1. 상수 또는 변수에 할당될 수 있음
2. 다른 함수에 인자로 전달될 수 있음
3. 다른 함수의 결과값으로 반환될 수 있음

### 3.2 할당 (Assignment)

### 3.2.1 변수에 함수 할당

```jsx
function isOddNum(number) {
  console.log((number % 2 ? "홀" : "짝") + "수입니다.");
  return number % 2 ? true : false;
}

const checkIfOdd = isOddNum; // 괄호 없이 할당

console.log(checkIfOdd(23)); // "홀수입니다." true
```

**주의사항:** 함수 이름 뒤에 괄호를 붙이지 않습니다. 괄호를 붙이면 함수 실행 결과가 할당됩니다.

### 3.2.2 함수의 참조 타입 특성

```jsx
let x = 7,
  y = 3;

let func1 = (a, b) => a + b;
let func2 = (a, b) => a - b;

console.log(func1(x, y), func2(x, y)); // 10, 4

func1 = func2; // func1이 func2를 참조

console.log(func1(x, y), func2(x, y)); // 4, 4
```

**핵심 개념:** 함수도 객체와 배열처럼 참조 타입입니다.

### 3.2.3 객체의 프로퍼티로 할당

```jsx
let person = {
  name: "홍길동",
  age: 30,
  married: true,
  introduce: function (formal) {
    return formal
      ? "안녕하십니까. 홍길동 대리라고 합니다."
      : "안녕하세요, 홍길동이라고 해요.";
  },
};

console.log(person.introduce(true));
console.log(person.introduce(false));
```

**용어 설명:** 객체의 함수 프로퍼티를 **메서드(method)**라고 부릅니다.

**주의사항:** ES6부터는 메서드의 정의가 단축 표현 방식으로 작성된 것만 가리킵니다.

### 3.2.4 배열의 요소로 할당

```jsx
let arithmetics = [
  (a, b) => a + b,
  (a, b) => a - b,
  (a, b) => a * b,
  (a, b) => a / b,
];

for (arm of arithmetics) {
  console.log(arm(5, 3));
}
// 출력: 8, 2, 15, 1.666...
```

**사용 상황:** 여러 연산을 동적으로 선택하여 실행할 때

### 3.2.5 객체에서 this 사용하기

```jsx
let person = {
  name: "홍길동",
  age: 30,
  married: true,
  introduce: function () {
    return (
      `저는 ${this.name}, ${this.age}살이고 ` +
      `${this.married ? "기혼" : "미혼"}입니다.`
    );
  },
};

console.log(person.introduce());
// "저는 홍길동, 30살이고 기혼입니다."
```

**핵심 포인트:**

- 객체의 다른 프로퍼티에 접근할 때 `this` 키워드를 사용합니다.
- 객체 리터럴의 프로퍼티로는 `this`를 사용하는 화살표 함수를 권장하지 않습니다.

### 3.3 인자로 전달 (Callback Function)

### 3.3.1 고차 함수와 콜백 함수

**개념 정의:**

- **고차 함수(Higher-Order Function)** : 함수를 인자로 받는 함수
- **콜백 함수(Callback Function)** : 인자로 전달되는 함수

```jsx
let list = [1, 2, 3, 4, 5];

function doInArray(array, func) {
  for (item of array) {
    func(item);
  }
}

doInArray(list, console.log);
// 1, 2, 3, 4, 5 출력
```

**분석:**

- `doInArray`: 고차 함수
- `console.log`: 콜백 함수

### 3.3.2 익명 함수 (Anonymous Function)

```jsx
function doNTimes(func, repeat, x, y) {
  let result = x;
  for (i = 0; i < repeat; i++) {
    result = func(result, y);
  }
  return result;
}

console.log(
  doNTimes((x, y) => x * y, 3, 5, 2), // 40
  doNTimes((x, y) => x / y, 3, 5, 2) // 0.625
);
```

**핵심 개념:** 변수나 상수에 할당되지 않고 인자로만 사용되는 함수를 **익명 함수**라고 합니다.

**사용 상황:** 일회성 함수, 콜백 함수로만 사용되는 경우

### 3.3.3 복합 예제

```jsx
// 계산 함수들
const add = (a, b) => a + b;
const subtract = (a, b) => a - b;
const multiply = (a, b) => a * b;

// 평가 함수들
const isOdd = (number) => !!(number % 2);
const isPositive = (number) => number > 0;

function calcAndEval(calc, eval, x, y) {
  return eval(calc(x, y));
}

console.log(
  calcAndEval(add, isOdd, 5, 7), // false (12는 짝수)
  calcAndEval(subtract, isPositive, 5, 7), // false (-2는 음수)
  calcAndEval(multiply, isOdd, 5, 7) // false (35는 홀수) -> true
);
```

**사용 상황:** 함수형 프로그래밍, 배열 메서드, 이벤트 핸들러

### 3.4 결과값으로 반환

### 3.4.1 함수를 반환하는 함수

```jsx
function getIntroFunc(name, formal) {
  return formal
    ? function () {
        console.log(`안녕하십니까, ${name}입니다.`);
      }
    : function () {
        console.log(`안녕하세요~ ${name}이라고 해요.`);
      };
}

const hongIntro = getIntroFunc("홍길동", true);
const jeonIntro = getIntroFunc("전우치", false);

hongIntro(); // "안녕하십니까, 홍길동입니다."
jeonIntro(); // "안녕하세요~ 전우치이라고 해요."
```

**사용 상황:** 설정에 따라 다른 동작을 하는 함수를 생성할 때

### 3.4.2 함수 조합

```jsx
const add = (a, b) => a + b;
const sub = (a, b) => a - b;
const mul = (a, b) => a * b;
const div = (a, b) => a / b;

function comb3ArmFuncs(armFunc1, armFunc2, armFunc3) {
  return (x, y) => armFunc3(armFunc2(armFunc1(x, y), y), y);
}

const add_mul_sub = comb3ArmFuncs(add, mul, sub);
const mul_add_div = comb3ArmFuncs(mul, add, div);

console.log(
  add_mul_sub(10, 4), // ((10 + 4) * 4) - 4 = 52
  mul_add_div(10, 4) // ((10 * 4) + 4) / 4 = 11
);
```

**사용 상황:** 여러 함수를 조합하여 새로운 함수를 만들 때

### 3.5 커링 (Currying)

**정의:** 필요한 인자보다 적은 수의 인자를 받으면, 나머지 인자를 받는 함수를 반환하는 기법

### 3.5.1 기존 방식 vs 커링

**기존 방식:**

```jsx
function addMultSubt(a, b, c, d) {
  return (a + b) * c - d;
}

const addMultSubt2 = (a, b, c, d) => (a + b) * c - d;

console.log(
  addMultSubt(2, 3, 4, 5), // 15
  addMultSubt2(2, 3, 4, 5) // 15
);
```

**커링 방식:**

```jsx
function curryAddMultSubt(a) {
  return function (b) {
    return function (c) {
      return function (d) {
        return (a + b) * c - d;
      };
    };
  };
}

const curryAddMultSubt2 = (a) => (b) => (c) => (d) => (a + b) * c - d;

console.log(
  curryAddMultSubt(2)(3)(4)(5), // 15
  curryAddMultSubt2(2)(3)(4)(5) // 15
);
```

### 3.5.2 부분 적용

```jsx
const curryAddMultSubtFrom2 = curryAddMultSubt(2);
const curryMultSubtFrom5 = curryAddMultSubt(2)(3);
const currySubtFrom20 = curryAddMultSubt(2)(3)(4);

console.log(curryAddMultSubtFrom2); // [Function]
console.log(curryMultSubtFrom5); // [Function]
console.log(currySubtFrom20); // [Function]

console.log(
  curryAddMultSubtFrom2(3)(4)(5), // 15
  curryMultSubtFrom5(4)(5), // 15
  currySubtFrom20(5) // 15
);
```

**사용 상황:** 일부 인자를 미리 고정하고, 나중에 나머지 인자를 받아 실행할 때

**장점:**

- 함수 재사용성 증가
- 코드의 유연성 향상
- 함수형 프로그래밍에 유용

## 4. 함수 설계 원칙

### 4.1 단일 책임 원칙

**원칙:** 하나의 함수는 한 가지 일만 하도록 설계해야 합니다.

**이유:**

- 하나의 함수가 여러 일을 수행하면 코드 수정이 복잡해집니다.
- 각자 하나의 일을 하는 여러 함수들의 조합을 사용하는 것이 좋습니다.

**나쁜 예:**

```jsx
function processUserData(user) {
  // 검증
  if (!user.name || !user.email) return false;

  // 데이터 변환
  user.name = user.name.toUpperCase();

  // 데이터베이스 저장
  database.save(user);

  // 이메일 발송
  sendEmail(user.email);

  return true;
}
```

**좋은 예:**

```jsx
function validateUser(user) {
  return user.name && user.email;
}

function transformUserData(user) {
  return {
    ...user,
    name: user.name.toUpperCase(),
  };
}

function saveUser(user) {
  database.save(user);
}

function notifyUser(email) {
  sendEmail(email);
}

// 조합하여 사용
if (validateUser(user)) {
  const transformedUser = transformUserData(user);
  saveUser(transformedUser);
  notifyUser(transformedUser.email);
}
```

## 📌 최종 핵심 요약

### 함수의 기본

- 함수는 반복 작업을 정의하고 재사용할 수 있는 코드 블록입니다.
- `return` 문으로 값을 반환하며, 없으면 `undefined`를 반환합니다.
- `return` 문 이후의 코드는 실행되지 않습니다.

### 함수 정의 방법 3가지

1. **함수 선언문** : 호이스팅 O, 가장 기본적인 방법
2. **함수 표현식** : 호이스팅 X, 함수를 값으로 취급
3. **화살표 함수** : 호이스팅 X, 간결한 문법, `this` 바인딩 차이

### 일급 객체

JavaScript 함수는 일급 객체로, 다음이 가능합니다:

- 변수/상수에 할당
- 다른 함수의 인자로 전달 (콜백 함수)
- 다른 함수의 반환값으로 사용

### 고급 패턴

- **고차 함수** : 함수를 인자로 받거나 반환하는 함수
- **콜백 함수** : 다른 함수에 인자로 전달되는 함수
- **커링** : 여러 인자를 받는 함수를 단일 인자를 받는 함수들의 체인으로 변환

### 설계 원칙

- 하나의 함수는 한 가지 일만 수행해야 합니다.
- 여러 작은 함수들을 조합하여 복잡한 기능을 구현합니다.

1. 함수 선언문 (Function Declaration)

해설: 함수 선언문만 호이스팅이 적용됩니다. JavaScript 엔진이 코드 실행 전에 함수 선언문을 메모리에 먼저 등록하기 때문에 선언 전에 호출할 수 있습니다. 함수 표현식과 화살표 함수는 변수/상수에 할당되므로 호이스팅되지 않습니다.

### 퀴즈 2

다음 코드의 출력 결과는?

```jsx
function test() {
  console.log("첫 번째");
  return "반환값";
  console.log("두 번째");
}

console.log(test());
```

1. 첫 번째, 두 번째, 반환값
2. 첫 번째, 반환값
3. 반환값, 첫 번째
4. 두 번째, 반환값
5. 에러 발생

**정답: 2. 첫 번째, 반환값**

해설: `return` 문 이후의 코드는 실행되지 않습니다. 따라서 '첫 번째'가 출력되고, 함수가 '반환값'을 반환한 후 종료되므로 '두 번째'는 출력되지 않습니다.

### 퀴즈 4

다음 코드에서 `calcAndEval`은 어떤 종류의 함수인가?

```jsx
function calcAndEval(calc, eval, x, y) {
  return eval(calc(x, y));
}

calcAndEval(
  (a, b) => a + b,
  (num) => num > 0,
  5,
  3
);
```

1. 익명 함수
2. 콜백 함수
3. 고차 함수
4. 화살표 함수
5. 즉시 실행 함수

**정답: 3. 고차 함수**

해설: `calcAndEval`은 다른 함수들(`calc`, `eval`)을 인자로 받아 실행하므로 고차 함수(Higher-Order Function)입니다. 인자로 전달된 `(a, b) => a + b`와 `num => num > 0`는 콜백 함수이며 익명 함수입니다.

1. 함수를 즉시 실행하는 패턴이다
2. 여러 인자를 받는 함수를 단일 인자를 받는 함수들의 체인으로 변환하는 기법이다
3. 함수의 실행 순서를 바꾸는 기법이다
4. 비동기 처리를 위한 패턴이다

**정답: 2. 여러 인자를 받는 함수를 단일 인자를 받는 함수들의 체인으로 변환하는 기법이다**

해설: 커링은 `f(a, b, c)`와 같은 함수를 `f(a)(b)(c)` 형태로 변환하는 기법입니다. 이를 통해 부분 적용(Partial Application)이 가능해지고, 함수의 재사용성과 유연성이 향상됩니다.

### 문제 1: 기본 함수 작성

두 숫자를 받아서 큰 수를 반환하는 함수를 작성하세요.

**기본 코드:**

```jsx
// 여기에 getMax 함수를 작성하세요

// 테스트
console.log(getMax(10, 5)); // 10
console.log(getMax(3, 7)); // 7
console.log(getMax(15, 15)); // 15
```

**정답:**

```jsx
function getMax(a, b) {
  return a > b ? a : b;
}

// 또는 화살표 함수로
const getMax = (a, b) => (a > b ? a : b);
```

**해설:**
삼항 연산자를 사용하여 두 값을 비교하고 큰 값을 반환합니다. 함수 선언문 또는 화살표 함수 모두 사용 가능합니다.

### 문제 2: 콜백 함수 활용

배열의 각 요소에 콜백 함수를 적용하는 `customMap` 함수를 작성하세요.

**기본 코드:**

```jsx
function customMap(array, callback) {
  // 여기에 코드를 작성하세요
}

// 테스트
const numbers = [1, 2, 3, 4, 5];
const doubled = customMap(numbers, (num) => num * 2);
const squared = customMap(numbers, (num) => num ** 2);

console.log(doubled); // [2, 4, 6, 8, 10]
console.log(squared); // [1, 4, 9, 16, 25]
```

**정답:**

```jsx
function customMap(array, callback) {
  const result = [];
  for (let item of array) {
    result.push(callback(item));
  }
  return result;
}
```

**해설:**
고차 함수를 구현하는 문제입니다. 배열을 순회하면서 각 요소에 콜백 함수를 적용하고, 결과를 새 배열에 담아 반환합니다. 이는 JavaScript 내장 메서드인 `Array.prototype.map()`의 간단한 구현입니다.

### 문제 3: 함수 조합

두 개의 계산 함수를 받아서 조합된 함수를 반환하는 `compose` 함수를 작성하세요.

**기본 코드:**

```jsx
function compose(func1, func2) {
  // 여기에 코드를 작성하세요
}

// 테스트
const addTwo = (x) => x + 2;
const multiplyThree = (x) => x * 3;

const addThenMultiply = compose(addTwo, multiplyThree);
const multiplyThenAdd = compose(multiplyThree, addTwo);

console.log(addThenMultiply(5)); // (5 + 2) * 3 = 21
console.log(multiplyThenAdd(5)); // (5 * 3) + 2 = 17
```

**정답:**

```jsx
function compose(func1, func2) {
  return function (x) {
    return func2(func1(x));
  };
}

// 또는 화살표 함수로
const compose = (func1, func2) => (x) => func2(func1(x));
```

**해설:**
함수를 반환하는 함수를 작성하는 문제입니다. `func1`을 먼저 실행하고 그 결과를 `func2`에 전달하는 새로운 함수를 반환합니다. 이는 함수형 프로그래밍의 핵심 개념인 함수 합성(Function Composition)입니다.

### 문제 4: 커링 실습

세 개의 숫자를 받아 모두 더하는 함수를 커링 방식으로 작성하세요.

**기본 코드:**

```jsx
// 여기에 curryAdd 함수를 작성하세요

// 테스트
console.log(curryAdd(1)(2)(3)); // 6

const addFrom5 = curryAdd(5);
console.log(addFrom5(3)(2)); // 10

const addFrom5And3 = curryAdd(5)(3);
console.log(addFrom5And3(7)); // 15
```

**정답:**

```jsx
function curryAdd(a) {
  return function (b) {
    return function (c) {
      return a + b + c;
    };
  };
}

// 또는 화살표 함수로
const curryAdd = (a) => (b) => (c) => a + b + c;
```

**해설:**
커링을 활용하여 세 개의 인자를 받는 함수를 단일 인자를 받는 함수들의 체인으로 구현합니다. 부분 적용(Partial Application)이 가능하여 일부 인자를 미리 고정하고 나중에 나머지 인자를 받을 수 있습니다.

### 문제 5: 실용적인 함수 작성

학생 객체 배열에서 특정 조건을 만족하는 학생들의 평균 점수를 계산하는 프로그램을 작성하세요.

**기본 코드:**

```jsx
const students = [
  { name: "김철수", score: 85, grade: 2 },
  { name: "이영희", score: 92, grade: 3 },
  { name: "박민수", score: 78, grade: 2 },
  { name: "정수진", score: 95, grade: 3 },
  { name: "최동욱", score: 88, grade: 2 },
];

// 필터 함수
function filterStudents(students, condition) {
  // 여기에 코드를 작성하세요
}

// 평균 계산 함수
function calculateAverage(students) {
  // 여기에 코드를 작성하세요
}

// 테스트
const grade2Students = filterStudents(students, (s) => s.grade === 2);
const grade2Average = calculateAverage(grade2Students);

console.log(`2학년 평균 점수: ${grade2Average}`); // 83.666...

const highScorers = filterStudents(students, (s) => s.score >= 90);
const highScorerAverage = calculateAverage(highScorers);

console.log(`90점 이상 학생 평균: ${highScorerAverage}`); // 93.5
```

**정답:**

```jsx
function filterStudents(students, condition) {
  const result = [];
  for (let student of students) {
    if (condition(student)) {
      result.push(student);
    }
  }
  return result;
}

function calculateAverage(students) {
  if (students.length === 0) return 0;

  let sum = 0;
  for (let student of students) {
    sum += student.score;
  }
  return sum / students.length;
}
```

**해설:**
이 문제는 고차 함수와 콜백 함수를 실용적으로 활용하는 예제입니다. `filterStudents`는 조건 함수를 받아 해당 조건을 만족하는 학생들만 필터링하고, `calculateAverage`는 학생들의 점수 평균을 계산합니다. 각 함수가 하나의 책임만 가지도록 설계되었으며, 조합하여 사용할 수 있습니다.
