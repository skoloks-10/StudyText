## 1. 객체의 기본 사용법

### 1.1 객체 생성과 프로퍼티 접근

### 객체란?

JavaScript에서 객체는 키(key)와 값(value)의 쌍으로 이루어진 프로퍼티들의 집합입니다. 관련된 데이터와 기능을 하나로 묶어서 관리할 수 있는 자료구조입니다.

### 객체 생성 방법

**방법 1: 객체 리터럴**

```jsx
const food1 = {
  name: '햄버거',
  price: 5000,
  vegan: false
};

```

**방법 2: 빈 객체 생성 후 프로퍼티 추가**

```jsx
const food2 = {};
food2.name = '샐러드';
food2.price = '6000';
food2['vegan'] = true;

```

### 프로퍼티 접근 방법

JavaScript는 두 가지 방식으로 객체의 프로퍼티에 접근할 수 있습니다.

**1) 마침표 표기법 (Dot notation)**

```jsx
console.log(food1.name); // '햄버거'

```

**2) 대괄호 표기법 (Bracket notation)**

```jsx
console.log(food1['price']); // 5000

```

**언제 대괄호 표기법을 사용해야 하나?**

- 프로퍼티 이름이 변수에 저장되어 있을 때
- 프로퍼티 이름이 식별자 명명 규칙을 따르지 않을 때
- 프로퍼티 이름에 공백이나 특수문자가 포함될 때

### 프로퍼티 수정

```jsx
food2['price'] = '6500';
food2.vegan = false;

```

### 1.2 식별자 명명 규칙을 벗어나는 키 사용

JavaScript 식별자 명명 규칙을 따르지 않는 키는 **반드시 대괄호 표기법**으로 접근해야 합니다.

```jsx
const obj = {
  1: '하나',              // 숫자 키
  'ab-cd': 'ABCD',        // 하이픈 포함
  's p a c e': 'Space'    // 공백 포함
}

// ✅ 올바른 접근 방법
console.log(obj[1]);           // '하나'
console.log(obj['ab-cd']);     // 'ABCD'
console.log(obj['s p a c e']); // 'Space'

// ❌ 오류 발생
// console.log(obj.1);
// console.log(obj.ab-cd);
// console.log(obj.s p a c e);

```

**왜 이런 규칙이 있나?**
마침표 표기법은 프로퍼티 이름을 식별자로 해석하기 때문에, JavaScript 식별자 규칙을 따라야 합니다. 대괄호 표기법은 문자열로 해석하므로 더 유연합니다.

### 1.3 표현식으로 키값 정의하기

객체를 정의할 때 **계산된 프로퍼티 이름(Computed Property Names)**을 사용할 수 있습니다.

```jsx
let idx = 0;
const obj = {
  ['key-' + ++idx]: `value-${idx}`,  // 'key-1': 'value-1'
  ['key-' + ++idx]: `value-${idx}`,  // 'key-2': 'value-2'
  ['key-' + ++idx]: `value-${idx}`,  // 'key-3': 'value-3'
  [idx ** idx]: 'POWER'               // '27': 'POWER'
}

```

**사용 시나리오:**

- 동적으로 프로퍼티 이름을 생성해야 할 때
- 반복문에서 여러 프로퍼티를 생성할 때
- 변수나 함수의 반환값을 키로 사용할 때

### ⚠️ 객체나 배열을 키로 사용할 때의 주의사항

```jsx
const objKey = { x: 1, y: 2 };
const arrKey = [1, 2, 3];

const obj = {
  [objKey]: '객체를 키값으로',
  [arrKey]: '배열을 키값으로'
}

console.log(obj[objKey]);              // '객체를 키값으로'
console.log(obj[{ a: 1, b: 2 }]);      // '객체를 키값으로' (!)
console.log(obj['[object Object]']);   // '객체를 키값으로'
console.log(obj['1,2,3']);             // '배열을 키값으로'

```

**중요한 포인트:**

- 객체를 키로 사용하면 `'[object Object]'` 문자열로 변환됩니다
- 배열을 키로 사용하면 쉼표로 구분된 문자열로 변환됩니다
- 실제 객체나 배열의 참조값이 키가 되는 것이 아닙니다
- 참조값을 키로 사용하려면 `Map` 객체를 사용해야 합니다

### 1.4 프로퍼티 삭제 - delete 연산자

`delete` 연산자를 사용하여 객체의 프로퍼티를 삭제할 수 있습니다.

```jsx
const person1 = {
  name: '홍길동',
  age: 24,
  school: '한국대',
  major: '컴퓨터공학'
};

delete person1.age;                  // age 프로퍼티 삭제
delete person1['major'];             // major 프로퍼티 삭제
delete person1.hobby;                // 존재하지 않는 프로퍼티 삭제 (오류 없음)

```

**특징:**

- 존재하지 않는 프로퍼티를 삭제해도 오류가 발생하지 않습니다
- 삭제 성공 시 `true`, 실패 시 `false`를 반환합니다
- 삭제된 프로퍼티는 완전히 제거되며, `undefined`로 설정되는 것이 아닙니다

### 1.5 키의 동적 사용

함수에서 객체의 프로퍼티를 동적으로 다룰 때는 **반드시 대괄호 표기법**을 사용해야 합니다.

```jsx
const product1 = {
  name: '노트북',
  color: 'gray',
  price: 800000
}

function addModifyProperty(obj, key, value) {
  // obj.key = value;    // ❌ 'key'라는 이름의 프로퍼티를 생성
  obj[key] = value;      // ✅ 매개변수 key의 값을 프로퍼티 이름으로 사용
}

function deleteProperty(obj, key) {
  // delete obj.key;     // ❌ 'key'라는 프로퍼티를 삭제하려고 시도
  delete obj[key];       // ✅ 매개변수 key의 값을 프로퍼티 이름으로 사용
}

addModifyProperty(product1, 'inch', 16);      // inch: 16 추가
addModifyProperty(product1, 'price', 750000); // price 수정
deleteProperty(product1, 'color');             // color 삭제

```

**왜 대괄호 표기법을 사용해야 하나?**

- `obj.key`는 문자 그대로 'key'라는 프로퍼티를 찾습니다
- `obj[key]`는 변수 key의 값을 평가하여 해당 이름의 프로퍼티를 찾습니다

### 1.6 ES6 추가 문법

### 1.6.1 단축 프로퍼티 (Shorthand Property)

프로퍼티 키와 변수명이 같을 때 축약해서 작성할 수 있습니다.

```jsx
const x = 1, y = 2;

// ES5 방식
const obj1 = {
  x: x,
  y: y
}

// ES6 방식 (단축 프로퍼티)
const obj2 = { x, y }  // { x: 1, y: 2 }

```

**실용적인 예시:**

```jsx
function createProduct(name, price, quantity) {
  return { name, price, quantity };  // 매개변수명과 프로퍼티명이 동일
}

const product1 = createProduct('선풍기', 50000, 50);
// { name: '선풍기', price: 50000, quantity: 50 }

```

**언제 사용하나?**

- 함수에서 객체를 반환할 때
- API 응답 데이터를 구성할 때
- 변수를 객체로 묶어서 전달할 때

### 1.6.2 메서드 (Method)

ES6부터는 객체 내부에 함수를 더 간결하게 정의할 수 있습니다.

```jsx
// ES5 방식 - 일반 함수 프로퍼티
const person = {
  name: '홍길동',
  salutate: function(formal) {
    return formal
      ? `안녕하십니까, ${this.name}입니다.`
      : `안녕하세요, ${this.name}이에요.`;
  }
}

// ES6 방식 - 메서드
const person = {
  name: '홍길동',
  salutate(formal) {  // function 키워드 생략
    return formal
      ? `안녕하십니까, ${this.name}입니다.`
      : `안녕하세요, ${this.name}이에요.`;
  }
}

console.log(person.salutate(true));  // '안녕하십니까, 홍길동입니다.'

```

**중요한 차이점:**

- ES6 메서드 문법으로 정의된 함수만 진정한 의미의 '메서드'입니다
- 일반 함수 프로퍼티와 메서드는 내부 동작 방식이 다릅니다
- 메서드는 `super` 키워드를 사용할 수 있습니다
- 메서드는 생성자 함수로 사용할 수 없습니다

## 2. 생성자 함수

### 2.1 생성자 함수의 필요성

같은 형식의 객체를 여러 개 만들어야 할 때, 매번 객체 리터럴로 작성하는 것은 비효율적입니다.

**문제 상황:**

```jsx
// 얄코치킨 체인점을 나타내는 객체들
const chain1 = {
  name: '판교',
  no: 3,
  introduce() {
    return `안녕하세요, ${this.no}호 ${this.name}점입니다!`;
  }
};

const chain2 = {
  name: '강남',
  no: 17,
  introduce() {
    return `안녕하세요, ${this.no}호 ${this.name}점입니다!`;
  }
};

const chain3 = {
  name: '제주',
  no: 24,
  introduce() {
    return `안녕하세요, ${this.no}호 ${this.name}점입니다!`;
  }
};

// 같은 구조를 반복해서 작성해야 함 → 비효율적!

```

**해결책: 생성자 함수**
동일한 구조의 객체를 쉽게 생성할 수 있는 템플릿을 만듭니다.

### 2.2 생성자 함수로 객체 만들기

### 생성자 함수의 기본 구조

```jsx
// 생성자 함수 정의
function YalcoChicken(name, no) {
  this.name = name;
  this.no = no;
  this.introduce = function() {
    return `안녕하세요, ${this.no}호 ${this.name}점입니다!`;
  }
}

// 인스턴스 생성
const chain1 = new YalcoChicken('판교', 3);
const chain2 = new YalcoChicken('강남', 17);
const chain3 = new YalcoChicken('제주', 24);

console.log(chain1.introduce());  // '안녕하세요, 3호 판교점입니다!'

```

### 생성자 함수의 핵심 개념

**1. 명명 규칙**

- 생성자 함수명은 **파스칼 케이스(PascalCase)**로 작성합니다
- 예: `YalcoChicken`, `User`, `ProductManager`

**2. this 키워드**

- `this`는 생성될 인스턴스를 가리킵니다
- `this.프로퍼티 = 값` 형태로 인스턴스의 프로퍼티를 정의합니다

**3. new 연산자**

- `new` 연산자와 함께 호출해야 합니다
- `new` 없이 호출하면 `undefined`를 반환합니다

**4. 암묵적 반환**

- 생성자 함수는 `return` 문 없이도 자동으로 `this`를 반환합니다
- 명시적으로 객체를 반환하면 그 객체가 반환됩니다

**5. 인스턴스(Instance)**

- 생성자 함수로 만들어진 객체를 **인스턴스**라고 부릅니다

**6. 메서드 정의 제한**

- 생성자 함수 내에서는 ES6 메서드 축약 문법을 사용할 수 없습니다
- 일반 함수 프로퍼티 형태로만 작성 가능합니다

### ⚠️ new 연산자를 빠뜨리면?

```jsx
function YalcoChicken(name, no) {
  this.name = name;
  this.no = no;
  this.introduce = function() {
    return `안녕하세요, ${this.no}호 ${this.name}점입니다!`;
  }
}

console.log(YalcoChicken('홍대', 30));  // undefined

```

**왜 undefined가 반환되나?**

- `new` 없이 호출하면 일반 함수로 동작합니다
- 일반 함수는 명시적인 `return`이 없으면 `undefined`를 반환합니다
- `this`는 전역 객체(브라우저: `window`, Node.js: `global`)를 가리킵니다

### 2.3 생성자 함수 vs 객체 반환 함수

**객체를 반환하는 일반 함수로도 비슷한 결과를 얻을 수 있습니다:**

```jsx
function createYalcoChicken(name, no) {
  return {
    name,
    no,
    introduce() {
      return `안녕하세요, ${this.no}호 ${this.name}점입니다!`;
    }
  }
}

const chain1 = createYalcoChicken('판교', 3);
const chain2 = createYalcoChicken('강남', 17);
const chain3 = createYalcoChicken('제주', 24);

// 기능적으로는 동일하게 작동
console.log(chain1.introduce());  // '안녕하세요, 3호 판교점입니다!'

```

**그렇다면 생성자 함수를 사용하는 이유는?**

1. **프로토타입 상속**: 생성자 함수는 프로토타입 체인을 활용할 수 있습니다
2. **인스턴스 확인**: `instanceof` 연산자로 객체의 출처를 확인할 수 있습니다
3. **메모리 효율**: 메서드를 프로토타입에 정의하면 모든 인스턴스가 공유합니다
4. **객체지향 패턴**: JavaScript의 객체지향 프로그래밍 패턴을 구현할 수 있습니다

## 3. 프로토타입

### 3.1 프로토타입이란?

프로토타입(Prototype)은 JavaScript 객체지향 프로그래밍의 핵심 개념입니다. 생성자 함수로 만들어진 모든 인스턴스가 **공통으로 사용할 수 있는 프로퍼티와 메서드를 저장하는 객체**입니다.

**비유:**

- 생성자 함수 = 본사
- 프로토타입 = 본사에서 배포하는 공통 매뉴얼
- 인스턴스 = 각 지점

### 3.2 프로토타입에 메서드 추가하기

```jsx
function YalcoChicken(name, no) {
  this.name = name;
  this.no = no;
  this.introduce = function() {
    return `안녕하세요, ${this.no}호 ${this.name}점입니다!`;
  }
}

const chain1 = new YalcoChicken('판교', 3);

// 본사에서 새 업무 추가 (프로토타입에 메서드 추가)
YalcoChicken.prototype.introEng = function() {
  return `Welcome to Yalco Chicken at ${this.name}!`;
};

console.log(chain1.introEng());
// 'Welcome to Yalco Chicken at 판교!'

console.log(new YalcoChicken('강남', 17).introEng());
// 'Welcome to Yalco Chicken at 강남!'

```

**핵심 포인트:**

- 프로토타입에 추가된 메서드는 **이미 생성된 인스턴스**에서도 즉시 사용 가능합니다
- 프로토타입에 메서드를 정의하면 모든 인스턴스가 **메모리를 공유**하므로 효율적입니다
- 인스턴스 메서드(`introduce`)와 프로토타입 메서드(`introEng`)는 종류가 다릅니다

### 3.3 인스턴스 메서드 vs 프로토타입 메서드

```jsx
function YalcoChicken(name, no) {
  // 인스턴스 메서드: 각 인스턴스마다 개별 생성
  this.introduce = function() {
    return `안녕하세요, ${this.no}호 ${this.name}점입니다!`;
  }
}

// 프로토타입 메서드: 모든 인스턴스가 공유
YalcoChicken.prototype.introEng = function() {
  return `Welcome to Yalco Chicken at ${this.name}!`;
};

```

**차이점:**

| 구분 | 인스턴스 메서드 | 프로토타입 메서드 |
| --- | --- | --- |
| 정의 위치 | 생성자 함수 내부 | 생성자 함수의 prototype |
| 메모리 | 인스턴스마다 별도 생성 | 모든 인스턴스가 공유 |
| 성능 | 메모리 사용량 많음 | 메모리 효율적 |
| 커스터마이징 | 인스턴스별로 다르게 정의 가능 | 모든 인스턴스에 동일 |

### 3.4 생성 방식에 따른 객체 비교

```jsx
function YalcoChicken(name, no) {
  this.name = name;
  this.no = no;
  this.introduce = function() {
    return `안녕하세요, ${this.no}호 ${this.name}점입니다!`;
  }
}

function createYalcoChicken(name, no) {
  return {
    name, no,
    introduce() {
      return `안녕하세요, ${this.no}호 ${this.name}점입니다!`;
    }
  }
}

// 1. 객체 리터럴
const chain1 = {
  name: '판교',
  no: 3,
  introduce: function() {
    return `안녕하세요, ${this.no}호 ${this.name}점입니다!`;
  }
};

// 2. 객체 반환 함수
const chain2 = createYalcoChicken('강남', 17);

// 3. 생성자 함수
const chain3 = new YalcoChicken('제주', 24);

console.log(chain1 instanceof YalcoChicken);  // false
console.log(chain2 instanceof YalcoChicken);  // false
console.log(chain3 instanceof YalcoChicken);  // true

```

### instanceof 연산자

`instanceof` 연산자는 객체가 특정 생성자 함수에 의해 만들어졌는지 확인합니다.

**동작 원리:**

- 객체의 프로토타입 체인에 해당 생성자 함수의 `prototype`이 존재하는지 확인합니다
- 생성자 함수로 만든 객체만 `true`를 반환합니다

**사용 예시:**

```jsx
const arr = [1, 2, 3];
console.log(arr instanceof Array);   // true
console.log(arr instanceof Object);  // true (모든 객체는 Object의 인스턴스)

```

### 3.5 생성자 함수의 정적 프로퍼티와 메서드

생성자 함수 자체에도 프로퍼티와 메서드를 추가할 수 있습니다.

```jsx
function YalcoChicken(name, no) {
  this.name = name;
  this.no = no;
  this.introduce = function() {
    return `안녕하세요, ${this.no}호 ${this.name}점입니다!`;
  }
}

// 본사의 정보 (정적 프로퍼티)
YalcoChicken.brand = '얄코치킨';

// 본사의 업무 (정적 메서드)
YalcoChicken.contact = function() {
  return `${this.brand}입니다. 무엇을 도와드릴까요?`;
};

const chain1 = new YalcoChicken('판교', 3);

console.log(YalcoChicken.contact());  // '얄코치킨입니다. 무엇을 도와드릴까요?'
console.log(chain1.contact());         // TypeError: chain1.contact is not a function

```

**특징:**

- 정적 프로퍼티/메서드는 생성자 함수에만 속합니다
- 인스턴스에서는 접근할 수 없습니다
- 클래스 문법에서는 `static` 키워드로 정의합니다

### 3.6 new 생략 실수 방지하기

`new` 없이 생성자 함수를 호출하는 실수를 방지하는 패턴:

```jsx
function YalcoChicken(name, no) {
  this.name = name;
  this.no = no;
  this.introduce = function() {
    return `안녕하세요, ${this.no}호 ${this.name}점입니다!`;
  }

  // new.target으로 new 연산자 사용 여부 확인
  if (!new.target) {
    return new YalcoChicken(name, no);  // 재귀 호출로 올바르게 생성
  }
}

const chain1 = new YalcoChicken('판교', 3);     // 정상
const chain2 = YalcoChicken('강남', 17);        // new 없어도 정상 작동

console.log(chain1, chain2);  // 둘 다 YalcoChicken 인스턴스

```

### new.target

- ES6에서 도입된 메타 프로퍼티입니다
- `new` 연산자와 함께 호출되면 생성자 함수 자신을 가리킵니다
- `new` 없이 호출되면 `undefined`입니다

**참고:**

- ES6 클래스 문법을 사용하면 `new` 없이 호출 시 자동으로 오류가 발생하므로 이 패턴이 필요 없습니다

## 4. 핵심 요약

### 객체 기본

- **객체는 키-값 쌍**의 프로퍼티 집합입니다
- **프로퍼티 접근**: 마침표 표기법(`obj.key`) 또는 대괄호 표기법(`obj['key']`)
- **동적 프로퍼티**: 변수를 키로 사용할 때는 반드시 대괄호 표기법 사용
- **delete 연산자**: 프로퍼티를 삭제합니다
- **ES6 단축 프로퍼티**: 키와 변수명이 같으면 `{x, y}` 형태로 축약 가능
- **ES6 메서드**: `functionName() {}` 형태로 함수를 간결하게 정의

### 생성자 함수

- **목적**: 동일한 구조의 객체를 효율적으로 생성
- **명명**: 파스칼 케이스(PascalCase) 사용
- **사용**: `new` 연산자와 함께 호출
- **this**: 생성될 인스턴스를 가리킴
- **반환**: `this`를 암묵적으로 반환

### 프로토타입

- **개념**: 모든 인스턴스가 공유하는 프로퍼티와 메서드 저장소
- **추가**: `생성자함수.prototype.메서드명 = function() {}`
- **장점**: 메모리 효율적, 동적 업데이트 가능
- **인스턴스 메서드 vs 프로토타입 메서드**: 개별 생성 vs 공유
- **instanceof**: 객체가 특정 생성자 함수의 인스턴스인지 확인

### 주의사항

- 객체/배열을 키로 사용하면 문자열로 변환됨 (참조값 아님)
- 동적 프로퍼티 접근 시 마침표 표기법 사용 불가
- `new` 없이 생성자 함수 호출 시 `undefined` 반환
- `new.target`으로 `new` 생략 실수 방지 가능

## 5. 복습 퀴즈

### 퀴즈 1

다음 중 객체의 프로퍼티에 접근할 때 **반드시 대괄호 표기법을 사용해야 하는 경우**는?

1. 프로퍼티 이름이 영문자로 시작하는 경우
2. 프로퍼티 이름이 변수에 저장되어 있는 경우
3. 프로퍼티 값이 문자열인 경우
4. 프로퍼티 값이 함수인 경우
5. 객체가 생성자 함수로 만들어진 경우

**정답: 2번**

해설: 프로퍼티 이름이 변수에 저장되어 있을 때는 대괄호 표기법(`obj[key]`)을 사용해야 합니다. 마침표 표기법(`obj.key`)을 사용하면 변수가 아닌 문자 그대로 'key'라는 프로퍼티를 찾게 됩니다. 또한 프로퍼티 이름에 공백, 하이픈 등 특수문자가 포함되거나 숫자로 시작하는 경우에도 대괄호 표기법을 사용해야 합니다.

### 퀴즈 2

다음 코드의 실행 결과로 올바른 것은?

```jsx
const objKey = { x: 1, y: 2 };
const obj = {
  [objKey]: 'test'
};

console.log(obj['[object Object]']);

```

1. `undefined`
2. `'test'`
3. `{ x: 1, y: 2 }`
4. 오류 발생
5. `null`

**정답: 2번**

해설: JavaScript에서 객체를 키로 사용하면 자동으로 문자열로 변환됩니다. 모든 객체는 `toString()` 메서드를 통해 `'[object Object]'` 문자열로 변환되므로, 실제로는 `'[object Object]'`가 키가 됩니다. 따라서 `obj['[object Object]']`로 접근하면 `'test'`가 반환됩니다. 이는 객체의 참조값이 키가 되는 것이 아니라는 점을 보여줍니다.

### 퀴즈 3

ES6 메서드 축약 문법으로 정의된 메서드와 일반 함수 프로퍼티의 차이점으로 **올바르지 않은 것**은?

1. 메서드는 `super` 키워드를 사용할 수 있다
2. 메서드는 생성자 함수로 사용할 수 없다
3. 메서드는 `function` 키워드를 생략할 수 있다
4. 메서드는 화살표 함수로만 정의할 수 있다
5. 메서드는 ES6부터 도입된 문법이다

**정답: 4번**

해설: 메서드는 화살표 함수로 정의할 수 없습니다. ES6 메서드 축약 문법은 `methodName() {}` 형태로 작성하며, 일반 함수로 동작합니다. 화살표 함수는 자체 `this` 바인딩이 없고 `super`를 사용할 수 없으므로 메서드로 적합하지 않습니다. 메서드의 주요 특징은 `super` 키워드 사용 가능, 생성자 함수로 사용 불가, 간결한 문법 등입니다.

### 퀴즈 4

생성자 함수를 `new` 없이 호출했을 때의 결과로 올바른 것은?

```jsx
function Car(name) {
  this.name = name;
}

const myCar = Car('Tesla');
console.log(myCar);

```

1. `{ name: 'Tesla' }`
2. `Car { name: 'Tesla' }`
3. `undefined`
4. `null`
5. 오류 발생

**정답: 3번**

해설: 생성자 함수를 `new` 연산자 없이 호출하면 일반 함수로 동작합니다. 일반 함수는 명시적인 `return` 문이 없으면 `undefined`를 반환합니다. 또한 이 경우 `this`는 전역 객체(브라우저에서는 `window`)를 가리키므로, 전역 객체에 `name` 프로퍼티가 추가되는 의도하지 않은 부작용이 발생합니다. 이를 방지하기 위해 `new.target`을 사용하거나 ES6 클래스 문법을 사용할 수 있습니다.

### 퀴즈 5

프로토타입 메서드에 대한 설명으로 올바른 것은?

```jsx

  this.name = name;
}

Animal.prototype.speak = function() {
  return `${this.name} makes a sound`;
};

const dog = new Animal('Dog');

```

1. `speak` 메서드는 각 인스턴스마다 별도로 생성된다
2. `speak` 메서드는 `Animal` 생성자 함수에서만 호출 가능하다
3. `speak` 메서드는 모든 `Animal` 인스턴스가 공유한다
4. 프로토타입에 추가한 메서드는 이전에 생성된 인스턴스에서 사용할 수 없다
5. 프로토타입 메서드는 `this`를 사용할 수 없다

**정답: 3번**

해설: 프로토타입에 정의된 메서드는 해당 생성자 함수로 생성된 모든 인스턴스가 공유합니다. 이는 메모리 효율성을 높이는 JavaScript의 중요한 특징입니다. 프로토타입에 메서드를 추가하면 이미 생성된 인스턴스에서도 즉시 사용 가능하며, `this`는 메서드를 호출한 인스턴스를 가리킵니다. 반면 생성자 함수 내부에서 `this.method = function() {}`로 정의하면 각 인스턴스마다 메서드가 별도로 생성됩니다.

```jsx
function hasProperty(obj, key) {
  // 여기에 코드를 작성하세요

  // 여기에 코드를 작성하세요
```

**정답:**

```jsx
function hasProperty(obj, key) {
  return key in obj;
  // 또는 return obj.hasOwnProperty(key);
}

function copyProperties(source, target, keys) {
  for (const key of keys) {
    if (hasProperty(source, key)) {
      target[key] = source[key];
    }
  }
  return target;
}

function renameProperty(obj, oldKey, newKey) {
  if (hasProperty(obj, oldKey)) {
    obj[newKey] = obj[oldKey];
    delete obj[oldKey];
  }
  return obj;
}

// 테스트 코드
const user = {
  name: '홍길동',
  age: 25,
  email: 'hong@example.com',
  phone: '010-1234-5678'
};

console.log(hasProperty(user, 'name'));      // true
console.log(hasProperty(user, 'address'));   // false

const newUser = {};
copyProperties(user, newUser, ['name', 'email']);
console.log(newUser);  // { name: '홍길동', email: 'hong@example.com' }

renameProperty(user, 'phone', 'mobile');
console.log(user.mobile);  // '010-1234-5678'
console.log(user.phone);   // undefined

```

**풀이:**

- `hasProperty`: `in` 연산자를 사용하여 객체에 해당 프로퍼티가 있는지 확인합니다. `hasOwnProperty` 메서드도 사용 가능하지만 `in` 연산자는 프로토타입 체인도 검색합니다
- `copyProperties`: 반복문으로 keys 배열을 순회하며 대괄호 표기법으로 동적으로 프로퍼티를 복사합니다
- `renameProperty`: 대괄호 표기법으로 새 키에 값을 할당한 후 `delete` 연산자로 이전 키를 삭제합니다

**핵심 개념:**

- 대괄호 표기법을 통한 동적 프로퍼티 접근
- `in` 연산자와 `delete` 연산자
- 함수 매개변수로 받은 키 이름으로 프로퍼티 조작

```jsx
function BankAccount(owner, balance = 0) {
  // new 생략 방지
  if (!new.target) {
    return new BankAccount(owner, balance);
  }

  this.owner = owner;
  this.balance = balance;
}

BankAccount.prototype.deposit = function(amount) {
  if (amount <= 0) {
    return '입금액은 0보다 커야 합니다.';
  }
  this.balance += amount;
  return `${amount}원이 입금되었습니다. 현재 잔액: ${this.balance}원`;
};

BankAccount.prototype.withdraw = function(amount) {
  if (amount <= 0) {
    return '출금액은 0보다 커야 합니다.';
  }
  if (amount > this.balance) {
    return '잔액이 부족합니다.';
  }
  this.balance -= amount;
  return `${amount}원이 출금되었습니다. 현재 잔액: ${this.balance}원`;
};

BankAccount.prototype.getBalance = function() {
  return this.balance;
};

// 정적 프로퍼티
BankAccount.bankName = '얄코은행';

// 정적 메서드
BankAccount.compareAccounts = function(acc1, acc2) {
  if (acc1.balance > acc2.balance) {
    return `${acc1.owner}의 잔액이 더 많습니다.`;
  } else if (acc1.balance < acc2.balance) {
    return `${acc2.owner}의 잔액이 더 많습니다.`;
  } else {
    return '두 계좌의 잔액이 같습니다.';
  }
};

// 테스트 코드
const account1 = new BankAccount('홍길동', 10000);
const account2 = BankAccount('김철수', 5000);  // new 없이 호출

account1.deposit(5000);
console.log(account1.getBalance());  // 15000

account1.withdraw(3000);
console.log(account1.getBalance());  // 12000

console.log(account1.withdraw(20000));  // '잔액이 부족합니다.'

console.log(BankAccount.bankName);  // '얄코은행'
console.log(BankAccount.compareAccounts(account1, account2));
// '홍길동의 잔액이 더 많습니다.'

```

**풀이:**

- `new.target`을 사용하여 `new` 없이 호출해도 올바르게 인스턴스를 생성합니다
- 매개변수 기본값(`balance = 0`)을 사용하여 초기 잔액이 없어도 작동합니다
- 각 메서드에서 유효성 검사를 수행하여 잘못된 입력을 방지합니다
- 정적 프로퍼티와 메서드는 생성자 함수 자체에 직접 추가합니다
- 프로토타입 메서드는 모든 인스턴스가 공유하므로 메모리 효율적입니다

**핵심 개념:**

- `new.target`을 사용한 생성자 함수 호출 방식 확인
- 프로토타입 메서드를 통한 공통 기능 구현
- 정적 프로퍼티/메서드와 인스턴스 프로퍼티/메서드의 구분
- 매개변수 기본값 사용

**기본 코드:**


**정답:**

```jsx
function deepCopy(obj) {
  // null이거나 객체가 아닌 경우 그대로 반환
  if (obj === null || typeof obj !== 'object') {
    return obj;
  }

  // 배열인 경우
  if (Array.isArray(obj)) {
    const arrCopy = [];
    for (let i = 0; i < obj.length; i++) {
      arrCopy[i] = deepCopy(obj[i]);
    }
    return arrCopy;
  }

  // 객체인 경우
  const objCopy = {};
  for (const key in obj) {
    if (obj.hasOwnProperty(key)) {
      objCopy[key] = deepCopy(obj[key]);
    }
  }
  return objCopy;
}

// 테스트 코드
const original = {
  name: '홍길동',
  age: 25,
  address: {
    city: '서울',
    district: '강남구'
  },
  hobbies: ['독서', '영화감상']
};

const copied = deepCopy(original);

// 복사본 수정
copied.name = '김철수';
copied.address.city = '부산';
copied.hobbies.push('운동');

console.log(original.name);           // '홍길동'
console.log(original.address.city);   // '서울'
console.log(original.hobbies);        // ['독서', '영화감상']

console.log(copied.name);             // '김철수'
console.log(copied.address.city);     // '부산'
console.log(copied.hobbies);          // ['독서', '영화감상', '운동']

```

**풀이:**

- 재귀 함수를 사용하여 중첩된 구조를 깊게 복사합니다
- 기본 타입(원시값)은 그대로 반환합니다
- 배열인 경우 새 배열을 만들고 각 요소를 재귀적으로 복사합니다
- 객체인 경우 새 객체를 만들고 각 프로퍼티를 재귀적으로 복사합니다
- `hasOwnProperty`로 객체 자신의 프로퍼티만 복사합니다 (프로토타입 체인 제외)

**핵심 개념:**

- 재귀 함수를 통한 중첩 구조 처리
- `typeof` 연산자와 `Array.isArray()`를 통한 타입 확인
- 얕은 복사 vs 깊은 복사의 차이
- `for...in` 루프와 `hasOwnProperty` 메서드

**참고:**
실무에서는 `JSON.parse(JSON.stringify(obj))`나 Lodash의 `_.cloneDeep()` 등을 사용하기도 하지만, 함수나 `undefined` 등을 제대로 복사하지 못하는 한계가 있습니다.
