# JavaScript 배열 고차함수 메서드 복습 자료 📚

> 출처: MDN 문서 기반 학습 자료
>
> 고차함수(Higher Order Function): 다른 함수를 인자로 받는 함수

---

## 1. forEach 🔄

### 언제 쓰나요?

- 배열의 모든 요소를 순회하면서 **부수효과(side effect)**를 실행할 때
- 콘솔 출력, DOM 조작, 외부 변수 수정 등

### 핵심 특징

- **반환값이 없음** (undefined 반환)
- `break`, `continue` 사용 불가 (중간에 멈출 수 없음)
- 원본 배열 수정 가능 (하지만 권장하지 않음)

### 실무 패턴

```javascript
// ✅ 좋은 사용: 각 항목에 대한 작업 수행
users.forEach((user) => {
  sendEmail(user.email);
});

// ❌ 나쁜 사용: 새 배열을 만들려면 map 사용
const doubled = [];
arr.forEach((num) => doubled.push(num * 2)); // 대신 map 사용
```

### 헷갈리는 포인트

- `forEach`는 값을 반환하지 않으므로 체이닝 불가
- 세 번째 인자는 **원본 배열의 참조**

## 2. map 🗺️

### 언제 쓰나요?

- 배열의 각 요소를 **변환**해서 **새 배열**을 만들 때
- 데이터 가공, 형식 변환 시

### 핵심 특징

- 원본 배열 길이와 동일한 새 배열 반환
- **원본 배열 수정 안 함** (불변성 유지)
- 콜백 함수는 **반드시 값을 반환**해야 함

### 실무 패�턴

```javascript
// ✅ API 응답 데이터 가공
const userNames = users.map((user) => user.name);

// ✅ 객체 배열에서 특정 속성만 추출
const prices = products.map(({ price }) => price);

// ✅ 메서드 체이닝
const result = arr
  .map((x) => x * 2)
  .filter((x) => x > 10)
  .join(", ");
```

### 헷갈리는 포인트

- 블록 `{}` 사용 시 `return` 필수
- `return` 없으면 `undefined` 배열 생성됨

## 3. find / findIndex 계열 🔍

### 언제 쓰나요?

- 조건에 맞는 **첫 번째 또는 마지막** 요소를 찾을 때

### 메서드 종류

| 메서드          | 반환값         | 없을 때     |
| --------------- | -------------- | ----------- |
| `find`          | 첫 번째 값     | `undefined` |
| `findLast`      | 마지막 값      | `undefined` |
| `findIndex`     | 첫 번째 인덱스 | `-1`        |
| `findLastIndex` | 마지막 인덱스  | `-1`        |

### 실무 패턴

```javascript
// ✅ 특정 ID를 가진 객체 찾기
const user = users.find((u) => u.id === targetId);

// ✅ 조건 검증 후 작업
const index = arr.findIndex((item) => item.status === "active");
if (index !== -1) {
  arr[index].status = "inactive";
}
```

## 4. some / every ✔️

### 언제 쓰나요?

- 배열이 특정 **조건을 충족하는지 검증**할 때

### 차이점

- `some`: 하나라도 true면 true (OR 조건)
- `every`: 모두 true여야 true (AND 조건)

### 실무 패턄

```javascript
// ✅ 유효성 검사
const hasEmptyField = formData.some((field) => !field.value);
const allValid = formData.every((field) => field.isValid);

// ✅ 권한 체크
const hasAdminRole = user.roles.some((role) => role === "admin");
```

## 5. filter 🎯

### 언제 쓰나요?

- 조건에 맞는 요소들로 **새 배열**을 만들 때
- 검색, 필터링 기능 구현 시

### 핵심 특징

- 원본 배열 수정 안 함
- 조건에 맞는 요소가 없으면 빈 배열 `[]` 반환

### 실무 패턴

```javascript
// ✅ 검색 결과 필터링
const searchResults = products.filter((p) => p.name.includes(searchTerm));

// ✅ 다중 조건 필터링
const activeAdults = users.filter((u) => u.age >= 18 && u.isActive);

// ✅ map과 조합
const activeUserNames = users.filter((u) => u.isActive).map((u) => u.name);
```

## 6. reduce / reduceRight ➕

### 언제 쓰나요?

- 배열을 **하나의 값으로 축약**할 때
- 합계, 평균, 그룹화, 객체 변환 등

### 핵심 특징

- **초기값 설정 권장** (안 하면 첫 번째 요소가 초기값)
- 반환 타입 자유 (숫자, 객체, 배열 등)

### 실무 패턴

```javascript
// ✅ 합계 계산
const total = prices.reduce((sum, price) => sum + price, 0);

// ✅ 객체로 그룹화
const grouped = items.reduce((acc, item) => {
  const key = item.category;
  if (!acc[key]) acc[key] = [];
  acc[key].push(item);
  return acc;
}, {});

// ✅ 카운팅
const counts = arr.reduce((acc, item) => {
  acc[item] = (acc[item] || 0) + 1;
  return acc;
}, {});
```

### 헷갈리는 포인트

- 초기값 없으면 인덱스가 **1부터** 시작
- 초기값 있으면 인덱스가 **0부터** 시작
- `reduceRight`는 오른쪽에서 왼쪽으로, 인덱스도 역순

## 7. sort ⬆️⬇️

### 언제 쓰나요?

- 배열을 정렬할 때 (오름차순, 내림차순)

### ⚠️ 주의사항

- **원본 배열을 수정**함 (불변성 깨짐)
- 인자 없이 사용 시 문자열로 변환 후 정렬

### 핵심 원리

```javascript
// 콜백 함수 (a, b) 반환값:
// 양수 → b를 앞으로 (순서 바꿈)
// 0 → 순서 유지
// 음수 → a를 앞으로 (순서 유지)
```

### 실무 패턴

```javascript
// ✅ 숫자 오름차순
arr.sort((a, b) => a - b);

// ✅ 숫자 내림차순
arr.sort((a, b) => b - a);

// ✅ 문자열 정렬
arr.sort((a, b) => (a > b ? 1 : -1));

// ✅ 다중 조건 정렬 (카테고리 → 가격)
arr.sort((a, b) => {
  if (a.category !== b.category) {
    return a.category > b.category ? 1 : -1;
  }
  return a.price - b.price;
});

// ✅ 원본 보존하며 정렬
const sorted = [...arr].sort((a, b) => a - b);
```

### 헷갈리는 포인트

- 브라우저마다 내부 동작이 다를 수 있지만, 결과는 동일
- `NaN` 반환하는 연산은 사용 불가 (`'A' - 'B'`)

## 8. flatMap 🎈

### 언제 쓰나요?

- `map` + `flat`을 동시에 수행할 때
- 각 요소를 여러 개로 펼치고 싶을 때

### 핵심 특징

- **한 단계만** 펼침 (depth 1)
- `map().flat(1)`과 동일

### 실무 패턴

```javascript
// ✅ 중첩 배열 펼치기
const nested = [
  [1, 2],
  [3, 4],
];
nested.flatMap((x) => x); // [1, 2, 3, 4]

// ✅ 한 요소를 여러 개로 확장
const duplicated = arr.flatMap((x) => [x, x, x]);

// ✅ 문자열 분리 후 펼치기
const words = "하나 둘 셋".split(" ");
words.flatMap((word) => word.split(""));
// ['하','나','둘','셋']
```

## 🎯 최종 핵심 요약

| 메서드    | 반환값        | 원본 수정 | 주요 용도           |
| --------- | ------------- | --------- | ------------------- |
| `forEach` | `undefined`   | 가능      | 순회 작업 실행      |
| `map`     | 새 배열       | ❌        | 변환된 배열 생성    |
| `find`    | 값/undefined  | ❌        | 조건 만족 요소 찾기 |
| `some`    | boolean       | ❌        | 하나라도 만족?      |
| `every`   | boolean       | ❌        | 모두 만족?          |
| `filter`  | 새 배열       | ❌        | 조건 만족 요소들    |
| `reduce`  | 단일 값       | ❌        | 배열 → 하나의 값    |
| `sort`    | 원본 배열     | ⚠️ **O**  | 정렬                |
| `flatMap` | 새 배열(펼침) | ❌        | map + 1단계 flat    |

### 기억할 3가지 원칙

1. **불변성**: `sort` 빼고는 원본을 수정하지 않음
2. **체이닝**: 배열을 반환하는 메서드는 연결 가능
3. **함수형**: 변수 사용 없이 데이터 가공 가능

## 📝 복습 퀴즈

### Q1. 다음 코드의 출력 결과는?

```javascript
const arr = [1, 2, 3];
const result = arr.forEach((x) => x * 2);
console.log(result);
```

1. `[2, 4, 6]`
2. `undefined`
3. `[1, 2, 3]`
4. `6`
5. 에러 발생

**정답: 2번**

해설: `forEach`는 배열을 순회하며 작업을 수행하지만 반환값이 없습니다. 항상 `undefined`를 반환하므로 새 배열을 만들려면 `map`을 사용해야 합니다.

---

### Q2. 배열에서 조건을 만족하는 첫 번째 요소의 인덱스를 찾는 메서드는?

1. `find`
2. `indexOf`
3. `findIndex`
4. `some`
5. `filter`

**정답: 3번**

해설: `findIndex`는 콜백 함수가 true를 반환하는 첫 번째 요소의 인덱스를 반환합니다. `find`는 값을 반환하고, `indexOf`는 값 자체를 찾을 때 사용합니다.

---

### Q3. 다음 코드의 결과는?

```javascript
const arr = [10, 5, 100, 2];
arr.sort();
console.log(arr);
```

1. `[2, 5, 10, 100]`
2. `[100, 10, 5, 2]`
3. `[10, 100, 2, 5]`
4. `[5, 10, 2, 100]`
5. 에러 발생

**정답: 3번**

해설: `sort()`를 인자 없이 사용하면 요소를 문자열로 변환하여 유니코드 순서로 정렬합니다. `"10"`, `"100"`, `"2"`, `"5"` 순서가 되므로 숫자 정렬을 위해서는 `sort((a, b) => a - b)`를 사용해야 합니다.

---

### Q4. 다음 중 원본 배열을 수정하는 메서드는?

1. `map`
2. `filter`
3. `sort`
4. `reduce`
5. `find`

**정답: 3번**

해설: `sort`는 배열 메서드 중 원본 배열을 직접 수정하는 몇 안 되는 메서드입니다. 원본을 보존하려면 `[...arr].sort()`처럼 복사 후 정렬해야 합니다.

---

### Q5. 다음 코드의 출력 결과는?

```javascript
const arr = [1, 2, 3, 4, 5];
const result = arr.reduce((acc, cur) => acc + cur);
console.log(result);
```

1. `0`
2. `15`
3. `[1, 2, 3, 4, 5]`
4. `undefined`
5. `5`

**정답: 2번**

해설: `reduce`는 초기값을 제공하지 않으면 첫 번째 요소(1)를 초기값으로 사용합니다. 1 + 2 + 3 + 4 + 5 = 15가 됩니다.

---

### Q6. 배열의 모든 요소가 조건을 만족하는지 확인하는 메서드는?

1. `some`
2. `every`
3. `filter`
4. `find`
5. `includes`

**정답: 2번**

해설: `every`는 배열의 모든 요소가 콜백 함수에서 true를 반환해야 true를 반환합니다. `some`은 하나라도 true면 true를 반환합니다.

---

### Q7. 다음 코드의 결과는?

```javascript
const arr = [1, 2, 3];
const result = arr.flatMap((x) => [x, x * 10]);
console.log(result);
```

1. `[[1, 10], [2, 20], [3, 30]]`
2. `[1, 10, 2, 20, 3, 30]`
3. `[1, 2, 3, 10, 20, 30]`
4. `[10, 20, 30]`
5. 에러 발생

**정답: 2번**

해설: `flatMap`은 각 요소를 매핑한 후 한 단계 펼칩니다. `[1, 10]`, `[2, 20]`, `[3, 30]`을 만든 후 한 단계 flat하여 `[1, 10, 2, 20, 3, 30]`이 됩니다.

---

### Q8. 다음 중 빈 배열을 반환할 수 있는 메서드는?

1. `map`
2. `reduce`
3. `filter`
4. `forEach`
5. `some`

**정답: 3번**

해설: `filter`는 조건을 만족하는 요소가 없으면 빈 배열 `[]`을 반환합니다. `map`은 원본과 같은 길이의 배열을 반환하며, `forEach`는 `undefined`를 반환합니다.
