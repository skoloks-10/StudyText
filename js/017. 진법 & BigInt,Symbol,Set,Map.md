## 📌 진법 표현과 변환

### 언제 쓰나요?

- **2진법**: 비트 연산, 플래그 관리, 권한 시스템
- **8진법**: 유닉스 파일 권한 (`chmod 755`)
- **16진법**: 색상 코드 (`#FF5733`), 메모리 주소, 해시값

### 표기법

```javascript
const binary = 0b1010; // 2진법: 0b 접두사
const octal = 0o755; // 8진법: 0o 접두사
const hex = 0xff; // 16진법: 0x 접두사
```

### 진법 변환 패턴

```javascript
const num = 255;

// 10진수 → 다른 진법 (문자열로 반환)
num.toString(2); // "11111111" (2진수)
num.toString(8); // "377" (8진수)
num.toString(16); // "ff" (16진수)

// 다른 진법 → 10진수
parseInt("11111111", 2); // 255
parseInt("377", 8); // 255
parseInt("ff", 16); // 255

// 진법 간 직접 변환
parseInt("ff", 16).toString(2); // 16진수 → 2진수
```

### ⚠️ 헷갈리는 포인트

- `toString()`은 **문자열** 반환, `parseInt()`는 **숫자** 반환
- 진법 범위: 2~36까지 가능 (36진법까지 지원)
- 잘못된 자릿수 사용 시 에러: `0b2`, `0o8` ❌

## 🔧 비트 연산자

### 언제 쓰나요?

- 권한 관리 (읽기/쓰기/실행)
- 플래그 조합 (여러 상태를 하나의 숫자로)
- 성능 최적화 (곱셈/나눗셈 대신)
- 색상 채널 추출/합성

### 주요 연산자

| 연산자 | 의미            | 예시               | 결과          |
| ------ | --------------- | ------------------ | ------------- |
| `&`    | AND (둘 다 1)   | `0b1010 & 0b1100`  | `0b1000`      |
| `\|`   | OR (하나라도 1) | `0b1010 \| 0b1100` | `0b1110`      |
| `^`    | XOR (다르면 1)  | `0b1010 ^ 0b1100`  | `0b0110`      |
| `~`    | NOT (비트 반전) | `~0b1010`          | `-11`         |
| `<<`   | 왼쪽 시프트     | `0b101 << 1`       | `0b1010` (×2) |
| `>>`   | 오른쪽 시프트   | `0b1010 >> 1`      | `0b101` (÷2)  |

### 실무 패턴

```javascript
// 권한 시스템
const READ = 0b100; // 4
const WRITE = 0b010; // 2
const EXECUTE = 0b001; // 1

const userPermission = READ | WRITE; // 읽기+쓰기 권한

// 권한 확인
if (userPermission & READ) {
  console.log("읽기 가능");
}

// 색상 채널 추출 (RGB)
const color = 0xff5733;
const red = (color >> 16) & 0xff; // 255
const green = (color >> 8) & 0xff; // 87
const blue = color & 0xff; // 51
```

## 🔢 BigInt

### 언제 쓰나요?

- 암호화 작업
- 매우 큰 ID 값 처리
- 금융 계산 (정밀도 필요시)
- `Number.MAX_SAFE_INTEGER` (9007199254740991) 초과 값

### 생성 방법

```javascript
const big1 = 9007199254740991n; // n 접미사
const big2 = BigInt(9007199254740991);
const big3 = BigInt("9007199254740991");
const big4 = BigInt(0x1fffffffffffff);
```

### ⚠️ 주의사항

```javascript
// ❌ number와 직접 연산 불가
1n + 1; // TypeError

// ✅ 모두 BigInt로 변환
1n + BigInt(1); // 2n

// ❌ Math 메서드 사용 불가
Math.max(1n, 2n); // TypeError

// ✅ 비교 연산은 가능
1n < 2; // true
1n == 1; // true
1n === 1; // false (타입 다름)

// ⚠️ 소수점 버림
5n / 2n; // 2n (not 2.5)

// ⚠️ number 변환시 정밀도 손실 가능
Number(9007199254740993n); // 부정확할 수 있음
```

### 실무 패턴

```javascript
// 안전한 계산 함수
const safeMath = (x, y, op) => {
  return op(BigInt(x), BigInt(y));
};

safeMath(1n, 1, (a, b) => a + b); // 2n
```

## 🔐 Symbol

### 언제 쓰나요?

- 객체의 **은닉 프로퍼티** (외부 접근 차단)
- 표준 객체에 **커스텀 메서드** 안전하게 추가
- **고유 식별자** 필요시
- 프레임워크 내부 구현 (React의 `$$typeof` 등)

### 기본 사용법

```javascript
const sym1 = Symbol("description");
const sym2 = Symbol("description");

sym1 === sym2; // false (항상 고유함)

// 객체 은닉 프로퍼티
const secret = Symbol("password");
const user = {
  name: "Alice",
  [secret]: "1234",
};

user.name; // 'Alice' ✅
user[secret]; // '1234' ✅
user["password"]; // undefined (접근 불가)
```

### 접근 제한 특성

```javascript
const key = Symbol('hidden');
const obj = { public: 1, [key]: 2 };

// ❌ 일반 방법으로 접근 불가
Object.keys(obj)                    // ['public']
Object.values(obj)                  // [1]
Object.entries(obj)                 // [['public', 1]]
for (let k in obj) { ... }          // 'public'만 순회

// ✅ Symbol 전용 메서드로만 가능
Object.getOwnPropertySymbols(obj)   // [Symbol(hidden)]
```

### 전역 심볼 레지스트리

```javascript
// 같은 키로 동일 심볼 재사용
const s1 = Symbol.for("app.id");
const s2 = Symbol.for("app.id");

s1 === s2; // true (전역 레지스트리 공유)

Symbol.keyFor(s1); // 'app.id'

// 일반 Symbol은 레지스트리에 없음
const s3 = Symbol("app.id");
Symbol.keyFor(s3); // undefined
```

### 실무 패턴

```javascript
// 표준 객체 확장 (안전하게)
Array.prototype[Symbol.for("average")] = function () {
  const nums = this.filter((x) => typeof x === "number");
  return nums.reduce((a, b) => a + b, 0) / nums.length;
};

[1, 2, 3][Symbol.for("average")](); // 2
```

**왜 Symbol.for를 쓰나요?**  
나중에 자바스크립트에 `Array.prototype.average`가 추가되어도 충돌하지 않음

## 📦 Set

### 언제 쓰나요?

- **중복 제거** (배열 → Set → 배열)
- **존재 여부 확인** (has 메서드가 indexOf보다 빠름)
- **고유값 컬렉션** 관리
- 교집합/합집합/차집합 구현

### 배열과의 차이점

| 특성        | 배열      | Set             |
| ----------- | --------- | --------------- |
| 중복 허용   | ✅        | ❌              |
| 순서 의미   | 있음      | 없음            |
| 인덱스 접근 | `arr[0]`  | 불가            |
| 값 확인     | `indexOf` | `has` (더 빠름) |

### 기본 사용법

```javascript
const set = new Set([1, 2, 2, 3]); // Set(3) {1, 2, 3}

set.add(4); // 추가
set.has(2); // true (존재 확인)
set.delete(3); // 제거
set.size; // 크기
set.clear(); // 전체 삭제
```

### 실무 패턴

```javascript
// 1. 배열 중복 제거
const arr = [1, 2, 2, 3, 3, 3];
const unique = [...new Set(arr)]; // [1, 2, 3]

// 2. 빠른 존재 확인
const ids = new Set([101, 102, 103]);
ids.has(102); // O(1) 속도

// 3. 메서드 체이닝
const set2 = new Set().add("a").add("b").add("c");
```

### ⚠️ 참조형 주의

```javascript
const set = new Set();

// ❌ 객체는 참조값이 다르면 다른 것으로 인식
set.add({ x: 1 }).add({ x: 1 });
set.size; // 2 (다른 객체로 취급)

// ✅ 같은 참조를 사용해야 함
const obj = { x: 1 };
set.add(obj).add(obj);
set.size; // 1
```

### 이터러블 활용

```javascript
const set = new Set(["A", "B", "C"]);

// for...of
for (const item of set) {
  console.log(item);
}

// 스프레드
const arr = [...set];

// 디스트럭처링
const [first, second, ...rest] = set;

// forEach
set.forEach((value, key, set) => {
  // value === key (Set은 키 개념 없음)
});
```

## 🗺️ Map

### 언제 쓰나요?

- **동적 키-값 관리** (자주 추가/삭제)
- **객체를 키로 사용** (일반 객체는 문자열만 가능)
- **순서 보장 필요** (삽입 순서 유지)
- **크기 추적** (size 프로퍼티)

### 객체와의 차이점

| 특성             | 객체                   | Map            |
| ---------------- | ---------------------- | -------------- |
| 키 타입          | 문자열/Symbol          | 모든 타입 가능 |
| 순서 보장        | ❌                     | ✅ (삽입 순서) |
| 크기 확인        | `Object.keys().length` | `map.size`     |
| 이터러블         | ❌                     | ✅             |
| 성능 (추가/삭제) | 느림                   | 빠름           |

### 기본 사용법

```javascript
const map = new Map([
  ["name", "Alice"],
  [123, "number key"],
  [true, "boolean key"],
]);

map.set("age", 25); // 추가
map.get("name"); // 'Alice'
map.has("age"); // true
map.delete(123); // 삭제
map.size; // 크기
map.clear(); // 전체 삭제
```

### 실무 패턴

```javascript
// 1. 객체를 키로 사용
const user1 = { id: 1 };
const user2 = { id: 2 };

const userRoles = new Map();
userRoles.set(user1, "admin");
userRoles.set(user2, "user");

userRoles.get(user1); // 'admin'

// 2. 캐시 구현
const cache = new Map();

function fetchData(key) {
  if (cache.has(key)) {
    return cache.get(key);
  }
  const data = expensiveOperation(key);
  cache.set(key, data);
  return data;
}

// 3. 메서드 체이닝
const map2 = new Map().set("a", 1).set("b", 2).set("c", 3);
```

### ⚠️ 참조형 키 주의

```javascript
const map = new Map();

// ❌ 새 객체는 매번 다른 참조
map.set({ x: 1 }, "value");
map.get({ x: 1 }); // undefined

// ✅ 변수에 저장해서 사용
const key = { x: 1 };
map.set(key, "value");
map.get(key); // 'value'
```

### 이터러블 활용

```javascript
const map = new Map([
  ["🐶", "강아지"],
  ["🐱", "고양이"],
]);

// for...of (디스트럭처링 활용)
for (const [emoji, name] of map) {
  console.log(emoji, name);
}

// 키/값/엔트리 이터레이터
map.keys(); // MapIterator {'🐶', '🐱'}
map.values(); // MapIterator {'강아지', '고양이'}
map.entries(); // MapIterator {['🐶', '강아지'], ...}

// 배열 변환
const arr = [...map]; // [['🐶', '강아지'], ['🐱', '고양이']]
```

## 📝 핵심 요약

### 진법

- `0b` (2진), `0o` (8진), `0x` (16진)
- `.toString(base)` → 진법 변환 (문자열)
- `parseInt(str, base)` → 10진수 변환

### 비트 연산

- `&` AND, `|` OR, `^` XOR, `~` NOT
- `<<` `>>` 시프트 (×2, ÷2)
- 권한/플래그 관리에 유용

### BigInt

- 끝에 `n` 붙이거나 `BigInt()` 사용
- number와 직접 연산 불가
- 소수점 버림, Math 메서드 불가

### Symbol

- `Symbol()` 항상 고유값 생성
- 객체 은닉 프로퍼티, 충돌 방지에 사용
- `Symbol.for()` 전역 레지스트리 공유

### Set

- 중복 없는 값 컬렉션
- `add`, `has`, `delete`, `size`
- 배열 중복 제거: `[...new Set(arr)]`

### Map

- 모든 타입을 키로 사용 가능
- `set`, `get`, `has`, `delete`, `size`
- 동적 키-값 관리, 순서 보장

## 🧩 복습 퀴즈

### Q1. 다음 코드의 출력 결과는?

```javascript
const num = 255;
console.log(num.toString(16));
```

1. "255"
2. "11111111"
3. "ff"
4. "377"
5. 에러 발생

**정답: 3) "ff"**

해설: `toString(16)`은 10진수를 16진수 문자열로 변환합니다. 255의 16진수 표현은 "ff"입니다.

### Q2. 비트 연산 결과로 올바른 것은?

```javascript
const result = 0b1100 & 0b1010;
```

1. `0b1110` (14)
2. `0b1000` (8)
3. `0b0110` (6)
4. `0b0010` (2)
5. `0b1111` (15)

**정답: 2) `0b1000` (8)**

해설: AND 연산(`&`)은 양쪽 비트가 모두 1일 때만 1을 반환합니다.

```
  1100
& 1010
------
  1000
```

### Q3. BigInt 사용 시 에러가 발생하는 코드는?

1. `1n + 1n`
2. `BigInt(100) * BigInt(200)`
3. `5n / 2n`
4. `Math.pow(2n, 3n)`
5. `1n < 2`

**정답: 4) `Math.pow(2n, 3n)`**

해설: BigInt는 Math 객체의 메서드를 사용할 수 없습니다. 1, 2, 3번은 정상 작동하며, 5번은 비교 연산이므로 가능합니다.

### Q4. Symbol에 대한 설명으로 틀린 것은?

1. `Symbol('x') === Symbol('x')`는 false이다
2. `Symbol.for('x') === Symbol.for('x')`는 true이다
3. 객체의 Symbol 키는 `Object.keys()`로 조회할 수 없다
4. Symbol은 `new` 키워드를 사용하지 않는다
5. `Symbol.keyFor(Symbol.for('test'))`는 'test'를 반환한다

**정답: 1)의 설명은 맞지만, 문제는 "틀린 것"을 찾는 것이므로 모든 설명이 올바릅니다**

정확한 답: 모든 설명이 맞습니다. 1) 일반 Symbol은 항상 고유하고, 2) Symbol.for는 전역 레지스트리를 공유하며, 3) Symbol 키는 일반 메서드로 조회 불가, 4) Symbol은 함수처럼 호출, 5) keyFor는 레지스트리 키를 반환합니다.

### Q5. 다음 코드의 출력 결과는?

```javascript
const arr = [1, 2, 2, 3, 3, 3];
const result = [...new Set(arr)];
console.log(result.length);
```

1. 6
2. 3
3. 4
4. 2

**정답: 2) 3**

해설: Set은 중복을 자동 제거하므로 `[1, 2, 3]`이 되고, 스프레드 문법으로 배열화하면 길이는 3입니다.

### Q6. Map과 일반 객체의 차이점으로 틀린 것은?

1. Map은 모든 타입을 키로 사용할 수 있다
2. Map은 size 프로퍼티로 크기를 확인할 수 있다
3. Map은 삽입 순서를 보장한다
4. 객체는 Symbol을 키로 사용할 수 없다
5. Map은 이터러블 프로토콜을 따른다

**정답: 4) 객체는 Symbol을 키로 사용할 수 없다**

### Q7. 다음 코드에서 `map.get(key)`의 결과는?

```javascript
const map = new Map();

const key = { id: 1 };

```

1. 'value'
2. undefined
3. null

**정답: 2) undefined**

해설: 객체는 참조값으로 비교되므로, `map.set`에 사용된 `{id: 1}`과 `const key`의 `{id: 1}`은 다른 객체입니다. 같은 참조를 사용해야 값을 가져올 수 있습니다.

### Q8. Set의 forEach 메서드에서 두 번째 인자의 의미는?

```javascript
const set = new Set(["A", "B"]);
set.forEach((value, key) => {
  console.log(value, key);
});
```

1. 인덱스
2. 배열의 원본
3. value와 동일한 값
4. Set의 크기
5. undefined

**정답: 3) value와 동일한 값**

해설: Set은 순서 개념이 없고 키가 없으므로, forEach의 두 번째 인자는 첫 번째 인자(value)와 같은 값입니다. 이는 Array의 forEach와 형식을 맞추기 위함입니다.
