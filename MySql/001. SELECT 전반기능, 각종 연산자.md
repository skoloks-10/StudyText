# 🗄️ SQL 복습자료 — SELECT & 연산자

> 📖 출처: SQL Lesson 1~2 (SELECT 전반 / 연산자)
> 🎯 목적: 빠른 복습용 정리본

---

## LESSON 1 | 🔍 SELECT — 내가 원하는 정보 가져오기

---

### 1️⃣ 모든 컬럼 가져오기

언제 쓰나요? → 테이블에 어떤 컬럼이 있는지 확인할 때, 전체 데이터를 볼 때

```sql
SELECT * FROM Customers;
```

> `*`(asterisk)는 "모든 컬럼"을 의미합니다.

---

### 2️⃣ 원하는 컬럼만 골라서 가져오기

언제 쓰나요? → 필요한 정보만 뽑아서 볼 때 (불필요한 데이터 제외)

```sql
SELECT CustomerName FROM Customers;

SELECT CustomerName, ContactName, Country
FROM Customers;
```

💡 컬럼 이름 외에 고정 값도 넣을 수 있어요.

```sql
SELECT CustomerName, 1, 'Hello', NULL
FROM Customers;
```

---

### 3️⃣ 조건으로 행(row) 필터링하기 — WHERE

언제 쓰나요? → 특정 조건에 맞는 데이터만 추출할 때

```sql
SELECT * FROM Orders
WHERE EmployeeID = 3;

SELECT * FROM OrderDetails
WHERE Quantity < 5;
```

---

### 4️⃣ 정렬해서 가져오기 — ORDER BY

언제 쓰나요? → 데이터를 특정 기준으로 오름차순/내림차순 정렬할 때

| 키워드 | 정렬 방식 | 기본값 |
|---|---|---|
| ASC | 오름차순 (작은 것 → 큰 것) | ✅ 기본 |
| DESC | 내림차순 (큰 것 → 작은 것) | |

```sql
-- 이름 기준 오름차순 (기본값)
SELECT * FROM Customers
ORDER BY ContactName;

-- 여러 기준 동시 정렬: ProductID 오름차순, Quantity 내림차순
SELECT * FROM OrderDetails
ORDER BY ProductID ASC, Quantity DESC;
```

---

### 5️⃣ 원하는 개수만 가져오기 — LIMIT

언제 쓰나요? → 페이지네이션(목록 페이징), 상위 N개 데이터 확인할 때

```sql
-- 처음 10개만 가져오기
SELECT * FROM Customers LIMIT 10;

-- 0번째부터 10개 (위와 동일)
SELECT * FROM Customers LIMIT 0, 10;

-- 30번째 이후부터 10개 (31~40번째 행)
SELECT * FROM Customers LIMIT 30, 10;
```

> LIMIT {건너뛸 개수}, {가져올 개수} 형식으로 사용합니다.

---

### 6️⃣ 컬럼에 별명(alias) 붙이기 — AS

언제 쓰나요? → 결과물의 컬럼명을 읽기 쉽게 바꿀 때, 한글로 표시할 때

```sql
SELECT
  CustomerID AS ID,
  CustomerName AS NAME,
  Address AS ADDR
FROM Customers;

-- 한글 별명 사용 시 따옴표 필요
SELECT
  CustomerID AS '아이디',
  CustomerName AS '고객명',
  Address AS '주소'
FROM Customers;
```

---

### 🎯 모든 기능 한번에 — 종합 예시

```sql
SELECT
  CustomerID AS '아이디',
  CustomerName AS '고객명',
  City AS '도시',
  Country AS '국가'
FROM Customers
WHERE City = 'London' OR Country = 'Mexico'
ORDER BY CustomerName
LIMIT 0, 5;
```

> SELECT → FROM → WHERE → ORDER BY → LIMIT 순서로 작성합니다.

## LESSON 2 | ⚙️ 각종 연산자들

---

### 1️⃣ 사칙연산

언제 쓰나요? → 가격 계산, 수량 합산, 할인율 적용 등 숫자 연산이 필요할 때

| 연산자 | 의미 |
|---|---|
| `+`, `-`, `*`, `/` | 더하기, 빼기, 곱하기, 나누기 |
| `%`, `MOD` | 나머지 |

```sql
SELECT 5 - 2.5 AS DIFFERENCE;
SELECT 3 * (2 + 4) / 2;
SELECT 10 % 3;  -- 결과: 1

-- 실무 활용 예시
SELECT ProductName, Price / 2 AS HalfPrice
FROM Products;
```

⚠️ 헷갈리는 포인트

```sql
-- 문자열에 사칙연산 → 0으로 처리됨
SELECT 'ABC' + 3;   -- 결과: 3
SELECT 'ABC' * 3;   -- 결과: 0

-- 숫자로만 이루어진 문자열은 자동으로 숫자로 인식
SELECT '1' + '002' * 3;  -- 결과: 7
```

---

### 2️⃣ TRUE / FALSE 연산자

언제 쓰나요? → WHERE 조건 구성, 비교 결과를 컬럼 값으로 출력할 때

```sql
-- MySQL에서 TRUE=1, FALSE=0
SELECT TRUE, FALSE;        -- 1, 0
SELECT !TRUE, NOT FALSE;   -- 0, 1
```

| 연산자 | 의미 |
|---|---|
| `IS` | 양쪽이 모두 TRUE 또는 FALSE |
| `IS NOT` | 한쪽만 TRUE |
| `AND`, `&&` | 양쪽 모두 TRUE일 때만 TRUE |
| `OR`, `\|\|` | 한쪽만 TRUE여도 TRUE |

```sql
-- 복합 조건 예시
SELECT * FROM Orders
WHERE CustomerId = 15 AND EmployeeId = 4;

SELECT * FROM Products
WHERE ProductName = 'Tofu' OR CategoryId = 8;

-- 괄호로 우선순위 명확히 하기
SELECT * FROM OrderDetails
WHERE ProductId = 20
AND (OrderId = 10514 OR Quantity = 50);
```

---

### 3️⃣ 비교 연산자

| 연산자 | 의미 |
|---|---|
| `=` | 같음 |
| `!=`, `<>` | 다름 |
| `>`, `<` | 크다, 작다 |
| `>=`, `<=` | 크거나 같다, 작거나 같다 |

```sql
-- 비교 결과를 컬럼 값으로 출력하는 실무 패턴
SELECT
  ProductName,
  Price,
  Price > 20 AS EXPENSIVE   -- 비싸면 1, 아니면 0
FROM Products;
```

⚠️ MySQL 기본 문자열 비교는 대소문자를 구분하지 않아요

```sql
SELECT 'A' = 'a';  -- 결과: 1 (같다고 판단)
```

---

### 4️⃣ 범위 연산자 — BETWEEN

언제 쓰나요? → 특정 숫자 범위, 날짜 범위, 알파벳 범위 필터링할 때

| 연산자 | 의미 |
|---|---|
| `BETWEEN A AND B` | A 이상 B 이하 |
| `NOT BETWEEN A AND B` | 범위 밖 |

```sql
SELECT * FROM OrderDetails
WHERE ProductID BETWEEN 1 AND 4;

-- 문자열 범위도 가능 (알파벳 순)
SELECT * FROM Customers
WHERE CustomerName BETWEEN 'b' AND 'c';
```

---

### 5️⃣ 목록 연산자 — IN

언제 쓰나요? → 여러 값 중 하나에 해당하는 행을 뽑을 때 (OR 여러 개 대신 사용)

```sql
-- OR를 여러 번 쓰는 것보다 깔끔한 방법
SELECT * FROM Customers
WHERE City IN ('Torino', 'Paris', 'Portland', 'Madrid');

-- 포함되지 않는 경우
SELECT * FROM Customers
WHERE City NOT IN ('Torino', 'Paris');
```

---

### 6️⃣ 패턴 매칭 — LIKE

언제 쓰나요? → 특정 문자가 포함된 데이터, 특정 형식의 데이터를 찾을 때

| 와일드카드 | 의미 |
|---|---|
| `%` | 0개 이상의 임의 문자 |
| `_` | 정확히 1개의 임의 문자 |

```sql
-- % 예시: 'eco'가 포함된 Notes 찾기
SELECT * FROM Employees
WHERE Notes LIKE '%economics%';

-- _ 예시: '1025'로 시작하는 5자리 OrderID 찾기
SELECT * FROM OrderDetails
WHERE OrderID LIKE '1025_';
```

💡 LIKE 패턴 정리

| 패턴 | 의미 |
|---|---|
| `'H%'` | H로 시작하는 모든 문자열 |
| `'%O'` | O로 끝나는 모든 문자열 |
| `'%abc%'` | abc를 포함하는 모든 문자열 |
| `'H___O'` | H로 시작, O로 끝나는 5글자 |
| `'_____'` | 정확히 5글자 |

## 🗂️ 핵심 요약

### SELECT 구문 기본 순서

```sql
SELECT 컬럼명 AS 별명
FROM 테이블명
WHERE 조건
ORDER BY 컬럼명 ASC/DESC
LIMIT 건너뛸수, 가져올수;
```

### 연산자 한눈에 보기

| 분류 | 연산자 | 용도 |
|---|---|---|
| 사칙연산 | `+` `-` `*` `/` `%` | 숫자 계산 |
| 논리 | `AND` `OR` `NOT` `IS` `IS NOT` | 조건 결합 |
| 비교 | `=` `!=` `<>` `>` `<` `>=` `<=` | 값 비교 |
| 범위 | `BETWEEN A AND B` | 범위 필터 |
| 목록 | `IN (...)` `NOT IN (...)` | 여러 값 중 하나 |
| 패턴 | `LIKE '%'` `LIKE '_'` | 문자열 패턴 |

## 📝 복습 퀴즈

### Q1. Customers 테이블에서 CustomerName과 Country만 가져오는 쿼리로 올바른 것은?

A) `SELECT * FROM Customers;`
B) `SELECT CustomerName FROM Customers, Country;`
C) `SELECT CustomerName, Country FROM Customers;`
D) `SELECT Customers FROM CustomerName, Country;`
E) `SELECT (CustomerName, Country) FROM Customers;`

정답: C
해설: SELECT 뒤에 원하는 컬럼명을 쉼표로 구분해서 나열하고, FROM 뒤에 테이블명을 씁니다. 순서는 SELECT → FROM 입니다.

---

### Q2. Products 테이블에서 Price가 10 이상 50 이하인 상품을 가져오는 쿼리는?

A) `SELECT * FROM Products WHERE Price > 10 AND Price < 50;`
B) `SELECT * FROM Products WHERE Price BETWEEN 10 AND 50;`
C) `SELECT * FROM Products WHERE Price IN (10, 50);`
D) `SELECT * FROM Products WHERE Price LIKE '10%50';`

정답: B
해설: BETWEEN A AND B는 A 이상 B 이하를 의미하며, 경계값을 포함합니다. A번은 10 초과 50 미만이므로 경계값이 포함되지 않아 다릅니다.

---

### Q3. 다음 쿼리의 실행 결과로 올바른 것은?

```sql
SELECT 'ABC' + 3;
```

A) 'ABC3'
B) ERROR 발생
C) 3
D) 0
E) NULL

정답: C
해설: MySQL에서 문자열에 사칙연산을 적용하면 문자열은 0으로 인식됩니다. 따라서 0 + 3 = 3이 됩니다. 단, '1' + '2' 처럼 숫자로만 이루어진 문자열은 자동으로 숫자로 인식합니다.

---

### Q4. Customers 테이블에서 CustomerName이 'A'로 시작하는 데이터를 찾는 쿼리는?

A) `WHERE CustomerName = 'A%'`
B) `WHERE CustomerName LIKE 'A_'`
C) `WHERE CustomerName LIKE 'A%'`
D) `WHERE CustomerName IN ('A')`
E) `WHERE CustomerName BETWEEN 'A' AND 'A'`

정답: C
해설: LIKE 'A%'는 A로 시작하는 0개 이상의 문자를 가진 패턴을 의미합니다. `_`는 정확히 1개의 문자를 의미하므로 B는 A + 1글자인 2글자 데이터만 찾습니다.

---

### Q5. 아래 쿼리에서 21~30번째 행을 가져오려면 LIMIT에 어떤 값이 들어가야 하나요?

```sql
SELECT * FROM Customers LIMIT ?, ?;
```

A) `LIMIT 21, 10`
B) `LIMIT 20, 10`
C) `LIMIT 21, 30`
D) `LIMIT 10, 20`
E) `LIMIT 3, 10`

정답: B
해설: LIMIT의 첫 번째 값은 "건너뛸 개수"입니다. 21번째 행부터 시작하려면 앞의 20개를 건너뛰어야 하므로 LIMIT 20, 10이 됩니다. (행 번호는 0부터 시작하지 않고 1부터 시작한다는 점에 주의하세요)
