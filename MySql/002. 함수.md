## 1️⃣ 숫자 관련 함수

### 🔢 반올림/올림/내림

| 함수 | 설명 | 예시 결과 |
|------|------|-----------|
| `ROUND(x)` | 반올림 | `ROUND(0.5)` → 1 |
| `CEIL(x)` | 올림 (무조건 위로) | `CEIL(0.4)` → 1 |
| `FLOOR(x)` | 내림 (무조건 아래로) | `FLOOR(0.6)` → 0 |

```sql
-- 실무 패턴: 가격 데이터 정리 시 자주 사용
SELECT Price, ROUND(Price), CEIL(Price), FLOOR(Price)
FROM Products;
```

> ⚠️ 헷갈리는 포인트: `CEIL(0.1)`은 1, `FLOOR(0.9)`는 0 — 소수점이 있으면 무조건 올리거나 내립니다.

### 📐 기타 숫자 함수

| 함수 | 설명 | 언제 쓰나요? |
|------|------|-------------|
| `ABS(x)` | 절대값 | 차이값의 부호를 무시하고 싶을 때 |
| `GREATEST(a, b, ...)` | 가장 큰 값 | 여러 컬럼 중 최댓값 비교 |
| `LEAST(a, b, ...)` | 가장 작은 값 | 여러 컬럼 중 최솟값 비교 |
| `POW(a, b)` | a의 b제곱 | 지수 계산 |
| `SQRT(x)` | 제곱근 | 거리/면적 계산 |
| `TRUNCATE(N, n)` | N을 소수점 n자리까지 (버림) | 정밀도 제어 |

```sql
-- ABS 활용: 수량이 10에서 5 이내인 항목 찾기
SELECT * FROM OrderDetails
WHERE ABS(Quantity - 10) < 5;

-- TRUNCATE 활용: 소수점 2자리까지만 보기
SELECT TRUNCATE(1234.5678, 2);  -- → 1234.56

-- TRUNCATE에서 음수 사용 (자릿수 올림 버림)
SELECT TRUNCATE(1234.5678, -2); -- → 1200
```

> ⚠️ 헷갈리는 포인트: `TRUNCATE`는 **반올림 없이 무조건 버립니다.** `ROUND`와 혼동 주의!

### 📊 그룹 집계 함수 (GROUP 함수)

> 💡 이 함수들은 **여러 행을 하나의 값으로 요약**할 때 사용합니다.
> **NULL 값은 집계에서 제외**됩니다.

| 함수 | 설명 |
|------|------|
| `MAX(col)` | 가장 큰 값 |
| `MIN(col)` | 가장 작은 값 |
| `COUNT(col)` | 행 개수 (NULL 제외) |
| `SUM(col)` | 합계 |
| `AVG(col)` | 평균 |

```sql
-- 실무 패턴: 특정 범위의 통계 한 번에 보기
SELECT MAX(Quantity), MIN(Quantity), COUNT(Quantity), SUM(Quantity), AVG(Quantity)
FROM OrderDetails
WHERE OrderDetailID BETWEEN 20 AND 30;
```

## 2️⃣ 문자열 관련 함수

### 🔤 대소문자 변환

| 함수 | 설명 |
|------|------|
| `UPPER(s)` / `UCASE(s)` | 대문자로 변환 |
| `LOWER(s)` / `LCASE(s)` | 소문자로 변환 |

```sql
SELECT UPPER('hello'), LOWER('WORLD');
-- → HELLO, world
```

---

### 🔗 문자열 이어붙이기

| 함수 | 설명 |
|------|------|
| `CONCAT(a, b, ...)` | 그냥 이어붙임 |
| `CONCAT_WS(구분자, a, b, ...)` | 구분자로 이어붙임 |

```sql
-- CONCAT: 공백도 직접 넣어야 함
SELECT CONCAT('Hello', ' ', 'World');  -- → Hello World

-- CONCAT_WS: 구분자를 한 번만 지정하면 자동으로 사이에 넣어줌
SELECT CONCAT_WS('-', 2024, 1, 15);   -- → 2024-1-15
```

> ✅ 실무 패턴: 이름 합치기 `CONCAT_WS(' ', FirstName, LastName) AS FullName`

---

### ✂️ 문자열 자르기

| 함수 | 설명 |
|------|------|
| `SUBSTR(s, start)` | start 위치부터 끝까지 |
| `SUBSTR(s, start, length)` | start 위치부터 length만큼 |
| `LEFT(s, n)` | 왼쪽부터 n글자 |
| `RIGHT(s, n)` | 오른쪽부터 n글자 |

```sql
-- 날짜 문자열에서 연/월/일 추출 (실무에서 자주 등장!)
SELECT
  LEFT(OrderDate, 4)        AS Year,   -- → 1996
  SUBSTR(OrderDate, 6, 2)   AS Month,  -- → 07
  RIGHT(OrderDate, 2)       AS Day     -- → 04
FROM Orders;
```

> ⚠️ 헷갈리는 포인트: SQL에서 인덱스는 **1부터** 시작합니다. `SUBSTR('ABC', 1)` → 'ABC'

---

### 📏 문자열 길이

| 함수 | 설명 |
|------|------|
| `LENGTH(s)` | **바이트** 길이 (한글 1자 = 3바이트) |
| `CHAR_LENGTH(s)` | **문자** 길이 (한글 1자 = 1) |

```sql
SELECT LENGTH('안녕하세요');      -- → 15 (5글자 × 3바이트)
SELECT CHAR_LENGTH('안녕하세요'); -- → 5
```

> ⚠️ 한글 처리 시 반드시 `CHAR_LENGTH` 사용!

---

### 🧹 공백 제거 / 채우기

| 함수 | 설명 |
|------|------|
| `TRIM(s)` | 양쪽 공백 제거 |
| `LTRIM(s)` | 왼쪽 공백 제거 |
| `RTRIM(s)` | 오른쪽 공백 제거 |
| `LPAD(s, n, p)` | 왼쪽에 p를 채워서 n글자로 만들기 |
| `RPAD(s, n, p)` | 오른쪽에 p를 채워서 n글자로 만들기 |

```sql
-- TRIM: 검색 조건에서 실수로 공백이 들어간 경우 처리
SELECT * FROM Categories
WHERE CategoryName = TRIM(' Beverages ');

-- LPAD: ID를 자릿수 맞춰 표시 (001, 002, 003...)
SELECT LPAD(SupplierID, 5, 0) FROM Products;
```

---

### 🔧 문자열 변환/검색

| 함수 | 설명 |
|------|------|
| `REPLACE(s, a, b)` | s에서 a를 b로 교체 |
| `INSTR(s, sub)` | sub가 s에서 시작하는 위치 (없으면 0) |
| `CAST(a AS 타입)` | 타입 변환 |

```sql
-- REPLACE 활용
SELECT REPLACE('맥도날드 햄버거', '맥도날드', '버거킹');
-- → 버거킹 햄버거

-- INSTR 활용: 이름에서 공백 위치가 6 이내인 고객 찾기
SELECT * FROM Customers
WHERE INSTR(CustomerName, ' ') BETWEEN 1 AND 6;

-- CAST: 문자열 숫자 비교 시 형변환
SELECT CAST('01' AS DECIMAL) = CAST('1' AS DECIMAL); -- → 1(true)
```

|------|------|
| `CURDATE()` / `CURRENT_DATE` | 오늘 날짜 |

---

### 🗓️ 날짜 구성 요소 추출

| 함수 | 반환 값 |
|------|---------|
| `YEAR(d)` | 연도 (숫자) |
| `MONTH(d)` | 월 (숫자) |
| `MONTHNAME(d)` | 월 (영문, 예: January) |
| `DAY(d)` | 일 |
| `DAYNAME(d)` | 요일명 (예: Monday) |
| `WEEKDAY(d)` | 요일 숫자 (월요일 = 0) |
| `HOUR(d)` | 시 |
| `MINUTE(d)` | 분 |
| `SECOND(d)` | 초 |

```sql
-- 실무 패턴: 월요일 주문만 조회
SELECT * FROM Orders WHERE WEEKDAY(OrderDate) = 0;
```

> ⚠️ 헷갈리는 포인트: `WEEKDAY`는 월요일이 **0**, 일요일이 **6** — 일반적인 달력과 다릅니다!

---

### ➕➖ 날짜 연산

| 함수 | 설명 |
|------|------|
| `ADDDATE(d, INTERVAL n 단위)` | 날짜 더하기 |
| `SUBDATE(d, INTERVAL n 단위)` | 날짜 빼기 |
| `DATEDIFF(a, b)` | 두 날짜의 **일수** 차이 |
| `TIMEDIFF(a, b)` | 두 시간의 **시간** 차이 |
| `LAST_DAY(d)` | 해당 월의 마지막 날 |

```sql
-- ADDDATE: 1년 후, 3주 전 계산
SELECT ADDDATE('2024-01-01', INTERVAL 1 YEAR);   -- → 2025-01-01
SELECT ADDDATE('2024-01-01', INTERVAL -3 WEEK);  -- → 2023-12-11

-- DATEDIFF: 주문일로부터 며칠 지났는지
SELECT OrderDate, DATEDIFF(NOW(), OrderDate) AS DaysAgo FROM Orders;

-- LAST_DAY: 이번 달 며칠 남았는지
SELECT DATEDIFF(LAST_DAY(NOW()), NOW()) AS DaysLeft;
```

---

### 🎨 날짜 포맷 변환

```sql
-- DATE_FORMAT: 원하는 형식으로 출력
SELECT DATE_FORMAT(NOW(), '%Y년 %m월 %d일');   -- → 2024년 01월 15일
SELECT DATE_FORMAT(NOW(), '%Y-%m-%d %H:%i:%s'); -- → 2024-01-15 13:30:00

-- STR_TO_DATE: 문자열을 날짜로 변환 (DATEDIFF 등과 함께 활용)
SELECT STR_TO_DATE('2024-06-04 07:48:52', '%Y-%m-%d %T');
```

| 포맷 기호 | 의미 |
|-----------|------|
| `%Y` | 연도 4자리 |
| `%m` | 월 2자리 |
| `%d` | 일 2자리 |
| `%H` | 시 (24시간) |
| `%h` | 시 (12시간) |
| `%i` | 분 |
| `%s` | 초 |
| `%p` | AM/PM |

## 4️⃣ 기타 유용한 함수

### 🔀 조건 처리

```sql
-- IF: 단순 조건
SELECT IF(Price > 30, 'Expensive', 'Cheap') FROM Products;

-- CASE: 복잡한 조건 (여러 분기)
SELECT Price,
  CASE
    WHEN Price < 20 THEN '저가'
    WHEN Price BETWEEN 20 AND 30 THEN '일반'
    ELSE '고가'
  END AS PriceRange
FROM Products;

-- IFNULL: NULL 값 대체
SELECT IFNULL(ContactName, '정보 없음') FROM Customers;
```

> ✅ 실무 패턴: 등급 분류, 상태 표시 등에서 `CASE WHEN`을 아주 많이 씁니다.

## 5️⃣ GROUP BY / HAVING / DISTINCT

### 📦 GROUP BY

> 특정 컬럼 기준으로 **행을 묶어** 집계합니다.

```sql
-- 나라별 고객 수
SELECT Country, COUNT(*) FROM Customers GROUP BY Country;

-- 여러 컬럼 기준 그룹화
SELECT Country, City FROM Customers GROUP BY Country, City;
```

**WITH ROLLUP** - 전체 합계 행 추가 (ORDER BY와 함께 사용 불가)

```sql
SELECT Country, COUNT(*) FROM Suppliers
GROUP BY Country WITH ROLLUP;
```

---

### 🔍 HAVING vs WHERE

| 구분 | WHERE | HAVING |
|------|-------|--------|
| 적용 시점 | 그룹화 **전** | 그룹화 **후** |
| 대상 | 개별 행 | 집계된 그룹 |
| 집계함수 사용 | ❌ 불가 | ✅ 가능 |

```sql
-- WHERE + HAVING 함께 사용하는 실무 패턴
SELECT COUNT(*) AS Count, OrderDate
FROM Orders
WHERE OrderDate > DATE('1996-12-31')  -- 먼저 개별 행 필터링
GROUP BY OrderDate
HAVING Count > 2;                      -- 그룹화 후 조건 필터링
```

---

### 🎯 DISTINCT

> 중복 제거. GROUP BY보다 빠르지만 **집계함수 사용 불가** (단독으로는).

```sql
-- 중복 없이 나라 목록만
SELECT DISTINCT Country FROM Customers ORDER BY Country;

-- GROUP BY와 DISTINCT 조합: 나라별 도시 수
SELECT Country, COUNT(DISTINCT City) FROM Customers GROUP BY Country;
```

> ⚠️ `SELECT COUNT DISTINCT` 형태는 오류! → `COUNT(DISTINCT col)` 로 써야 합니다.

## 📌 핵심 요약본

| 분류 | 핵심 포인트 |
|------|------------|
| 반올림 | `ROUND` 반올림 / `CEIL` 올림 / `FLOOR` 내림 / `TRUNCATE` 버림 |
| 문자열 | `CONCAT_WS`로 구분자 이어붙이기 / `SUBSTR`은 인덱스 1부터 |
| 한글 길이 | `LENGTH` = 바이트, `CHAR_LENGTH` = 실제 글자 수 |
| 날짜 요일 | `WEEKDAY`는 월=0, 일=6 |
| 조건 | 단순 분기 → `IF`, 다중 분기 → `CASE WHEN` |
| NULL 처리 | `IFNULL(컬럼, 대체값)` / 그룹 함수는 NULL 자동 제외 |
| 그룹 필터 | 행 필터 → `WHERE`, 그룹 필터 → `HAVING` |
| 중복 제거 | `DISTINCT` 빠름 / 집계 포함 시 `GROUP BY` |

### Q1. 다음 중 `CEIL(3.1)`의 결과로 옳은 것은?

1. 3
2. 3.1
3. 4
4. 3.0
5. 오류 발생

정답: 3번 (4)

해설: `CEIL`은 올림 함수입니다. 소수점이 조금이라도 있으면 무조건 위 정수로 올립니다. `CEIL(3.1)` → 4, `CEIL(3.9)` → 4, `CEIL(3.0)` → 3

---

### Q2. 한글 문자열 `'안녕하세요'`의 `CHAR_LENGTH`와 `LENGTH`의 값이 올바르게 짝지어진 것은?

1. `CHAR_LENGTH` = 15, `LENGTH` = 5
2. `CHAR_LENGTH` = 5, `LENGTH` = 15
3. `CHAR_LENGTH` = 5, `LENGTH` = 5
4. `CHAR_LENGTH` = 15, `LENGTH` = 15
5. `CHAR_LENGTH` = 10, `LENGTH` = 5

정답: 2번

해설: `CHAR_LENGTH`는 실제 글자 수(5), `LENGTH`는 바이트 수(한글 1자 = 3바이트 → 5 × 3 = 15)를 반환합니다.

---

### Q3. `WEEKDAY('2024-01-01')`이 0을 반환한다면, 2024년 1월 1일은 무슨 요일인가?

1. 일요일
2. 토요일
3. 월요일
4. 화요일
5. 수요일

정답: 3번 (월요일)

해설: `WEEKDAY` 함수는 월요일 = 0, 화요일 = 1, ..., 일요일 = 6 순서입니다. 일반적인 달력(일요일 = 1)과 다르므로 주의가 필요합니다.

---

### Q4. 다음 중 `WHERE`와 `HAVING`의 차이를 올바르게 설명한 것은?

1. `WHERE`는 그룹 후, `HAVING`은 그룹 전에 사용된다.
2. `WHERE`와 `HAVING`은 동일한 기능이며 같은 자리에 쓸 수 있다.
3. `WHERE`는 개별 행 필터링, `HAVING`은 그룹화된 데이터 필터링에 사용된다.
4. `HAVING`은 `GROUP BY` 없이도 항상 사용 가능하다.
5. `WHERE`에서는 집계 함수를 자유롭게 사용할 수 있다.

정답: 3번

해설: `WHERE`는 `GROUP BY` 전에 각 행을 필터링하고, `HAVING`은 `GROUP BY` 후 집계된 그룹을 필터링합니다. `WHERE`에서는 `SUM()`, `COUNT()` 같은 집계 함수를 사용할 수 없습니다.

### Q5. 다음 SQL의 실행 결과는?

```sql
SELECT CONCAT_WS('-', 2024, 'Jan', 15);
```

1. `2024Jan15`
2. `2024-Jan-15`
3. `-2024-Jan-15-`
4. 오류 발생
5. `2024, Jan, 15`

정답: 2번 (`2024-Jan-15`)

해설: `CONCAT_WS(구분자, 값1, 값2, ...)`는 첫 번째 인자를 구분자로 하여 나머지 값들 사이에 자동으로 삽입합니다. 앞뒤에는 구분자가 붙지 않습니다.
