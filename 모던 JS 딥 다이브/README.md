## 💡 핵심 개념 정리

### 변수 (004장)
```javascript
// var: 함수 스코프, 중복 선언 가능, 호이스팅
var x = 1;
var x = 2;  // ✓ 가능

// let/const: 블록 스코프, 중복 선언 불가, 재할당 제어
let y = 1;
let y = 2;  // ✗ SyntaxError

const z = 1;
z = 2;      // ✗ TypeError
```

### 표현식과 문 (005장)
```javascript
// 표현식: 값으로 평가되는 것
1 + 2           // 표현식 (값: 3)
'hello'         // 표현식 (값: 'hello')
x = 1 + 2       // 표현식 (값: 3)

// 문: 프로그램을 구성하는 기본 단위
var x;          // 변수 선언 문
x = 5;          // 표현식 문
if (x > 3) {}   // 제어 문
```

## 📚 학습 방법

1. **장별 순차 학습**: 각 장을 정해진 순서로 학습
2. **개념 정리**: 각 장 학습 후 핵심 개념을 요약 정리
3. **코드 실습**: 도서의 예제를 직접 작성하고 실행
4. **심화 이해**: 다른 자료(MDN, 블로그)로 보완
5. **복습 계획**:
   - 1주일 후: 어려웠던 챕터 복습
   - 1개월 후: 전체 내용 통합 복습
