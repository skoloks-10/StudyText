## 📚 학습 로드맵

### 🔷 Be동사와 기본 시제 (001~008강)

#### **001. Be동사**
- Be동사의 의미 (상태, 위치, 특성)
- 주어에 따른 형태 변화 (am, is, are)
- 긍정문, 부정문, 의문문 기본 구조

#### **002. 진행형**
- 현재 진행 (~ing 형태)
- 과거 진행형
- 진행형의 활용

#### **003. 현재 시제**
- 일반 현재 (현재의 사실, 습관)
- 주어에 따른 동사 변화 (3인칭 단수 -s)
- 현재 시제 사용 상황

#### **004. 과거 시제**
- 규칙 동사 (과거형 -ed)
- 불규칙 동사
- 과거 시제의 활용

#### **005. 과거진행형 & used to**
- 과거진행형 (과거의 진행 상황)
- used to + 동사 (과거의 반복된 행동)
- 시간 표현과 함께 사용

#### **006. 현재완료**
- Have/has + 과거분사
- 현재와 연결된 과거 경험
- 최근 일어난 사건

#### **007. 현재완료 2**
- 현재완료 지속용법 (지금까지의 기간)
- for와 since의 차이
- 현재완료의 심화 개념

#### **008. 미래시제**
- will을 이용한 미래 표현
- be going to의 미래 의도
- 미래 시제 사용 구분

### 🔷 조동사와 문장 구조 (009~013강)

#### **009. 조동사 can, could, might, may**
- can: 능력, 가능성, 허가
- could: can의 과거형, 정중한 표현
- might/may: 가능성, 추측, 허가

#### **010. 조동사 must, have to, should, would**
- must: 강한 의무, 필요, 추측
- have to: 외적 의무
- should: 조언, 의무, 예상
- would: 습관, 조건부

#### **011. 수동태**
- 수동태 구조 (be + 과거분사)
- 능동태와 수동태 변환
- 수동태 활용

#### **012. 의문문 1**
- Yes/No 질문 (조동사 앞으로 도치)
- 의문문의 어순
- 짧은 대답 형태

#### **013. 의문문 2**
- Wh-질문 (Where, What, Who, When, Why, How)
- 복합 의문문
- 간접 의문문

### 🔷 비동사와 동명사 (014~016강)

#### **014. 동명사와 to부정사**
- 동명사 (verb+ing의 명사 형태)
- to부정사 (to+동사 기본형)
- 둘의 차이와 사용 구분

#### **015. to부정사**
- to부정사의 다양한 역할 (명사, 형용사, 부사)
- 동사의 목적어로서 to부정사
- 형용사를 수식하는 to부정사

#### **016. 명사와 관사**
- 가산명사와 불가산명사
- 관사 a/an의 사용 (부정관사)
- 관사 the의 사용 (정관사)
- 관사 생략 경우

## 💡 주요 문법 정리

### Be동사와 일반동사
```
Be동사: I am, You are, He/She/It is, We/They are
일반동사: I/You/We/They 동사, He/She/It 동사+s
```

### 시제 변화 패턴
```
현재: V / V+s
과거: V+ed (불규칙: 별도 형태)
현재완료: have/has + V+ed
미래: will + V
```

### 조동사 + 동사
```
can play, must go, should study, would like
```

### 의문문 만들기
```
Do you like coffee?     (일반동사 의문)
Are you from Korea?     (Be동사 의문)
Where do you live?      (Wh-의문)
What time is it?        (Wh-의문)
```

## 💬 활용 방법

### 일상 회화
- Be동사와 일반동사 조합: "I am a student." / "I study English."
- 현재 진행형: "What are you doing?" / "I am reading a book."
- 과거 시제: "Did you go to the market yesterday?"

### 이메일 및 작문
- 현재완료: "I have finished the project."
- 수동태: "The report was completed by the team."
- to부정사: "I would like to meet you tomorrow."

### 듣기 및 읽기
- 조동사의 이해: "You should arrive early." (조언)
- 의문문 인식: "Could you help me?" (정중한 요청)
- 관사 구분: "I saw a dog." vs "The dog is big."
