# 🖥️ 컴퓨터 구조 학습 기록

> 하드웨어 아키텍처, CPU, 메모리, 운영체제를 아우르는 컴퓨터 시스템의 기초를 학습합니다.

## 📖 학습 로드맵

### 🔢 데이터 표현 기초 (001~003강)
- **001. 컴퓨터구조 시작하기** - 컴퓨터 구조 학습 목표, 핵심 구성 요소, 메인보드와 시스템 버스
- **002. 0과 1로 숫자를 표현하는 방법** - 진법 (2진, 8진, 16진), 음수 표현, 실수 표현 (부동소수점)
- **003. 0과 1로 문자를 표현하는 방법** - 인코딩, ASCII, Unicode, UTF-8

### 💾 명령어와 CPU 기초 (004~006강)
- **004. 소스코드와 명령어, 명령어의 구조** - 고급언어 → 저급언어, 명령어 형식, Opcode와 Operand
- **005. 주소지정 방식과 CPU 구조** - 주소지정 방식 (즉시, 직접, 간접 등), CPU 내부 구조 (레지스터, ALU, 제어부)
- **006. CPU 작동 원리** - Fetch-Decode-Execute-Writeback 사이클, 클럭과 사이클

### 🧠 CPU와 메모리 시스템 (007~008강)
- **007. CPU 구조와 메모리 시스템** - 멀티코어, 캐시 메모리 (L1, L2, L3), 메모리 계층 구조
- **008. 보조기억장치** - HDD, SSD, RAID 기술

### 🔌 입출력과 저장 시스템 (009강)
- **009. RAID와 입출력 시스템** - RAID 레벨 (0, 1, 5, 6), 입출력 방식 (폴링, 인터럽트, DMA)

### 🎯 운영체제 기초 (010강)
- **010. 운영체제** - 운영체제의 역할, 커널 개념, 프로세스와 스레드 개요

### 📊 프로세스 관리 (011강)
- **011. 프로세스와 메모리 관리** - 프로세스 메모리 구조 (Code, Data, Heap, Stack), 컨텍스트 스위칭

### 🔄 스레드와 스케줄링 (012~013강)
- **012. 스레드와 스케줄링** - 멀티스레딩, 스레드 풀, CPU 스케줄링 알고리즘 소개
- **013. 스케줄링 알고리즘, 동기화** - FCFS, SJF, Round Robin, 임계 구간, 뮤텍스, 세마포어

### 🔒 동기화와 교착상태 (014~015강)
- **014. 동기화 기법, 교착상태** - Monitor, 모니터, 교착상태 정의 및 필요조건
- **015. 교착 상태와 메모리 할당** - 교착상태 회피/감지/복구, 메모리 할당 전략 (고정, 동적)

### 💾 가상메모리 (016~017강)
- **016. 페이징과 가상메모리** - 페이징, TLB, 가상 메모리의 이점
- **017. 페이지 교체와 프레임 할당** - 페이지 교체 알고리즘 (FIFO, LRU, LFU), 프레임 할당 전략

### 📁 파일 시스템 (018강)
- **018. 파일시스템** - 파일 시스템 구조, 디렉토리, 파일 접근 방식 (순차, 직접, 인덱스)

## 💡 중요 개념 정리

### 1. 프로세스 메모리 구조
```
┌─────────────────────┐
│   Code (텍스트)      │  → 프로그램 명령어
├─────────────────────┤
│   Data (초기화된 데이터) │  → 전역변수
├─────────────────────┤
│   BSS (미초기화 데이터) │  → 정적변수
├─────────────────────┤
│   Heap (동적 할당)    │  ↓ 위로 증가
├─────────────────────┤
│                      │
│    (여유 공간)        │
│                      │
├─────────────────────┤
│   Stack (함수 호출)   │  ↑ 아래로 증가
└─────────────────────┘
```

### 2. CPU 스케줄링 알고리즘 비교
| 알고리즘 | 대기시간 | 응답시간 | 맥락교환 | 기아 |
|---------|---------|---------|---------|------|
| FCFS | 나쁨 | 나쁨 | 적음 | 없음 |
| SJF | 좋음 | 좋음 | 많음 | 있음 |
| Round Robin | 보통 | 좋음 | 많음 | 없음 |
| Priority | 가변 | 가변 | 많음 | 있음 |

### 3. 페이지 교체 알고리즘
- **FIFO**: 먼저 들어온 페이지 제거 (구현 간단, 성능 낮음)
- **LRU**: 가장 오래 사용되지 않은 페이지 제거 (성능 좋음, 구현 복잡)
- **LFU**: 가장 적게 사용된 페이지 제거 (공정성 우수)

## 🛠️ 실습 방법

### 개념 시각화
```
이진법 변환 예시:
10진수 10 → 이진법 1010

명령어 구조:
Opcode (연산)  │ Operand (피연산자)
 10010       │  01100 (메모리 주소)

캐시 효율성:
L1 캐시 (4KB, 4 사이클)
  └→ L2 캐시 (256KB, 12 사이클)
      └→ L3 캐시 (8MB, 40 사이클)
          └→ RAM (8GB, 200+ 사이클)
```

### 학습 방법
1. **개념 이해**: 각 강의 읽고 핵심 개념 정리
2. **그림 그리기**: 프로세스 메모리, 캐시 계층, 교착상태 상황 직접 그려보기
3. **복습 계획**:
   - 1주일 후: 어려웠던 알고리즘 복습 (스케줄링, 페이지 교체)
   - 1달 후: 전체 컴퓨터 구조 체계 정리
