# 보조기억장치 완벽 정리 📚

## 주제목: 다양한 보조기억장치

### 중제목 1: 하드 디스크 (HDD)

### 소제목 1-1: 하드 디스크의 기본 개념

**하드 디스크란?**

- HDD(Hard Disk Drive)는 가장 먼저 발명된 보조기억장치입니다
- 자기적 방식으로 데이터를 저장하는 **자기 디스크(Magnetic disk)**입니다
- 하드 디스크는 **마그네틱 디스크**의 일종으로 자기로 정보하여 읽습니다
- 대용량 저장 장치로 필요한 시점에나 시점에서 사후 삭제 없이는 데이터를 차지

**구성 요소:**

- 플래터(Platter): 데이터가 실제로 저장되는 원판
- 헤드(Head): 데이터를 읽고 쓰는 부품
- 스핀들: 플래터를 회전시키는 축
- 디스크 암: 헤드를 이동시키는 장치

**하드 디스크의 동작 원리:**

- CD나 LP와 유사한 방식으로 작동합니다
- 플래터가 회전하면서 헤드가 데이터를 읽고 씁니다
- 우리가 아는 CD와 LP가 변호를 갖는 것처럼 하드 디스크도 유사한 구조입니다

### 소제목 1-2: 하드 디스크의 구조

**플래터의 데이터 저장 구조:**

하드 디스크에서 실제로 데이터를 저장하는 플래터는 여러 단위로 구분됩니다.

**1. 트랙(Track)**

- 플래터를 여러 동심원으로 나눈 각각의 원
- 플래터는 트랙과 섹터라는 단위로 데이터를 저장합니다

**2. 섹터(Sector)**

- 트랙을 여러 조각으로 나눈 것
- **하드 디스크의 가장 작은 저장 단위**
- 하드 디스크에서 데이터를 읽고 쓰는 기본 단위

**3. 실린더(Cylinder)**

- 여러 겹의 플래터에서 같은 트랙의 모음
- 여러 플래터를 쌓아 놓았을 때 같은 위치의 트랙들을 묶은 것

| 구조 단위 | 설명 | 특징 |
| --- | --- | --- |
| **트랙(Track)** | 플래터의 동심원 | 하나의 둥근 원 형태 |
| **섹터(Sector)** | 트랙을 나눈 조각 | 하드 디스크의 가장 작은 저장 단위 |
| **실린더(Cylinder)** | 여러 플래터의 같은 위치 트랙 | 수직으로 쌓인 트랙의 모음 |

### 소제목 1-3: 하드 디스크의 데이터 접근

**데이터를 읽는 과정:**

1. 플래터가 데이터를 읽고 쓰는 구성
2. 그렇게 이 플래터를 트랙과 섹터 단위로 데이터를 저장합니다
3. 이때 여러 조각 모여 있는 트랙들을 실린더라고 합니다

**하드 디스크의 접근 시간 구성:**

하드 디스크가 데이터를 읽는 데 걸리는 시간은 세 가지로 구성됩니다:

**1. 탐색 시간(Seek Time)**

- 접근하려는 데이터가 저장된 트랙까지 헤드를 이동시키는 시간
- 헤드를 원하는 트랙으로 이동하는 시간

**2. 회전 지연(Rotational Latency)**

- 헤드가 있는 곳으로 플래터를 회전시키는 시간
- 플래터가 회전하여 목표 섹터가 헤드 아래로 올 때까지의 시간

**3. 전송 시간(Transfer Time)**

- 하드 디스크와 컴퓨터 간에 데이터를 전송하는 시간

| 시간 종류 | 설명 | 상대적 소요 시간 |
| --- | --- | --- |
| **탐색 시간** | 헤드를 목표 트랙으로 이동 | 가장 김 |
| **회전 지연** | 플래터 회전으로 섹터 찾기 | 중간 |
| **전송 시간** | 데이터를 컴퓨터로 전송 | 가장 짧음 |

**실제 접근 시간 데이터:**

| 작업 | 소요 시간 |
| --- | --- |
| L1 캐시 최초 시간 | 0.5ns |
| L2 캐시 최초 시간 | 5ns |
| 내부의 최초 시간 | 7ns |
| 메모리에서 1MB를 순차적으로 읽는 시간 | 250,000ns |
| (하드) 디스크 탐색 시간 | 10,000,000ns |
| (하드) 디스크에서 1MB를 순차적으로 읽는 시간 | 30,000,000ns |
| 한 곳의 패킷(미국↔유럽)이 대륙횡단기기 왕복하는 시간 | 150,000,000ns |

> 💡 참고: 메모리와 하드 디스크의 속도 차이가 매우 큽니다. 그래서 빠른 메모리로 느리 하드 디스크에서 데이터를 불러와 임시 사용은 매우 중요합니다.
> 

### 소제목 1-4: RPM과 하드 디스크 성능

**RPM(Revolution Per Minute)이란?**

- 분당 회전수를 의미합니다
- 플래터를 빠르게 돌리는 정도를 나타냅니다

**일반적인 RPM 수치:**

- 5,400 RPM
- 7,200 RPM
- 15,000 RPM (고성능)

> ⚠️ 주의: RPM이 높다고 해서 무조건 빠른 하드 디스크는 아닙니다. 하드 디스크의 성능은 여러 복합적 요인에 좌우됩니다.
> 

### 소제목 1-5: 하드 디스크의 종류

**1. 단일 헤드 디스크 (Single-head disk)**

- 플래터의 한 면만 읽을 수 있는 하드 디스크
- 일반적으로 사용되는 형태

**2. 다중 헤드 디스크 (Multiple-head disk)**

- 여러 개의 헤드가 있는 하드 디스크
- 고성능이지만 비용이 높아 일반 시장에 많이 보급되지 않음

---

### 중제목 2: 플래시 메모리 (Flash Memory)

### 소제목 2-1: 플래시 메모리의 기본 개념

**플래시 메모리란?**

- 하드 디스크 다음으로 널리 사용되는 보조기억장치입니다
- **전기적 방식**으로 데이터를 저장합니다
- 반도체 기반의 저장 장치입니다

**플래시 메모리의 대표적 사례:**

- USB 메모리
- SD 카드
- SSD (Solid State Drive)

**플래시 메모리 vs 하드 디스크:**

| 특징 | 하드 디스크 | 플래시 메모리 |
| --- | --- | --- |
| **저장 방식** | 자기적 방식 | 전기적 방식 |
| **물리적 구조** | 플래터, 헤드 등 기계 부품 | 반도체 칩 (기계 부품 없음) |
| **속도** | 상대적으로 느림 | 빠름 |
| **내구성** | 충격에 약함 | 충격에 강함 |
| **소음** | 있음 | 없음 |
| **전력 소비** | 높음 | 낮음 |

### 소제목 2-2: 플래시 메모리의 구조

**플래시 메모리의 저장 단위:**

플래시 메모리는 셀(Cell) → 페이지(Page) → 블록(Block)의 계층 구조로 이루어져 있습니다.

**1. 셀(Cell)**

- 플래시 메모리에서 데이터를 저장하는 **가장 작은 단위**
- 한 셀에 몇 비트를 저장하느냐에 따라 플래시 메모리의 종류가 나뉩니다

**2. 페이지(Page)**

- 셀이 모여 구성된 단위
- 데이터를 읽고 쓰는 단위

**3. 블록(Block)**

- 페이지가 모여 구성된 단위
- 데이터를 삭제하는 단위

```
셀 (Cell)
  ↓ (여러 개 모임)
페이지 (Page)
  ↓ (여러 개 모임)
블록 (Block)

```

**중요한 특징:**

- **읽기/쓰기는 페이지 단위**로 이루어집니다
- **삭제는 블록 단위**로 이루어집니다

| 단위 | 역할 | 특징 |
| --- | --- | --- |
| **셀(Cell)** | 데이터 저장의 최소 단위 | 1~3bit 저장 가능 |
| **페이지(Page)** | 읽기/쓰기 단위 | 여러 셀의 모음 |
| **블록(Block)** | 삭제 단위 | 여러 페이지의 모음 |

### 소제목 2-3: 플래시 메모리의 종류 (SLC, MLC, TLC)

플래시 메모리는 한 셀에 몇 비트를 저장하느냐에 따라 세 가지 타입으로 나뉩니다.

**SLC (Single Level Cell) 타입:**

**특징:**

- 한 셀에 **1bit** 저장 (0 또는 1)
- 가장 빠른 속도
- 가장 긴 수명
- 가장 높은 비용
- 용량이 적음

**장점:**

- 한 셀에 한 비트만 저장하므로 속도가 매우 빠름
- 내구성이 뛰어남
- 신뢰성이 높음

**단점:**

- 가격이 매우 비쌈
- 저장 용량이 작음

**사용 사례:**

- 고성능이 필요한 기업용 서버
- 데이터베이스 서버
- 고속 처리가 필요한 전문 작업

---

**MLC (Multi Level Cell) 타입:**

**특징:**

- 한 셀에 **2bit** 저장 (00, 01, 10, 11 네 가지 상태)
- 속도는 SLC보다 느림
- 수명은 SLC보다 짧음
- 가격은 SLC보다 저렴
- 용량은 SLC보다 많음

**장점:**

- SLC보다 저렴한 가격
- SLC의 2배 용량
- 일반 사용에 충분한 성능

**단점:**

- SLC보다 느린 속도
- SLC보다 짧은 수명
- 두 비트를 구분해야 하므로 복잡함

**사용 사례:**

- 일반 소비자용 SSD
- 고성능이 필요한 개인용 컴퓨터
- 중급 이상의 제품

---

**TLC (Triple Level Cell) 타입:**

**특징:**

- 한 셀에 **3bit** 저장 (8가지 상태 표현)
- 가장 느린 속도
- 가장 짧은 수명
- 가장 저렴한 비용
- 가장 큰 용량

**장점:**

- 가장 저렴한 가격
- 대용량 구현이 쉬움
- 일반 사용자에게 적합

**단점:**

- 속도가 가장 느림
- 수명이 가장 짧음
- 세 비트를 구분하므로 가장 복잡함

**사용 사례:**

- 저가형 SSD
- 일반 소비자용 제품
- 대용량 저장이 필요한 경우

**플래시 메모리 타입 비교표:**

| 구분 | SLC | MLC | TLC |
| --- | --- | --- | --- |
| **셀당 저장 비트** | 1bit | 2bit | 3bit |
| **속도** | 빠름 ⚡⚡⚡ | 보통 ⚡⚡ | 느림 ⚡ |
| **수명** | 길다 | 보통 | 짧다 |
| **용량** | 작음 | 보통 | 큼 |
| **가격** | 비쌈 💰💰💰 | 보통 💰💰 | 저렴 💰 |
| **용도** | 기업용, 서버 | 중급 제품 | 일반 소비자용 |

> 💡 핵심 원리: 한 셀에 더 많은 비트를 저장할수록 용량은 늘어나지만, 각 상태를 정확하게 구분해야 하므로 속도와 수명이 떨어집니다.
> 

### 소제목 2-4: 플래시 메모리의 수명 문제

**플래시 메모리 수명이 왜 짧은가?**

플래시 메모리는 반도체 특성상 데이터를 삭제할 때마다 셀이 조금씩 손상됩니다.

- 이러한 손상이 축적되면 해당 셀을 사용할 수 없게 됩니다
- USB 메모리, SSD, SD 카드 등 플래시 메모리를 이용한 보조기억장치가 오래 사용하면 문제가 생기는 이유입니다

**플래시 메모리의 삭제/쓰기 특성:**

- 플래시 메모리는 ROM에도 사용되고, 우리가 일상적으로 접하는 거의 모든 전자 제품 안에 플래시 메모리가 내장되어 있습니다
- 추가 역할 중 하나인 ROM에도 사용되고 일상적으로 접하는 거의 모든 전자 제품에 들어갑니다

### 소제목 2-5: 플래시 메모리의 페이지 상태

플래시 메모리에서 페이지는 세 가지 상태를 가질 수 있습니다:

**1. Free 상태**

- 어떠한 데이터도 저장하고 있지 않아 새로운 데이터를 저장할 수 있는 상태
- 깨끗한 빈 페이지

**2. Valid 상태**

- 이미 유효한 데이터를 저장하고 있는 상태
- 사용 중인 페이지

**3. Invalid 상태**

- 쓰레기값이라 부르는 유효하지 않은 데이터를 저장하고 있는 상태
- 삭제해야 할 페이지

**페이지 상태 전환:**

```
Free (빈 상태)
  ↓ 데이터 쓰기
Valid (유효한 상태)
  ↓ 데이터 무효화
Invalid (무효한 상태)
  ↓ 블록 삭제
Free (빈 상태)

```

> ⚠️ 중요: 플래시 메모리는 덮어쓰기가 불가능합니다. 데이터를 수정하려면 Valid → Invalid로 만든 후, 전체 블록을 삭제해야 합니다.
> 

### 소제목 2-6: 가비지 컬렉션 (Garbage Collection)

**가비지 컬렉션이란?**

- Invalid 상태의 페이지들을 정리하는 작업
- 사용하지 않는 공간을 확보하여 효율성을 높이는 기능

**가비지 컬렉션의 과정:**

1. **유효한 페이지만 복사**
    - Invalid 페이지를 제외하고 Valid 페이지만 새로운 블록으로 복사
2. **기존 블록 삭제**
    - 유효한 페이지를 복사한 후, 기존 블록 전체를 삭제

**예시:**

```
블록 X (삭제 전)          블록 Y (복사 후)
┌──────────┐           ┌──────────┐
│ A (Valid)│   →       │    B     │
├──────────┤           ├──────────┤
│ B (Valid)│   →       │    C     │
├──────────┤           ├──────────┤
│ C (Valid)│   →       │  A'      │
├──────────┤           └──────────┘
│ A'(Invalid)│ (삭제)
└──────────┘
블록 X 전체 삭제

```

**가비지 컬렉션의 특징:**

- 유효한 페이지들만 새로운 블록으로 복사
- 기존 블록을 삭제하여 공간 확보
- SSD의 성능을 유지하는 중요한 기능

> 💡 참고: 가비지 컬렉션은 유효한 페이지만 새로운 블록으로 복사한 후 기존 블록을 삭제하는 기능입니다. 이를 통해 플래시 메모리의 공간을 효율적으로 관리합니다.

## 핵심 요약본 ⭐

### 하드 디스크 (HDD) 핵심 정리

**기본 개념:**

- 자기적 방식으로 데이터 저장
- 플래터, 헤드, 스핀들로 구성
- CD/LP와 유사한 회전 방식

**구조:**

- 트랙: 동심원 형태의 원
- 섹터: 하드 디스크의 최소 저장 단위
- 실린더: 여러 플래터의 같은 위치 트랙

**접근 시간:**

- 탐색 시간: 헤드 이동
- 회전 지연: 플래터 회전
- 전송 시간: 데이터 전송

**성능:**

- RPM이 높을수록 빠르지만 절대적 지표는 아님
- 단일/다중 헤드 디스크로 구분

### 플래시 메모리 핵심 정리

**기본 개념:**

- 전기적 방식으로 데이터 저장
- USB, SD카드, SSD에 사용
- 하드 디스크보다 빠르고 충격에 강함

**구조:**

- 셀 → 페이지 → 블록
- 읽기/쓰기: 페이지 단위
- 삭제: 블록 단위

**종류:**

- SLC: 1bit/셀, 빠름, 비쌈, 기업용
- MLC: 2bit/셀, 중간, 일반용
- TLC: 3bit/셀, 느림, 저렴, 대용량

**특징:**

- 페이지 상태: Free, Valid, Invalid
- 가비지 컬렉션으로 공간 관리
- 삭제 횟수 제한으로 수명 있음

## 복습용 퀴즈 📝

### 퀴즈 1: 하드 디스크의 최소 저장 단위

**문제:** 하드 디스크에서 데이터를 읽고 쓰는 가장 작은 저장 단위는 무엇입니까?

① 트랙(Track)
② 섹터(Sector)
③ 실린더(Cylinder)
④ 플래터(Platter)

**정답:** ② 섹터(Sector)

**해설:** 섹터는 하드 디스크의 가장 작은 저장 단위입니다. 트랙을 여러 조각으로 나눈 것이 섹터이며, 하드 디스크는 이 섹터 단위로 데이터를 읽고 씁니다. 트랙은 동심원, 실린더는 여러 플래터의 같은 위치 트랙 모음, 플래터는 데이터가 저장되는 원판입니다.

---

### 퀴즈 2: 하드 디스크의 접근 시간

**문제:** 하드 디스크의 데이터 접근 시간을 구성하는 세 가지 요소가 아닌 것은?

① 탐색 시간(Seek Time)
② 회전 지연(Rotational Latency)
③ 전송 시간(Transfer Time)
④ 컴파일 시간(Compile Time)

**정답:** ④ 컴파일 시간(Compile Time)

**해설:** 하드 디스크의 접근 시간은 탐색 시간(헤드 이동), 회전 지연(플래터 회전), 전송 시간(데이터 전송)의 세 가지로 구성됩니다. 컴파일 시간은 프로그래밍과 관련된 용어로 하드 디스크의 접근 시간과는 무관합니다.

---

### 퀴즈 3: 플래시 메모리의 구조

**문제:** 플래시 메모리의 계층 구조를 올바르게 나타낸 것은?

① 블록 → 페이지 → 셀
② 셀 → 블록 → 페이지
③ 페이지 → 셀 → 블록
④ 셀 → 페이지 → 블록

**정답:** ④ 셀 → 페이지 → 블록

**해설:** 플래시 메모리는 가장 작은 단위인 셀이 모여 페이지를 구성하고, 페이지가 모여 블록을 구성하는 계층 구조입니다. 셀은 데이터 저장의 최소 단위, 페이지는 읽기/쓰기 단위, 블록은 삭제 단위입니다.

---

### 퀴즈 4: 플래시 메모리 타입

**문제:** 다음 중 한 셀에 가장 많은 비트를 저장할 수 있는 플래시 메모리 타입은?

① SLC (Single Level Cell)
② MLC (Multi Level Cell)
③ TLC (Triple Level Cell)
④ 모두 같다

**정답:** ③ TLC (Triple Level Cell)

**해설:** TLC는 한 셀에 3bit를 저장할 수 있어 가장 많은 데이터를 저장할 수 있습니다. SLC는 1bit, MLC는 2bit를 저장합니다. 저장 용량이 많을수록 속도와 수명은 감소하고 가격은 저렴해집니다.

---

### 퀴즈 5: SLC의 특징

**문제:** SLC(Single Level Cell) 타입의 플래시 메모리에 대한 설명으로 옳지 않은 것은?

① 한 셀에 1bit를 저장한다
② 가장 빠른 속도를 제공한다
③ 가장 저렴한 가격대를 형성한다
④ 가장 긴 수명을 가진다

**정답:** ③ 가장 저렴한 가격대를 형성한다

**해설:** SLC는 가장 비싼 플래시 메모리 타입입니다. 한 셀에 1bit만 저장하므로 같은 용량을 구현하려면 더 많은 셀이 필요하고, 속도와 수명이 뛰어나 주로 기업용 서버나 고성능이 필요한 곳에 사용됩니다. 가장 저렴한 것은 TLC입니다.

---

### 퀴즈 6: 플래시 메모리 페이지 상태

**문제:** 플래시 메모리에서 유효하지 않은 데이터(쓰레기값)를 저장하고 있는 페이지의 상태는?

① Free 상태
② Valid 상태
③ Invalid 상태
④ Error 상태

**정답:** ③ Invalid 상태

**해설:** Invalid 상태는 유효하지 않은 데이터(쓰레기값)를 저장하고 있는 페이지 상태입니다. Free는 빈 상태, Valid는 유효한 데이터를 저장한 상태입니다. Invalid 페이지는 가비지 컬렉션을 통해 정리됩니다.

---

### 퀴즈 7: 가비지 컬렉션

**문제:** 플래시 메모리의 가비지 컬렉션(Garbage Collection)에 대한 설명으로 옳은 것은?

① Invalid 페이지만 삭제하고 Valid 페이지는 그대로 둔다
② Valid 페이지를 복사한 후 기존 블록을 삭제한다
③ 페이지 단위로 개별적으로 삭제한다
④ 데이터를 압축하여 저장 공간을 늘린다

**정답:** ② Valid 페이지를 복사한 후 기존 블록을 삭제한다

**해설:** 가비지 컬렉션은 유효한(Valid) 페이지들만 새로운 블록으로 복사한 후, 기존 블록 전체를 삭제하여 공간을 확보하는 작업입니다. 플래시 메모리는 블록 단위로만 삭제가 가능하므로 이러한 과정이 필요합니다.

---

### 퀴즈 8: 하드 디스크 vs 플래시 메모리

**문제:** 하드 디스크와 플래시 메모리를 비교한 설명으로 옳지 않은 것은?

① 하드 디스크는 자기적 방식, 플래시 메모리는 전기적 방식으로 저장한다
② 하드 디스크는 기계적 부품이 있고, 플래시 메모리는 반도체 기반이다
③ 플래시 메모리가 하드 디스크보다 빠르고 충격에 강하다
④ 하드 디스크가 플래시 메모리보다 전력 소비가 적다

**정답:** ④ 하드 디스크가 플래시 메모리보다 전력 소비가 적다

**해설:** 하드 디스크는 플래터를 회전시키고 헤드를 이동시키는 기계적 동작이 필요하므로 플래시 메모리보다 전력 소비가 많습니다. 플래시 메모리는 반도체 기반으로 기계적 동작이 없어 전력 소비가 적고 소음도 없습니다.
