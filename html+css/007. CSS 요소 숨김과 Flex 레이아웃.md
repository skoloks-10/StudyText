## 1. 요소를 숨기는 방법들

### 1.1 cursor 속성

**개념** : 마우스 커서가 요소 위에 올라갔을 때 표시되는 커서의 모양을 지정하는 속성입니다.

**문법** :

```css
cursor: auto | pointer | default | text | move | not-allowed |...;
```

**주요 값들** :

- `auto`: 브라우저가 자동으로 커서를 결정
- `pointer`: 손가락 모양 (링크나 버튼에 주로 사용)
- `default`: 기본 화살표
- `text`: 텍스트 선택 커서 (I-beam)
- `move`: 이동 가능함을 나타내는 십자 화살표
- `not-allowed`: 금지 표시

  **사용 상황** :

- 클릭 가능한 요소임을 시각적으로 알릴 때
- 드래그 가능한 요소를 표시할 때
- 비활성화된 요소를 나타낼 때

  **예시 코드** :

```css
button {
  cursor: pointer; /* 버튼에 손가락 커서 */
}

.disabled {
  cursor: not-allowed; /* 비활성화된 요소 */
}

.draggable {
  cursor: move; /* 드래그 가능한 요소 */
}
```

### 1.2 요소를 숨기는 세 가지 방법

### 1.2.1 opacity 속성

**개념** : 요소의 투명도를 조절하는 속성으로, 0(완전 투명)부터 1(완전 불투명)까지의 값을 가집니다.

**문법** :

```css
opacity: 0 ~1;
```

**특징** :

- 모습만 감춤 (시각적으로만 투명)
- 여전히 자리를 차지함
- 클릭, 마우스 오버 등 이벤트가 여전히 작동함
- 스크린 리더에 따라 읽지 않을 수도 있음

  **사용 상황** :

- 페이드 인/아웃 애니메이션을 구현할 때
- 반투명 효과를 주고 싶을 때
- 마우스 오버 시 투명도를 변경하고 싶을 때

  **예시 코드** :

```css
.fade-out {
  opacity: 0; /* 완전히 투명하게 */
}

.semi-transparent {
  opacity: 0.5; /* 반투명 */
}

.hover-effect:hover {
  opacity: 0.7; /* 마우스 오버 시 약간 투명하게 */
}
```

---

### 1.2.2 visibility 속성

**개념** : 요소의 가시성을 제어하는 속성으로, 요소를 보이거나 숨길 수 있습니다.

**문법** :

```css
visibility: visible | hidden | collapse;
```

**주요 값** :

- `visible`: 기본값, 요소를 보이게 함
- `hidden`: 요소를 숨김

  **특징** :

- 모습을 감춤 (시각적으로 보이지 않음)
- 여전히 자리를 차지함
- 마우스 오버, 포커스, 클릭 등 모든 이벤트가 무효화됨
- 스크린 리더에게도 읽히지 않음

  **사용 상황** :

- 레이아웃을 유지하면서 요소를 숨기고 싶을 때
- 인터랙션을 완전히 차단하고 싶을 때
- 공간은 유지하되 접근성에서도 제외하고 싶을 때

  **예시 코드** :

```css
.hidden-but-space {
  visibility: hidden; /* 숨기지만 공간은 유지 */
}

.show-on-hover {
  visibility: hidden;
}

.container:hover .show-on-hover {
  visibility: visible; /* 부모에 마우스 오버 시 보이게 */
}
```

---

### 1.2.3 display 속성

**개념** : 요소가 화면에 어떻게 표시될지를 결정하는 속성으로, 레이아웃에 큰 영향을 미칩니다.

**문법** :

```css
display: block | inline | inline-block | flex | inline-flex | none |...;
```

**주요 값** :

- `block`: 블록 레벨 요소로 표시 (한 줄 전체를 차지)
- `inline`: 인라인 요소로 표시 (내용만큼만 공간 차지)
- `inline-block`: 인라인처럼 배치되지만 블록 속성 적용 가능
- `flex`: 플렉스 컨테이너로 지정
- `none`: 요소를 완전히 숨김

  **특징 (display: none)** :

- 모습을 감춤
- 자리도 차지하지 않음 (레이아웃에서 완전히 제거됨)
- 모든 이벤트가 무효화됨
- 스크린 리더에게도 읽히지 않음

  **사용 상황** :

- 요소를 완전히 제거하고 싶을 때
- 조건부로 요소를 표시/숨김할 때
- 반응형 디자인에서 특정 화면 크기에서 요소를 숨길 때

  **예시 코드** :

```css
.completely-hidden {
  display: none; /* 완전히 제거 */
}

@media (max-width: 768px) {
  .desktop-only {
    display: none; /* 모바일에서 숨김 */
  }
}

.toggle-content {
  display: none;
}

.toggle-content.active {
  display: block; /* 활성화 시 표시 */
}
```

---

### 1.3 세 가지 방법 비교표

| 속성                 | 시각적 표시 | 공간 차지     | 이벤트 작동 | 스크린 리더         |
| -------------------- | ----------- | ------------- | ----------- | ------------------- |
| `opacity: 0`         | ❌ 투명     | ✅ 차지함     | ✅ 작동함   | ⚠️ 경우에 따라 다름 |
| `visibility: hidden` | ❌ 숨김     | ✅ 차지함     | ❌ 무효화됨 | ❌ 읽지 않음        |
| `display: none`      | ❌ 숨김     | ❌ 차지 안 함 | ❌ 무효화됨 | ❌ 읽지 않음        |

## 2. Flex 레이아웃

### 2.1 Flex 기본 개념

**개념** : Flexbox는 CSS3에 도입된 1차원 레이아웃 시스템으로, 요소들을 행 또는 열 방향으로 효율적으로 배치하고 정렬할 수 있게 해줍니다.

**기본 구조** :

- **Flex Container** : `display: flex` 또는 `display: inline-flex`가 적용된 부모 요소
- **Flex Item** : Flex Container의 직계 자식 요소들

---

### 2.2 Flex Container 속성

### 2.2.1 display

**개념** : 요소를 Flex Container로 만드는 속성입니다.

**문법** :

```css
display: flex | inline-flex;
```

**값의 차이** :

- `flex`: 블록 레벨 Flex Container (한 줄 전체를 차지)
- `inline-flex`: 인라인 레벨 Flex Container (내용만큼만 공간 차지)

  **사용 상황** :

- 자식 요소들을 가로 또는 세로로 배치하고 싶을 때
- 요소들을 동적으로 정렬하고 싶을 때
- 반응형 레이아웃을 만들고 싶을 때

  **예시 코드** :

```css
.container {
  display: flex; /* Flex Container로 지정 */
}

.inline-container {
  display: inline-flex; /* 인라인 Flex Container */
}
```

---

### 2.2.2 flex-direction

**개념** : Flex Item들이 배치되는 주축(main axis)의 방향을 결정하는 속성입니다.

**문법** :

```css
flex-direction: row | row-reverse | column | column-reverse;
```

**주요 값** :

- `row`: 기본값, 가로 방향 (왼쪽 → 오른쪽)
- `row-reverse`: 가로 방향 역순 (오른쪽 → 왼쪽)
- `column`: 세로 방향 (위 → 아래)
- `column-reverse`: 세로 방향 역순 (아래 → 위)

  **특징** :

- 이 값에 따라 `justify-content`, `align-items` 등의 속성이 작용할 방향이 결정됨
- **주축(main axis)** : `flex-direction`이 가리키는 방향
- **교차축(cross axis)** : 주축에 수직인 방향

  **사용 상황** :

- 요소들을 가로로 나열할 때 (네비게이션 메뉴 등)
- 요소들을 세로로 쌓을 때 (사이드바 등)
- 요소들의 순서를 역순으로 표시할 때

  **예시 코드** :

```css
.horizontal-layout {
  display: flex;
  flex-direction: row; /* 가로 배치 */
}

.vertical-layout {
  display: flex;
  flex-direction: column; /* 세로 배치 */
}

.reverse-order {
  display: flex;
  flex-direction: row-reverse; /* 역순 가로 배치 */
}
```

---

### 2.2.3 flex-wrap

**개념** : Flex Item들이 Container의 크기를 넘어갈 때 줄바꿈 여부를 결정하는 속성입니다.

**문법** :

```css
flex-wrap: nowrap | wrap | wrap-reverse;
```

**주요 값** :

- `nowrap`: 기본값, 줄바꿈 안 함 (한 줄에 모두 배치)
- `wrap`: 줄바꿈 함 (여러 줄에 걸쳐 배치)
- `wrap-reverse`: 역방향으로 줄바꿈

  **특징** :

- `nowrap`일 때는 아이템들이 Container를 넘어가거나 축소될 수 있음
- `wrap`일 때는 아이템들이 여러 줄로 나뉘어 배치됨

  **사용 상황** :

- 반응형 그리드 레이아웃을 만들 때
- 아이템의 최소 크기를 보장하면서 배치하고 싶을 때
- 화면 크기에 따라 자동으로 줄바꿈이 되게 하고 싶을 때

  **예시 코드** :

```css
.single-line {
  display: flex;
  flex-wrap: nowrap; /* 한 줄에 모두 배치 */
}

.multi-line {
  display: flex;
  flex-wrap: wrap; /* 넘치면 줄바꿈 */
}

.responsive-grid {
  display: flex;
  flex-wrap: wrap; /* 반응형 그리드 */
}

.responsive-grid > * {
  min-width: 200px; /* 최소 너비 보장 */
}
```

### 2.2.4 justify-content

**개념** : 주축(main axis) 방향으로 Flex Item들을 어떻게 정렬할지 결정하는 속성입니다.

**문법** :

```css
justify-content: flex-start | flex-end | center | space-between | space-around |
  space-evenly;
```

**주요 값** :

- `flex-start`: 주축의 시작점에 정렬 (기본값)
- `flex-end`: 주축의 끝점에 정렬
- `center`: 주축의 중앙에 정렬
- `space-between`: 첫 아이템과 마지막 아이템은 양 끝에, 나머지는 균등 간격
- `space-around`: 각 아이템의 좌우에 동일한 여백
- `space-evenly`: 모든 간격이 동일하게 균등 배치

  **특징** :

- `flex-start`/`flex-end`는 `row-reverse`, `column-reverse`의 영향을 받음
- `start`/`end`보다 `flex-start`/`flex-end` 사용을 권장

  **사용 상황** :

- 요소들을 가운데 정렬하고 싶을 때
- 요소들 사이에 균등한 간격을 주고 싶을 때
- 요소들을 끝에 정렬하고 싶을 때

  **예시 코드** :

```css
.center-items {
  display: flex;
  justify-content: center; /* 가운데 정렬 */
}

.space-between-items {
  display: flex;
  justify-content: space-between; /* 양 끝 정렬, 중간 균등 간격 */
}

.even-spacing {
  display: flex;
  justify-content: space-evenly; /* 모든 간격 동일 */
}
```

### 2.2.5 align-items

**개념** : 교차축(cross axis) 방향으로 Flex Item들을 어떻게 정렬할지 결정하는 속성입니다.

**문법** :

```css
align-items: stretch | flex-start | flex-end | center | baseline;
```

**주요 값** :

- `stretch`: 기본값, 교차축 방향으로 늘어남 (Container의 높이/너비를 채움)
- `flex-start`: 교차축의 시작점에 정렬
- `flex-end`: 교차축의 끝점에 정렬
- `center`: 교차축의 중앙에 정렬
- `baseline`: 텍스트 베이스라인에 맞춰 정렬

  **특징** :

- `flex-direction`이 `row`일 때는 세로 방향 정렬을 제어
- `flex-direction`이 `column`일 때는 가로 방향 정렬을 제어
- 한 줄일 때 사용 (여러 줄일 때는 `align-content` 사용)

  **사용 상황** :

- 세로 방향으로 가운데 정렬하고 싶을 때
- 아이템들의 높이를 동일하게 맞추고 싶을 때
- 텍스트 베이스라인을 맞추고 싶을 때

  **예시 코드** :

```css
.vertical-center {
  display: flex;
  align-items: center; /* 세로 가운데 정렬 */
  height: 300px;
}

.stretch-items {
  display: flex;
  align-items: stretch; /* 높이를 채움 */
  height: 300px;
}

.baseline-align {
  display: flex;
  align-items: baseline; /* 텍스트 베이스라인 정렬 */
}
```

---

### 2.2.6 align-content

**개념** : 여러 줄의 Flex Item들이 있을 때 교차축 방향으로 줄들을 어떻게 정렬할지 결정하는 속성입니다.

**문법** :

```css
align-content: stretch | flex-start | flex-end | center | space-between |
  space-around | space-evenly;
```

**주요 값** :

- `stretch`: 기본값, 줄들이 Container를 채우도록 늘어남
- `flex-start`: 교차축의 시작점에 정렬
- `flex-end`: 교차축의 끝점에 정렬
- `center`: 교차축의 중앙에 정렬
- `space-between`: 첫 줄과 마지막 줄은 양 끝에, 나머지는 균등 간격
- `space-around`: 각 줄의 위아래에 동일한 여백
- `space-evenly`: 모든 간격이 동일하게 균등 배치

  **특징** :

- `flex-wrap: wrap`이 적용되어 여러 줄이 될 때만 효과가 있음
- 한 줄일 때는 `align-items`를 사용

  **사용 상황** :

- 여러 줄의 아이템들을 정렬하고 싶을 때
- 줄들 사이에 간격을 주고 싶을 때
- 반응형 그리드의 정렬을 제어하고 싶을 때

  **예시 코드** :

```css
.multi-line-center {
  display: flex;
  flex-wrap: wrap;
  align-content: center; /* 여러 줄을 가운데 정렬 */
  height: 400px;
}

.multi-line-space {
  display: flex;
  flex-wrap: wrap;
  align-content: space-between; /* 줄 사이 균등 간격 */
  height: 400px;
}
```

### 2.2.7 gap

**개념** : Flex Item들 사이의 간격을 설정하는 속성입니다.

**문법** :

```css
gap: <row-gap> <column-gap>;
/* 또는 */
gap: <gap-value>; /* 행과 열 간격이 동일할 때 */
```

**특징** :

- 하나의 값만 지정하면 행과 열 간격이 동일하게 적용됨
- 두 개의 값을 지정하면 첫 번째는 행 간격, 두 번째는 열 간격
- `margin`보다 편리하게 아이템 간격을 제어할 수 있음

  **사용 상황** :

- 아이템들 사이에 일정한 간격을 주고 싶을 때
- 그리드처럼 균등한 간격의 레이아웃을 만들 때
- 반응형 레이아웃에서 간격을 조절하고 싶을 때

  **예시 코드** :

```css
.equal-gap {
  display: flex;
  gap: 20px; /* 모든 방향 20px 간격 */
}

.different-gap {
  display: flex;
  flex-wrap: wrap;
  gap: 20px 30px; /* 행 간격 20px, 열 간격 30px */
}

.responsive-gap {
  display: flex;
  gap: 10px;
}

@media (min-width: 768px) {
  .responsive-gap {
    gap: 20px; /* 큰 화면에서 간격 증가 */
  }
}
```

### 2.3 Flex Item 속성

### 2.3.1 flex-basis

**개념** : 주축 방향의 초기 크기를 지정하는 속성입니다. Container의 `flex-direction`에 따라 너비 또는 높이로 작용합니다.

**문법** :

```css
flex-basis: auto | <length> | <percentage>;
```

**주요 값** :

- `auto`: 기본값, 아이템의 내용이나 `width`/`height` 속성에 따름
- `<length>`: px, em, rem 등의 단위로 크기 지정
- `<percentage>`: 부모 Container 크기의 백분율

  **특징** :

- `flex-direction: row`일 때는 너비를 의미
- `flex-direction: column`일 때는 높이를 의미
- `width`/`height`보다 우선순위가 높음

  **사용 상황** :

- 아이템의 기본 크기를 설정하고 싶을 때
- 비율 기반 레이아웃을 만들고 싶을 때
- 반응형 레이아웃에서 초기 크기를 제어하고 싶을 때

  **예시 코드** :

```css
.item-basic {
  flex-basis: 200px; /* 기본 너비 200px */
}

.item-percent {
  flex-basis: 50%; /* 부모의 50% */
}

.item-auto {
  flex-basis: auto; /* 내용에 따라 자동 */
}
```

---

### 2.3.2 flex-grow

**개념** : 여유 공간이 있을 때 아이템이 얼마나 늘어날 수 있는지를 지정하는 속성입니다.

**문법** :

```css
flex-grow: <number>; /* 기본값: 0 */
```

**특징** :

- 기본값은 `0` (늘어나지 않음)
- 값이 클수록 더 많은 여유 공간을 차지
- 다른 아이템들의 `flex-grow` 값과의 비율로 공간을 분배
- 음수 값은 허용되지 않음

  **사용 상황** :

- 특정 아이템이 남은 공간을 채우게 하고 싶을 때
- 아이템들의 크기 비율을 조절하고 싶을 때
- 반응형 레이아웃에서 유연한 크기 조절이 필요할 때

  **예시 코드** :

```css
.item-grow {
  flex-grow: 1; /* 여유 공간을 채움 */
}

.item-double-grow {
  flex-grow: 2; /* 다른 아이템의 2배로 늘어남 */
}

/* 예시: 사이드바와 메인 컨텐츠 */
.sidebar {
  flex-basis: 200px;
  flex-grow: 0; /* 고정 크기 */
}

.main-content {
  flex-grow: 1; /* 남은 공간 모두 차지 */
}
```

---

### 2.3.3 flex-shrink

**개념** : 공간이 부족할 때 아이템이 얼마나 줄어들 수 있는지를 지정하는 속성입니다.

**문법** :

```css
flex-shrink: <number>; /* 기본값: 1 */
```

**특징** :

- 기본값은 `1` (공간이 부족하면 줄어듦)
- 값이 클수록 더 많이 줄어듦
- `0`으로 설정하면 절대 줄어들지 않음
- 다른 아이템들의 `flex-shrink` 값과의 비율로 축소 비율이 결정됨
- 음수 값은 허용되지 않음

  **사용 상황** :

- 특정 아이템의 최소 크기를 보장하고 싶을 때
- 공간이 부족할 때 특정 아이템을 우선적으로 축소하고 싶을 때
- 반응형 레이아웃에서 아이템의 축소 동작을 제어하고 싶을 때

  **예시 코드** :

```css
.no-shrink {
  flex-shrink: 0; /* 절대 줄어들지 않음 */
}

.shrink-more {
  flex-shrink: 2; /* 다른 아이템보다 2배 더 줄어듦 */
}

/* 예시: 로고와 메뉴 */
.logo {
  flex-shrink: 0; /* 로고는 고정 크기 유지 */
  flex-basis: 150px;
}

.menu {
  flex-shrink: 1; /* 메뉴는 공간이 부족하면 줄어듦 */
}
```

---

### 2.3.4 flex 단축 속성

**개념** : `flex-grow`, `flex-shrink`, `flex-basis`를 한 번에 지정하는 단축 속성입니다.

**문법** :

```css
flex: <flex-grow>;
flex: <flex-grow> <flex-basis>;
flex: <flex-grow> <flex-shrink> <flex-basis>;
```

**주요 사용 패턴** :

```css
/* 한 개 값 */
flex: 1; /* flex-grow: 1, flex-shrink: 1, flex-basis: 0% */

/* 두 개 값 */
flex: 1 200px; /* flex-grow: 1, flex-shrink: 1, flex-basis: 200px */

/* 세 개 값 */
flex: 1 0 200px; /* flex-grow: 1, flex-shrink: 0, flex-basis: 200px */
```

**특별한 키워드 값** :

- `flex: initial` → `flex: 0 1 auto` (기본값)
- `flex: auto` → `flex: 1 1 auto` (늘어나고 줄어듦)
- `flex: none` → `flex: 0 0 auto` (고정 크기)

  **사용 상황** :

- 코드를 간결하게 작성하고 싶을 때
- 자주 사용하는 패턴을 빠르게 적용하고 싶을 때

  **예시 코드** :

```css
.flex-item {
  flex: 1; /* 여유 공간을 균등하게 분배 */
}

.fixed-item {
  flex: none; /* 고정 크기, 늘어나거나 줄어들지 않음 */
}

.flexible-item {
  flex: 1 1 200px; /* 기본 200px, 늘어나고 줄어듦 */
}
```

---

### 2.3.5 order

**개념** : Flex Item들의 시각적 순서를 변경하는 속성입니다. HTML 구조는 변경하지 않고 표시 순서만 변경합니다.

**문법** :

```css
order: <integer>; /* 기본값: 0 */
```

**특징** :

- 기본값은 `0`
- 숫자가 작을수록 앞에 배치됨
- 같은 값을 가진 아이템들은 HTML 코드 순서대로 배치됨
- 음수 값도 사용 가능

  **주의사항** :

- 시각적 순서만 변경되며, 탭 순서나 스크린 리더 순서는 HTML 구조를 따름
- 접근성을 위해 신중하게 사용해야 함

  **사용 상황** :

- 반응형 디자인에서 화면 크기에 따라 요소 순서를 변경하고 싶을 때
- 특정 요소를 맨 앞이나 맨 뒤로 이동시키고 싶을 때

  **예시 코드** :

```css
.item-first {
  order: -1; /* 가장 먼저 표시 */
}

.item-last {
  order: 999; /* 가장 나중에 표시 */
}

/* 반응형 예시 */
.sidebar {
  order: 2; /* 기본적으로 뒤에 */
}

@media (min-width: 768px) {
  .sidebar {
    order: 0; /* 큰 화면에서는 앞에 */
  }
}
```

## 핵심 요약

### 요소 숨김 방법

1. **opacity: 0**
   - ✅ 시각적으로만 투명하게 만듦
   - ✅ 공간은 차지, 이벤트는 작동
   - 💡 페이드 애니메이션에 적합
2. **visibility: hidden**
   - ✅ 시각적으로 숨기고 이벤트도 차단
   - ✅ 공간은 여전히 차지
   - 💡 레이아웃 유지하며 숨길 때 적합
3. **display: none**
   - ✅ 완전히 제거 (공간도 차지 안 함)
   - ✅ 모든 이벤트 차단
   - 💡 조건부 표시/숨김에 적합

### Flex 레이아웃 핵심

**Container 속성 (부모)** :

- `display: flex` - Flex Container로 지정
- `flex-direction` - 배치 방향 (row/column)
- `flex-wrap` - 줄바꿈 여부
- `justify-content` - 주축 정렬
- `align-items` - 교차축 정렬 (한 줄)
- `align-content` - 교차축 정렬 (여러 줄)
- `gap` - 아이템 간격

  **Item 속성 (자식)** :

- `flex-basis` - 기본 크기
- `flex-grow` - 늘어나는 비율
- `flex-shrink` - 줄어드는 비율
- `flex` - 위 세 속성의 단축형
- `order` - 표시 순서 변경

  **주요 패턴** :

```css
/* 가운데 정렬 */
.center {
  display: flex;
  justify-content: center;
  align-items: center;
}

/* 균등 분배 */
.equal-items > * {
  flex: 1;
}

/* 고정 + 유동 레이아웃 */
.sidebar {
  flex: 0 0 200px;
}
.main {
  flex: 1;
}
```

## 복습 퀴즈

### 퀴즈 1

요소를 시각적으로 숨기면서도 마우스 클릭 이벤트는 여전히 작동하게 하려면 어떤 속성을 사용해야 할까요?

**① opacity: 0**

② visibility: hidden

③ display: none

④ cursor: none

**정답: ①**

**해설** : `opacity: 0`은 요소를 투명하게 만들어 시각적으로만 숨기지만, 요소는 여전히 자리를 차지하고 모든 이벤트(클릭, 마우스 오버 등)가 작동합니다. `visibility: hidden`과 `display: none`은 모두 이벤트를 차단합니다.

---

### 퀴즈 2

Flex Container에서 아이템들을 세로 방향으로 배치하려면 어떤 속성 값을 사용해야 할까요?

① flex-direction: row

**② flex-direction: column**

③ flex-wrap: wrap

④ align-items: flex-start

**정답: ②**

**해설** : `flex-direction: column`은 Flex Item들을 세로 방향(위에서 아래로)으로 배치합니다. `row`는 가로 방향 배치이며, `flex-wrap`은 줄바꿈 여부를, `align-items`는 정렬 방식을 결정합니다.

---

### 퀴즈 3

Flex Item들 사이에 균등한 간격을 주되, 첫 번째와 마지막 아이템은 Container의 양 끝에 붙게 하려면?

① justify-content: space-around

**② justify-content: space-between**

③ justify-content: space-evenly

④ gap: 20px

**정답: ②**

**해설** : `space-between`은 첫 번째 아이템을 시작점에, 마지막 아이템을 끝점에 배치하고 나머지 아이템들 사이에 균등한 간격을 줍니다. `space-around`는 각 아이템 양옆에 동일한 여백을 주고, `space-evenly`는 모든 간격이 완전히 동일합니다.

---

### 퀴즈 4

다음 중 요소를 완전히 제거하여 레이아웃에서 차지하는 공간까지 없애는 방법은?

① opacity: 0

② visibility: hidden

**③ display: none**

④ cursor: none

**정답: ③**

**해설** : `display: none`은 요소를 완전히 제거하여 시각적으로도 보이지 않고, 공간도 차지하지 않으며, 모든 이벤트가 차단됩니다. `opacity: 0`과 `visibility: hidden`은 모두 공간을 차지합니다.

---

### 퀴즈 5

Flex Item이 여유 공간이 있을 때 다른 아이템들보다 2배 더 많이 늘어나게 하려면?

① flex-shrink: 2

**② flex-grow: 2**

③ flex-basis: 200%

④ order: 2

**정답: ②**

**해설** : `flex-grow`는 여유 공간이 있을 때 아이템이 얼마나 늘어날지를 결정합니다. 값이 클수록 더 많은 공간을 차지하며, 다른 아이템들의 `flex-grow` 값과의 비율로 분배됩니다. `flex-grow: 2`는 `flex-grow: 1`인 아이템보다 2배 많이 늘어납니다.

---

### 퀴즈 6

여러 줄로 나뉜 Flex Item들을 교차축 방향으로 정렬할 때 사용하는 속성은?

① align-items

**② align-content**

③ justify-content

④ flex-wrap

**정답: ②**

**해설** : `align-content`는 `flex-wrap: wrap`으로 인해 여러 줄로 나뉜 경우, 줄들을 교차축 방향으로 어떻게 정렬할지 결정합니다. `align-items`는 한 줄 내에서의 정렬을 담당합니다.

---

### 퀴즈 7

다음 CSS 코드의 의미는 무엇일까요?

```css
.item {
  flex: 1 0 200px;
}
```

① 늘어나지 않고, 줄어들지 않으며, 기본 크기 200px

**② 늘어나고, 줄어들지 않으며, 기본 크기 200px**

③ 늘어나고, 줄어들고, 기본 크기 200px

④ 늘어나지 않고, 줄어들고, 기본 크기 200px

**정답: ②**

**해설** : `flex: 1 0 200px`는 `flex-grow: 1`, `flex-shrink: 0`, `flex-basis: 200px`를 의미합니다. 따라서 여유 공간이 있으면 늘어나지만(`flex-grow: 1`), 공간이 부족해도 줄어들지 않으며(`flex-shrink: 0`), 기본 크기는 200px입니다.

### 문제 4: 요소 숨김 비교

**문제** : 세 개의 버튼이 있고, 각각 다른 방법으로 요소를 숨기는 기능을 구현하세요.

**요구사항** :

- 버튼 1 클릭: `opacity`를 사용하여 박스를 숨김/표시
- 버튼 2 클릭: `visibility`를 사용하여 박스를 숨김/표시
- 버튼 3 클릭: `display`를 사용하여 박스를 숨김/표시
- 각 박스에는 클릭 이벤트 리스너가 있어 클릭 시 "Clicked!" 알림

  **기본 코드** :

```html
<div class="controls">
  <button id="btn1">Toggle Opacity</button>
  <button id="btn2">Toggle Visibility</button>
  <button id="btn3">Toggle Display</button>
</div>

<div class="boxes">
  <div class="box box1">Box 1 (opacity)</div>
  <div class="box box2">Box 2 (visibility)</div>
  <div class="box box3">Box 3 (display)</div>
</div>
```

```css
.boxes {

  gap: 20px;
  margin-top: 20px;
}

.box {
  width: 150px;
  height: 150px;
  background-color: skyblue;
  display: flex;
  justify-content: center;
  align-items: center;
  cursor: pointer;
  transition: opacity 0.3s;
}

/* 여기에 숨김 상태의 CSS 작성 */
.box1.hidden {
  /* opacity를 사용한 숨김 */
}

.box2.hidden {
  /* visibility를 사용한 숨김 */
}

.box3.hidden {
  /* display를 사용한 숨김 */
}
```

```jsx
// 여기에 JavaScript 작성
```

---

**정답** :

```css
.boxes {
  display: flex;
  gap: 20px;
  margin-top: 20px;
}

.box {
  width: 150px;
  height: 150px;
  background-color: skyblue;
  display: flex;
  justify-content: center;
  align-items: center;
  cursor: pointer;
  transition: opacity 0.3s;
}

.box1.hidden {
  opacity: 0; /* 투명하게 (클릭 가능) */
}

.box2.hidden {
  visibility: hidden; /* 숨김 (클릭 불가) */
}

.box3.hidden {
  display: none; /* 완전히 제거 */
}
```

```jsx
// 박스 클릭 이벤트
const boxes = document.querySelectorAll(".box");
boxes.forEach((box) => {
  box.addEventListener("click", () => {
    alert("Clicked!");
  });
});

// 버튼 1: opacity 토글
document.getElementById("btn1").addEventListener("click", () => {
  const box1 = document.querySelector(".box1");
  box1.classList.toggle("hidden");
});

// 버튼 2: visibility 토글
document.getElementById("btn2").addEventListener("click", () => {
  const box2 = document.querySelector(".box2");
  box2.classList.toggle("hidden");
});

// 버튼 3: display 토글
document.getElementById("btn3").addEventListener("click", () => {
  const box3 = document.querySelector(".box3");
  box3.classList.toggle("hidden");
});
```

**풀이 및 해설** :

1. **Box 1 (opacity)** : `opacity: 0`을 사용하면 시각적으로만 투명해지며, 여전히 공간을 차지하고 클릭 이벤트도 작동합니다. 투명한 상태에서도 "Clicked!" 알림이 뜹니다.
2. **Box 2 (visibility)** : `visibility: hidden`을 사용하면 시각적으로 숨겨지고 클릭 이벤트도 차단됩니다. 하지만 공간은 여전히 차지하므로 레이아웃은 변하지 않습니다.
3. **Box 3 (display)** : `display: none`을 사용하면 완전히 제거되어 공간도 차지하지 않으며, 클릭 이벤트도 차단됩니다. 레이아웃이 변경되어 나머지 박스들이 이동합니다.
4. `classList.toggle()`을 사용하여 클릭할 때마다 `hidden` 클래스를 추가/제거합니다.

## 학습 체크리스트

### 요소 숨김 방법

- [ ] `cursor` 속성의 주요 값들을 이해하고 적절한 상황에 사용할 수 있다
- [ ] `opacity: 0`의 특징을 이해하고, 언제 사용하는지 안다
- [ ] `visibility: hidden`의 특징을 이해하고, 언제 사용하는지 안다
- [ ] `display: none`의 특징을 이해하고, 언제 사용하는지 안다
- [ ] 세 가지 숨김 방법의 차이점을 명확히 구분할 수 있다
- [ ] 각 방법이 공간 차지, 이벤트 작동, 스크린 리더에 미치는 영향을 안다

### Flex Container 속성

- [ ] `display: flex`와 `display: inline-flex`의 차이를 이해한다
- [ ] `flex-direction`의 네 가지 값과 각각의 효과를 안다
- [ ] 주축(main axis)과 교차축(cross axis)의 개념을 이해한다
- [ ] `flex-wrap`을 사용하여 줄바꿈을 제어할 수 있다
- [ ] `justify-content`의 여러 값들을 이해하고 적절히 사용할 수 있다
- [ ] `align-items`와 `align-content`의 차이를 이해한다
- [ ] `gap` 속성으로 아이템 간격을 효율적으로 제어할 수 있다

### Flex Item 속성

- [ ] `flex-basis`의 개념과 사용법을 이해한다
- [ ] `flex-grow`를 사용하여 요소가 늘어나는 비율을 제어할 수 있다
- [ ] `flex-shrink`를 사용하여 요소가 줄어드는 비율을 제어할 수 있다
- [ ] `flex` 단축 속성의 여러 패턴을 이해하고 사용할 수 있다
- [ ] `order` 속성으로 요소의 순서를 변경할 수 있다
- [ ] `order` 사용 시 접근성 문제를 인지하고 있다
