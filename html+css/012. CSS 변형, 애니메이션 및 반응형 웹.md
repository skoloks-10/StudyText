## 1. Transform 속성 🔄

### 1.1 개념 및 특징

**Transform**은 요소의 시각적 모습을 변형시키는 CSS 속성입니다.

**핵심 특징:**

- 주위 요소들의 레이아웃에 영향을 주지 않음
- 요소의 위치, 크기, 회전 등을 변경 가능
- GPU 가속을 사용하여 성능이 우수함

📖 **출처:** MDN Web Docs - CSS Transform

### 1.2 주요 transform 함수

| 함수              | 설명             | 예시                                 |
| ----------------- | ---------------- | ------------------------------------ |
| `translate(x, y)` | 요소를 이동      | `transform: translate(50px, 100px);` |
| `scale(x, y)`     | 요소의 크기 조절 | `transform: scale(1.5, 2);`          |
| `rotate(angle)`   | 요소를 회전      | `transform: rotate(45deg);`          |
| `skew(x, y)`      | 요소를 기울임    | `transform: skew(10deg, 20deg);`     |

### 1.3 사용 예시

**요소를 중앙에 배치하는 예시:**

```css
/* 절대 위치 지정 후 중앙 배치 */
div {
  position: absolute;
  top: 50%;
  left: 50%;
  transform: translate(-50%, -50%);
}
```

**이 코드가 작동하는 원리:**

1. `top: 50%; left: 50%;` - 요소의 좌상단이 부모의 중앙에 위치
2. `transform: translate(-50%, -50%);` - 요소 자신의 너비/높이의 절반만큼 역방향 이동
3. 결과적으로 요소의 중심이 부모의 중앙에 정확히 위치

**여러 transform 함수 조합:**

```css
div {
  /* 여러 변형을 공백으로 구분하여 나열 */
  transform: translate(100px, 50px) rotate(45deg) scale(1.5);
}
```

## 2. Transition 속성 ⏱️

### 2.1 개념 및 특징

**Transition**은 CSS 속성값이 변경될 때 부드러운 전환 효과를 제공합니다.

**핵심 특징:**

- 상태 변화가 있어야 작동 (예: hover, focus, class 변경)
- 기존값이 이미 적용되어 있어야 함
- JavaScript 없이 간단한 애니메이션 구현 가능

📖 **출처:** MDN Web Docs - CSS Transitions

### 2.2 문법 구조

```css
transition: [property] [duration] [timing-function] [delay];
```

**각 값의 의미:**

1. **property** (속성): 전환 효과를 적용할 CSS 속성
   - `all`: 모든 변경 가능한 속성
   - 특정 속성명: `background-color`, `transform` 등
2. **duration** (지속시간): 전환이 완료되는 시간
   - 단위: `s` (초) 또는 `ms` (밀리초)
   - 예시: `0.5s`, `500ms`
3. **timing-function** (시간 함수): 전환 속도 곡선
   - `linear`: 일정한 속도
   - `ease`: 천천히 시작, 빠르게, 천천히 끝 (기본값)
   - `ease-in`: 천천히 시작
   - `ease-out`: 천천히 끝
   - `ease-in-out`: 천천히 시작하고 끝
   - `cubic-bezier(n,n,n,n)`: 사용자 정의 곡선
4. **delay** (지연시간): 전환 시작 전 대기 시간
   - 단위: `s` 또는 `ms`

### 2.3 사용 예시

**기본 hover 효과:**

```css
.button {
  background-color: blue;
  /* 모든 속성에 0.3초 동안 ease 효과 적용 */
  transition: all 0.3s ease;
}

.button:hover {
  background-color: red;
  transform: scale(1.1);
}
```

**여러 속성에 개별 전환 적용:**

```css
.box {
  width: 100px;
  height: 100px;
  background-color: blue;
  /* 쉼표로 구분하여 각 속성에 다른 전환 설정 */
  transition:
    width 0.5s ease,
    height 1s linear,
    background-color 0.3s ease-in-out;
}

.box:hover {
  width: 200px;
  height: 150px;
  background-color: red;
}
```

**주의사항 예시:**

```css
/* ❌ 잘못된 사용 - 초기값이 없음 */
.box {
  transition: transform 0.3s;
}
.box:hover {
  transform: scale(1.2); /* 초기 transform 값이 없어서 효과가 이상할 수 있음 */
}

/* ✅ 올바른 사용 - 초기값 설정 */
.box {
  transform: scale(1); /* 초기값 명시 */
  transition: transform 0.3s;
}
.box:hover {
  transform: scale(1.2);
}
```

## 3. Animation 속성 🎬

### 3.1 개념 및 특징

**Animation**은 JavaScript 없이 복잡한 애니메이션을 구현할 수 있는 CSS 기능입니다.

**Transition과의 차이점:**

| 구분   | Transition                | Animation               |
| ------ | ------------------------- | ----------------------- |
| 트리거 | 상태 변화 필요 (hover 등) | 자동 실행 가능          |
| 제어   | 시작과 끝만 정의          | 중간 단계 세밀하게 제어 |
| 반복   | 불가능                    | 반복 가능               |
| 복잡도 | 간단한 효과               | 복잡한 애니메이션       |

📖 **출처:** MDN Web Docs - CSS Animations

### 3.2 @keyframes 정의

**기본 문법:**

```css
@keyframes 애니메이션이름 {
  from {
    /* 시작 상태 (0%) */
  }
  to {
    /* 끝 상태 (100%) */
  }
}
```

**퍼센트를 사용한 세밀한 제어:**

```css
@keyframes 애니메이션이름 {
  0% {
    /* 시작 */
  }
  25% {
    /* 1/4 지점 */
  }
  50% {
    /* 중간 */
  }
  75% {
    /* 3/4 지점 */
  }
  100% {
    /* 끝 */
  }
}
```

### 3.3 Animation 속성

```css
.element {
  /* 개별 속성으로 설정 */
  animation-name: 애니메이션이름;
  animation-duration: 2s;
  animation-timing-function: linear;
  animation-delay: 1s;
  animation-iteration-count: 3;
  animation-direction: alternate;
  animation-fill-mode: forwards;

  /* 단축 속성 */
  animation: 이름 시간 함수 지연 반복 방향 채우기모드;
}
```

**주요 속성 설명:**

1. **animation-name** : 사용할 @keyframes 이름
2. **animation-duration** : 한 사이클 완료 시간
3. **animation-timing-function** : 속도 곡선 (transition과 동일)
4. **animation-delay** : 시작 전 대기 시간
5. **animation-iteration-count** : 반복 횟수

- 숫자: 해당 횟수만큼 반복
- `infinite`: 무한 반복

1. **animation-direction** : 진행 방향

- `normal`: 정방향 (기본값)
- `reverse`: 역방향
- `alternate`: 정방향 → 역방향 교차
- `alternate-reverse`: 역방향 → 정방향 교차

1. **animation-fill-mode** : 애니메이션 전후 스타일

- `none`: 기본값, 애니메이션 스타일 미적용
- `forwards`: 끝 상태 유지
- `backwards`: 시작 상태 즉시 적용
- `both`: forwards + backwards

### 3.4 실전 예시

**예시 1: 회전하며 이동하는 애니메이션**

```css
@keyframes roll-and-round {
  from {
    left: 36px;
    border-radius: 0;
    transform: scale(1) rotate(0deg);
    opacity: 1;
  }

  to {
    left: 600px;
    border-radius: 100%;
    transform: scale(0.25) rotate(1080deg);
    opacity: 0;
  }
}

#square {
  position: absolute;
  width: 100px;
  height: 100px;
  background-color: red;

  animation: roll-and-round 2s linear 1s infinite alternate;
}
```

**예시 2: 로딩 스피너**

```css
@keyframes spin {
  from {
    transform: rotate(0deg);
  }
  to {
    transform: rotate(360deg);
  }
}

.spinner {
  width: 50px;
  height: 50px;
  border: 5px solid #f3f3f3;
  border-top: 5px solid #3498db;
  border-radius: 50%;
  animation: spin 1s linear infinite;
}
```

**예시 3: 펄스 효과**

```css
@keyframes pulse {
  0% {
    transform: scale(1);
    opacity: 1;
  }
  50% {
    transform: scale(1.1);
    opacity: 0.8;
  }
  100% {
    transform: scale(1);
    opacity: 1;
  }
}

.button {
  animation: pulse 2s ease-in-out infinite;
}
```

## 4. 반응형 웹 📱💻

### 4.1 적응형 vs 반응형

**비교표:**

| 구분        | 적응형 (Adaptive)                          | 반응형 (Responsive)                  |
| ----------- | ------------------------------------------ | ------------------------------------ |
| 방식        | 화면 크기별 별도 페이지                    | 하나의 페이지가 유동적으로 변화      |
| 예시        | 네이버 ([m.naver.com](http://m.naver.com)) | 애플 ([apple.com](http://apple.com)) |
| 장점        | 각 디바이스에 최적화된 경험 제공           | 하나의 코드로 모든 크기 대응         |
| 단점        | 개발/유지보수 비용 높음                    | 복잡한 레이아웃 구현 어려움          |
| 적합한 경우 | 모바일/데스크톱이 완전히 다른 UX           | 비슷한 콘텐츠를 다양한 화면에 표시   |

📖 **출처:** 웹 개발 표준 관행

### 4.2 미디어 쿼리 (Media Query)

**미디어 쿼리**는 화면 크기, 해상도, 방향 등의 조건에 따라 다른 CSS를 적용하는 기능입니다.

**기본 문법:**

```css
@media 미디어타입 and (조건) {
  /* 조건이 참일 때 적용할 CSS */
}
```

### 4.3 주요 미디어 타입

- `all`: 모든 디바이스 (기본값)
- `screen`: 화면이 있는 디바이스
- `print`: 인쇄 미리보기/인쇄
- `speech`: 화면 읽기 프로그램

### 4.4 주요 조건 (Media Features)

**화면 크기 관련:**

- `width`, `min-width`, `max-width`: 뷰포트 너비
- `height`, `min-height`, `max-height`: 뷰포트 높이

**기타:**

- `orientation`: 화면 방향 (`portrait` 또는 `landscape`)
- `resolution`: 화면 해상도

### 4.5 일반적인 브레이크포인트

```css
/* 모바일 (기본 스타일) */
.element {
  width: 100%;
}

/* 저해상도 태블릿 (576px 이상) */
@media (min-width: 576px) {
  .element {
    width: 80%;
  }
}

/* 태블릿 세로 (768px 이상) */
@media (min-width: 768px) {
  .element {
    width: 750px;
  }
}

/* 저해상도 PC (992px 이상) */
@media (min-width: 992px) {
  .element {
    width: 970px;
  }
}

/* 일반 PC (1200px 이상) */
@media (min-width: 1200px) {
  .element {
    width: 1170px;
  }
}
```

### 4.6 실전 예시

**모바일 우선 접근법:**

```css
/* 모바일 스타일 (기본) */
.container {
  padding: 10px;
}

.sidebar {
  display: none; /* 모바일에서는 사이드바 숨김 */
}

.content {
  width: 100%;
}

/* 태블릿 이상 */
@media (min-width: 768px) {
  .container {
    padding: 20px;
  }

  .sidebar {
    display: block;
    width: 200px;
    float: left;
  }

  .content {
    width: calc(100% - 220px);
    float: right;
  }
}

/* 데스크톱 */
@media (min-width: 1024px) {
  .container {
    max-width: 1200px;
    margin: 0 auto;
  }

  .sidebar {
    width: 300px;
  }

  .content {
    width: calc(100% - 320px);
  }
}
```

**화면 방향에 따른 스타일:**

```css
/* 가로 모드 */
@media (orientation: landscape) {
  .header {
    height: 60px;
  }
}

/* 세로 모드 */
@media (orientation: portrait) {
  .header {
    height: 80px;
  }
}
```

**여러 조건 조합:**

```css
/* 768px 이상이면서 가로 모드일 때 */
@media (min-width: 768px) and (orientation: landscape) {
  .gallery {
    grid-template-columns: repeat(4, 1fr);
  }
}

/* 768px 미만이거나 세로 모드일 때 */
@media (max-width: 767px), (orientation: portrait) {
  .gallery {
    grid-template-columns: repeat(2, 1fr);
  }
}
```

## 5. 📝 핵심 요약

### Transform

- 주변 레이아웃에 영향 없이 요소의 시각적 변형 가능
- `translate()`, `scale()`, `rotate()`, `skew()` 함수 사용
- 중앙 배치에 자주 활용: `transform: translate(-50%, -50%);`

### Transition

- CSS 속성값 변경 시 부드러운 전환 효과 제공
- 문법: `transition: property duration timing-function delay;`
- **기존값이 있어야 작동**하며, 상태 변화(hover 등)가 필요

### Animation

- `@keyframes`로 복잡한 애니메이션 정의
- 자동 실행, 반복, 중간 단계 제어 가능
- 주요 속성: name, duration, timing-function, delay, iteration-count, direction, fill-mode

### 반응형 웹

- **적응형** : 화면별 별도 페이지 / **반응형** : 하나의 페이지가 유동적 변화
- 미디어 쿼리로 화면 크기별 스타일 적용
- 모바일 우선 접근법 권장: 작은 화면부터 스타일 작성

## 6. 🎯 복습 퀴즈

### 퀴즈 1

다음 중 transform 속성의 특징으로 올바른 것은?

A) 주변 요소들의 레이아웃을 변경한다
B) JavaScript가 필수적으로 필요하다
C) 주변 요소들에 영향을 주지 않으면서 요소의 모습을 바꾼다
D) animation 속성과 함께 사용할 수 없다

정답: C
해설: transform 속성은 주변 요소들의 레이아웃에 영향을 주지 않으면서 요소의 시각적 모습만을 변경합니다. 이는 문서의 흐름을 방해하지 않으면서도 시각적 효과를 줄 수 있는 장점이 있습니다.

### 퀴즈 2

transition 속성이 올바르게 작동하기 위한 필수 조건은?

A) JavaScript 이벤트 리스너가 있어야 한다
B) 적용할 CSS 속성의 기존값이 이미 정의되어 있어야 한다
C) animation 속성과 함께 사용되어야 한다
D) @keyframes 규칙이 정의되어 있어야 한다

정답: B
해설: transition은 CSS 속성값의 변화를 부드럽게 전환하는 기능이므로, 변화의 시작점이 되는 기존값이 반드시 정의되어 있어야 합니다. 기존값이 없으면 어디서부터 전환을 시작해야 할지 알 수 없습니다.

### 퀴즈 3

`animation-iteration-count: infinite;`의 의미는?

A) 애니메이션이 3번 반복된다
B) 애니메이션이 무한히 반복된다
C) 애니메이션이 역방향으로 재생된다
D) 애니메이션이 한 번만 재생된다

정답: B
해설: `infinite` 값은 애니메이션이 무한히 반복되도록 설정합니다. 숫자를 지정하면 해당 횟수만큼만 반복되지만, infinite를 사용하면 페이지가 열려있는 동안 계속 반복됩니다.

### 퀴즈 4

다음 중 transition과 animation의 차이점으로 올바른 것은?

A) transition은 자동으로 실행되지만 animation은 트리거가 필요하다
B) animation은 중간 단계를 세밀하게 제어할 수 있지만 transition은 시작과 끝만 정의한다
C) transition은 반복이 가능하지만 animation은 불가능하다
D) animation은 간단한 효과에만 사용되고 transition은 복잡한 애니메이션에 사용된다

정답: B
해설: animation은 @keyframes를 통해 0%부터 100%까지의 모든 중간 단계를 퍼센트 단위로 세밀하게 제어할 수 있습니다. 반면 transition은 시작 상태와 끝 상태만 정의하고, 그 사이는 자동으로 보간됩니다.

### 퀴즈 5

반응형 웹과 적응형 웹에 대한 설명으로 올바른 것은?

A) 반응형 웹은 화면 크기별로 별도의 페이지를 만든다
B) 적응형 웹은 하나의 페이지가 유동적으로 변화한다
C) 반응형 웹은 하나의 코드로 여러 화면 크기에 대응할 수 있다
D) 네이버는 반응형 웹의 대표적인 예시다

정답: C
해설: 반응형 웹은 하나의 HTML/CSS 코드로 다양한 화면 크기에 자동으로 적응하는 방식입니다. 미디어 쿼리를 사용하여 화면 크기에 따라 레이아웃이 유동적으로 변화합니다. 적응형 웹은 화면별로 별도 페이지를 만드는 방식이며, 네이버([m.naver.com](http://m.naver.com))가 이에 해당합니다.

### 퀴즈 6

미디어 쿼리 `@media (min-width: 768px)`의 의미는?

A) 화면 너비가 768px 이하일 때 적용
B) 화면 너비가 정확히 768px일 때만 적용
C) 화면 너비가 768px 이상일 때 적용
D) 화면 높이가 768px 이상일 때 적용

정답: C
해설: `min-width`는 "최소 너비"를 의미하므로, 화면 너비가 지정된 값(768px) 이상일 때 해당 스타일이 적용됩니다. 즉, 768px부터 그 이상의 모든 화면 크기에서 적용됩니다.

### 문제 1: Transform으로 카드 뒤집기 효과 만들기

다음 기본 코드에 transform을 추가하여 카드에 마우스를 올리면 뒤집히는 효과를 구현하세요.

**기본 코드:**

```html
<!DOCTYPE html>
<html lang="ko">
  <head>
    <meta charset="UTF-8" />
    <meta name="viewport" content="width=device-width, initial-scale=1.0" />
    <title>카드 뒤집기</title>
    <style>
      .card {
        width: 200px;
        height: 300px;
        background-color: #3498db;
        display: flex;
        align-items: center;
        justify-content: center;
        color: white;
        font-size: 24px;
        cursor: pointer;
        /* 여기에 코드 추가 */
      }

      .card:hover {
        /* 여기에 코드 추가 */
      }
    </style>
  </head>
  <body>
    <div class="card">카드</div>
  </body>
</html>
```

**정답:**

```css
.card {
  width: 200px;
  height: 300px;
  background-color: #3498db;
  display: flex;
  align-items: center;
  justify-content: center;
  color: white;
  font-size: 24px;
  cursor: pointer;
  transition: transform 0.6s;
  transform: rotateY(0deg);
}

.card:hover {
  transform: rotateY(180deg);
}
```

**해설:**

- `rotateY()` 함수를 사용하여 Y축을 기준으로 카드를 회전시킵니다
- 초기값을 `rotateY(0deg)`로 설정하여 transition이 올바르게 작동하도록 합니다
- hover 시 180도 회전하여 뒤집히는 효과를 만듭니다
- `transition: transform 0.6s`로 부드러운 전환 효과를 줍니다

### 문제 2: 로딩 애니메이션 만들기

점 3개가 순차적으로 위아래로 움직이는 로딩 애니메이션을 구현하세요.

**기본 코드:**

```html
<!DOCTYPE html>
<html lang="ko">
  <head>
    <meta charset="UTF-8" />
    <meta name="viewport" content="width=device-width, initial-scale=1.0" />
    <title>로딩 애니메이션</title>
    <style>
      .loading {
        display: flex;
        gap: 10px;
      }

      .dot {
        width: 15px;
        height: 15px;
        background-color: #3498db;
        border-radius: 50%;
        /* 여기에 애니메이션 추가 */
      }

      /* 각 점에 지연시간 다르게 적용 */
      .dot:nth-child(2) {
        /* 여기에 코드 추가 */
      }

      .dot:nth-child(3) {
        /* 여기에 코드 추가 */
      }

      /* 여기에 @keyframes 추가 */
    </style>
  </head>
  <body>
    <div class="loading">
      <div class="dot"></div>
      <div class="dot"></div>
      <div class="dot"></div>
    </div>
  </body>
</html>
```

**정답:**

```css
.loading {
  display: flex;
  gap: 10px;
}

.dot {
  width: 15px;
  height: 15px;
  background-color: #3498db;
  border-radius: 50%;
  animation: bounce 1.4s infinite ease-in-out;
}

.dot:nth-child(2) {
  animation-delay: 0.2s;
}

.dot:nth-child(3) {
  animation-delay: 0.4s;
}

@keyframes bounce {
  0%,
  80%,
  100% {
    transform: translateY(0);
  }
  40% {
    transform: translateY(-20px);
  }
}
```

**해설:**

- `@keyframes bounce`로 위아래로 움직이는 애니메이션을 정의합니다
- 0%, 80%, 100%에서 원위치, 40%에서 위로 20px 이동하여 통통 튀는 효과를 만듭니다
- `animation-delay`로 각 점마다 0.2초씩 지연시켜 순차적으로 움직이게 합니다
- `infinite`로 무한 반복되도록 설정합니다
- `ease-in-out`으로 부드러운 속도 변화를 줍니다

- 가로 메뉴에서는 `border-right`로 구분선을 변경하고, 마지막 항목의 border는 제거합니다

### 문제 4: 버튼 호버 효과 종합 연습

transition과 transform을 활용하여 버튼에 다양한 호버 효과를 구현하세요.

**기본 코드:**

```html
<!DOCTYPE html>
<html lang="ko">
  <head>
    <meta charset="UTF-8" />
    <meta name="viewport" content="width=device-width, initial-scale=1.0" />
    <title>버튼 효과</title>
    <style>
      body {
        display: flex;
        gap: 20px;
        padding: 50px;
        background-color: #ecf0f1;
      }

      button {
        padding: 15px 30px;
        font-size: 16px;
        border: none;
        cursor: pointer;
        background-color: #3498db;
        color: white;
        border-radius: 5px;
      }

      /* 버튼 1: 크기가 커지는 효과 */
      .btn1 {
        /* 여기에 코드 추가 */
      }

      .btn1:hover {
        /* 여기에 코드 추가 */
      }

      /* 버튼 2: 위로 떠오르는 효과 + 그림자 */
      .btn2 {
        /* 여기에 코드 추가 */
      }

      .btn2:hover {
        /* 여기에 코드 추가 */
      }

      /* 버튼 3: 회전하며 색 변경 */
      .btn3 {
        /* 여기에 코드 추가 */
      }

      .btn3:hover {
        /* 여기에 코드 추가 */
      }
    </style>
  </head>
  <body>
    <button class="btn1">확대 효과</button>
    <button class="btn2">떠오르는 효과</button>
    <button class="btn3">회전 효과</button>
  </body>
</html>
```

**정답:**

```css
body {
  display: flex;
  gap: 20px;
  padding: 50px;
  background-color: #ecf0f1;
}

button {
  padding: 15px 30px;
  font-size: 16px;
  border: none;
  cursor: pointer;
  background-color: #3498db;
  color: white;
  border-radius: 5px;
}

/* 버튼 1: 크기가 커지는 효과 */
.btn1 {
  transform: scale(1);
  transition: transform 0.3s ease;
}

.btn1:hover {
  transform: scale(1.1);
}

/* 버튼 2: 위로 떠오르는 효과 + 그림자 */
.btn2 {
  transform: translateY(0);
  box-shadow: 0 2px 5px rgba(0, 0, 0, 0.2);
  transition: all 0.3s ease;
}

.btn2:hover {
  transform: translateY(-5px);
  box-shadow: 0 8px 15px rgba(0, 0, 0, 0.3);
}

/* 버튼 3: 회전하며 색 변경 */
.btn3 {
  transform: rotate(0deg);
  background-color: #3498db;
  transition: all 0.5s ease;
}

.btn3:hover {
  transform: rotate(360deg);
  background-color: #e74c3c;
}
```

**해설:**

- 버튼 1: `scale()`로 크기를 10% 증가시킵니다. 초기값 `scale(1)` 설정이 중요합니다
- 버튼 2: `translateY()`로 위로 5px 이동시키고, box-shadow를 변경하여 떠오르는 효과를 만듭니다. `transition: all`로 모든 속성 변화를 부드럽게 처리합니다
- 버튼 3: `rotate(360deg)`로 한 바퀴 회전시키며 동시에 배경색을 변경합니다. 지속시간을 0.5s로 길게 설정하여 효과를 더 잘 보이게 합니다
- 모든 버튼에 초기 transform 값을 설정하여 transition이 올바르게 작동하도록 합니다
