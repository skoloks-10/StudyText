## 1. 테이블 스타일링

### 1.1 테이블 테두리 관련 속성

### 1.1.1 border-collapse

**개념:**
인접한 `td` 요소들 간 또는 `table`과 `td` 간 테두리를 분리할지(separate) 또는 공유할지(collapse)를 지정하는 속성입니다.

**문법:**

```css
table {
  border-collapse: separate; /* 기본값: 테두리 분리 */
  border-collapse: collapse; /* 테두리 공유 */
}
```

**사용 상황:**

- `separate`: 각 셀의 테두리를 독립적으로 표시하고 싶을 때
- `collapse`: 인접한 셀들의 테두리를 하나로 합쳐 깔끔하게 표시하고 싶을 때

**예시 코드:**

```css
table {
  border-collapse: collapse;
  border: 2px solid gray;
}

th,
td {
  border: 1px solid lightgray;
  padding: 8px;
}
```

### 1.1.2 border-spacing

**개념:**`border-collapse`가 `separate`일 때 인접한 테두리들 간의 간격을 지정합니다. 과거 HTML의 `cellspacing` 속성을 대체하는 CSS 속성입니다.

**문법:**

```css
table {
  border-collapse: separate;
  border-spacing: 10px; /* 모든 방향 */
  border-spacing: 10px 5px; /* 가로 세로 */
}
```

**사용 상황:**

- 테이블 셀 사이에 공간을 두어 시각적 분리를 원할 때
- `border-collapse: separate`와 함께 사용해야 효과가 나타남

**예시 코드:**

```css
table {
  border-collapse: separate;
  border-spacing: 0.5em;
  border: 1px solid black;
}
```

### 1.2 테이블 레이아웃 속성

### 1.2.1 caption-side

**개념:**
테이블 캡션(`<caption>` 요소)의 위치를 지정하는 속성입니다.

**문법:**

```css
table {
  caption-side: top; /* 기본값: 테이블 위 */
  caption-side: bottom; /* 테이블 아래 */
}
```

**사용 상황:**

- 테이블의 제목이나 설명을 테이블 상단 또는 하단에 배치할 때

### 1.2.2 table-layout

**개념:**
표와 칸의 크기가 결정되는 알고리즘을 선택하는 속성입니다.

**문법:**

```css
table {
  table-layout: auto; /* 기본값: 내용에 따라 자동 조절 */
  table-layout: fixed; /* 고정 너비 알고리즘 */
}
```

**사용 상황:**

- `auto`: 셀 내용에 따라 열 너비가 자동으로 조절되어야 할 때
- `fixed`: 테이블 너비를 고정하고 균등하게 분배하거나, 첫 행의 너비를 기준으로 고정할 때 (렌더링 속도가 빠름)

**예시 코드:**

```css
table {
  width: 600px;
  table-layout: fixed;
}

th,
td {
  border: 1px solid gray;
}
```

### 1.3 열(Column) 스타일링

### colgroup과 col 활용

**개념:**`<colgroup>` 내의 `<col>` 요소에 CSS 속성을 부여하여 n번째 열들의 스타일을 일괄 지정할 수 있습니다.

**사용 상황:**

- 특정 열의 너비를 지정하고 싶을 때
- 특정 열에만 배경색이나 스타일을 적용하고 싶을 때

**예시 코드:**

```html
<table>
  <colgroup>
    <col />
    <col />
    <col />
  </colgroup>
  <tr>
    <th>A</th>
    <th>B</th>
    <th>C</th>
  </tr>
  <tr>
    <td>D</td>
    <td>E</td>
    <td>F</td>
  </tr>
</table>
```

```css
colgroup col:first-child {
  width: 300px;
}
```

### 1.4 테이블 요소의 display 속성

**개념:**
테이블 관련 요소들은 각각의 역할에 맞는 특수한 내부 display 속성이 기본적으로 부여됩니다.

**주요 display 값:**

- `table`: `<table>` 요소의 기본값
- `table-row-group`: `<tbody>` 요소의 기본값
- `table-row`: `<tr>` 요소의 기본값
- `table-cell`: `<th>`, `<td>` 요소의 기본값

**사용 상황:**

- 일반 div나 다른 요소를 테이블처럼 동작하게 만들고 싶을 때
- 반응형 디자인에서 테이블을 block으로 변경하고 싶을 때

**참고:** [MDN - CSS display 속성](https://developer.mozilla.org/ko/docs/Web/CSS/display)

## 2. 텍스트 심화 속성

### 2.1 vertical-align 속성

### 2.1.1 inline 요소 안에서의 사용

**개념:**
인라인 요소들의 세로 정렬을 제어하는 속성입니다. 텍스트, 인풋, 이미지 등이 나란히 배치될 때 세로 위치를 조정합니다.

**문법:**

```css
img,
input,
button {
  vertical-align: baseline; /* 기본값 */
  vertical-align: top;
  vertical-align: middle;
  vertical-align: bottom;
  vertical-align: text-top;
  vertical-align: text-bottom;
  vertical-align: sub;
  vertical-align: super;
  vertical-align: 10px; /* 숫자값 */
}
```

**사용 상황:**

- 텍스트와 아이콘, 이미지를 정렬할 때
- 인라인 요소들의 기준선을 맞출 때
- 아래첨자, 위첨자 효과를 낼 때

**예시 코드:**

```css
input[type="text"],
button,
img {
  vertical-align: middle;
}
```

**참고:** [MDN - vertical-align (inline)](https://developer.mozilla.org/ko/docs/Web/CSS/vertical-align)

### 2.1.2 table-cell 요소 안에서의 사용

**개념:**
테이블 셀(`<td>`, `<th>`) 내부 컨텐츠의 세로 정렬을 제어합니다.

**문법:**

```css
td {
  vertical-align: middle; /* 기본값 */
  vertical-align: top;
  vertical-align: bottom;
  vertical-align: baseline;
}
```

**사용 상황:**

- 테이블 셀 안의 텍스트를 상단, 중앙, 하단에 배치할 때
- 셀 높이가 다를 때 컨텐츠 정렬을 통일하고 싶을 때

**참고:** [MDN - vertical-align (table-cell)](https://developer.mozilla.org/ko/docs/Web/CSS/vertical-align)

### 2.2 white-space 속성

**개념:**
요소 내의 공백(스페이스, 탭)과 줄바꿈이 처리되는 방식을 지정하는 속성입니다.

**문법:**

```css
div {
  white-space: normal; /* 기본값: 공백 병합, 자동 줄바꿈 */
  white-space: nowrap; /* 공백 병합, 줄바꿈 안함 */
  white-space: pre; /* 공백 유지, 줄바꿈 유지 */
  white-space: pre-wrap; /* 공백 유지, 자동 줄바꿈 */
  white-space: pre-line; /* 공백 병합, 줄바꿈 유지 */
}
```

**주요 값 비교:**

| 값       | 공백/탭 | 줄바꿈 | 자동 줄바꿈 |
| -------- | ------- | ------ | ----------- |
| normal   | 병합    | 무시   | O           |
| nowrap   | 병합    | 무시   | X           |
| pre      | 유지    | 유지   | X           |
| pre-wrap | 유지    | 유지   | O           |
| pre-line | 병합    | 유지   | O           |

**사용 상황:**

- 한 줄로 표시하고 싶을 때: `nowrap`
- 코드나 시를 원본 형식 그대로 표시하고 싶을 때: `pre`
- 긴 텍스트를 보기 좋게 줄바꿈하면서도 원본 줄바꿈을 유지하고 싶을 때: `pre-wrap`

**예시 코드:**

```css
.code-block {
  white-space: pre;
  font-family: monospace;
}

.single-line {
  white-space: nowrap;
  overflow: hidden;
}
```

**참고:** [MDN - white-space](https://developer.mozilla.org/ko/docs/Web/CSS/white-space)

### 2.3 text-overflow 속성

**개념:**
텍스트가 컨테이너의 너비를 넘어갈 때 어떻게 표시될지를 지정하는 속성입니다.

**필수 조건:**

- `overflow: hidden` 또는 `scroll`
- `white-space: nowrap`

**문법:**

```css
div {
  text-overflow: clip; /* 기본값: 잘림 */
  text-overflow: ellipsis; /* ... 표시 */
}
```

**사용 상황:**

- 한 줄로 제한된 제목이나 라벨에서 긴 텍스트를 `...`으로 표시할 때
- 테이블 셀이나 카드 UI에서 텍스트 오버플로우를 처리할 때

**예시 코드:**

```css
.text-truncate {
  width: 300px;
  overflow: hidden;
  white-space: nowrap;
  text-overflow: ellipsis;
}
```

## 3. Float 속성

### 3.1 float과 clear 속성

### 3.1.1 float 속성

**개념:**
요소를 일반적인 문서 흐름에서 제거하고 좌측 또는 우측으로 '띄워' 배치하는 속성입니다. Float된 요소는 블록 요소의 자리를 차지하지 않지만, 텍스트와 인라인 요소는 float 요소를 피해 배치됩니다.

**문법:**

```css
.element {
  float: none; /* 기본값 */
  float: left; /* 왼쪽으로 띄움 */
  float: right; /* 오른쪽으로 띄움*/
}
```

**Float의 특징:**

1. 요소가 '붕 뜬' 상태가 되어 일반 블록 요소의 자리를 차지하지 않음
2. 다음에 오는 블록 요소가 float 요소 아래로 들어감
3. 텍스트와 인라인 요소는 float 요소에 밀려남
4. 인라인 요소에 float을 적용하면 블록처럼 동작 (width, height 적용 가능)

**사용 상황:**

- 이미지 주위로 텍스트를 감싸고 싶을 때
- 과거에는 페이지 레이아웃에 사용되었으나, 현재는 Flexbox나 Grid 사용 권장

**예시 코드:**

```css
.image-left {
  float: left;
  margin-right: 20px;
}

.sidebar {
  float: right;
  width: 300px;
}
```

### 3.1.2 clear 속성

**개념:**
이전 형제 요소에 적용된 float의 효과를 해제하여, float 요소 밑으로 들어가지 않고 그 아래로 빠져나오게 하는 속성입니다.

**문법:**

```css
.element {
  clear: none; /* 기본값 */
  clear: left; /* 왼쪽 float 해제 */
  clear: right; /* 오른쪽 float 해제 */
  clear: both; /* 양쪽 float 모두 해제 */
}
```

**사용 상황:**

- Float된 요소들 다음에 오는 요소를 float 영향 없이 배치하고 싶을 때
- 푸터 등을 float된 컨텐츠 아래에 확실히 배치하고 싶을 때

**예시 코드:**

```css
.blue {
  float: left;
}
.red {
  float: left;
}
.footer {
  clear: both;
}
```

### 3.2 Float 사용 시 부모 요소의 높이 문제

**문제:**
Float 요소는 공간을 차지하지 않으므로, 부모 요소가 자식의 float 요소를 인지하지 못해 높이가 0이 되는 문제가 발생합니다.

**해결 방법:**

1. **부모에 overflow 속성 적용**

```css
.parent {
  overflow: auto; /* 또는 hidden */
}
```

1. **Clearfix 기법 (::after 가상 요소 활용)**

```css
.parent::after {
  content: "";
  display: block;
  clear: both;
}
```

1. **부모도 float 적용**

```css
.parent {
  float: left;
  width: 100%;
}
```

**사용 상황:**

- Float된 자식 요소들을 감싸는 부모 요소의 높이를 확보해야 할 때
- 배경색이나 테두리가 float 요소까지 적용되어야 할 때

## 4. Grid 레이아웃

**개념:**
CSS Grid는 2차원(행과 열) 레이아웃 시스템으로, 복잡한 웹 페이지 레이아웃을 쉽게 구성할 수 있게 해주는 강력한 도구입니다.

### 4.1 부모 컨테이너 속성

### 4.1.1 display: grid

**개념:**
요소를 그리드 컨테이너로 만드는 속성입니다.

**문법:**

```css
.container {
  display: grid; /* 블록 레벨 그리드 */
  display: inline-grid; /* 인라인 레벨 그리드 */
}
```

### 4.1.2 grid-template-columns / grid-template-rows

**개념:**
그리드의 열(column)과 행(row)의 크기를 정의하는 속성입니다.

**문법:**

```css
.container {
  grid-template-columns: 200px 1fr 300px; /* 3개의 열 */
  grid-template-rows: 100px auto 200px; /* 3개의 행 */
}
```

**단위:**

- `px`: 고정 크기
- `fr`: 비율 단위 (fraction, 남은 공간을 비율로 분배)
- `%`: 백분율
- `auto`: 내용에 맞춰 자동 크기
- `minmax(최소, 최대)`: 최소/최대 크기 지정
- `repeat(반복횟수, 크기)`: 패턴 반복

**사용 상황:**

- 페이지를 여러 개의 열과 행으로 나누어 레이아웃을 구성할 때
- 반응형 레이아웃에서 `fr` 단위로 유연한 크기 조절이 필요할 때

**예시 코드:**

```css
.container {
  display: grid;
  grid-template-columns: 200px 1fr 300px;
  grid-template-rows: 80px 200px auto 200px;
}
```

### 4.1.3 gap (grid-gap)

**개념:**
그리드 아이템들 사이의 간격을 지정하는 속성입니다.

**문법:**

```css
.container {
  gap: 20px; /* 행과 열 모두 20px */
  gap: 10px 20px; /* 행 10px, 열 20px */

  /* 개별 지정 */
  row-gap: 10px;
  column-gap: 20px;
}
```

**사용 상황:**

- 그리드 아이템 간 일정한 간격을 주고 싶을 때
- 마진 대신 깔끔하게 간격을 조절하고 싶을 때

### 4.1.4 grid-auto-rows

**개념:**
명시적으로 정의하지 않은 행의 크기를 자동으로 설정하는 속성입니다.

**문법:**

```css
.container {
  grid-auto-rows: 100px; /* 자동 생성되는 행의 높이 */
  grid-auto-rows: minmax(100px, auto); /* 최소 100px */
}
```

**사용 상황:**

- 그리드 아이템이 동적으로 추가될 때
- 일정한 행 높이를 유지하고 싶을 때

### 4.1.5 justify-items / align-items

**개념:**
그리드 아이템들의 가로(justify) 및 세로(align) 정렬을 지정하는 속성입니다.

**문법:**

```css
.container {
  justify-items: stretch; /* 기본값: 가로로 늘림 */
  justify-items: start; /* 시작점 정렬 */
  justify-items: center; /* 중앙 정렬 */
  justify-items: end; /* 끝점 정렬 */

  align-items: stretch; /* 기본값: 세로로 늘림 */
  align-items: start;
  align-items: center;
  align-items: end;
}
```

**사용 상황:**

- 모든 그리드 아이템을 특정 방향으로 정렬하고 싶을 때
- 아이템의 크기가 셀보다 작을 때 정렬이 필요할 때

### 4.2 자식 아이템 속성

### 4.2.1 grid-column / grid-row

**개념:**
그리드 아이템이 차지할 열(column)과 행(row)의 범위를 지정하는 속성입니다.

**문법:**

```css
.item {
  /* 시작 / 끝 */
  grid-column: 1 / 3; /* 1번 라인부터 3번 라인까지 */
  grid-row: 2 / 4;

  /* 시작 / span 개수 */
  grid-column: 1 / span 2; /* 1번부터 2칸 차지 */

  /* -1은 마지막 라인 */
  grid-column: 1 / -1; /* 전체 너비 */
}
```

**사용 상황:**

- 특정 아이템을 여러 칸에 걸쳐 배치하고 싶을 때
- 헤더, 푸터 등을 전체 너비로 만들고 싶을 때
- 복잡한 레이아웃에서 아이템의 위치를 정확히 지정하고 싶을 때

**예시 코드:**

```css
nav {
  grid-column: 1 / -1; /* 전체 너비 */
}

aside {
  grid-column: 1;
  grid-row: 2 / span 2; /* 2번 행부터 2칸 차지 */
}

.sec-1 {
  grid-column: 2 / -1; /* 2번 열부터 마지막까지 */
}
```

### 4.2.2 justify-self / align-self

**개념:**
개별 그리드 아이템의 가로(justify) 및 세로(align) 정렬을 지정하는 속성입니다. 부모의 `justify-items`, `align-items`를 개별 아이템에서 재정의합니다.

**문법:**

```css
.item {
  justify-self: stretch; /* 기본값 */
  justify-self: start;
  justify-self: center;
  justify-self: end;

  align-self: stretch;
  align-self: start;
  align-self: center;
  align-self: end;
}
```

**사용 상황:**

- 특정 아이템만 다르게 정렬하고 싶을 때
- 부모의 정렬 규칙을 개별 아이템에서 재정의하고 싶을 때

**참고:** [MDN - CSS Grid Layout](https://developer.mozilla.org/ko/docs/Web/CSS/CSS_Grid_Layout)

## 핵심 요약

### 테이블 스타일링

- `border-collapse`: 테두리 병합 여부 결정 (collapse/separate)
- `border-spacing`: separate 시 셀 간격 지정
- `table-layout`: 테이블 크기 계산 알고리즘 선택 (auto/fixed)
- `colgroup col`: 특정 열에 스타일 일괄 적용

### 텍스트 심화

- `vertical-align`: 인라인 요소와 테이블 셀의 세로 정렬
- `white-space`: 공백과 줄바꿈 처리 방식 제어 (nowrap, pre, pre-wrap 등)
- `text-overflow`: 텍스트 오버플로우 처리 (ellipsis는 overflow:hidden, white-space:nowrap과 함께 사용)

### Float

- `float`: 요소를 문서 흐름에서 분리하여 좌우로 배치 (left/right)
- `clear`: float 효과 해제 (left/right/both)
- Float된 요소는 부모의 높이 계산에서 제외됨 → clearfix나 overflow로 해결
- 현대 웹에서는 Flexbox, Grid 권장

### Grid 레이아웃

- `display: grid`: 그리드 컨테이너 생성
- `grid-template-columns/rows`: 열/행 크기 정의 (px, fr, auto 등)
- `gap`: 아이템 간 간격
- `justify-items/align-items`: 모든 아이템의 가로/세로 정렬
- `grid-column/row`: 아이템이 차지할 영역 지정
- `justify-self/align-self`: 개별 아이템 정렬

### 문제 1

다음 중 `border-collapse` 속성에 대한 설명으로 올바른 것은?

1. 테이블 셀 간의 간격을 지정하는 속성이다
2. 테이블 캡션의 위치를 지정하는 속성이다
3. 인접한 셀들의 테두리를 분리하거나 공유할지를 결정하는 속성이다
4. 테이블의 너비 계산 방식을 결정하는 속성이다

정답: 3번

해설: `border-collapse`는 테이블의 인접한 셀들 또는 테이블과 셀 간의 테두리를 분리(separate)할지 공유(collapse)할지를 지정하는 속성입니다. 1번은 `border-spacing`, 2번은 `caption-side`, 4번은 `table-layout`에 대한 설명입니다.

### 문제 2

`text-overflow: ellipsis`가 제대로 작동하기 위해 함께 설정해야 하는 속성은?

1. `display: block`과 `margin: auto`
2. `overflow: hidden`과 `white-space: nowrap`
3. `position: relative`와 `z-index: 1`
4. `text-align: center`와 `line-height: 1.5`

정답: 2번

해설: `text-overflow: ellipsis`는 텍스트가 넘칠 때 `...`으로 표시하는 속성입니다. 이 속성이 작동하려면 반드시 `overflow: hidden` (또는 scroll)과 `white-space: nowrap`이 함께 설정되어야 합니다. 이 세 가지 속성이 모두 있어야 한 줄로 제한된 텍스트가 넘칠 때 말줈표로 표시됩니다.

### 문제 3

`white-space` 속성의 값 중 공백을 유지하면서 자동 줄바꿈도 허용하는 값은?

1. `normal`
2. `nowrap`
3. `pre`
4. `pre-wrap`
5. `pre-line`

정답: 4번

해설: `pre-wrap`은 공백과 줄바꿈을 모두 유지하면서 필요시 자동으로 줄바꿈도 허용합니다. `normal`과 `pre-line`은 공백을 병합하고, `pre`는 자동 줄바꿈을 허용하지 않으며, `nowrap`은 줄바꿈 자체를 하지 않습니다.

### 문제 4

Float된 자식 요소들을 가진 부모 요소의 높이가 0이 되는 문제를 해결하는 방법이 아닌 것은?

1. 부모에 `overflow: auto` 적용
2. 부모에 `::after` 가상 요소로 clearfix 적용
3. 부모에 `display: flex` 적용
4. 부모에도 `float` 적용

정답: 3번

해설: `display: flex`를 적용하면 부모가 Flexbox 컨테이너가 되어 자식의 float 속성이 무시되므로, float 문제를 "해결"하는 것이 아니라 float 자체를 사용하지 않게 됩니다. 1, 2, 4번은 모두 float를 유지하면서 부모의 높이 문제를 해결하는 방법입니다.

### 문제 5

Grid 레이아웃에서 `grid-column: 1 / -1`의 의미는?

1. 1번 열만 차지한다
2. 마지막 열만 차지한다
3. 1번 열부터 마지막 열까지 모든 열을 차지한다
4. 1번 열부터 마지막에서 두 번째 열까지 차지한다

정답: 3번

해설: Grid에서 `-1`은 마지막 라인을 의미합니다. 따라서 `grid-column: 1 / -1`은 1번 그리드 라인부터 마지막 그리드 라인까지, 즉 전체 너비를 차지한다는 의미입니다. 이는 헤더나 푸터를 전체 너비로 만들 때 자주 사용되는 패턴입니다.

### 문제 6

`vertical-align` 속성이 적용될 수 있는 요소는?

1. `display: block` 요소
2. `display: inline` 또는 `display: table-cell` 요소
3. `position: absolute` 요소
4. `display: flex` 요소
5. `display: grid` 요소

정답: 2번

해설: `vertical-align`은 인라인 요소(`inline`, `inline-block`)와 테이블 셀(`table-cell`) 요소에만 적용됩니다. 블록 레벨 요소나 Flexbox, Grid의 아이템에는 다른 정렬 방법(Flexbox의 `align-items`, Grid의 `align-items` 등)을 사용해야 합니다.

### 문제 7

다음 중 Grid의 `fr` 단위에 대한 설명으로 올바른 것은?

1. 고정된 픽셀 크기를 나타낸다
2. 부모 요소의 백분율을 나타낸다
3. 남은 공간을 비율로 분배하는 단위이다
4. 최소 크기를 나타내는 단위이다

정답: 3번

해설: `fr`(fraction)은 Grid에서 사용하는 비율 단위로, 남은 공간을 비율에 따라 분배합니다. 예를 들어 `grid-template-columns: 1fr 2fr`은 남은 공간을 1:2 비율로 나눕니다. 1번은 `px`, 2번은 `%`, 4번은 `minmax()` 함수와 관련된 설명입니다.

- sec-3: 3열, 3행
- footer: 전체 너비, 4행

**기본 코드:**

```html
<main>
  <nav>nav</nav>
  <aside>aside</aside>
  <section class="sec-1">.sec-1</section>
  <section class="sec-2">.sec-2</section>
  <section class="sec-3">.sec-3</section>
  <footer>footer</footer>
</main>
```

```css
body {
  margin: 0;
}

main {
  width: 100vw;
}

main > * {
  padding: 0.8em;
  color: slateblue;
  background-color: lavender;
}

/* 여기에 Grid CSS 작성 */
```

**정답:**

```css
body {
  margin: 0;
}

main {
  width: 100vw;
  display: grid;
  grid-template-columns: 200px 1fr 300px;
  grid-template-rows: 80px 200px auto 200px;
  gap: 12px;
}

main > * {
  padding: 0.8em;
  color: slateblue;
  background-color: lavender;
}

nav {
  grid-column: 1 / -1;
}

aside {
  grid-column: 1;
  grid-row: 2 / span 2;
}

.sec-1 {
  grid-column: 2 / -1;
}

.sec-2 {
  grid-column: 2;
  grid-row: 3;
}

.sec-3 {
  grid-column: 3;
  grid-row: 3;
}

footer {
  grid-column: 1 / -1;
}
```

**해설:**

- 3개 열: `200px 1fr 300px` (사이드바-메인-우측 영역)
- 4개 행: `80px 200px auto 200px` (헤더-상단섹션-중간섹션-푸터)
- `gap: 12px`로 요소 간 간격 설정
- `nav`와 `footer`는 `grid-column: 1 / -1`로 전체 너비 차지
- `aside`는 `grid-row: 2 / span 2`로 2행부터 2칸 차지
- `.sec-1`은 `grid-column: 2 / -1`로 2열부터 끝까지 차지
- `.sec-2`와 `.sec-3`는 명시하지 않아도 자동 배치되지만, 명확성을 위해 명시 가능
