# HTML 문서 기초 - 복습자료

## 1. HTML 문서 시작하기

### 1.1 개발 환경 설정

- **에디터** : VS Code 사용
- **폴더 구조** : 파일 → 폴더 열기 → 원하는 폴더 생성 및 지정
- **파일 생성** : index.html 파일 생성

### 1.2 index.html의 특별한 의미

| 항목                        | 설명                                                                                |
| --------------------------- | ----------------------------------------------------------------------------------- |
| **기본 페이지 역할**        | 특정 폴더의 디폴트 페이지로 작동                                                    |
| **URL 접근 방식**           | `www.example.com/folder/`입력 시 자동으로 index.html을 표시                         |
| **다른 HTML 파일과의 차이** | a.html, b.html 등은 `www.example.com/folder/a.html`처럼 파일명을 명시해야 접근 가능 |
| **사용 목적**               | 웹사이트의 홈페이지나 각 디렉토리의 대표 페이지로 활용                              |

### 1.3 HTML 기본 구조 생성

**Emmet 단축키 사용법** :

1. `!` 입력 후 Tab 키 → HTML 기본 틀 자동 생성
2. `lang="en"`을 `lang="ko"`로 수정 (한국어 문서 명시)
3. `<body>` 태그 내부에 페이지 콘텐츠 작성

**lang 속성의 중요성** :

- 접근성 향상 (스크린 리더가 올바른 발음 적용)
- 검색 엔진 최적화 (SEO)
- 적절한 폰트 렌더링

  **실행 방법** : HTML 파일 우클릭 → Open with Live Server

> ⚠️ 주의: 최근 VS Code 버전에서는 일부 Emmet 기능이 제한될 수 있으므로, 작동하지 않는 경우 직접 코드를 작성하세요.

## 2. HTML 기본 태그

### 2.1 제목과 문단 태그

| 태그          | 설명                                | 사용 상황                      | 예시 코드                                 |
| ------------- | ----------------------------------- | ------------------------------ | ----------------------------------------- |
| `<h1>`~`<h6>` | 제목 태그 (숫자가 클수록 낮은 단계) | 문서의 계층 구조를 표현할 때   | `<h1>메인 제목</h1><br>``<h2>부제목</h2>` |
| `<p>`         | 문단 태그                           | 텍스트를 문단 단위로 구분할 때 | `<p>이것은 하나의 문단입니다.</p>`        |

**제목 태그 사용 원칙** :

- h1은 페이지당 하나만 사용 (페이지의 주제)
- 계층을 건너뛰지 않고 순차적으로 사용 (h1 → h2 → h3)
- SEO와 접근성에 중요한 역할

### 2.2 줄바꿈과 구분선

| 태그   | 설명        | 사용 상황                           | 예시 코드          |
| ------ | ----------- | ----------------------------------- | ------------------ |
| `<br>` | 줄바꿈      | 문단 내에서 강제 줄바꿈이 필요할 때 | `첫 줄<br>둘째 줄` |
| `<hr>` | 가로 구분선 | 주제나 섹션을 구분할 때             | `<hr>`             |

**특징** :

- 닫는 태그가 필요 없음 (self-closing tag)
- `<br/>`, `<br />` 형태로도 사용 가능

### 2.3 특수 문자

| 구문     | 설명                      | 사용 상황                         | 예시 코드              |
| -------- | ------------------------- | --------------------------------- | ---------------------- |
| `&nbsp;` | 공백 (Non-Breaking Space) | 연속된 공백을 강제로 표시할 때    | `단어&nbsp;&nbsp;사이` |
| `&lt;`   | < (less than)             | HTML 태그가 아닌 문자로 표시할 때 | `&lt;div&gt;`→`<div>`  |
| `&gt;`   | > (greater than)          | HTML 태그가 아닌 문자로 표시할 때 | `x &gt; 5`→`x > 5`     |

**Entity Name이 필요한 이유** : HTML에서 특별한 의미를 가진 문자를 일반 텍스트로 표시하기 위함

## 3. 텍스트 스타일 태그

### 3.1 강조 태그

> 💡 중요 원칙: HTML 태그는 정보의 종류만 구분하고, 스타일은 CSS로 처리!

| 태그       | 설명                 | 의미적 목적               | 사용 상황                 | 예시 코드                    |
| ---------- | -------------------- | ------------------------- | ------------------------- | ---------------------------- |
| `<strong>` | 중요한 내용 표시     | 의미적 중요도 강조        | 경고, 중요 공지사항       | `<strong>필수 항목</strong>` |
| `<em>`     | 강조할 내용 표시     | 문맥상 강세 표시          | 특정 단어에 강세를 줄 때  | `<em>반드시</em> 확인하세요` |
| `<b>`      | 굵은 글씨 (구버전)   | 시각적 효과만 (의미 없음) | 가능하면 strong 사용 권장 | `<b>굵은 글씨</b>`           |
| `<i>`      | 기울임 글씨 (구버전) | 시각적 효과만 (의미 없음) | 가능하면 em 사용 권장     | `<i>기울임 글씨</i>`         |

**strong vs. em 차이점** :

- `<strong>`: 중요도를 나타냄 (이것은 중요합니다!)
- `<em>`: 문맥상 강조를 나타냄 (이 부분에 주목하세요)

### 3.2 첨자 태그

| 태그    | 설명      | 사용 상황            | 예시 코드                                    |
| ------- | --------- | -------------------- | -------------------------------------------- |
| `<sup>` | 위 첨자   | 지수 표현, 서수 표현 | `x<sup>2</sup>`→ x²`<br>1<sup>st</sup>`→ 1ˢᵗ |
| `<sub>` | 아래 첨자 | 각주, 변수, 화학식   | `H<sub>2</sub>O`→ H₂O`<br>x<sub>1</sub>`→ x₁ |

**사용 예시** :

- 수학: E = mc`<sup>`2`</sup>`
- 화학: CO`<sub>`2`</sub>`
- 각주: 참고문헌`<sup>`1`</sup>`

### 3.3 텍스트 표시 태그

| 태그  | 설명   | 의미적 목적                | 사용 상황         | 예시 코드                  |
| ----- | ------ | -------------------------- | ----------------- | -------------------------- |
| `<u>` | 밑줄   | 철자 오류 표시             | 맞춤법 검사 표시  | `<u>speling</u> 오류`      |
| `<s>` | 취소선 | 더 이상 유효하지 않은 정보 | 할인 전 가격 표시 | `<s>50,000원</s> 30,000원` |

**주의사항** :

- `<u>`는 과거에 단순 밑줄로 사용되었으나, 현재는 의미적 목적만 사용
- 단순 스타일링은 CSS의 `text-decoration` 속성 사용

## 4. 인용문 태그

### 4.1 인용 관련 태그

| 태그           | 설명                  | 사용 상황                         | 속성             | 예시 코드                                                 |
| -------------- | --------------------- | --------------------------------- | ---------------- | --------------------------------------------------------- |
| `<blockquote>` | 긴 인용문 (블록 레벨) | 여러 줄의 인용문을 표시할 때      | `cite`: 출처 URL | `<blockquote cite="https://...">인용문 내용</blockquote>` |
| `<q>`          | 짧은 인용문 (인라인)  | 문장 안에 짧은 인용구를 삽입할 때 | `cite`: 출처 URL | `그는 <q cite="https://...">말했다</q>`                   |
| `<cite>`       | 저작물 출처 표기      | 책, 영화, 노래 등의 제목 표시     | -                | `<cite>해리포터</cite>에서 인용`                          |
| `<mark>`       | 하이라이트 표시       | 검색 결과 강조, 중요 부분 표시    | -                | `검색어: <mark>HTML</mark>`                               |

**blockquote vs. q 차이점** :

- `<blockquote>`: 독립된 블록으로 표시 (앞뒤 줄바꿈)
- `<q>`: 문장 내 인라인으로 표시 (자동으로 따옴표 추가)

  **cite 속성과 cite 태그** :

- `cite` 속성: 인용문의 출처 URL (브라우저에 표시되지 않음)
- `<cite>` 태그: 저작물의 제목을 시각적으로 표시

  **예시** :

```html
<blockquote cite="<https://example.com/article>">
  <p>이것은 긴 인용문입니다.</p>
  <cite>출처: 기사 제목</cite>
</blockquote>
```

## 5. 약어 태그

### 5.1 abbr 태그

| 태그     | 설명               | 사용 상황                    | 속성               | 예시 코드                                             |
| -------- | ------------------ | ---------------------------- | ------------------ | ----------------------------------------------------- |
| `<abbr>` | 준말/머릿글자 표시 | 약어의 원래 형태를 설명할 때 | `title`: 전체 형태 | `<abbr title="HyperText Markup Language">HTML</abbr>` |

**사용 예시** :

  **title 속성의 효과** :

- 마우스를 올리면 툴팁으로 전체 형태 표시
- 스크린 리더가 전체 형태를 읽어줌
- 접근성 향상

## 핵심 개념 요약

### 1. 문서 구조

- **index.html** : 폴더의 기본 페이지
- **lang 속성** : 문서 언어 명시 (접근성, SEO, 폰트)

### 2. 기본 태그

- **제목** : h1~h6 (계층적 사용)

- **줄바꿈** : br (강제 줄바꿈)

- **HTML = 의미** , **CSS = 스타일**
- strong/em (의미 있음) > b/i (의미 없음)

### 4. 텍스트 표현

- **강조** : strong (중요), em (강세)
- **첨자** : sup (위), sub (아래)
- **표시** : u (오류), s (무효)

### 5. 인용과 출처

- **긴 인용** : blockquote
- **짧은 인용** : q
- **출처 표기** : cite
- **하이라이트** : mark

### 6. 특수 처리

- **약어** : abbr + title 속성
- **특수문자** : , <, >
- **주석** : `<!-- -->` (Ctrl/Cmd + /)

## 퀴즈 1: index.html의 역할

**문제** : 다음 중 index.html 파일에 대한 설명으로 올바른 것은?

1. 모든 HTML 파일은 반드시 index.html로 이름을 지어야 한다
2. index.html은 특정 폴더의 기본 페이지로, URL에 파일명을 명시하지 않아도 접근할 수 있다
3. index.html은 다른 HTML 파일보다 로딩 속도가 빠르다
4. index.html은 CSS 파일을 포함할 수 없다

<details>
<summary><strong>정답 및 해설 보기</strong></summary>

**정답** : 2번

**해설** : index.html은 웹 서버에서 특정 폴더의 디폴트 페이지로 인식됩니다. 따라서 `www.example.com/folder/`와 같이 파일명 없이 폴더 경로만 입력해도 자동으로 index.html이 표시됩니다. 다른 파일(예: a.html)은 `www.example.com/folder/a.html`처럼 파일명을 명시해야 접근할 수 있습니다.

</details>

## 퀴즈 2: 의미적 마크업

**문제** : HTML에서 "매우 중요한 경고 메시지"를 표시하려고 합니다. 의미적 마크업 관점에서 가장 적절한 태그는?

1. `<b>매우 중요한 경고 메시지</b>`
2. `<i>매우 중요한 경고 메시지</i>`
3. `<strong>매우 중요한 경고 메시지</strong>`
4. `<em>매우 중요한 경고 메시지</em>`

<details>
<summary><strong>정답 및 해설 보기</strong></summary>

**정답** : 3번

**해설** : `<strong>` 태그는 내용의 중요도를 의미적으로 나타냅니다. `<b>` 태그는 단순히 시각적으로 굵게 표시하는 구버전 태그로 의미가 없으며, `<em>` 태그는 문맥상 강조(강세)를 나타냅니다. 현대 HTML에서는 정보의 의미를 태그로 표현하고, 스타일은 CSS로 처리하는 것이 원칙입니다. 경고처럼 중요한 내용에는 `<strong>`이 적합합니다.

</details>

## 퀴즈 3: 인용문 태그

**문제** : 다음 중 인용문 관련 태그와 그 사용법이 올바르게 연결된 것은?

1. `<cite>` - 긴 인용문을 표시할 때 사용
2. `<blockquote>` - 저작물의 제목을 표시할 때 사용
3. `<q>` - 문장 안에 짧은 인용구를 삽입할 때 사용
4. `<mark>` - 인용문의 출처를 표기할 때 사용

<details>
<summary><strong>정답 및 해설 보기</strong></summary>

**정답** : 3번

**해설** : `<q>` 태그는 문장 내에서 짧은 인용문을 인라인으로 삽입할 때 사용하며, 브라우저가 자동으로 따옴표를 추가합니다. `<blockquote>`는 여러 줄의 긴 인용문에 사용하는 블록 레벨 태그이고, `<cite>`는 책, 영화 등 저작물의 제목을 표기하는 태그입니다. `<mark>`는 인용문 중 하이라이트하거나 검색 결과를 강조할 때 사용합니다.

</details>

## 퀴즈 4: 첨자 태그

**문제** : 화학식 H₂SO₄를 HTML로 올바르게 표현한 것은?

1. `H<sup>2</sup>SO<sup>4</sup>`
2. `H<sub>2</sub>SO<sub>4</sub>`
3. `H<sub>2</sub>SO<sup>4</sup>`
4. `H<sup>2</sup>SO<sub>4</sub>`

<details>
<summary><strong>정답 및 해설 보기</strong></summary>

**정답** : 2번

**해설** : 화학식에서 원자의 개수는 아래 첨자로 표시합니다. `<sub>` 태그는 아래 첨자를 나타내며, 화학식, 각주, 변수 등에 사용됩니다. H₂SO₄는 수소(H) 2개, 황(S) 1개, 산소(O) 4개를 의미하므로 2와 4는 모두 아래 첨자로 표시해야 합니다. 반면 `<sup>` 태그는 위 첨자로, 지수(x²)나 서수(1ˢᵗ) 표현에 사용됩니다.

</details>

## 퀴즈 5: 특수 문자와 Entity

**문제** : HTML 코드를 텍스트로 표시하려고 합니다. `<div>태그</div>`를 화면에 그대로 출력하려면?

1. `<div>태그</div>`
2. `&lt;div&gt;태그&lt;/div&gt;`
3. `\\<div>태그\\</div>`
4. `[div]태그[/div]`

<details>
<summary><strong>정답 및 해설 보기</strong></summary>

**정답** : 2번

**해설** : HTML에서 `<`와 `>`는 태그를 나타내는 특수 문자입니다. 이들을 일반 텍스트로 표시하려면 Entity Name을 사용해야 합니다. `&lt;`는 `<` (less than), `&gt;`는 `>` (greater than)를 나타냅니다. 따라서 `&lt;div&gt;`라고 작성하면 브라우저가 이를 태그로 해석하지 않고 `<div>`라는 텍스트로 표시합니다. 이는 코드 예시를 보여줄 때 필수적입니다.

</details>

## 퀴즈 6: 약어 태그

**문제** : "HTML"이라는 약어에 마우스를 올렸을 때 "HyperText Markup Language"라는 툴팁을 표시하려면?

1. `<abbr>HTML(HyperText Markup Language)</abbr>`
2. `<abbr cite="HyperText Markup Language">HTML</abbr>`
3. `<abbr title="HyperText Markup Language">HTML</abbr>`
4. `<abbr alt="HyperText Markup Language">HTML</abbr>`

<details>

**정답** : 3번

**해설** : `<abbr>` 태그는 준말이나 머릿글자를 표시할 때 사용하며, `title` 속성으로 약어의 전체 형태를 명시합니다. 마우스를 올리면 title 속성의 내용이 툴팁으로 표시되고, 스크린 리더도 이 정보를 읽어줍니다. `cite` 속성은 인용문의 출처 URL에 사용되며, `alt` 속성은 이미지의 대체 텍스트에 사용됩니다. 접근성을 고려할 때 약어는 반드시 title 속성으로 설명을 제공해야 합니다.
