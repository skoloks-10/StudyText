## 1. 글자와 텍스트 스타일

### 1.1 CSS 기본 문법 구조

```css
선택자 {
  속성1: 값;
  속성2: 값;
}
```

CSS는 선택자를 통해 HTML 요소를 지정하고, 중괄호 안에 속성과 값을 작성하여 스타일을 적용합니다.

---

### 1.2 font-style: 글자 기울이기

| 속성      | 설명                      | 사용 상황                          | 예시 코드              |
| --------- | ------------------------- | ---------------------------------- | ---------------------- |
| `normal`  | 기본 상태 (기울이지 않음) | 일반적인 텍스트 표시               | `font-style: normal;`  |
| `italic`  | 기울임 전용 서체 사용     | 강조, 인용, 외래어 표시            | `font-style: italic;`  |
| `oblique` | 기본 서체를 기울임        | italic이 없는 서체에서 기울임 효과 | `font-style: oblique;` |

**중요 포인트:**

- `italic`은 디자인된 '기울임 서체'를 사용
- `oblique`는 원래 서체를 단순히 기울임
- 서체에 해당 스타일이 없으면 상호 교차 사용됨

```css
p {
  font-style: italic; /* 이탤릭 서체 적용 */
}
```

---

### 1.3 font-weight: 글자 굵기

| 속성      | 설명                        | 사용 상황                        | 예시 코드              |
| --------- | --------------------------- | -------------------------------- | ---------------------- |
| `normal`  | 기본 굵기 (400)             | 본문 텍스트                      | `font-weight: normal;` |
| `bold`    | 굵은 글씨 (700)             | 제목, 강조 텍스트                | `font-weight: bold;`   |
| `100-900` | 세밀한 굵기 조절 (100 단위) | 디자인 요구사항에 맞춘 정밀 조절 | `font-weight: 300;`    |

**서체 지원 범위:**

- 서체마다 지원하는 굵기가 다름
- 지원하지 않는 굵기는 가장 가까운 값으로 대체

```css
h1 {
  font-weight: 700; /* 또는 bold */
}

p.light {
  font-weight: 300; /* 얇은 글씨 */
}
```

### 1.4 font-size: 글자 크기

| 단위  | 설명                             | 특징                   | 사용 상황                    | 예시 코드            |
| ----- | -------------------------------- | ---------------------- | ---------------------------- | -------------------- |
| `px`  | 픽셀 단위 (절대값)               | 고정 크기, 정확한 제어 | 정확한 크기 지정이 필요할 때 | `font-size: 16px;`   |
| `%`   | 부모 요소 기준 백분율            | 부모에 따라 변함       | 부모 크기에 비례한 조절      | `font-size: 120%;`   |
| `em`  | 부모 요소 기준 배수 (1em = 100%) | 중첩되면 누적됨        | 부모 크기 기준 상대 조절     | `font-size: 1.5em;`  |
| `rem` | html 요소 기준 배수              | 중첩 영향 없음         | 일관된 상대 크기 조절        | `font-size: 1.2rem;` |
| `pt`  | 포인트 (1인치/72)                | 인쇄 단위              | 프린트용 문서                | `font-size: 12pt;`   |

**em vs rem 차이점:**

```css
html {
  font-size: 14px;
} /* 기본 크기 설정 */
div {
  font-size: 2em;
} /* 부모의 2배 (중첩 시 4배, 8배...) */

/* rem은 항상 html 기준이므로 중첩 무관 */
div {
  font-size: 2rem;
} /* 항상 28px (14px의 2배) */
```

### 1.5 text-decoration: 텍스트 꾸미기

| 속성           | 설명      | 사용 상황        | 예시 코드                              |
| -------------- | --------- | ---------------- | -------------------------------------- |
| `none`         | 장식 없음 | 링크 밑줄 제거   | `text-decoration: none;`               |
| `underline`    | 밑줄      | 강조, 링크 표시  | `text-decoration: underline;`          |
| `line-through` | 취소선    | 삭제된 내용 표시 | `text-decoration: line-through;`       |
| `overline`     | 윗줄      | 특수 강조        | `text-decoration: overline;`           |
| `wavy`         | 물결선    | 오류 표시        | `text-decoration: underline wavy red;` |

**고급 사용법:**

```css
a {
  /* 여러 속성 조합 가능 */
  text-decoration: underline dotted blue 2px;
  /* 스타일: 밑줄, 점선, 파란색, 2px 굵기 */
}
```

### 1.6 text-transform: 대소문자 변환

| 속성         | 설명                   | 사용 상황                  | 예시 코드                     |
| ------------ | ---------------------- | -------------------------- | ----------------------------- |
| `none`       | 원본 유지              | 기본 상태                  | `text-transform: none;`       |
| `capitalize` | 각 단어 첫 글자 대문자 | 제목 스타일                | `text-transform: capitalize;` |
| `uppercase`  | 모두 대문자            | 강조, 로고, 버튼 텍스트    | `text-transform: uppercase;`  |
| `lowercase`  | 모두 소문자            | 이메일 주소, 통일된 스타일 | `text-transform: lowercase;`  |

**주의사항:**

- HTML/CSS 등 원래 대문자인 텍스트는 `capitalize`의 영향을 받지 않음

```css
.button {
  text-transform: uppercase; /* "click me" → "CLICK ME" */
}

.title {
  text-transform: capitalize; /* "hello world" → "Hello World" */
}
```

## 2. 문단과 목록 스타일

### 2.1 text-align: 텍스트 정렬

| 속성      | 설명               | 사용 상황              | 예시 코드              |
| --------- | ------------------ | ---------------------- | ---------------------- |
| `left`    | 왼쪽 정렬 (기본값) | 일반 문단              | `text-align: left;`    |
| `center`  | 가운데 정렬        | 제목, 캡션             | `text-align: center;`  |
| `right`   | 오른쪽 정렬        | 날짜, 가격 표시        | `text-align: right;`   |
| `justify` | 양쪽 정렬          | 신문, 잡지 스타일 본문 | `text-align: justify;` |

**justify 동작:**

- 여러 줄 텍스트에서 마지막 줄을 제외한 모든 줄의 양쪽 끝을 맞춤
- 단어 간격을 자동 조절하여 균일한 너비 생성

```css
p.article {
  text-align: justify; /* 양쪽 정렬로 깔끔한 문단 생성 */
}
```

---

### 2.2 간격 조절 속성

| 속성             | 설명                  | 단위         | 사용 상황                | 예시 코드                |
| ---------------- | --------------------- | ------------ | ------------------------ | ------------------------ |
| `letter-spacing` | 자간 (글자 사이 간격) | px, em       | 가독성 향상, 디자인 강조 | `letter-spacing: 0.1em;` |
| `word-spacing`   | 단어 간격             | px, em       | 단어 구분 명확화         | `word-spacing: 0.3em;`   |
| `line-height`    | 줄 높이 (행간)        | 숫자, px, em | 가독성 개선              | `line-height: 1.6;`      |

**line-height 사용 팁:**

```css
p {
  line-height: 1.6; /* 단위 없는 숫자 권장 (글자 크기의 1.6배) */
  /* 또는 */
  line-height: 1.6em; /* em 단위 사용 */
}
```

**최적 값:**

- 본문 텍스트: `line-height: 1.5~1.8`
- 제목: `line-height: 1.2~1.4`

---

### 2.3 text-indent: 들여쓰기

| 속성값  | 설명                   | 사용 상황                  | 예시 코드            |
| ------- | ---------------------- | -------------------------- | -------------------- |
| 양수 값 | 첫 줄 들여쓰기         | 문단 시작 표시             | `text-indent: 2em;`  |
| 음수 값 | 첫 줄 내어쓰기         | 목록 스타일, 특수 레이아웃 | `text-indent: -1em;` |
| `0`     | 들여쓰기 없음 (기본값) | 일반 텍스트                | `text-indent: 0;`    |

```css
p.paragraph {
  text-indent: 1.5em; /* 첫 줄만 1.5em 들여쓰기 */
}

li.custom {
  text-indent: -1em; /* 내어쓰기 효과 */
  padding-left: 1em; /* 전체를 오른쪽으로 밀어 균형 */
}
```

### 2.4 list-style: 목록 스타일

| 속성                  | 설명             | 사용 가능한 값                                | 예시 코드                      |
| --------------------- | ---------------- | --------------------------------------------- | ------------------------------ |
| `list-style-type`     | 불릿/번호 스타일 | disc, circle, square, decimal, lower-alpha 등 | `list-style: circle;`          |
| `list-style-image`    | 이미지 불릿      | url() 함수                                    | `list-style: url('icon.png');` |
| `list-style-position` | 불릿 위치        | inside, outside                               | `list-style-position: inside;` |
| `none`                | 불릿/번호 제거   | -                                             | `list-style: none;`            |

**다양한 스타일 예시:**

```css
ul {
  list-style: circle; /* 빈 원 불릿 */
}

ul > li:first-child {
  list-style: "🚩 "; /* 이모지 사용 */
}

ol {
  list-style: lower-alpha; /* a, b, c... */
  /* 다른 옵션: upper-alpha (A, B, C), lower-roman (i, ii, iii) */
}

.custom-list {
  list-style: none; /* 불릿 제거 후 커스텀 스타일 적용 */
}
```

## 3. 색상 표현

### 3.1 CSS 색상 표현 방식

| 방식        | 설명                               | 장점                | 사용 상황            | 예시                                                             |
| ----------- | ---------------------------------- | ------------------- | -------------------- | ---------------------------------------------------------------- |
| **Keyword** | 색상 이름                          | 직관적, 간단        | 기본 색상 사용       | `color: red;`                                                    |
| **RGB(A)**  | Red, Green, Blue (Alpha)           | 정밀한 제어, 투명도 | 디자인 정밀 작업     | `color: rgb(255, 0, 0);<br>``color: rgba(255, 0, 0, 0.5);`       |
| **HEX**     | 16진수 색상 코드                   | 간결, 웹 표준       | 일반적인 웹 디자인   | `color: #ff0000;<br>``color: #f00;`(단축형)                      |
| **HSL(A)**  | Hue, Saturation, Lightness (Alpha) | 직관적 색상 조절    | 색상 변형, 테마 작업 | `color: hsl(0, 100%, 50%);<br>``color: hsla(0, 100%, 50%, 0.5);` |

---

### 3.2 각 방식의 상세 설명

**1. RGB(A) - 가산 혼합 방식**

```css
/* RGB: 각 채널 0~255 */
color: rgb(255, 0, 0); /* 빨강 */
color: rgb(0, 255, 0); /* 초록 */
color: rgb(0, 0, 255); /* 파랑 */
color: rgb(255, 255, 255); /* 흰색 */

/* RGBA: 알파값 0~1 (투명도) */
color: rgba(255, 0, 0, 0.5); /* 반투명 빨강 */
color: rgba(0, 0, 0, 0.8); /* 80% 불투명 검정 */
```

**2. HEX - 16진수 표현**

```css
/* #RRGGBB 형식 (00~FF) */
color: #ff0000; /* 빨강 */
color: #00ff00; /* 초록 */
color: #0000ff; /* 파랑 */

/* 단축형: 같은 숫자 반복 시 */
color: #f00; /* #ff0000과 동일 */
color: #fff; /* #ffffff (흰색) */

/* 알파값 포함 */
color: #ff000080; /* 반투명 빨강 (80은 16진수로 50% 투명도) */
```

**3. HSL(A) - 색상, 채도, 명도**

```css
/* hsl(색상각도, 채도%, 명도%) */
color: hsl(0, 100%, 50%); /* 빨강 (0도) */
color: hsl(120, 100%, 50%); /* 초록 (120도) */
color: hsl(240, 100%, 50%); /* 파랑 (240도) */

/* 채도 조절 */
color: hsl(0, 100%, 50%); /* 선명한 빨강 */
color: hsl(0, 50%, 50%); /* 탁한 빨강 */

/* 명도 조절 */
color: hsl(0, 100%, 25%); /* 어두운 빨강 */
color: hsl(0, 100%, 75%); /* 밝은 빨강 */

/* 알파값 추가 */
color: hsla(0, 100%, 50%, 0.5); /* 반투명 빨강 */
```

---

### 3.3 색상 적용 속성

| 속성               | 설명        | 사용 상황       | 예시 코드                            |
| ------------------ | ----------- | --------------- | ------------------------------------ |
| `color`            | 글자 색상   | 텍스트 스타일링 | `color: #333;`                       |
| `background-color` | 배경 색상   | 요소 배경       | `background-color: rgba(0,0,0,0.1);` |
| `border-color`     | 테두리 색상 | 테두리 스타일링 | `border-color: hsl(200, 50%, 50%);`  |

```css
p {
  color: #333; /* 진한 회색 글자 */
  background-color: #f5f5f5; /* 연한 회색 배경 */
}

.highlight {
  color: white;
  background-color: rgba(255, 0, 0, 0.8); /* 반투명 빨강 배경 */
}
```

**구글 색상 피커 활용:**

- 구글 검색: "color picker" 또는 "#ffffff"
- 시각적으로 색상 선택 가능
- 자동으로 HEX, RGB, HSL 변환

## 4. 인라인 요소와 블록 요소

### 4.1 개념 이해

**블록 요소 (Block Element)**

- 딱딱한 사각형 상자처럼 동작
- 명확한 너비와 높이를 가짐
- 한 줄을 독차지함

**인라인 요소 (Inline Element)**

- 비닐이나 랩처럼 내용물에 맞게 형태가 변함
- 페이지 흐름에 따라 다른 요소와 한 줄에 배치
- 너비와 높이 지정 불가

---

### 4.2 display 속성 비교표

| 속성                    | `inline`                         | `block`               | `inline-block`   |
| ----------------------- | -------------------------------- | --------------------- | ---------------- |
| **기본 너비**           | 컨텐츠만큼                       | 부모의 100%           | 컨텐츠만큼       |
| **width, height**       | ❌ 무시됨                        | ✅ 적용               | ✅ 적용          |
| **가로 공간**           | 다른 요소와 공유                 | 한 줄 독점            | 다른 요소와 공유 |
| **margin (바깥 여백)**  | 좌우만 적용                      | 모두 적용 (상하 상쇄) | 모두 적용        |
| **padding (안쪽 여백)** | 좌우만 적용`<br>`상하는 배경색만 | 모두 적용             | 모두 적용        |

---

### 4.3 상세 동작 방식

**1. inline (인라인)**

```css
span {
  display: inline;
  width: 100px; /* ❌ 무시됨 */
  height: 50px; /* ❌ 무시됨 */
  margin: 10px; /* 좌우만 적용, 상하 무시 */
  padding: 10px; /* 좌우 정상, 상하는 배경색만 */
}
```

**사용 예시:**

- `<span>`, `<a>`, `<strong>`, `<em>` 등
- 텍스트 일부에 스타일 적용
- 링크, 강조 표시

**2. block (블록)**

```css
div {
  display: block;
  width: 300px; /* ✅ 적용 */
  height: 200px; /* ✅ 적용 */
  margin: 20px; /* ✅ 모두 적용 (상하 margin은 상쇄됨) */
  padding: 15px; /* ✅ 모두 적용 */
}
```

**사용 예시:**

- `<div>`, `<p>`, `<h1>~<h6>`, `<section>` 등
- 레이아웃 구성
- 독립적인 콘텐츠 블록

**3. inline-block (인라인-블록)**

```css
button {
  display: inline-block;
  width: 120px; /* ✅ 적용 */
  height: 40px; /* ✅ 적용 */
  margin: 10px; /* ✅ 모두 적용 */
  padding: 8px 16px; /* ✅ 모두 적용 */
}
```

**사용 예시:**

- 버튼, 네비게이션 메뉴
- 같은 줄에 배치하면서 크기 조절이 필요한 요소
- 이미지 갤러리

---

### 4.4 실전 활용 예시

**네비게이션 메뉴 만들기**

```css
/* HTML: <ul><li>홈</li><li>소개</li><li>제품</li></ul> */

ul {
  list-style: none;
  padding: 0;
}

li {
  display: inline-block; /* 가로로 배치하면서 크기 조절 가능 */
  margin-right: 2em;
  padding: 10px 20px;
  background-color: #007bff;
  color: white;
}

li:hover {
  background-color: #0056b3;
}
```

**주의사항:**

- 인라인 요소 내부에 블록 요소를 넣으면 안 됨

  ```html
  <!-- ❌ 잘못된 예 --><span> <div>블록 요소</div></span
  ><!-- ✅ 올바른 예 -->
  <div><span>인라인 요소</span></div>
  ```

## 💡 핵심 요약

### 글자 스타일

- **font-style** : italic(기울임 서체), oblique(기울인 서체)
- **font-weight** : normal(400), bold(700), 100-900 (서체 지원 범위)
- **font-size** : px(절대), em(부모 기준, 중첩), rem(html 기준), %(부모 기준)
- **text-decoration** : 밑줄, 취소선, 물결선 등
- **text-transform** : capitalize, uppercase, lowercase

### 문단 및 목록

- **text-align** : left, center, right, justify
- **간격** : letter-spacing(자간), word-spacing(단어), line-height(줄 높이)
- **text-indent** : 들여쓰기/내어쓰기 (양수/음수)
- **list-style** : 불릿 스타일 (circle, decimal, 이모지, 이미지, none)

### 색상

- **Keyword** : red, blue 등 이름
- **RGB(A)** : rgb(255, 0, 0), rgba(255, 0, 0, 0.5)
- **HEX** : #ff0000, #f00
- **HSL(A)** : hsl(0, 100%, 50%), hsla(0, 100%, 50%, 0.5)

### Display 속성

- **inline** : 너비/높이 무시, 가로 공간 공유, margin/padding 좌우만
- **block** : 모든 속성 적용, 한 줄 독점, 기본 너비 100%
- **inline-block** : 너비/높이 적용, 가로 공간 공유, 모든 margin/padding

### 퀴즈 1

`font-style: italic`과 `font-style: oblique`의 차이점은 무엇인가요?

**① italic은 기울인 서체, oblique는 기울임 전용 서체다**

- 서체에 해당 스타일이 없으면 브라우저가 자동으로 상호 교차하여 사용하지만, 본질적으로는 다른 방식입니다.
- 문서 내용: "italic이 '기울여서 쓴' 서체라면 oblique는 본래 서체를 기울여놓은 것입니다."

### 퀴즈 2

다음 중 `font-size`에서 중첩(nesting)의 영향을 받지 않는 단위는?

① px
② em
③ %
④ rem

**정답: ①, ④**

**해설:**

- `px`는 절대 단위로 항상 고정된 크기를 유지합니다.
- `rem`은 항상 html 요소의 font-size를 기준으로 하므로 중첩의 영향을 받지 않습니다.
- `em`과 `%`는 부모 요소를 기준으로 하므로 중첩되면 값이 누적됩니다.
- 예: `html {font-size: 14px}`, `div {font-size: 2em}` → 중첩된 div는 28px, 56px, 112px로 계속 커짐
- 문서 내용: "rem은 html 요소와의 상대적 크기를 가지므로, 요소의 중첩에 영향을 받지 않습니다."

### 퀴즈 3

`text-align: justify`의 동작 방식으로 올바른 것은?

② 마지막 줄을 제외한 줄들의 양쪽 끝을 맞춘다
③ 첫 줄만 양쪽 끝을 맞춘다
④ 단어 수가 많은 줄만 양쪽 끝을 맞춘다

**정답: ②**

**해설:**

- `justify`는 여러 줄 텍스트에서 **마지막 줄을 제외한** 모든 줄의 양쪽 끝을 맞춥니다.
- 각 줄의 단어 간격을 자동으로 조절하여 오른쪽 끝이 나란하게 정렬됩니다.
- 신문이나 잡지처럼 깔끔한 문단 레이아웃을 만들 때 사용합니다.
- 문서 내용: "justify는 왼쪽으로 정렬하면서, 텍스트가 여러 줄이 될 때 마지막 줄을 제외한 줄들의 오른쪽이 나란히 되도록 각 줄의 공간을 조절합니다."

### 퀴즈 5

`rgba(255, 0, 0, 0.5)`의 의미로 올바른 것은?

① 빨간색, 투명도 5%
② 빨간색, 투명도 50%
③ 주황색, 투명도 50%
④ 분홍색, 투명도 50%

**정답: ②**

- `rgba(red, green, blue, alpha)`에서 각 값의 의미:

  - blue: 0 → 파랑 0%

- 결과: 50% 투명한 빨간색
- 문서 내용: "RGBA는 빨강, 초록, 파랑의 광원으로 색을 혼합하는 방식이며 끝에 알파값을 붙여서 투명도를 조절할 수 있죠."

### 퀴즈 6

다음 중 `display: inline` 요소의 특징으로 **잘못된** 것은?

① width와 height 속성이 무시된다
② 다른 요소와 같은 줄에 배치된다
③ margin은 상하좌우 모두 적용된다
④ 기본 너비는 컨텐츠 크기만큼이다

**정답: ③**

**해설:**

- `display: inline` 요소는 **margin이 좌우만 적용**되고 상하는 무시됩니다.
- padding도 좌우는 정상 적용되지만, 상하는 배경색만 적용되고 레이아웃에 영향을 주지 않습니다.
- 인라인 요소는 텍스트 흐름에 따라 배치되므로 크기 관련 속성이 제한적입니다.
- `inline-block`을 사용하면 margin과 padding을 모두 적용할 수 있습니다.
- 문서 내용 표: "margin 속성 - 가로만 적용"

### 퀴즈 7

네비게이션 메뉴를 가로로 배치하면서 각 항목의 너비와 높이를 조절하려고 할 때 가장 적합한 `display` 값은?

① inline
② block
③ inline-block
④ list-item

**정답: ③**

**해설:**

- `inline-block`은 요소를 가로로 배치하면서도 width, height를 적용할 수 있습니다.
- `inline`은 너비/높이를 조절할 수 없어 부적합합니다.
- `block`은 한 줄을 독점하므로 세로로 배치됩니다.
- 네비게이션 메뉴는 가로 배치 + 크기 조절이 필요하므로 `inline-block`이 최적입니다.
- 문서 예시: "ul > li { display: inline-block; margin-right: 2em; }"

### 퀴즈 8

HEX 색상 코드 `#f00`과 동일한 색상은?

① #ff0000
② #f0f0f0
③ #0000ff
④ #00ff00

**정답: ①**

**해설:**

- HEX 색상 코드에서 같은 숫자가 반복될 때 단축 표기가 가능합니다.
- `#f00` = `#ff0000` (빨강)
- 각 자리를 두 번씩 반복: f → ff, 0 → 00, 0 → 00
- 다른 예시: `#fff` = `#ffffff` (흰색), `#abc` = `#aabbcc`
- 문서 내용: "HEX는 R, G, B, Alpha 값들을 16진수형태로 나타낸 것입니다."

```css
}

.accent {
  background-color: hsla(200, 80%, 60%, 0.8);
  color: white;
  padding: 2px 6px;
  font-weight: 600;
}
```

**해설:**

- **HSL의 장점** : 같은 색상(hue)으로 채도와 명도만 조절하여 일관된 테마 생성
- **hue 200** - 파란색 계열 유지
- **명도 조절** : 95%(배경, 매우 밝음) → 60%(강조) → 40%(제목) → 30%(본문, 가장 진함)
- **hsla 사용** : 투명도(0.8)로 부드러운 강조 효과
- 이 방식으로 전체 사이트의 색상 스키마를 쉽게 관리 가능
- 색상을 변경하려면 hue 값만 바꾸면 됨 (예: 120은 초록, 0은 빨강)
