## 1. CSS 적용 방법

### 1.1 인라인 스타일 (Inline Style)

**개념** : HTML 태그에 직접 `style` 속성을 사용하여 CSS를 작성하는 방식

**특징** :

- HTML과 CSS 코드가 혼재되어 유지보수가 어려움
- 재사용성이 없어 같은 스타일을 여러 요소에 적용할 수 없음
- 우선순위가 가장 높음 (특별한 경우를 제외하고 사용 비권장)

| 항목      | 설명                                                        | 예시 코드                                                  |
| --------- | ----------------------------------------------------------- | ---------------------------------------------------------- |
| 사용 방법 | HTML 태그의 style 속성에 직접 작성                          | `<p style="color: red;">텍스트</p>`                        |
| 사용 상황 | 긴급한 수정, 이메일 템플릿, 특정 요소만 스타일 변경 필요 시 | `<div style="background: blue; padding: 10px;">내용</div>` |
| 장점      | 즉시 적용 가능, 가장 높은 우선순위                          | -                                                          |
| 단점      | 재사용 불가, 유지보수 어려움, HTML과 CSS 분리 원칙 위배     | -                                                          |

### 1.2 내부 스타일 시트 (Internal Style Sheet)

**개념** : HTML 문서의 `<head>` 태그 안에 `<style>` 태그를 넣고 그 안에 CSS를 작성하는 방식

**특징** :

- HTML과 CSS가 한 파일에 존재하지만 영역은 분리됨
- 해당 HTML 문서에만 적용됨
- 코드량이 적고 단일 페이지에만 적용할 스타일일 때 유용

| 항목      | 설명                                                    | 예시 코드                             |
| --------- | ------------------------------------------------------- | ------------------------------------- |
| 사용 방법 | `<head>`내 `<style>`태그 안에 작성                      | `<style> p { color: blue; } </style>` |
| 사용 상황 | 단일 페이지 전용 스타일, 프로토타입 제작, 작은 프로젝트 | 랜딩 페이지, 이메일 템플릿            |
| 장점      | 외부 파일 요청 없음, 페이지 로딩 속도 향상 가능         | -                                     |
| 단점      | 다른 페이지에서 재사용 불가, HTML 파일 크기 증가        | -                                     |

### 1.3 링킹 스타일 시트 (Linking Style Sheet)

**개념** : 외부 CSS 파일을 작성하고 HTML 문서에서 `<link>` 태그로 연결하는 방식

**특징** :

- HTML과 CSS가 완전히 분리됨
- 여러 HTML 파일에서 같은 CSS 파일을 공유 가능
- 가장 널리 사용되는 표준 방식
- 유지보수와 협업에 유리

| 항목      | 설명                                               | 예시 코드                                  |
| --------- | -------------------------------------------------- | ------------------------------------------ |
| 사용 방법 | 별도 .css 파일 작성 후 link 태그로 연결            | `<link rel="stylesheet" href="style.css">` |
| 사용 상황 | 대부분의 웹 프로젝트, 여러 페이지가 있는 사이트    | 모든 실무 프로젝트                         |
| 장점      | 재사용성 높음, 유지보수 용이, 협업 편리, 캐싱 가능 | -                                          |
| 단점      | 추가 HTTP 요청 발생 (초기 로딩 시)                 | -                                          |

## 2. 선택자의 종류와 우선순위

### 2.1 전체 선택자 (Universal Selector)

**개념** : 페이지의 모든 요소를 선택하는 선택자

| 항목      | 설명                                              | 예시 코드                      |
| --------- | ------------------------------------------------- | ------------------------------ |
| 문법      | `*`기호 사용                                      | `* { margin: 0; padding: 0; }` |
| 사용 상황 | CSS 리셋, 모든 요소에 공통 스타일 적용            | 브라우저 기본 스타일 제거 시   |
| 우선순위  | 가장 낮음 (0점)                                   | -                              |
| 주의사항  | 성능에 영향을 줄 수 있으므로 필요한 경우에만 사용 | -                              |

```css
/* 모든 요소의 기본 여백 제거 */
* {
  margin: 0;
  padding: 0;
  box-sizing: border-box;
}
```

### 2.2 태그 선택자 (Type Selector)

**개념** : HTML 태그 이름으로 요소를 선택하는 선택자

| 항목      | 설명                              | 예시 코드                |
| --------- | --------------------------------- | ------------------------ |
| 문법      | 태그 이름 그대로 사용             | `p { color: blue; }`     |
| 사용 상황 | 특정 태그 전체에 공통 스타일 적용 | 모든 `<h1>`태그 스타일링 |
| 우선순위  | 낮음 (1점)                        | -                        |
| 특징      | 해당 태그 모두에 적용됨           | `div`,`span`,`p`등       |

```css
/* 모든 p 태그에 적용 */
p {
  line-height: 1.6;
  color: #333;
}
```

### 2.3 클래스 선택자 (Class Selector)

**개념** : HTML 요소의 `class` 속성 값으로 선택하는 선택자

| 항목      | 설명                                               | 예시 코드                |
| --------- | -------------------------------------------------- | ------------------------ |
| 문법      | `.`기호 + 클래스명                                 | `.blue { color: blue; }` |
| 사용 상황 | 여러 요소에 같은 스타일 적용, 재사용 가능한 스타일 | 버튼, 카드 컴포넌트 등   |
| 우선순위  | 중간 (10점)                                        | -                        |
| 특징      | 하나의 요소가 여러 클래스를 가질 수 있음           | `<div class="box blue">` |

```css
/* 클래스 선택자 */
.blue {
  color: lightblue;
}

/* 태그와 클래스 결합 - 더 구체적 */
p.blue {
  color: slateblue;
}

/* 여러 클래스를 동시에 가진 요소 선택 */
.blue.dark {
  color: mediumblue;
}
```

### 2.4 ID 선택자 (ID Selector)

**개념** : HTML 요소의 `id` 속성 값으로 선택하는 선택자

| 항목      | 설명                                        | 예시 코드                       |
| --------- | ------------------------------------------- | ------------------------------- |
| 문법      | `#`기호 + ID명                              | `#header { background: gray; }` |
| 사용 상황 | 페이지 내 유일한 요소 선택, JavaScript 연동 | 헤더, 메인 컨테이너 등          |
| 우선순위  | 높음 (100점)                                | -                               |
| 특징      | ID는 페이지 내에서 고유해야 함 (중복 불가)  | 하나의 요소만 선택              |

```css
/* ID 선택자 - 가장 높은 우선순위 */
#red {
  color: tomato;
}
```

### 2.5 그룹 선택자 (Group Selector)

**개념** : 여러 선택자를 쉼표로 구분하여 동일한 스타일을 한 번에 적용하는 선택자

| 항목      | 설명                                           | 예시 코드                     |
| --------- | ---------------------------------------------- | ----------------------------- |
| 문법      | 선택자를 쉼표로 구분                           | `h1, h2, h3 { color: blue; }` |
| 사용 상황 | 여러 요소에 같은 스타일 적용 시 코드 중복 방지 | 제목 태그들에 공통 스타일     |
| 장점      | CSS 코드량 감소, 유지보수 편리                 | -                             |
| 특징      | 선택자의 종류는 제한 없음                      | 태그, 클래스, ID 혼합 가능    |

```css
/* 여러 선택자에 동일한 스타일 적용 */
span,
.dark,
#red {
  text-decoration: underline;
}
```

### 2.6 우선순위 정리

**CSS 우선순위 계산 규칙** :

1. **인라인 스타일** : 1000점
2. **ID 선택자** : 100점
3. **클래스, 속성, 가상 클래스 선택자** : 10점
4. **태그, 가상 요소 선택자** : 1점
5. **전체 선택자** : 0점

**중요 원칙** :

- 같은 점수일 경우 나중에 선언된 것이 적용됨
- 선택자가 구체적일수록 우선순위가 높음
- `!important`는 모든 우선순위를 무시하지만 사용 비권장

```css
/* 우선순위 예시 */
* {
  color: plum;
} /* 0점 */
p {
  color: olivedrab;
} /* 1점 */
.blue {
  color: lightblue;
} /* 10점 */
p.blue {
  color: slateblue;
} /* 11점 (1+10) */
.blue.dark {
  color: mediumblue;
} /* 20점 (10+10) */
#red {
  color: tomato;
} /* 100점 */
```

## 3. 결합자 (Combinators)

### 3.1 자손 결합자 (Descendant Combinator)

**개념** : 특정 요소의 모든 하위 요소(자손)를 선택하는 결합자

| 항목      | 설명                               | 예시 코드                    |
| --------- | ---------------------------------- | ---------------------------- |
| 문법      | 공백으로 구분                      | `.outer li { color: red; }`  |
| 선택 범위 | 1촌 자식뿐만 아니라 모든 하위 요소 | 손자, 증손자 등 모두 포함    |
| 사용 상황 | 특정 영역 내 모든 특정 요소 선택   | 메뉴 안의 모든 링크 스타일링 |
| 특징      | 깊이 제한 없음                     | -                            |

```css
/* .outer 안의 모든 li 요소 (깊이 무관) */
.outer li {
  color: olivedrab;
}
```

### 3.2 자식 결합자 (Child Combinator)

**개념** : 특정 요소의 직계 자식(1촌)만 선택하는 결합자

| 항목      | 설명                           | 예시 코드                      |
| --------- | ------------------------------ | ------------------------------ |
| 문법      | `>`기호 사용                   | `.outer > li { color: blue; }` |
| 선택 범위 | 바로 아래 자식만 선택          | 손자 이하는 선택 안 됨         |
| 사용 상황 | 특정 깊이의 요소만 스타일 적용 | 메뉴의 1단계 항목만 스타일링   |
| 특징      | 자손 결합자보다 구체적         | -                              |

```css
/* .outer의 직계 자식 li만 선택 */
.outer > li {
  color: dodgerblue;
}

/* 위 요소의 하위 모든 li 선택 */
.outer > li li {
  text-decoration: underline;
}
```

### 3.3 인접 형제 결합자 (Adjacent Sibling Combinator)

**개념** : 특정 요소 바로 다음에 오는 형제 요소 하나만 선택하는 결합자

| 항목      | 설명                                   | 예시 코드                              |
| --------- | -------------------------------------- | -------------------------------------- |
| 문법      | `+`기호 사용                           | `.starter + li { font-weight: bold; }` |
| 선택 범위 | 바로 다음 형제 요소 1개만              | 같은 부모를 가진 요소 중               |
| 사용 상황 | 특정 요소 바로 다음 요소만 스타일 적용 | 제목 다음의 첫 문단 스타일링           |
| 특징      | 반드시 인접해야 함                     | -                                      |

```css
/* .starter 클래스를 가진 요소 바로 다음의 li */
.starter + li {
  font-weight: bold;
}
```

### 3.4 일반 형제 결합자 (General Sibling Combinator)

**개념** : 특정 요소 뒤에 오는 모든 형제 요소를 선택하는 결합자

| 항목      | 설명                                 | 예시 코드                               |
| --------- | ------------------------------------ | --------------------------------------- |
| 문법      | `~`기호 사용                         | `.starter ~ li { font-style: italic; }` |
| 선택 범위 | 뒤따르는 모든 형제 요소              | 인접하지 않아도 됨                      |
| 사용 상황 | 특정 요소 이후의 모든 같은 형제 선택 | 구분선 이후 모든 항목 스타일링          |
| 특징      | 앞에 있는 요소는 선택 안 됨          | -                                       |

```css
/* .starter 이후의 모든 형제 li 요소 */
.starter ~ li {
  font-style: italic;
}
```

## 4. 가상 클래스 (Pseudo-classes)

### 4.1 구조 가상 클래스

**개념** : 요소의 위치나 순서에 따라 선택하는 가상 클래스

### 4.1.1 first-child & last-child

| 항목           | 설명                           | 예시 코드                          |
| -------------- | ------------------------------ | ---------------------------------- |
| `:first-child` | 형제 요소 중 첫 번째 선택      | `li:first-child { color: red; }`   |
| `:last-child`  | 형제 요소 중 마지막 선택       | `li:last-child { color: blue; }`   |
| 사용 상황      | 목록의 첫/마지막 항목 스타일링 | 메뉴의 첫 항목, 마지막 항목        |
| 주의사항       | 반드시 첫/마지막 자식이어야 함 | 다른 타입 요소가 있으면 선택 안 됨 |

```css
/* 첫 번째와 마지막 li 요소 */
ol li:first-child,
ol li:last-child {
  color: yellowgreen;
}
```

### 4.1.2 nth-child

| 항목      | 설명                     | 예시 코드                         |
| --------- | ------------------------ | --------------------------------- |
| 문법      | `:nth-child(n)`          | `li:nth-child(3) { color: red; }` |
| 숫자      | 특정 번째 요소           | `:nth-child(3)`- 3번째            |
| `odd`     | 홀수 번째 요소           | `:nth-child(odd)`- 1, 3, 5...     |
| `even`    | 짝수 번째 요소           | `:nth-child(even)`- 2, 4, 6...    |
| `an+b`    | 패턴으로 선택            | `:nth-child(2n+1)`- 홀수          |
| 사용 상황 | 테이블 줄무늬, 반복 패턴 | 리스트 스타일링                   |

```css
/* 3번째 li 요소 */
ol li:nth-child(3) {
  font-weight: bold;
  color: deeppink;
}

/* 짝수 번째 li 요소 */
ol li:nth-child(even) {
  background-color: #f0f0f0;
}
```

### 4.2 부정 가상 클래스

**개념** : 특정 조건에 해당하지 않는 요소를 선택하는 가상 클래스

| 항목      | 설명                             | 예시 코드                           |
| --------- | -------------------------------- | ----------------------------------- |
| 문법      | `:not(selector)`                 | `li:not(.special) { color: gray; }` |
| 사용 상황 | 특정 요소를 제외하고 나머지 선택 | 마지막 항목 제외 모두 선택          |
| 장점      | 예외 처리가 간결해짐             | -                                   |
| 특징      | 다른 선택자와 조합 가능          | -                                   |

```css
/* 마지막 자식이 아닌 .outer의 자식 li */
.outer > li:not(:last-child) {
  text-decoration: line-through;
}

/* .outer 클래스가 없는 ul의 모든 li */
ul:not(.outer) li {
  font-weight: bold;
}
```

### 4.3 동적 가상 클래스

**개념** : 사용자 상호작용에 따라 스타일이 변경되는 가상 클래스

### 4.3.1 hover

| 항목      | 설명                            | 예시 코드                            |
| --------- | ------------------------------- | ------------------------------------ |
| 문법      | `:hover`                        | `button:hover { background: blue; }` |
| 적용 시점 | 마우스 커서가 요소 위에 있을 때 | -                                    |
| 사용 상황 | 버튼, 링크, 메뉴 등 인터랙션    | 호버 효과, 툴팁 표시                 |
| 모바일    | 터치 기기에서는 동작 방식 다름  | 탭 시 적용, 다른 곳 탭하면 해제      |

```css
/* 마우스를 올렸을 때 스타일 변경 */
li:hover {
  font-weight: bold;
  color: blue;
  cursor: pointer;
}
```

## 5. CSS 상속의 이해

### 5.1 상속의 개념

**개념** : 부모 요소에 적용된 특정 CSS 속성이 자식 요소에도 자동으로 적용되는 현상

**특징** :

- 모든 CSS 속성이 상속되는 것은 아님
- 주로 텍스트 관련 속성이 상속됨
- 명시적으로 덮어쓰지 않으면 상속된 값이 유지됨

### 5.2 상속되는 속성과 상속되지 않는 속성

| 상속되는 속성             | 상속되지 않는 속성   |
| ------------------------- | -------------------- |
| `color`(글자 색)          | `background`(배경)   |
| `font-family`(글꼴)       | `border`(테두리)     |
| `font-size`(글자 크기)    | `margin`(바깥 여백)  |
| `font-weight`(글자 굵기)  | `padding`(안쪽 여백) |
| `line-height`(줄 높이)    | `width`(너비)        |
| `text-align`(텍스트 정렬) | `height`(높이)       |
| `visibility`(가시성)      | `display`(표시 방식) |

### 5.3 자식 선택자와 상속의 관계

```css
/* 1촌 자식만 선택하지만 */
.outer > li {
  color: dodgerblue; /* color는 상속되는 속성 */
}

/* 결과:
   - .outer의 직계 자식 li는 dodgerblue
   - 그 자식 li들도 dodgerblue (상속됨)
   - 다른 선택자로 덮어쓰지 않는 한 계속 상속
*/
```

**중요 포인트** :

- 자식 선택자(`>`)는 선택 대상만 제한할 뿐
- 적용된 속성이 상속 가능한 속성이면 자동으로 하위로 전달됨
- 상속을 막으려면 하위 요소에 명시적으로 다른 값을 지정해야 함

### 5.4 상속 제어 키워드

| 키워드    | 설명                                  | 예시               |
| --------- | ------------------------------------- | ------------------ |
| `inherit` | 부모 속성값을 강제로 상속             | `border: inherit;` |
| `initial` | 속성의 기본값으로 초기화              | `color: initial;`  |
| `unset`   | 상속 가능하면 inherit, 아니면 initial | `all: unset;`      |

```css
/* 상속 예시 */
.parent {
  color: blue;
  border: 1px solid black; /* 상속 안 됨 */
}

.child {
  /* color는 자동으로 blue 상속 */
  /* border는 상속 안 되므로 지정 필요 */
  border: inherit; /* 부모의 border 강제 상속 */
}
```

## 📌 핵심 요약본

### CSS 적용 방법

- **인라인** : HTML 태그에 직접 작성, 재사용 불가, 비권장
- **내부** : `<style>` 태그 사용, 단일 페이지용
- **외부** : 별도 CSS 파일, 재사용 가능, 실무 표준

### 선택자 우선순위 (높은 순)

1. 인라인 스타일 (1000점)
2. ID 선택자 `#id` (100점)
3. 클래스 선택자 `.class` (10점)
4. 태그 선택자 `tag` (1점)
5. 전체 선택자 (0점)

### 결합자

- **자손** (공백): 모든 하위 요소 선택
- **자식** (`>`): 직계 자식만 선택
- **인접 형제** (`+`): 바로 다음 형제 1개
- **일반 형제** (`~`): 뒤따르는 모든 형제

### 주요 가상 클래스

- `:first-child` / `:last-child` - 첫/마지막 자식
- `:nth-child(n)` - n번째 자식 (odd, even, 2n+1 등)
- `:not(selector)` - 조건에 맞지 않는 요소
- `:hover` - 마우스 오버 시

### CSS 상속

- **상속됨** : color, font 관련, text 관련
- **상속 안 됨** : border, margin, padding, width, height
- 자식 선택자로 선택해도 상속 가능 속성은 하위로 전달됨

.parent {

<div class="parent">

1. 검정색 (브라우저 기본)
2. blue

### 퀴즈 6. 그룹 선택자와 우선순위

**문제** : 다음 중 **같은 우선순위**를 가지는 선택자 조합은?

1. `p.blue`와 `div#red`
2. `.blue.dark`와 `p.blue`
3. `#red`와 `.blue`
4. 와 `p`

**정답** : 2. `.blue.dark`와 `p.blue`

**해설** :

- `p.blue` = 태그(1) + 클래스(10) = 11점
- `.blue.dark` = 클래스(10) + 클래스(10) = 20점... 아니 잠깐!
- 실제로 `.blue.dark` = 20점, `p.blue` = 11점이므로 다릅니다.
- 올바른 답은 없지만, 문제의 의도는 복합 선택자의 점수 계산 방법을 이해하는 것입니다.

  **정정된 정답** : 사실 제시된 보기 중 정확히 같은 우선순위는 없습니다.

- 1번: `p.blue`(11점) ≠ `div#red`(101점)
- 2번: `.blue.dark`(20점) ≠ `p.blue`(11점)
- 3번: `#red`(100점) ≠ `.blue`(10점)
- 4번: (0점) ≠ `p`(1점)

  **해설 보완** : 이 문제는 선택자의 우선순위 점수 계산 방법을 이해했는지 테스트하는 문제입니다. 각 선택자 타입의 점수를 정확히 계산할 수 있어야 합니다.

### 문제 1: 기본 선택자 활용

**과제** : 다음 HTML에 CSS를 작성하여 요구사항을 만족시키세요.

```html
<div class="container">
  <h1 id="title">제목</h1>
  <p class="intro">소개 문단</p>
  <p>일반 문단</p>
  <p class="intro">소개 문단2</p>
</div>
```

**요구사항** :

1. 모든 요소의 `margin`을 0으로 설정
2. `#title`의 글자 색을 빨간색으로 설정
3. `.intro` 클래스를 가진 요소의 글자 크기를 18px로 설정
4. `.intro` 클래스가 없는 `p` 태그의 글자 색을 회색으로 설정

**기본 코드** :

```css
/* 여기에 CSS 작성 */
```

**정답** :

```css
/* 1. 모든 요소의 margin을 0으로 */
* {
  margin: 0;
}

/* 2. ID 선택자로 제목 색상 변경 */
#title {
  color: red;
}

/* 3. 클래스 선택자로 소개 문단 크기 변경 */
.intro {
  font-size: 18px;
}

/* 4. 부정 가상 클래스로 일반 문단만 선택 */
p:not(.intro) {
  color: gray;
}
```

**풀이** :

- 전체 선택자 로 모든 요소에 공통 스타일 적용
- ID는 페이지에서 유일하므로 `#title`로 특정 요소 선택
- 클래스는 재사용 가능하므로 `.intro`로 여러 요소 선택
- `:not()` 가상 클래스로 특정 조건을 제외한 요소 선택

### 문제 2: 결합자 활용

**과제** : 다음 HTML 구조에서 CSS 결합자를 사용하여 요구사항을 만족시키세요.

```html
<nav class="menu">
  <ul>
    <li>메뉴1</li>
    <li>
      메뉴2
      <ul>
        <li>서브메뉴1</li>
        <li>서브메뉴2</li>
      </ul>
    </li>
    <li>메뉴3</li>
  </ul>
</nav>
```

**요구사항** :

1. `.menu` 안의 모든 `li`의 리스트 스타일 제거 (`list-style: none`)
2. `.menu`의 직계 자식 `ul`의 직계 자식 `li`만 글자를 굵게 표시
3. 서브메뉴의 모든 `li`는 왼쪽에 20px 여백 추가
4. 서브메뉴 `ul`의 배경색을 연한 회색으로 설정

**기본 코드** :

```css
/* 여기에 CSS 작성 */
```

**정답** :

```css
/* 1. 자손 결합자로 모든 하위 li 선택 */
.menu li {
  list-style: none;
}

/* 2. 자식 결합자를 연속 사용하여 1단계 메뉴만 선택 */
.menu > ul > li {
  font-weight: bold;
}

/* 3. 서브메뉴의 li 선택 (1단계 메뉴의 ul 아래 모든 li) */
.menu > ul > li ul li {
  margin-left: 20px;
}

/* 4. 서브메뉴 ul 선택 */
.menu > ul > li ul {
  background-color: #f0f0f0;
}
```

**풀이** :

- 자손 결합자(공백)는 깊이와 관계없이 모든 하위 요소 선택
- 자식 결합자(`>`)는 직계 자식만 선택하여 특정 레벨 지정 가능
- 결합자를 연결하여 복잡한 구조에서 원하는 요소를 정확히 선택
- 구조가 명확할수록 더 구체적인 선택자 작성 가능

### 문제 3: 가상 클래스 활용

**과제** : 다음 HTML에 가상 클래스를 활용한 CSS를 작성하세요.

```html
<ul class="items">
  <li>항목1</li>
  <li>항목2</li>
  <li>항목3</li>
  <li>항목4</li>
  <li>항목5</li>
  <li>항목6</li>
</ul>
```

**요구사항** :

1. 첫 번째 항목의 글자 색을 파란색으로 설정
2. 마지막 항목의 글자 색을 빨간색으로 설정
3. 짝수 번째 항목의 배경색을 연한 회색으로 설정
4. 모든 항목에 마우스를 올렸을 때 커서를 포인터로 변경하고 배경색을 노란색으로 설정

**기본 코드** :

```css
/* 여기에 CSS 작성 */
```

**정답** :

```css
/* 1. 첫 번째 자식 선택 */
.items li:first-child {
  color: blue;
}

/* 2. 마지막 자식 선택 */
.items li:last-child {
  color: red;
}

/* 3. 짝수 번째 항목 선택 */
.items li:nth-child(even) {
  background-color: #f0f0f0;
}

/* 4. 호버 상태 스타일 */
.items li:hover {
  cursor: pointer;
  background-color: yellow;
}
```

**풀이** :

- `:first-child`와 `:last-child`로 시작과 끝 요소 선택
- `:nth-child(even)` 또는 `:nth-child(2n)`으로 짝수 항목 선택
- `:hover` 가상 클래스로 사용자 인터랙션에 반응하는 스타일 추가
- 가상 클래스는 JavaScript 없이도 동적 효과 구현 가능
