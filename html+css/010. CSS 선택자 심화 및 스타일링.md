# CSS 선택자 심화 및 스타일링 복습 자료

---

## 1. 특성 선택자 (Attribute Selector)

### 1.1 특성 선택자란?

HTML 요소의 속성(attribute)을 기준으로 요소를 선택하는 CSS 선택자입니다. 속성의 존재 여부, 속성값의 일치 여부, 속성값에 특정 텍스트 포함 여부 등을 기준으로 요소를 선택할 수 있습니다.

### 1.2 특성 선택자 종류

### 1.2.1 정확한 속성값 매칭 `[attribute="value"]`

**설명:** 특정 속성이 정확히 일치하는 값을 가진 요소를 선택합니다.

**사용 상황:** 특정 URL을 가진 링크, 특정 타입의 input 등을 선택할 때 사용합니다.

**예시 코드:**

```css
/* href 속성이 정확히 "https://www.yalco.kr"인 a 요소 선택 */
a[href="https://www.yalco.kr"] {
  color: #ff4e00;
  font-weight: bold;
}

```

### 1.2.2 속성 존재 여부 `[attribute]`

**설명:** 특정 속성을 가진 요소를 선택합니다. 속성값은 상관없습니다.

**사용 상황:** disabled, required 등의 불린(Boolean) 속성을 가진 요소를 선택할 때 유용합니다.

**예시 코드:**

```css
/* disabled 속성을 가진 input의 다음 형제 label 선택 */
input[disabled] + label {
  color: lightgray;
  text-decoration: line-through;
}

```

### 1.2.3 속성값 포함 `[attribute*="value"]`

**설명:** 속성값에 특정 텍스트를 포함하는 요소를 선택합니다.

**사용 상황:** 클래스명의 일부분으로 요소를 선택하거나, URL에 특정 단어가 포함된 링크를 선택할 때 사용합니다.

**예시 코드:**

```css
/* class 속성값에 "item"이 포함된 span 요소 선택 */
span[class*="item"] {
  text-decoration: underline;
}

```

### 1.2.4 속성값 시작 문자 `[attribute^="value"]`

**설명:** 속성값이 특정 텍스트로 시작하는 요소를 선택합니다.

**사용 상황:** 특정 접두사를 가진 클래스명을 선택하거나, 특정 프로토콜로 시작하는 URL을 선택할 때 사용합니다.

**예시 코드:**

```css
/* class가 "fruit"으로 시작하는 span 요소 */
span[class^="fruit"] {
  color: tomato;
}

/* class가 "vege"로 시작하는 span 요소 */
span[class^="vege"] {
  color: olivedrab;
}

```

### 1.2.5 속성값 끝 문자 `[attribute$="value"]`

**설명:** 속성값이 특정 텍스트로 끝나는 요소를 선택합니다.

**사용 상황:** 파일 확장자로 링크를 선택하거나, 특정 접미사를 가진 클래스명을 선택할 때 사용합니다.

**예시 코드:**

```css
/* class가 "-1"로 끝나는 span 요소 */
span[class$="-1"] {
  font-weight: bold;
}

```

## 2. 가상 클래스 (Pseudo-class)

### 2.1 가상 클래스란?

요소의 특정 상태를 선택하는 선택자입니다. 콜론(`:`)을 사용하여 표기하며, 사용자의 상호작용, 요소의 상태, 구조적 위치 등을 기준으로 요소를 선택할 수 있습니다.

### 2.2 사용자 상호작용 가상 클래스

### 2.2.1 `:hover`

**설명:** 마우스 커서가 요소 위에 올라갔을 때의 상태를 선택합니다.

**사용 상황:** 버튼이나 링크에 호버 효과를 주어 사용자에게 상호작용 가능함을 알릴 때 사용합니다.

**예시 코드:**

```css
/* 마우스 오버 시 배경색 변경 */
a:hover {
  background-color: yellow;
}

```

### 2.2.2 `:active`

**설명:** 요소를 클릭하고 있는 동안의 상태를 선택합니다.

**사용 상황:** 버튼을 누르는 순간의 피드백을 제공할 때 사용합니다.

**예시 코드:**

```css
/* 클릭 중 배경색 변경 */
a:active {
  background-color: aqua;
}

```

### 2.2.3 `:focus`

**설명:** 요소가 포커스를 받은 상태(클릭되거나 탭으로 선택된 상태)를 선택합니다.

**사용 상황:** input 필드나 버튼 등이 선택되었을 때 시각적 피드백을 제공할 때 사용합니다.

**예시 코드:**

```css
/* 인풋이 포커스된 상태 */
input[type="text"]:focus {
  outline: 2px solid dodgerblue;
}

```

### 2.2.4 `:focus-visible`

**설명:** 탭 키로 포커스된 요소만 선택합니다. 마우스 클릭으로 포커스된 경우는 제외됩니다.

**사용 상황:** 키보드 네비게이션 사용자를 위한 접근성 개선에 사용합니다. 단, 브라우저 지원을 확인해야 합니다.

**예시 코드:**

```css
/* 탭으로 포커스된 요소에만 아웃라인 적용 */
[class*="tab-focus"]:focus-visible {
  outline: 2px solid dodgerblue;
}

```

**주의사항:**

- 타이핑 인풋 요소(텍스트 인풋 등)는 `focus-visible`을 사용해도 클릭과 탭 모두에 반응합니다.
- 사파리 등 일부 브라우저에서 제대로 지원되지 않을 수 있습니다.

### 2.3 폼 요소 상태 가상 클래스

### 2.3.1 `:checked`

**설명:** 체크박스나 라디오 버튼이 선택된 상태를 선택합니다.

**사용 상황:** 선택된 옵션에 스타일을 적용할 때 사용합니다.

**예시 코드:**

```css
/* 체크된 라디오 버튼의 다음 형제 label */
input[type=radio]:checked + label {
  color: tomato;
  font-weight: bold;
}

```

### 2.3.2 `:enabled`

**설명:** 활성화된 폼 요소를 선택합니다.

**사용 상황:** 사용 가능한 입력 필드를 구분할 때 사용합니다.

**예시 코드:**

```css
/* 활성화된 라디오 버튼의 다음 형제 label */
input[type=radio]:enabled + label {
  text-decoration: underline;
}

```

### 2.3.3 `:disabled`

**설명:** 비활성화된 폼 요소를 선택합니다.

**사용 상황:** 사용 불가능한 입력 필드를 시각적으로 구분할 때 사용합니다.

**예시 코드:**

```css
/* 비활성화된 라디오 버튼의 다음 형제 label */
input[type=radio]:disabled + label {
  color: lightgray;
  text-decoration: line-through;
}

```

### 2.3.4 `:required`

**설명:** required 속성을 가진 필수 입력 요소를 선택합니다.

**사용 상황:** 필수 입력 필드를 시각적으로 강조할 때 사용합니다.

**예시 코드:**

```css
/* 필수 입력 요소 */
input:required {
  border-color: orangered;
}

```

### 2.3.5 `:valid` / `:not(:valid)`

**설명:** 입력값이 유효한/무효한 요소를 선택합니다.

**사용 상황:** 실시간 폼 유효성 검사 피드백을 제공할 때 사용합니다.

**예시 코드:**

```css
/* 값이 유효한 이메일 입력 요소 */
input[type="email"]:valid {
  border-color: green;
}

/* 값이 무효한 이메일 입력 요소 */
input[type="email"]:not(:valid) {
  border-color: purple;
}

```

### 2.4 구조적 가상 클래스

### 2.4.1 `:first-of-type`

**설명:** 부모 요소 내에서 해당 타입의 첫 번째 요소를 선택합니다.

**사용 상황:** 같은 타입의 여러 요소 중 첫 번째만 스타일링할 때 사용합니다.

**예시 코드:**

```css
/* 부모 내 첫 번째 b 요소 */
b:first-of-type {
  text-decoration: overline;
}

```

### 2.4.2 `:last-of-type`

**설명:** 부모 요소 내에서 해당 타입의 마지막 요소를 선택합니다.

**사용 상황:** 같은 타입의 여러 요소 중 마지막만 스타일링할 때 사용합니다.

**예시 코드:**

```css
/* 부모 내 마지막 i 요소 */
i:last-of-type {
  text-decoration: line-through;
}

```

### 2.4.3 `:nth-of-type(n)`

**설명:** 부모 요소 내에서 해당 타입의 n번째 요소를 선택합니다.

**사용 상황:** 특정 순서의 요소만 선택할 때 사용합니다.

**예시 코드:**

```css
/* 부모 내 2번째 b 요소 */
b:nth-of-type(2) {
  text-decoration: underline;
}

```

### 2.4.4 `:only-of-type`

**설명:** 부모 요소 내에서 해당 타입의 유일한 요소를 선택합니다.

**사용 상황:** 형제 요소가 없는 특정 타입의 요소를 선택할 때 사용합니다.

**예시 코드:**

```css
/* 부모 내 유일한 타입의 요소 */
div :only-of-type {
  text-decoration: overline line-through underline;
}

```

### 2.4.5 `:only-child`

**설명:** 부모 요소 내에서 유일한 자식 요소(타입 무관)를 선택합니다.

**사용 상황:** 형제 요소가 전혀 없는 독자 요소를 선택할 때 사용합니다.

**예시 코드:**

```css
/* 부모 내 종류 무관 유일한 요소 */
div :only-child {
  text-decoration: wavy underline tomato;
}

```

## 3. 가상 요소 (Pseudo-element)

### 3.1 가상 요소란?

실제 HTML에 존재하지 않지만 CSS로 생성하여 스타일링할 수 있는 요소입니다. 이중 콜론(`::`)을 사용하여 표기합니다.

### 3.2 가상 요소 종류

### 3.2.1 `::before`

**설명:** 요소의 콘텐츠 앞에 가상의 요소를 생성합니다.

**사용 상황:** 아이콘, 장식 요소, 번호 매기기 등을 추가할 때 사용합니다.

**예시 코드:**

```css
/* 리스트 아이템 앞에 체크 아이콘 추가 */
li::before {
  content: '';
  display: inline-block;
  margin: 0 0.4em;
  width: 0.8em;
  height: 0.8em;
  background-image: url(./check.png);
  background-size: contain;
}

```

**주의사항:** `content` 속성은 필수이며, 빈 문자열이라도 지정해야 합니다.

### 3.2.2 `::after`

**설명:** 요소의 콘텐츠 뒤에 가상의 요소를 생성합니다.

**사용 상황:** 배지, 라벨, 장식 요소 등을 추가할 때 사용합니다.

**예시 코드:**

```css
/* 특정 리스트 아이템 뒤에 "다음 강좌" 배지 추가 */
li.later::after {
  content: '다음 강좌';
  margin-left: 0.6em;
  padding: 0.16em 0.36em;
  font-size: 0.72em;
  font-weight: bold;
  color: white;
  background-color: darkmagenta;
  border-radius: 0.2em;
}

```

### 3.2.3 `::selection`

**설명:** 사용자가 드래그하여 선택한 텍스트 영역의 스타일을 지정합니다.

**사용 상황:** 텍스트 선택 시 브랜드 컬러를 적용하거나 가독성을 높일 때 사용합니다.

**예시 코드:**

```css
/* 오렌지 배경으로 선택 영역 스타일링 */
.orange::selection {
  background-color: orange;
}

/* 다크 테마로 선택 영역 스타일링 */
.dark::selection {
  color: lightgreen;
  background-color: #222;
}

```

### 3.2.4 `::placeholder`

**설명:** input이나 textarea의 placeholder 텍스트 스타일을 지정합니다.

**사용 상황:** placeholder의 색상, 폰트 등을 변경하여 디자인과 일치시킬 때 사용합니다.

**예시 코드:**

```css
/* 필수 입력 필드의 placeholder 강조 */
input:required::placeholder {
  color: darkred;
  background-color: yellow;
}

```

## 4. 상속 (Inheritance)

### 4.1 상속이란?

부모 요소의 특정 CSS 속성값이 자식 요소에게 자동으로 전달되는 메커니즘입니다.

### 4.2 상속되는 주요 속성들

**텍스트 관련:**

- `color` - 글자 색상
- `font` 관련 (font-family, font-size, font-weight 등)
- `letter-spacing` - 글자 간격
- `line-height` - 줄 높이
- `text-align` - 텍스트 정렬
- `text-decoration` - 텍스트 장식
- `text-shadow` - 텍스트 그림자
- `word-spacing` - 단어 간격

**기타:**

- `cursor` - 마우스 커서 모양
- `list-style` 관련
- `visibility` - 가시성

### 4.3 상속의 작동 방식

**예시 코드:**

```css
.blue { color: slateblue; }
.green { color: olivedrab; }
.red { color: orangered; }

```

**작동 원리:**

1. 속성값을 따로 지정하지 않은 자식은 부모의 속성값을 물려받습니다.
2. 상속되는 속성들의 값은 그 아래 후손들에게도 전달됩니다.
3. 자식 대에서 다른 속성값을 특정하면 부모의 것을 덮어씁니다.
4. 덮어쓴 값 역시 후손들에게 대물림됩니다.

## 5. CSS 속성 값 키워드

### 5.1 `inherit`

**설명:** 스스로의 값을 포기하고 부모로부터 받은 상속값을 강제로 적용합니다.

**사용 상황:** 일반적으로 상속되지 않는 속성을 부모로부터 상속받고 싶을 때, 또는 자신이 지정한 값을 취소하고 부모 값을 따르고 싶을 때 사용합니다.

**예시 코드:**

```css
.parent {
  font-weight: bold;
  color: slateblue;
}
.parent > div {
  color: olivedrab;
}
/* 마지막 자식은 부모의 color 값을 상속받음 */
.parent > :last-child {
  color: inherit;
}

```

### 5.2 `initial`

**설명:** 브라우저가 부여한 값을 포기하고 각 속성의 CSS 명세상 초기값을 적용합니다.

**사용 상황:** 브라우저 기본 스타일을 제거하고 속성의 초기값으로 되돌릴 때 사용합니다.

**예시 코드:**

```css
/* p 요소의 display를 초기값인 inline으로 변경 */
p:not(:first-child) {
  display: initial;
}

```

**주의사항:** 브라우저 기본값과 CSS 명세상 초기값은 다를 수 있습니다. 예를 들어 `<p>` 요소의 `display` 속성은 브라우저가 `block`을 부여하지만, CSS 명세상 초기값은 `inline`입니다.

### 5.3 `unset`

**설명:** 상속되는 속성이면 `inherit`처럼, 상속되지 않는 속성이면 `initial`처럼 작동합니다.

**사용 상황:** 속성이 상속되는지 아닌지 확실하지 않을 때, 또는 여러 속성을 한 번에 리셋할 때 사용합니다.

**예시 코드:**

```css
.parent { color: slateblue; }
.parent > div { color: olivedrab; }

/* color는 상속되는 속성이므로 inherit처럼 작동 */
.parent :last-child {
  color: unset;
}

/* display는 상속되지 않으므로 initial처럼 작동 */
p:not(:first-child) {
  display: unset;
}

```

### 5.4 `revert`

**설명:** `unset`과 유사하지만, 상속받지 않은 값을 초기값으로 되돌리지 않고 브라우저 기본값으로 되돌립니다.

**사용 상황:** 브라우저의 기본 스타일을 유지하면서 일부 스타일만 제거하고 싶을 때 사용합니다.

**예시 코드:**

```css
.parent { color: slateblue; }
.parent > div { color: olivedrab; }

/* color는 부모의 slateblue를 상속받음 */
.parent :last-child {
  color: revert;
}

/* display는 브라우저 기본값인 block 유지 */
p:not(:first-child) {
  display: revert;
}

```

### 5.5 `all` 속성

**설명:** 대부분의 CSS 속성을 한 번에 `inherit`, `initial`, `unset`, `revert` 값으로 지정할 수 있는 단축 속성입니다.

**사용 상황:** 브라우저 기본 스타일을 완전히 제거하고 처음부터 스타일링하고 싶을 때 사용합니다.

**예시 코드:**

```css
.parent { color: slateblue; }

/* 버튼의 모든 브라우저 기본 스타일 제거 */
button:not(:first-of-type) {
  all: unset;
}

/* 이후 원하는 스타일 추가 */
button:last-child {
  padding: 0.6em 1em;
  background-color: white;
  border: 2px solid #ddd;
  border-radius: 0.4em;
  cursor: pointer;
  box-shadow: 2px 2px 6px rgba(0, 0, 0, 0.16);
}

```

## 6. CSS Reset

### 6.1 CSS Reset이란?

브라우저마다 다른 기본 스타일을 제거하고 일관된 시작점을 제공하기 위한 CSS 코드입니다.

### 6.2 주요 CSS Reset 방식

### 6.2.1 Eric Meyer Reset (2.0)

**특징:** 모든 브라우저 기본 스타일을 완전히 제거하는 공격적인 리셋 방식입니다.

**사용 상황:** 모든 스타일을 처음부터 정의하고 싶을 때 사용합니다.

### 6.2.2 Normalize.css

**특징:** 브라우저 간 일관성을 유지하면서 유용한 기본값은 보존하는 방식입니다.

**사용 상황:** 브라우저 기본 스타일의 이점을 활용하면서 일관성을 원할 때 사용합니다.

### 6.2.3 Elad Shechter Reset

**특징:** 현대적인 웹 개발에 맞춰 업데이트된 리셋 방식입니다.

**사용 상황:** 최신 브라우저 환경에서 작업할 때 사용합니다.

## 7. 벤더 프리픽스 (Vendor Prefixes)

### 7.1 벤더 프리픽스란?

아직 표준화되지 않은 CSS 속성을 브라우저별로 실험적으로 구현할 때 사용하는 접두사입니다.

### 7.2 주요 벤더 프리픽스

| 접두사 | 브라우저 |
| --- | --- |
| `-webkit-` | 사파리, 크롬, 오페라 |
| `-moz-` | 파이어폭스 |
| `-ms-` | 엣지, 익스플로러 |
| `-o-` | 구버전 오페라 |

### 7.3 사용 방법

**예시 코드:**

```css
.element {
  -webkit-transition: all 4s ease;
     -moz-transition: all 4s ease;
      -ms-transition: all 4s ease;
       -o-transition: all 4s ease;
          transition: all 4s ease;
}

.element {
  background: -webkit-gradient(linear, left top, left bottom, from(white), to(black));
  background: -o-linear-gradient(top, white, black);
  background: linear-gradient(to bottom, white, black);
}

```

**중요 규칙:** 접두사가 붙지 않은 표준 속성은 맨 마지막 줄에 작성해야 합니다. 이렇게 하면 브라우저가 표준 속성을 지원할 경우 표준 속성이 적용됩니다.

### 7.4 자동화 도구

**Autoprefixer:** CSS 코드를 입력하면 필요한 벤더 프리픽스를 자동으로 추가해주는 온라인 툴입니다.

**입력 예시:**

```css
.element {
  width: 100vw;
  break-after: auto;
  tab-size: 4;
  writing-mode: horizontal-tb;
}

```

## 8. 웹 폰트 (Web Fonts)

### 8.1 font-family 속성

**설명:** 요소에 적용할 글꼴을 지정하는 속성입니다. 여러 폰트를 나열하여 우선순위를 지정할 수 있습니다.

**사용 상황:** 사용자 환경에 특정 폰트가 없을 경우를 대비하여 여러 대체 폰트를 지정합니다.

**예시 코드:**

```css
body {
  font-family: AppleSDGothicNeo-Regular, 'Malgun Gothic', '맑은 고딕', dotum, '돋움', sans-serif;
}

```

### 8.2 Sans-serif vs Serif

**Sans-serif (산세리프):**

- 글자 끝에 장식(세리프)이 없는 글꼴
- 깔끔하고 현대적인 느낌
- 웹에서 가독성이 좋음

**Serif (세리프):**

- 글자 끝에 장식이 있는 글꼴
- 전통적이고 격식있는 느낌
- 인쇄물에 적합

**Cursive (필기체):**

- 손글씨 스타일의 글꼴
- 장식적인 용도로 사용

### 8.3 CSS 폰트의 한계

1. 사용자의 컴퓨터에 설치된 폰트만 실제로 적용 가능
2. 맥과 윈도우 사용자 간 탑재 폰트 차이로 일관성 유지 어려움
3. 디자인 의도를 정확히 구현하기 어려움

### 8.4 웹 폰트

**설명:** 서버에 저장된 폰트 파일을 사용자의 브라우저로 전송하여 사용할 수 있게 하는 기술입니다.

**장점:**

- 모든 사용자에게 동일한 폰트 제공
- 디자인 일관성 유지
- 다양한 폰트 선택 가능

**주요 서비스:**

- 구글 폰트 (Google Fonts)
- 눈누 (상업용 무료 한글 폰트)

### 8.5 웹 폰트 적용 방식

### 8.5.1 방식 1: 외부 서버에서 직접 가져오기

**설명:** 구글 폰트 등의 서비스에서 제공하는 CDN 링크를 사용하여 폰트를 불러옵니다.

**사용 상황:** 빠르게 웹 폰트를 적용하고 싶을 때, 서버 용량을 절약하고 싶을 때 사용합니다.

**예시 코드:**

```html
<!-- HTML head에 추가 -->
<link href="https://fonts.googleapis.com/css2?family=Noto+Sans+KR&display=swap" rel="stylesheet">

```

```css
/* CSS에서 사용 */
body {
  font-family: 'Noto Sans KR', sans-serif;
}

```

### 8.5.2 방식 2: 자체 서버에 탑재하여 사용

**설명:** 폰트 파일을 직접 다운로드하여 프로젝트 내에 포함시키고 `@font-face`로 정의합니다.

**사용 상황:** 외부 서비스 의존성을 제거하고 싶을 때, 커스텀 폰트를 사용할 때 사용합니다.

**예시 코드:**

```css
/* 폰트 파일 정의 */
@font-face {
  font-family: 'Noto Sans KR';
  font-weight: 100;
  src: url('./fonts/NotoSansKR-Thin.woff2') format('woff2');
}

@font-face {
  font-family: 'Noto Sans KR';
  font-weight: 300;
  src: url('./fonts/NotoSansKR-Light.woff2') format('woff2');
}

@font-face {
  font-family: 'Noto Sans KR';
  font-weight: 400;
  src: url('./fonts/NotoSansKR-Regular.woff2') format('woff2');
}

/* 사용 */
body {
  font-family: 'Noto Sans KR', sans-serif;
}

```

**중요:** 굵기별로 `@font-face`를 정의하지 않으면, `font-weight`를 변경해도 브라우저가 인위적으로 굵기를 조절하여 품질이 떨어질 수 있습니다. 각 굵기에 맞는 폰트 파일을 별도로 정의하는 것이 좋습니다.

## 최종 핵심 요약

1. **특성 선택자**는 HTML 속성을 기준으로 요소를 선택합니다. `=`, `=`, `^=`, `$=` 등의 연산자로 정확한 값, 포함, 시작, 끝 문자를 매칭할 수 있습니다.
2. **가상 클래스**는 요소의 상태를 선택합니다. `:hover`, `:active`, `:focus` 등으로 상호작용 상태를, `:checked`, `:disabled`, `:valid` 등으로 폼 요소 상태를, `:first-of-type`, `:nth-of-type()` 등으로 구조적 위치를 선택합니다.
3. **가상 요소**는 `::before`, `::after`로 가상의 콘텐츠를 생성하거나, `::selection`, `::placeholder`로 특수한 상태를 스타일링합니다. `content` 속성은 필수입니다.
4. **상속**은 부모의 특정 CSS 속성(color, font 관련, text 관련 등)이 자식에게 자동 전달되는 메커니즘입니다.
5. **CSS 속성 값 키워드**: `inherit`(부모값 강제 상속), `initial`(CSS 명세 초기값), `unset`(상속 속성이면 inherit, 아니면 initial), `revert`(브라우저 기본값), `all` 속성으로 모든 속성을 한 번에 리셋 가능합니다.
6. **CSS Reset**은 브라우저 기본 스타일을 제거하여 일관성을 제공합니다. Eric Meyer Reset, Normalize.css, Elad Shechter 등의 방식이 있습니다.
7. **벤더 프리픽스**(`webkit-`, `moz-`, `ms-`, `o-`)는 표준화되지 않은 CSS 속성에 사용하며, 표준 속성은 마지막에 작성합니다. Autoprefixer로 자동화 가능합니다.
8. **웹 폰트**는 서버의 폰트를 사용자에게 전송하여 일관된 디자인을 제공합니다. 외부 CDN 방식과 `@font-face`로 자체 서버에 탑재하는 방식이 있으며, 굵기별 폰트 파일을 별도로 정의해야 품질이 유지됩니다.

### 퀴즈 5

다음 CSS 속성 값 키워드에 대한 설명으로 올바른 것은?

1. `initial`은 부모 요소의 값을 강제로 상속받는다
2. `inherit`은 CSS 명세상의 초기값으로 되돌린다
3. `unset`은 상속되는 속성이면 inherit처럼, 아니면 initial처럼 작동한다
4. `revert`는 항상 CSS 명세상의 초기값으로 되돌린다

정답: 3번

해설: `unset`은 해당 속성이 상속되는 속성인지 아닌지에 따라 다르게 작동합니다. 상속되는 속성(예: color)이면 `inherit`처럼 부모 값을 상속받고, 상속되지 않는 속성(예: display)이면 `initial`처럼 CSS 명세상 초기값으로 되돌립니다. `inherit`은 부모 값을 강제 상속, `initial`은 CSS 초기값, `revert`는 브라우저 기본값으로 되돌립니다.

3. 표준 속성과 벤더 프리픽스의 순서는 중요하지 않다
4. 벤더 프리픽스만 작성하고 표준 속성은 생략한다

### 퀴즈 7

웹 폰트를 자체 서버에 탑재할 때 `@font-face`를 굵기별로 정의해야 하는 이유는?

1. 파일 크기를 줄이기 위해
2. 브라우저 호환성을 높이기 위해
3. font-weight 변경 시 품질을 유지하기 위해
4. 폰트 로딩 속도를 빠르게 하기 위해

정답: 3번

해설: 굵기별로 `@font-face`를 정의하지 않으면, `font-weight`를 변경했을 때 브라우저가 하나의 폰트 파일을 인위적으로 굵게 만들어 표시하게 됩니다. 이는 폰트 디자이너가 의도한 굵기가 아니므로 품질이 떨어집니다. 각 굵기(100, 300, 400, 700 등)에 해당하는 폰트 파일을 별도로 정의하면, 각 굵기에 최적화된 폰트가 사용되어 높은 품질을 유지할 수 있습니다.

- [ ]  사용자 상호작용 가상 클래스(`:hover`, `:active`, `:focus`)를 구분하여 사용할 수 있다
- [ ]  `:focus`와 `:focus-visible`의 차이를 이해하고 접근성 개선에 활용할 수 있다
- [ ]  폼 요소 상태 가상 클래스(`:checked`, `:disabled`, `:valid` 등)를 활용할 수 있다
- [ ]  구조적 가상 클래스(`:first-of-type`, `:nth-of-type` 등)로 요소를 선택할 수 있다
- [ ]  `::before`와 `::after` 가상 요소를 사용하여 콘텐츠를 추가할 수 있다
- [ ]  `content` 속성이 가상 요소에서 필수임을 이해한다
- [ ]  `::selection`과 `::placeholder` 가상 요소를 활용할 수 있다
- [ ]  상속되는 CSS 속성과 상속되지 않는 속성을 구분할 수 있다
- [ ]  `inherit`, `initial`, `unset`, `revert`의 차이를 설명할 수 있다
- [ ]  `all` 속성으로 브라우저 기본 스타일을 리셋할 수 있다
- [ ]  CSS Reset의 필요성과 주요 방식들을 이해한다
- [ ]  벤더 프리픽스의 용도와 올바른 작성 순서를 안다
- [ ]  Autoprefixer와 같은 자동화 도구를 활용할 수 있다
- [ ]  Sans-serif, Serif, Cursive 폰트의 차이를 설명할 수 있다
- [ ]  웹 폰트의 두 가지 적용 방식을 이해하고 상황에 맞게 선택할 수 있다
- [ ]  `@font-face`로 웹 폰트를 정의하고 굵기별로 적용할 수 있다

## 연습문제

### 문제 1: 특성 선택자 활용하기

**문제:**
다음 요구사항을 만족하는 CSS를 작성하세요.

요구사항:

1. `href` 속성이 "https://google.com"인 링크는 파란색 텍스트와 굵은 글씨체
2. `type` 속성이 "email"인 input 요소는 2px 두께의 초록색 테두리
3. `class` 속성에 "btn"이 포함된 요소는 밑줄 추가
4. `class` 속성이 "icon-"으로 시작하는 요소는 빨간색 텍스트
5. `data-status` 속성이 "active"로 끝나는 요소는 노란색 배경

**기본 코드:**

```html
<!DOCTYPE html>
<html>
<head>
  <style>
    /* 여기에 CSS를 작성하세요 */
  </style>
</head>
<body>
  <a href="https://google.com">구글</a>
  <a href="https://naver.com">네이버</a>
  <input type="email" placeholder="이메일">
  <input type="text" placeholder="텍스트">
  <button class="btn-primary">버튼</button>
  <span class="icon-home">홈</span>
  <div data-status="is-active">활성화</div>
</body>
</html>

```

**정답:**

```css
/* 1. href가 정확히 "https://google.com"인 링크 */
a[href="https://google.com"] {
  color: blue;
  font-weight: bold;
}

/* 2. type이 "email"인 input */
input[type="email"] {
  border: 2px solid green;
}

/* 3. class에 "btn"이 포함된 요소 */
[class*="btn"] {
  text-decoration: underline;
}

/* 4. class가 "icon-"으로 시작하는 요소 */
[class^="icon-"] {
  color: red;
}

/* 5. data-status가 "active"로 끝나는 요소 */
[data-status$="active"] {
  background-color: yellow;
}

```

**해설:**

- `[attribute="value"]`는 정확한 값 매칭에 사용합니다.
- `[attribute*="value"]`는 속성값에 해당 문자열이 포함되어 있으면 선택합니다.
- `[attribute^="value"]`는 속성값이 해당 문자열로 시작하면 선택합니다.
- `[attribute$="value"]`는 속성값이 해당 문자열로 끝나면 선택합니다.
- 특성 선택자는 클래스나 ID 선택자로 처리하기 어려운 동적인 상황에 매우 유용합니다.

### 문제 2: 가상 클래스로 폼 스타일링하기

**문제:**
사용자 친화적인 폼을 만들기 위해 다음 요구사항을 만족하는 CSS를 작성하세요.

요구사항:

1. 모든 input에 포커스되면 파란색 아웃라인 표시
2. 필수 입력 필드(required)는 빨간색 테두리
3. 이메일 입력값이 유효하면 초록색 테두리, 무효하면 주황색 테두리
4. 체크된 체크박스의 다음 형제 label은 굵은 글씨와 파란색 텍스트
5. 비활성화된(disabled) input의 다음 형제 label은 회색에 취소선

**기본 코드:**

```html
<!DOCTYPE html>
<html>
<head>
  <style>
    input {
      display: block;
      margin: 10px 0;
      padding: 8px;
    }

    /* 여기에 CSS를 작성하세요 */
  </style>
</head>
<body>
  <input type="text" placeholder="이름" required>
  <input type="email" placeholder="이메일" required>
  <input type="text" placeholder="선택 입력">

  <input type="checkbox" id="agree">
  <label for="agree">동의합니다</label>

  <input type="checkbox" id="terms" disabled>
  <label for="terms">약관 (비활성)</label>
</body>
</html>

```

**정답:**

```css
input {
  display: block;
  margin: 10px 0;
  padding: 8px;
}

/* 1. 포커스된 input */
input:focus {
  outline: 2px solid blue;
}

/* 2. 필수 입력 필드 */
input:required {
  border: 2px solid red;
}

/* 3. 유효한 이메일 입력 */
input[type="email"]:valid {
  border: 2px solid green;
}

/* 4. 무효한 이메일 입력 */
input[type="email"]:not(:valid) {
  border: 2px solid orange;
}

/* 5. 체크된 체크박스의 다음 형제 label */
input[type="checkbox"]:checked + label {
  font-weight: bold;
  color: blue;
}

/* 6. 비활성화된 input의 다음 형제 label */
input:disabled + label {
  color: gray;
  text-decoration: line-through;
}

```

**해설:**

- `:focus`는 클릭이나 탭으로 요소가 선택된 상태를 나타냅니다.
- `:required`는 HTML의 required 속성을 가진 요소를 선택합니다.
- `:valid`와 `:not(:valid)`로 폼 유효성 상태에 따른 실시간 피드백을 제공할 수 있습니다.
- `:checked`는 체크박스나 라디오 버튼의 선택 상태를 감지합니다.
- `:disabled`는 비활성화된 폼 요소를 선택하며, 인접 형제 선택자(`+`)와 함께 사용하여 관련 label을 스타일링할 수 있습니다.
- 이러한 가상 클래스들은 JavaScript 없이도 사용자에게 즉각적인 시각적 피드백을 제공할 수 있습니다.

### 문제 3: 가상 요소로 UI 개선하기

**문제:**
가상 요소를 활용하여 리스트 아이템을 꾸며보세요.

요구사항:

1. 모든 li 요소 앞에 "✓" 문자를 추가 (초록색, 굵게)
2. `.premium` 클래스를 가진 li 요소 뒤에 "PREMIUM" 배지 추가 (흰색 텍스트, 금색 배경, 패딩 4px 8px, 둥근 모서리)
3. `.highlight` 클래스 텍스트 선택 시 노란색 배경에 검은색 텍스트

**기본 코드:**

```html
<!DOCTYPE html>
<html>
<head>
  <style>
    ul {
      list-style: none;
      padding: 0;
    }

    li {
      padding: 10px;
      margin: 5px 0;
      background-color: #f5f5f5;
    }

    /* 여기에 CSS를 작성하세요 */
  </style>
</head>
<body>
  <ul>
    <li>일반 항목 1</li>
    <li class="premium">프리미엄 항목</li>
    <li>일반 항목 2</li>
    <li class="premium highlight">프리미엄 하이라이트 항목</li>
  </ul>
</body>
</html>

```

**정답:**

```css
ul {
  list-style: none;
  padding: 0;
}

li {
  padding: 10px;
  margin: 5px 0;
  background-color: #f5f5f5;
}

/* 1. 모든 li 앞에 체크 마크 추가 */
li::before {
  content: '✓';
  color: green;
  font-weight: bold;
  margin-right: 8px;
}

/* 2. premium 클래스 li 뒤에 배지 추가 */
li.premium::after {
  content: 'PREMIUM';
  margin-left: 8px;
  padding: 4px 8px;
  color: white;
  background-color: gold;
  border-radius: 4px;
  font-size: 0.75em;
  font-weight: bold;
}

/* 3. highlight 클래스 텍스트 선택 시 스타일 */
.highlight::selection {
  background-color: yellow;
  color: black;
}

```

**해설:**

- `::before`와 `::after`는 가상의 요소를 생성하며 `content` 속성은 필수입니다.
- `content` 속성에는 텍스트, 문자, 심지어 빈 문자열('')도 올 수 있습니다.
- `::before`는 요소의 콘텐츠 앞에, `::after`는 뒤에 생성됩니다.
- 가상 요소는 실제 DOM에 존재하지 않으므로 JavaScript로 직접 접근할 수 없습니다.
- `::selection`은 사용자가 드래그하여 선택한 텍스트의 스타일을 변경합니다.
- 가상 요소를 활용하면 HTML 마크업을 추가하지 않고도 시각적 요소를 추가할 수 있어 코드가 깔끔해집니다.

### 문제 4: 상속과 리셋 키워드 활용하기

**문제:**
다양한 CSS 속성 값 키워드를 사용하여 스타일을 제어해보세요.

요구사항:

1. `.parent`는 파란색 텍스트, 굵은 글씨체
2. `.child-inherit`은 부모의 color를 강제로 상속받음
3. `.child-initial`의 font-weight를 CSS 초기값으로 리셋
4. `.child-unset`의 color와 font-weight를 unset으로 설정
5. 모든 button의 기본 스타일을 `all: unset`으로 제거하고 커스텀 스타일 적용

**기본 코드:**

```html
<!DOCTYPE html>
<html>
<head>
  <style>
    /* 여기에 CSS를 작성하세요 */
  </style>
</head>
<body>
  <div class="parent">
    부모 요소
    <div class="child-inherit" style="color: red;">
      inherit 테스트
    </div>
    <div class="child-initial">
      initial 테스트
    </div>
    <div class="child-unset">
      unset 테스트
    </div>
  </div>

  <button>기본 버튼</button>
  <button class="custom">커스텀 버튼</button>
</body>
</html>

```

**정답:**

```css
/* 1. 부모 요소 스타일 */
.parent {
  color: blue;
  font-weight: bold;
}

/* 2. 부모의 color를 강제로 상속 */
.child-inherit {
  color: inherit;
}

/* 3. font-weight를 CSS 초기값으로 리셋 */
.child-initial {
  font-weight: initial;
}

/* 4. color와 font-weight를 unset */
.child-unset {
  color: unset;
  font-weight: unset;
}

/* 5. 모든 button의 기본 스타일 제거 */
button {
  all: unset;
}

/* 커스텀 버튼 스타일 */
button.custom {
  padding: 10px 20px;
  background-color: blue;
  color: white;
  border-radius: 5px;
  cursor: pointer;
}

button.custom:hover {
  background-color: darkblue;
}

```

**해설:**

- `inherit`: 자신이 지정한 값(인라인 스타일 포함)을 포기하고 부모로부터 값을 강제로 상속받습니다. `.child-inherit`은 인라인으로 `color: red`가 지정되어 있지만, `inherit`으로 부모의 파란색을 상속받습니다.
- `initial`: CSS 명세상의 초기값으로 되돌립니다. `font-weight`의 초기값은 `normal`입니다.
- `unset`: 해당 속성이 상속되는 속성이면 `inherit`처럼, 상속되지 않으면 `initial`처럼 작동합니다. `color`는 상속되므로 부모의 파란색을 받고, `font-weight`도 상속되므로 부모의 bold를 받습니다.
- `all: unset`: 거의 모든 CSS 속성을 한 번에 리셋할 수 있어, 브라우저 기본 스타일을 완전히 제거하고 처음부터 스타일링할 때 유용합니다.
- 이러한 키워드들은 CSS를 더욱 유연하고 예측 가능하게 만들어줍니다.

### 문제 5: 웹 폰트 적용하기

**문제:**
자체 서버에 웹 폰트를 탑재하여 사용하는 방식으로 CSS를 작성하세요.

요구사항:

1. 'CustomFont'라는 이름으로 폰트 정의
2. 세 가지 굵기 지원: 300(Light), 400(Regular), 700(Bold)
3. 각 굵기에 해당하는 woff2 파일 경로:
    - Light: './fonts/CustomFont-Light.woff2'
    - Regular: './fonts/CustomFont-Regular.woff2'
    - Bold: './fonts/CustomFont-Bold.woff2'
4. body에 CustomFont 적용 (대체 폰트: sans-serif)
5. .light 클래스는 font-weight 300
6. .bold 클래스는 font-weight 700

**기본 코드:**

```html
<!DOCTYPE html>
<html>
<head>
  <style>
    /* 여기에 @font-face와 CSS를 작성하세요 */
  </style>
</head>
<body>
  <p>일반 텍스트 (Regular - 400)</p>
  <p class="light">얇은 텍스트 (Light - 300)</p>
  <p class="bold">굵은 텍스트 (Bold - 700)</p>
</body>
</html>

```

**정답:**

```css
/* 1, 2, 3. 폰트 정의 - 굵기별로 분리 */
@font-face {
  font-family: 'CustomFont';
  font-weight: 300;
  src: url('./fonts/CustomFont-Light.woff2') format('woff2');
}

@font-face {
  font-family: 'CustomFont';
  font-weight: 400;
  src: url('./fonts/CustomFont-Regular.woff2') format('woff2');
}

@font-face {
  font-family: 'CustomFont';
  font-weight: 700;
  src: url('./fonts/CustomFont-Bold.woff2') format('woff2');
}

/* 4. body에 폰트 적용 */
body {
  font-family: 'CustomFont', sans-serif;
}

/* 5. light 클래스 */
.light {
  font-weight: 300;
}

/* 6. bold 클래스 */
.bold {
  font-weight: 700;
}

```

**해설:**

- `@font-face`는 웹 폰트를 정의하는 규칙입니다.
- `font-family` 속성은 폰트의 이름을 정의하며, 나중에 이 이름으로 폰트를 참조합니다.
- `font-weight` 속성으로 각 폰트 파일이 어떤 굵기에 해당하는지 명시합니다.
- `src` 속성은 폰트 파일의 경로와 형식을 지정합니다. `format('woff2')`는 브라우저에게 파일 형식을 알려줍니다.
- 굵기별로 `@font-face`를 분리하지 않으면, 브라우저가 하나의 폰트 파일을 인위적으로 굵게 만들어 품질이 떨어집니다.
- 각 굵기에 최적화된 폰트 파일을 사용하면 디자이너가 의도한 형태대로 정확하게 표현됩니다.
- 대체 폰트(sans-serif)를 지정하면 CustomFont 로딩에 실패하더라도 기본 폰트가 표시됩니다.
