## 1. CSS 고급 속성

### 1-1. clip과 clip-path 속성

#### 📌 개념 및 정의

**clip 속성**은 요소의 어느 부분이 시각적으로 보이도록 할지를 지정하는 CSS 속성입니다. 그러나 현재는 deprecated(더 이상 권장되지 않음) 상태이므로, 대신 **clip-path** 속성 사용을 권장합니다.

#### 🔍 주요 차이점

| 속성      | position 요구사항        | 상태       | 권장 여부 |
| --------- | ------------------------ | ---------- | --------- |
| clip      | absolute 또는 fixed 필수 | deprecated | ❌        |
| clip-path | 제약 없음                | 표준       | ✅        |

#### 💡 사용 상황

**clip 속성의 전통적 사용**

- 웹 접근성을 위한 스크린 리더 전용 텍스트 숨김 (.sr-only)
- 시각적으로는 숨기되, 스크린 리더에서는 읽을 수 있도록 처리

**clip-path 속성의 현대적 사용**

- 요소를 다양한 모양으로 자르기
- 디자인적 요소로 활용
- position 값에 관계없이 자유롭게 사용 가능

#### 📝 예시 코드

**웹 접근성을 위한 clip 사용 (레거시)**

```css
.sr-only {
  position: absolute;
  width: 1px;
  height: 1px;
  padding: 0;
  margin: -1px;
  overflow: hidden;
  clip: rect(0, 0, 0, 0);
  white-space: nowrap;
  border-width: 0;
}
```

**clip-path를 이용한 원형 자르기**

```css
.circle-clip {
  clip-path: circle(50%);
}
```

**clip-path를 이용한 다각형 자르기**

```css
.polygon-clip {
  clip-path: polygon(50% 0%, 100% 50%, 50% 100%, 0% 50%);
}
```

### 1-2. scroll-snap 관련 속성

#### 📌 개념 및 정의

**scroll-snap**은 스크롤할 때 특정 위치에 자동으로 정렬(스냅)되도록 하는 CSS 속성입니다. 슬라이더나 갤러리 등에서 사용자 경험을 향상시킵니다.

#### 🔍 구성 요소

**부모 요소: scroll-snap-type**

- 스크롤 스냅의 방향과 방식을 설정
- 구문: `scroll-snap-type: [방향] [방식];`

**방향 옵션:**

- `none`: 스냅 비활성화
- `x`: 가로 방향 스냅
- `y`: 세로 방향 스냅
- `both`: 양방향 스냅

**방식 옵션:**

- `proximity`: 스냅 위치에 가까울 때만 스냅
- `mandatory`: 항상 가장 가까운 스냅 위치로 강제 이동

**자식 요소: scroll-snap-align**

- 스크롤 스냅될 기준선 지정
- 옵션: `none`, `start`, `end`, `center`

#### 💡 사용 상황

- 이미지 갤러리 구현
- 카드형 슬라이더
- 풀페이지 스크롤 사이트
- 모바일 터치 인터페이스

#### 📝 예시 코드

**가로 스크롤 갤러리**

```css
/* 부모 요소 */
.gallery-container {
  display: flex;
  overflow-x: scroll;
  scroll-snap-type: x mandatory;
}

/* 자식 요소 */
.gallery-item {
  flex: 0 0 100%;
  scroll-snap-align: start;
}
```

**세로 풀페이지 스크롤**

```css
/* 부모 요소 */
.fullpage-container {
  height: 100vh;
  overflow-y: scroll;
  scroll-snap-type: y mandatory;
}

/* 자식 요소 */
.section {
  height: 100vh;
  scroll-snap-align: start;
}
```

### 1-3. aspect-ratio 속성

#### 📌 개념 및 정의

**aspect-ratio** 속성은 박스 요소의 가로 세로 비율을 지정하는 CSS 속성입니다. 반응형 디자인에서 요소의 비율을 유지하면서 크기를 조절할 때 유용합니다.

#### 🔍 특징

- width나 height 중 하나만 지정해도 비율에 맞춰 다른 값이 자동 계산됨
- 이미지나 비디오의 비율 유지에 효과적
- 기존의 padding-top 해킹을 대체하는 표준 방식

#### 💡 사용 상황

- 16:9 비디오 플레이어
- 정사각형 썸네일 이미지
- 반응형 카드 레이아웃
- 인스타그램 스타일 1:1 이미지

#### 📝 예시 코드

**16:9 비디오 컨테이너**

```css
.video-container {
  width: 100%;
  aspect-ratio: 16 / 9;
  background-color: black;
}
```

**정사각형 카드**

```css
.card {
  width: 300px;
  aspect-ratio: 1;
  background-color: lightblue;
}
```

**세로 형태의 포스터**

```css
.poster {
  width: 100%;
  aspect-ratio: 3 / 4;
}
```

### 1-4. backdrop-filter 속성

#### 📌 개념 및 정의

**backdrop-filter** 속성은 요소의 배경 영역에만 필터 효과를 적용하는 CSS 속성입니다. 요소 자체가 아닌, 요소 뒤에 있는 배경에 블러, 색상 변환 등의 효과를 줄 수 있습니다.

#### 🔍 특징

- 글래스모피즘(Glassmorphism) 디자인 구현에 필수
- `-webkit-` 벤더 프리픽스와 함께 사용 권장
- filter 속성과 동일한 함수 사용 가능

#### 💡 사용 상황

- 반투명 모달 배경
- 네비게이션 바의 블러 효과
- 글래스 디자인 카드
- 오버레이 효과

#### 📝 예시 코드

**블러 효과가 있는 모달**

```css
.modal-overlay {
  background-color: rgba(255, 255, 255, 0.3);
  backdrop-filter: blur(10px);
  -webkit-backdrop-filter: blur(10px);
}
```

**글래스모피즘 카드**

```css
.glass-card {
  background: rgba(255, 255, 255, 0.1);
  backdrop-filter: blur(20px) saturate(180%);
  -webkit-backdrop-filter: blur(20px) saturate(180%);
  border: 1px solid rgba(255, 255, 255, 0.2);
  border-radius: 12px;
}
```

**밝기 조절이 있는 오버레이**

```css
.dark-overlay {
  background-color: rgba(0, 0, 0, 0.5);
  backdrop-filter: brightness(0.7);
  -webkit-backdrop-filter: brightness(0.7);
}
```

## 2. 프론트엔드 프레임워크와 라이브러리

### 2-1. 프론트엔드 프레임워크

#### 📌 유명 프레임워크 소개

**주요 프레임워크:**

- **Bootstrap** : 가장 인기 있는 CSS 프레임워크
- **UIkit** : 모던하고 가벼운 프레임워크
- **Materialize** : 구글의 Material Design 기반
- **Bulma** : Flexbox 기반의 모던 프레임워크

#### 🔍 프레임워크 사용의 장단점

**장점 ✅**

- 디자인 과정 없이 빠른 프로토타이핑 가능
- 일관된 디자인 시스템 제공
- 반응형 그리드 시스템 기본 제공
- 크로스 브라우저 호환성 보장

**단점 ❌**

- 사이트 용량 증가 (불필요한 코드 포함)
- 커스터마이징 시 복잡해짐
- 프레임워크 의존성 증가
- 모든 사이트가 비슷해 보일 수 있음

#### 💡 사용이 적합한 경우

- 디자이너가 없는 프로젝트
- 빠른 MVP(Minimum Viable Product) 개발
- 중소형 프로젝트
- 관리자 페이지나 내부 도구

#### 📝 Bootstrap 예시 코드

**네비게이션 바**

```html
<nav class="navbar navbar-expand-lg navbar-light bg-light">
  <div class="container-fluid">
    <a class="navbar-brand" href="#">Navbar</a>
    <ul class="navbar-nav">
      <li class="nav-item">
        <a class="nav-link active" href="#">Active</a>
      </li>
      <li class="nav-item">
        <a class="nav-link" href="#">Link</a>
      </li>
    </ul>
  </div>
</nav>
```

**버튼 그룹**

```html
<div class="btn-group" role="group">
  <button type="button" class="btn btn-primary">Left</button>
  <button type="button" class="btn btn-primary">Middle</button>
  <button type="button" class="btn btn-primary">Right</button>
</div>
```

## 🎯 핵심 요약

### CSS 고급 속성

1. **clip vs clip-path**
   - clip은 deprecated, clip-path 사용 권장
   - clip-path는 position 제약 없이 자유롭게 사용 가능
   - 웹 접근성(.sr-only)과 디자인 요소로 활용
2. **scroll-snap**
   - 부모: `scroll-snap-type` (방향과 방식 설정)
   - 자식: `scroll-snap-align` (기준선 설정)
   - mandatory는 강제 스냅, proximity는 근접 시 스냅
3. **aspect-ratio**
   - 가로 세로 비율을 간단하게 지정
   - 반응형 디자인에서 비율 유지에 필수
   - padding-top 해킹의 표준 대체
4. **backdrop-filter**
   - 요소 뒤 배경에 필터 효과 적용
   - 글래스모피즘 디자인 구현의 핵심
   - `-webkit-` 프리픽스 필수

### 프론트엔드 도구

1. **프레임워크 (Bootstrap, UIkit 등)**
   - 빠른 개발 vs 무거운 용량
   - 중소형 프로젝트, 디자이너 부재 시 적합
2. **아이콘 라이브러리 (Font Awesome, Material Icons)**
   - 웹폰트 또는 SVG 방식
   - CDN으로 간편하게 사용

## 📝 복습 퀴즈

### 문제 1

clip과 clip-path 속성에 대한 설명으로 옳지 않은 것은?

A) clip 속성은 deprecated 상태이다
B) clip-path는 position 값에 상관없이 사용할 수 있다
C) clip 속성은 position이 absolute 또는 fixed일 때만 작동한다
D) clip 속성이 clip-path보다 더 최신 기술이다
E) .sr-only 클래스에서 clip 속성을 사용할 수 있다

**정답: D**
해설: clip 속성은 오래된 기술이며 deprecated 되었습니다. clip-path가 더 최신 기술이며, 현재 사용이 권장되는 표준 속성입니다.

### 문제 2

scroll-snap-type의 방식 중 항상 가장 가까운 스냅 위치로 강제 이동하는 옵션은?

A) none
B) proximity
C) mandatory
D) auto
E) strict

**정답: C**
해설: mandatory는 항상 가장 가까운 스냅 위치로 강제 이동합니다. proximity는 스냅 위치에 가까울 때만 스냅되는 방식입니다.

### 문제 3

다음 중 aspect-ratio 속성에 대한 설명으로 올바른 것은?

A) 오직 이미지 요소에만 사용할 수 있다
B) width와 height를 모두 지정해야만 작동한다
C) 가로 세로 비율을 유지하면서 크기를 조절할 수 있다
D) 오래된 속성으로 deprecated 상태이다
E) position이 absolute일 때만 작동한다

**정답: C**
해설: aspect-ratio는 박스 요소의 가로 세로 비율을 지정하는 속성입니다. width나 height 중 하나만 지정해도 비율에 맞춰 다른 값이 자동으로 계산됩니다.

### 문제 4

### 문제 1: 웹 접근성 텍스트 숨김 구현하기

스크린 리더에서는 읽을 수 있지만 화면에는 보이지 않는 텍스트를 만들어보세요.

**기본 코드:**

```html
<button class="icon-button">
  <span class="sr-only"><!-- 여기에 텍스트 추가 --></span>
  ❤️
</button>
```

```css
.sr-only {
  /* 여기에 CSS 작성 */
}
```

**정답:**

```html
<button class="icon-button">
  <span class="sr-only">좋아요 버튼</span>
  ❤️
</button>
```

```css
.sr-only {
  position: absolute;
  width: 1px;
  height: 1px;
  padding: 0;
  margin: -1px;
  overflow: hidden;
  clip: rect(0, 0, 0, 0);
  white-space: nowrap;
  border-width: 0;
}
```

**해설:** .sr-only 클래스는 시각적으로는 완전히 숨기되, DOM에는 존재하여 스크린 리더가 읽을 수 있도록 합니다. width와 height를 1px로 설정하고, clip으로 영역을 잘라내며, overflow: hidden으로 내용을 숨깁니다.

### 문제 2: 가로 스크롤 이미지 갤러리 만들기

카드가 화면에 딱 맞게 스냅되는 가로 스크롤 갤러리를 구현하세요.

**기본 코드:**

```html
<div class="gallery">
  <div class="card">Image 1</div>
  <div class="card">Image 2</div>
  <div class="card">Image 3</div>
  <div class="card">Image 4</div>
</div>
```

```css
.gallery {
  /* 여기에 CSS 작성 */
}

.card {
  /* 여기에 CSS 작성 */
}
```

**정답:**

```css
.gallery {
  display: flex;
  overflow-x: scroll;
  scroll-snap-type: x mandatory;
  gap: 10px;
}

.card {
  flex: 0 0 300px;
  height: 200px;
  scroll-snap-align: center;
  background-color: lightblue;
  display: flex;
  align-items: center;
  justify-content: center;
}
```

**해설:** 부모 요소(.gallery)에 `scroll-snap-type: x mandatory`를 설정하여 가로 방향 강제 스냅을 활성화합니다. 자식 요소(.card)에 `scroll-snap-align: center`를 설정하여 카드가 중앙에 정렬되도록 합니다.

### 문제 3: 16:9 반응형 비디오 컨테이너 만들기

화면 크기에 관계없이 16:9 비율을 유지하는 비디오 컨테이너를 만드세요.

**기본 코드:**

```html
<div class="video-wrapper">
  <div class="video-container">비디오 영역</div>
</div>
```

```css
.video-wrapper {
  width: 80%;
  margin: 0 auto;
}

.video-container {
  /* 여기에 CSS 작성 */
}
```

**정답:**

```css
.video-wrapper {
  width: 80%;
  margin: 0 auto;
}

.video-container {
  width: 100%;
  aspect-ratio: 16 / 9;
  background-color: #000;
  display: flex;
  align-items: center;
  justify-content: center;
  color: white;
}
```

**해설:** `aspect-ratio: 16 / 9`를 사용하면 width만 지정해도 자동으로 16:9 비율에 맞는 높이가 계산됩니다. 이는 기존의 padding-top 해킹보다 훨씬 직관적이고 간단합니다.

### 문제 4: 글래스모피즘 카드 디자인 구현하기

블러 효과가 있는 반투명 유리 느낌의 카드를 만드세요.

**기본 코드:**

```html
<div class="background">
  <div class="glass-card">
    <h2>Glass Card</h2>
    <p>This is a glassmorphism design</p>
  </div>
</div>
```

```css
.background {
  width: 100%;
  height: 400px;
  background: linear-gradient(135deg, #667eea 0%, #764ba2 100%);
  display: flex;
  align-items: center;
  justify-content: center;
}

.glass-card {
  /* 여기에 CSS 작성 */
}
```

**정답:**

```css
.background {
  width: 100%;
  height: 400px;
  background: linear-gradient(135deg, #667eea 0%, #764ba2 100%);
  display: flex;
  align-items: center;
  justify-content: center;
}

.glass-card {
  padding: 30px;
  background: rgba(255, 255, 255, 0.1);
  backdrop-filter: blur(10px);
  -webkit-backdrop-filter: blur(10px);
  border: 1px solid rgba(255, 255, 255, 0.2);
  border-radius: 15px;
  color: white;
}
```

**해설:** 글래스모피즘 효과는 반투명 배경(`rgba`)과 `backdrop-filter: blur()`의 조합으로 만들어집니다. 벤더 프리픽스 `-webkit-`을 함께 사용하여 브라우저 호환성을 높입니다. 얇은 테두리를 추가하면 더욱 세련된 효과를 낼 수 있습니다.

### 문제 5: Font Awesome 아이콘이 포함된 버튼 만들기

아이콘과 텍스트가 함께 있는 버튼을 만드세요.

**기본 코드:**

```html
<!-- CDN 추가 -->
<link
  rel="stylesheet"
  href="https://cdnjs.cloudflare.com/ajax/libs/font-awesome/6.0.0/css/all.min.css"
/>

<button class="icon-btn">
  <!-- 여기에 아이콘과 텍스트 추가 -->
</button>
```

```css
.icon-btn {
  /* 여기에 CSS 작성 */
}
```

**정답:**

```html
<link
  rel="stylesheet"
  href="https://cdnjs.cloudflare.com/ajax/libs/font-awesome/6.0.0/css/all.min.css"
/>

<button class="icon-btn">
  <i class="fas fa-download"></i>
  <span>다운로드</span>
</button>
```

```css
.icon-btn {
  padding: 10px 20px;
  background-color: #007bff;
  color: white;
  border: none;
  border-radius: 5px;
  cursor: pointer;
  display: flex;
  align-items: center;
  gap: 8px;
  font-size: 16px;
}

.icon-btn:hover {
  background-color: #0056b3;
}
```

**해설:** Font Awesome 아이콘은 `<i>` 태그와 클래스를 사용하여 삽입합니다. `fa-download`는 다운로드 아이콘을 의미합니다. flexbox를 사용하고 gap을 설정하면 아이콘과 텍스트 사이에 일정한 간격을 쉽게 만들 수 있습니다.
